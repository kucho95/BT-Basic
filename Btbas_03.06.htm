The Simple Branch (goto)
The simple branch is made by a goto statement. When this statement is encountered, the program goes immediately to the line label identified by the goto and continues program execution at that line. For example:
  goto Test_Resistors
This statement branches to the line labelled Test_Resistors and continues program execution there. The following example in Example 4-1 shows how a simple branch could be used in a program—in this case, to return to the beginning of a test after each board has been tested.
 
 
It is generally recommended practice to minimize the usage of the "goto" statement for program readability.
Example 4-1 Simple branch (goto)
  NEXT_TEST:                 !
                             ! program statements to test board
  print "Test finished: place next PC board on the fixture."
  wait for start             !  waits for operator to press START
  goto Next_Test
