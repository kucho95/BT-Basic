Logarithmic and Exponential Functions
• Argument — numeric
• Result — numeric
 
Table 3-6 Logarithmic & exponential functions 
Function
Description
Examples
lgt
The common logarithm returns the logarithm to the base 10 of the function’s positive, nonzero argument.
lgt(305.2) = 2.48458452928
lgt(.0049) = ‑2.30980391997
lgt(1) = 0
lgt(‑2) — error
log
The natural logarithm returns the logarithm to the base e of the function’s positive, nonzero argument.
log(8001) = 8.98732181285
log(.0026) = ‑5.95224383395
log(0) — error
exp
The exponential function returns the constant, e, raised to the power of the function’s argument—argument <= 709.78
exp(1) = 2.71828182846
exp(‑3) =.0497870683679
