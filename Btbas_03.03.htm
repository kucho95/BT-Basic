Branching
Branching enables you to selectively execute sets of program statements; that is, to skip statements, or to go to some other point in the program and continue execution there. A branch is unconditional if the program must branch; the branch is conditional if the program can determine whether or not to make the branch.
The statements presented in Table 4-2 control branching.
 
Table 4-2 Branching statements
Statement
Description
goto
causes an unconditional branch to the program line specified by a line label
if then
(simple‑if) conditionally executes or skips a statement on a single line
if then/end if
(simple‑if) conditionally executes or skips multiple statements
if then/else/end if
(structured‑if) conditionally executes or skips a group of one or more statements
on‑call
(computed call) based on the value of a variable, it selects, from a list of options, which subroutine to call
on‑goto
(computed branch) based on the value of a variable, it selects, from a list of line labels, which program line to branch to
off break
turns off a previous on break
off error
turns off a previous on error
on break
(error trapping) branches if the user generates a trappable break at any time during the program
on error
(error trapping) branches if a runtime error subsequently occurs and there is no error variable associated with the statement that caused the error
