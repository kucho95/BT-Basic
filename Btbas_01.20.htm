Substring Output
Outputting a substring involves reading the characters from the specified part of the parent string; this does not change the contents of the parent. Remember, if the length of the substring is not specified, the substring defaults to the start character and all characters which follow it in the parent string. Example 2-11 contains examples of output.
Example 2-11 Examples of output
  print "Board Test Development"[7;10]  ! prints   Test Devel
  print "Board Test Development"[7]
                                     ! prints   Test Development
  A$ = "Test"
  print (A$ & " Records")[4]         ! prints    t Records
  print A$ & " Records"[4]           ! prints    Testcords
                                     ! note that "[ ]" has higher
                                     ! priority than "&"
  Z$ = "ABCDEFGHIJ"
  print Z$[3;5]                      ! prints   CDEFG
  print Z$[4;1]                      ! prints   D
  print Z$[4]                        ! prints   DEFGHIJ
 
Example 2-12 contains an example of a parent variable with a dimensioned length greater than its current length. In this case, the substring can start at any character position in the parent variable from 1 to current length + 1. (The len function, used in the example, is a numeric function which returns the length of a specified string.)
Example 2-12 Example of a parent variable with a dimensioned length greater than its current length
  dim A$[30]                    ! dimensioned length is 30
  A$ = "ABCDEFGHIJKLM"          ! parent variable; current length
                                ! is 13
  print A$[6;5] , len(A$[6;5])  ! prints  GHIJ  5
  print len(A$[14;6])           ! prints  0  (a "null" string)
  print A$[15;3]                ! error — start is beyond current
                                ! length + 1
  print A$[11;25]               ! error — exceeds dimensioned
                                ! length of 30
