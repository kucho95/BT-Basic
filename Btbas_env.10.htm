File Manipulation Statements
File manipulation statements provide a link between the workspace and the file system. Except for the compile statement, these statements are used to store the contents of the workspace into files and to bring the contents of files back into the workspace. The statements operate only on source files. These statements are briefly described in Table 1-2; for complete descriptions, refer to the Syntax Reference.
Two sets of statements perform identical functions. They are:
• get, save, and re‑save
• load, store, and re‑store
Both sets are included in BT-Basic as a convenience to test developers from other systems, who may be used to either set. Feel free to use whichever you prefer, or mix them.
 
Table 1-2 File manipulation statements 
Term
Definition
compile
Used to compile object code from source files.
merge
Lets you merge all or part of one or more files into into the work area.
get, load
Clears the workspace and copies the contents of a disk file into it. The file is checked for correct syntax. The statement can be executed only from the workstation command line; it is not programmable. The file mode can be specified as well (e.g., load digital "digital/u11" sets the mode to digital and does a digital syntax check on the file "digital/u11" as it loads into the work area).
re‑save, re-store
Same as save or store, except writes to an existing file.
save, store
Creates a new file on the disk and stores the contents of the workspace in it. Records the current mode in the file.
