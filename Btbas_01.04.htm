String constant
A string constant is a series of zero or more printable characters enclosed in double quotation marks; you can use single quotation marks when typing a string.
A string can be printed or displayed, as prompts to the operator for example, or it can be assigned to (stored in) a string variable.
A string can have one line of up to 2048 characters, including all spaces. If required, the concatenation function (&) can be used to join shorter strings together.
The null string is a string of zero characters in length ("").
To include a double quotation mark in the body of a string, type two consecutive double quotation marks; this counts as only one character when the string is printed, or is assigned to a variable.
Strings are assigned to variables by means of the assignment operator (=). Once a typed string is assigned to a variable or printed, the enclosing quotation marks are no longer included.
The syntax of a string is:
  "<zero or more printable characters>"
Example 2-2 contains some examples of string constants, showing what they are and how they could be used.
Example 2-2 Examples of string constants
  "This is a string constant."
  "the next line contains a null string, it has zero length."
  ""
  "any $&#*675_%~!‑^Toto:]+XX{'Z printable characters are allowed"
  Name$ = "Peter"              ! assigns a string constant to a variable (Name$)
  print Name$                      ! prints:  Peter
  print  """Hello,"" David said."  ! prints:  "Hello," David said.
  print "Digital " & "Test"        ! concatenates (joins) the strings
                                   !   and prints Digital Test
