Structured‑if
The structured‑if is similar to the simple‑if except that more than one statement can be conditionally executed or skipped, as a group. In addition, the structured‑if has an optional keyword, else; this enables the structure to choose which of two groups of statements to execute.
Unlike the simple‑if, the structured‑if consists of more than one statement; it consists of a number of statements bounded by the if and end if statements. Like the simple‑if, the if is followed by an expression and the then keyword. The else keyword is optional; without the else the structure acts similarly to the simple‑if:
• If the expression is true, the statements following then are executed.
• If the expression is false, the statements following then are skipped, and program execution continues with the statement after the end if.
Example 4-7 contains an example of a structured-if without else.
Example 4-7 Example of a structured if statement
   dim Name$[30] | input Name$
   if Name$ = "Manager" then
      ! Test Results (to be printed only for a manager)
      print "Accumulated Test Results are:"
      print "   Boards Tested:  "; A;  "   Failures:  "; B
   end if
   ! program continues
 
Without else, the group of statements in the structured-if is either skipped or executed. With else, there are two groups of statements and one of the groups must be executed. The structured‑if uses the expression to choose which group to execute. The program then resumes after the end if.
• If the expression is true, the statements following then are executed and the statements following else are skipped.
• If the expression is false, the statements following then are skipped and the statements following else are executed.
Example 4-8 shows a structured‑if with else.
Example 4-8 Example of a structured if with else
   ! Instructions to Submariners wishing to disembark:
   input "Number of times sub has dived?", Dives
   input "Number of times sub has surfaced?", Surfaces
   if (Dives ‑ Surfaces) = 0 then
      print "O.K. to disembark."
   else
      print "Please do not open the hatch. Thank you."
   end if
 
If a goto branches execution out of the structure, then the branch occurs immediately and any remaining statements in the structure will not be executed. If a branch is made into the structure (that is, bypassing the if statement), then the structure will operate as though the if condition had caused the branch (for example, if the branch is to the statements following then, the statements following else will be skipped).
 
 
Branching into or out of the structure is very bad practice and should be minimized.
The structured‑if can contain other program structures (for example, a loop, or another structured‑if), but these nested structures must be arranged so that they do not interfere with each other's operation. Example 4-9 illustrates this.
This routine selects one of five strings to print based on the value in a variable (G). The routine consists of four, nested structured‑ifs. To help you to see which end if belongs to which if, we have indented the program lines so that the statements related to any one structure are all at the same indented level (for example, the first end if terminates the last if; and the last end if terminates the first if).
Only one of the strings will be printed when this routine is executed. For example, if String_3$ is printed (G = 3), then the program skips all lines from the next else down to the third end if.
Example 4-9  
if G > 3 then  |  print String_4$
else
   if G = 3 then  |  print String_3$
   else
      if G = 2 then  |  print String_2$
      else
         if G = 1 then  |  print String_1$
         else  |  print String_0$
         end if
      end if
   end if
end if
 
This particular example is trivial; however, the nesting technique can be used effectively to select between complex routines.
