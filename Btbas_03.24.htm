Formal Parameters and Passed Parameters
The statement which calls a subroutine can (optionally) give to that subroutine the data on which it is to operate; this is referred to as passing parameters. That capability enables the subroutine to be written in a general purpose way, so that each time the subroutine is called, it can perform the same operations on different sets of data. Up to 31 parameters can be passed to a subroutine.
Parameters can be passed only to a subroutine which has formal parameters. Formal parameters do not really exist—they are dummy names which are listed in the subroutine's sub statement. (The first example subroutine used earlier, Printer, has just one formal parameter, named Passed_value.) When the subroutine is called, the call statement lists the parameters which are to be passed. Each passed parameter is paired with a formal parameter, in the order the parameters appear in the lists, so the list of passed parameters must match the list of formal parameters. The two names in each pair can be the same or different, but each parameter in the call list must be the same type (numeric, string, @<name>, etc.) as its corresponding parameter in the sub list.
The subroutine operates on each passed parameter via the name of the formal parameter it was paired with. Any time a formal parameter is referenced, its corresponding passed parameter is accessed. If the subroutine makes any changes to the parameters, those changes remain in effect after the exit from the subroutine.
Example 4-15 shows a program which makes multiple calls to a subroutine and passes parameters to it. This program calculates the area of a ring by subtracting the area of the inner circle of the ring from the area of the outer circle of the ring. The subroutine can calculate the area of any single circle. The main program calls the subroutine twice: the first time to calculate the area of the outer circle, and the second time for the inner circle. Each time the subroutine is called, the program passes to it two variables—the first contains the radius of the ring whose area is to be calculated; and the second identifies the variable where the result is to be stored. The main program then completes the calculation by subtracting the smaller area from the larger.
Example 4-15 Example of calling a subroutine with parameters
MAIN :                     ! Calculates the area of any ring:
  input "What is the outer radius of the ring?" ,  Ro
  call Circle (Ro, Ao)            !  FIRST SUBROUTINE CALL
  input "What is the inner radius of the ring?" , Ri
  call Circle (Ri, Ai)            ! SECOND SUBROUTINE CALL
  Ring_area = Ao ‑ Ai             ! CALCULATE AREA OF RING
  print "The area of the ring is "; Ring_area
end        ! **END OF MAIN PROGRAM**
 
sub Circle (Radius, Area)         ! START OF SUBROUTINE (with
                                  ! formal parameters)
   Area = pi * Radius ^ 2         ! calculates area of circle
subend
 
The main program calls the subroutine by its name, Circle. The first time the subroutine is called, variables Ro and Ao are passed—that is, they are paired, in order, with the subroutine's formal parameters, Radius and Area. The subroutine then uses the value in Ro as its value for Radius, and it stores the result in Ao, which it knows as Area. Similarly, the second time the subroutine is called, it uses the value in Ri and stores the result in Ai. The main program then completes the calculation using the two calculated values stored by the subroutine in the main program's variables Ao and Ai.
