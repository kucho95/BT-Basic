Outputting Data in Free-Field Format
For output, free‑field format divides an 80-character line into four 20‑character fields. Each item in a list of data is then left‑justified within its field. After four items are output, an EOL (End Of Line) is sent and a new line is started.
A number is output with a leading space for the sign. If the number is negative, the minus sign is printed in that space. Leading zeros (after the sign space) are suppressed. The number (with the sign space) is left‑justified in its field, and the rest of the twenty spaces in that field remain blank. An output string is also left‑justified in its field, with any remaining spaces left blank.
   T = 53 | print "Boards Passed =", T
prints:
   Boards Passed =     53
   <‑‑‑‑‑20 spaces‑‑‑‑><‑‑‑‑‑20 spaces‑‑‑‑>
If a string, or a number, requires more than twenty characters, it takes as many fields (multiples of 20 characters) as it needs. See Example 5-7.
Example 5-7 Example of a string requiring more than twenty characters
   print "This string is much longer than 20 characters.", 46
prints:
   This string is much longer than 20 characters.              46
   <‑‑‑‑20 spaces‑‑---><‑‑‑‑20 spaces‑‑‑--><‑‑‑‑20 spaces‑‑---><--‑‑‑
   print 12345678.9765e‑18, 24
prints:
   .0000000000123456789765                 24
   <‑‑‑‑‑20 spaces‑‑‑‑><‑‑‑‑‑20 spaces‑‑‑‑><‑‑‑‑‑20 spaces‑‑‑‑><‑‑‑‑‑
 
The items to be output in the preceding example are separated from each other by a comma, referred to as a delimiter. If a semicolon follows a data item instead of a comma, that item is packed. When an item is packed, its field is shortened. If the item is a number, the field is just long enough to include the number and one trailing space. If the item is a string, the field is exactly the same length as that string. The next field then starts immediately after the shortened field (assuming there is sufficient room on that line). Commas and semicolons can both be used in the same list, if required.
In the example in Example 5-8, two fields are packed. The first field is shortened to fifteen spaces, and the second to only four.
Example 5-8 Example of 2 packed fields
   T = 53 \ print "Boards Passed ="; T; ‑10, 45
prints:
   Boards Passed = 53 ‑10                  45
   ‑‑‑15 spaces‑‑>‑4‑>‑‑‑‑‑‑21 spaces‑‑‑‑‑><‑‑‑‑20 spaces‑‑‑‑‑‑>
 
Notice that, after a packed field, the next regular field is not necessarily 20 characters long. It can be longer or shorter, depending on its contents and on where the preceding packed field ended. This is because (unless a tab function lengthens it) a regular field always ends in one of four specific columns, which are columns 20, 40, 60, and 80 (the left most column is #1).
The fields can also be moved by means of the tab function. In Example 5-9, the second field starts at column #25.
Example 5-9 Example of fields being moved by tab function
   T = 53 \ print "Boards Passed =", tab(25), T, ‑10
prints:
   Boards Passed =         53              ‑10
   <‑‑‑‑‑‑‑24 spaces‑‑‑‑‑‑><‑‑16 spaces‑‑‑><‑‑‑‑‑20 spaces‑‑‑‑>
 
If a tab function specifies a column that is in, or is to the left of, the previous field—that is, it tabs backwards—then the EOL occurs and the tab is made to the specified column on the next line as in Example 5-10.
Example 5-10 Example of backwards tab
   T = 53 \ print "Boards Passed =", T, tab(9), "Total =", 300
prints:
   Boards Passed =     53
   Total =             300
   ‑‑‑‑‑‑20 spaces‑‑‑‑>‑‑‑‑‑‑20 spaces‑‑‑‑>
   ‑‑8 sp‑>‑12 spaces‑>‑‑‑‑‑‑20 spaces‑‑‑‑>
 
The tab can also be used to add extra linefeeds by specifying a column number greater than 80. One linefeed will occur for every multiple of 80, and the remainder will then be the number of the column to which the tab is made.
The example in Example 5-11 prints three lines. The first string starts at column 20. The second string starts at column 25 after two linefeeds; i.e., 185/80 = 2, with a remainder of 25.
Example 5-11 Example of using the tab function to add extra linefeeds
   print tab(20), "The End", tab(185), "NEW SECTION"
prints:
   <‑‑‑‑19 spaces‑‑‑‑><‑‑‑‑‑‑21 spaces‑‑‑‑>
                      The End
                           NEW SECTION
   <‑‑‑‑‑‑‑24 spaces‑‑‑‑‑‑><‑‑‑16 spaces‑‑>
