Default Devices
The Simple I/O statements assume the default input, output, and report devices, so these statements do not specify a device. At login various devices are automatically designated as the defaults. All data input and output is sent to, or read from, these devices unless you specifically select some other device by executing the appropriate device/file statements or by specifying a different default.
At login the default input device is your keyboard, which you can change with the keyboard is statement. The default output device is the screen, which you can change with the printer is statement. The default report device is to have report output discarded (report is *) but you can change it with the report is statement. Once established as a default, a device remains the default until you change it, or until you log out of the system.
