Examples of Substring Input and Output
Example 2-19 shows more substring output examples.
Example 2-19 Examples of substring input and output
  dim P$[25]            ! dimensioned length = 25
  P$ = "ABCDEFGHIJ"     ! parent variable
  print len(P$)         ! prints  10  (current length)
  P$[6;3] = "fgh"
  print P$, len(P$)     ! prints  ABCDEfghIJ  10
  P$[9;4] = "ijKL"      ! lengthens parent to 12
  print P$, len(P$)     ! prints  ABCDEfghijKL  12
  P$[13;4] = "MNOP"     ! lengthens parent to 16
  print P$, len(P$)     ! prints  ABCDEfghilKLMNOP  16
  P$[6] = "XYZ"         ! shortens parent to 8
  print P$, len(P$)     ! prints  ABCDEXYZ  8
  Test$[ 2*R ; Chars ]  ! parameters are expressions
  Q$[S] = Char$         ! assigns string variable to substring
 
Example 2-20 shows one way of constructing a string from strings of variable length, using a substring and the len function.
Example 2-20 Constructing a string using a substring and the len function
  L1$ = "Analog"
  L2$ = "Test Program"
  L3$ = "Digital"
  L3$[ len(L3$) + 1 ;  len(L2$) + 1 ]  = " " & L2$
 
  print L3$                       ! prints   Digital Test Program
  print len(L3$)                  ! prints   20
! Another (and less confusing) way to do this is shown below:
L3$ = L3$ & " " & L2$
