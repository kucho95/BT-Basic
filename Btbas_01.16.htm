Identifying Array Elements
An array element is identified by combining the array id with the element's position in each dimension in that array. For example, in the array shown earlier [dim Scores(1:5,1:20)],
  Scores(5,16)
is the 5th element in the first dimension, and the 16th element in the second dimension. The positions must be specified in the same order as the dimensions were specified in the dim statement.
In this book, we describe arrays as consisting of rows and columns: some programmers prefer to think of arrays as consisting of columns and rows. But it really does not matter which way you think of the array as long as you remember the order in which the dimensions were specified in the dim statement.
If you think of the example array Scores as having five rows and twenty columns, then, to you, Scores(3,9) identifies the 9th element in row 3. Or, if you think of the array as having 5 columns and twenty rows, then Scores(3,9) identifies the 3rd element in row 9. But it does not matter how you think of it, because Scores(3,9) is the same element in both cases—what counts is the order in which the dimensions were specified in the dim statement.
An element in a string array is identified the same way as an element in a numeric array (the length of the string is not included). For example:
  dim Q$(10, 100, 40)[128]
  print Q$(6,78,36)   ! prints the
                      ! string in one
                      ! element of
                      ! the array
 
 
 
No matrix math commands are intrinsic in BT-Basic, so the user can establish any array dimension convention as long as it is used consistently within the BT-Basic program.
