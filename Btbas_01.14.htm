Dimensioning an Array
Each array must be dimensioned before any of its elements can be accessed. The dim (dimension) statement is used to reserve space in the workspace for arrays and to initialize their elements; numeric elements are initially set to zero, and string elements to the null string (""). Once an array (or simple variable) is dimensioned, it cannot again be dimensioned until the system workspace is cleared, or until a program is run, or if it is local to a subroutine the array is dimensioned each time the subroutine is called.
An array can have up to, and including, six dimensions; each dimension can have up to, and including, 32767 elements. However, the maximum number of elements an array can have is 131072 (i.e., 2^17, or approximately 4 times 32767).
The elements in each dimension are numbered consecutively, in ascending order; an element number can be in the range ‑32767, 0, 32767. When an array is dimensioned, the lower and upper bounds of each dimension are established. The lower bound is the lowest numbered element in that dimension, and the upper bound is the highest numbered element. For example, dim Scores(1:5,1:20) dimensions a 5 by 20 rectangular array; that is, the array has 100 elements. In each dimension, the lower bound is 1; the upper bounds are 5 and 20 respectively. The 9th element in row 3 is identified as Scores(3,9).
If the lower bound is not specified in the dim statement, it defaults to zero:
   dim Long_Box(5, 20)
This statement also dimensions a rectangular array—but in this case a 6 by 21 array, because both lower bounds default to zero. This array has 126 elements. The same array could have been dimensioned as:
   dim Long_Box(0:5,0:20)
All elements in a string array have the same dimensioned (maximum) length. The length is established by the dim statement. For example:
   dim Tasks$(1:10,1:10)[45]
dimensions an array with 100 strings, each of which can contain from zero to 45 characters. If the string length is not specified, it defaults to 80 characters for each element. Strings cannot be dimensioned longer than 2048 characters.
Example 2-8 shows examples of statements to dimension different sizes of arrays.
Example 2-8 Examples of statements to dimension arrays
  dim W(1:10 , 10)         ! a 10 by 11 numeric array named "W";
                           ! 2nd dimension is the same as 0:10
                           ! (i.e., it has 11 elements)
  dim Q$(9,9,9)[128]       ! a 10 by 10 by 10 string array, each
                           ! string has a dimensioned length of
                           ! 128 characters. The array contains
                           ! 1000 elements (strings).
  dim Neg(‑99:‑30,‑20:40)  ! a 70 by 61 numeric array
