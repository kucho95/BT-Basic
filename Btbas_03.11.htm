Error functions
Two numeric functions and two string functions can be used in conjunction with the error trapping routines. These functions allow the program to make decisions based on the different types of errors which could occur.
 
Table 4-3 Error functions
Function
Description
errl
Program line number at which the most recent runtime error occurred
errn
Error number of the most recent runtime error
errm$
String containing the error message for the most recent runtime error, or, if requested, for a specific error number. errm$ returns the short version of the error message.
errmlong$
Same as errm$, except returns the long version of the error message
As an example, you could use the following statement at the end of a test routine to determine if an error had occurred and, if so, what the most recent error was.
Example 4-5 Example of testing for errors
if errn <> 0 then print "Error# "; errn ; "--" ; errm$
