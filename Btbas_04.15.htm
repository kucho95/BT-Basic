Reference Description: Free-Field INPUT
The rules for inputting data in free-field format are:
• Each input item must match the input variable (numeric or string to which it is to be assigned)
• Delimiters between numerical items (numbers):
• Delimiter can be a comma, a space or a Return (EOL or EOR). Extra spaces before or after a delimiter are ignored.
• A null input can be made to a numeric variable—i.e., the variable retains its current value—by omitting a number and inputting just a comma (with or without extra spaces).
• Delimiters between strings:
• Return (EOL or EOR)—the input variable is then the same length as the string assigned to it, except that the dimensioned length of the variable cannot be exceeded.
• If an input string is longer than the variable to which it is assigned, the extra characters are assigned to the next variable, if there is one.
• When inputting both strings and numbers the same general rules apply but note the following:
• If a string precedes a number and is on the same line (in the same record), then the string must be the same length as the dimensioned length of the string variable to which it will be assigned. There is no other way to terminate the string in this case.
• The string described above can be optionally followed by a comma (as a delimiter), but this comma will have no effect. That is, it does not by itself constitute a null input to the next numeric variable. It requires a second comma to make a null input.
• Terminating the input:
• When all input variables are satisfied, if there is no EOR at that time, the input is read and discarded up to the next EOR. The input then terminates.
• If a blank line (a null record) is read, the input terminates and any remaining input variables retain their current values.
• The input can cross record boundaries, but an individual item cannot.
• If an enter statement has no input variables, then one record is read and discarded. An input statement must have at least input variable. In all other respects, input, in response to two statements, is the same.
