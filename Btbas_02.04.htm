Relational Operators
These operators compare two expressions and return a value of 1 if the relationship is true, or a value of zero if it is false. Numeric expressions are compared for value; string expressions are compared, character by character, according to the ASCII numerical equivalent of each character. These operators are described in Table 3-2.
• Operands — both numeric or both string
• Result — numeric (1 or 0)
• Priority — 4

BT-Basic may not handle numeric equality the way you may expect. This is due to how the system stores numeric values in memory. It is better to do an inequality test (less than or greater than).
For example, change "if X = 1.1 then" to "if X > 1.05 then".
