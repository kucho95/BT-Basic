Variables
A variable is an element which can be changed. Variables can be numeric or string; both types can be simple or array.
A simple numeric variable can contain a number; for example:
  A = 12
  print A   ! prints  12
A simple string variable can contain a string; for example:
  Machine$ = "Bulldozer"
  print Machine$    ! prints  Bulldozer
Values are assigned to numeric variables, and strings are assigned to string variables, by the assignment operator (=), as in the preceding examples.
A variable identifier (I.D.) is used to name a variable. Here are some general rules for variable names:
• The I.D. of a numeric variable consists of a label. For example, “A” is a numeric variable I.D.
• The I.D. of a string variable is a label with a dollar‑sign ($) appended. For example, “Tmp$” is a string variable I.D.
• The first character of the variable I.D. must be a capital letter.
• Each label used to name a variable or an array (numeric or string) must be unique; for example, Test and Test$ cannot both exist at the same time.
• Variable names are NOT case sensitive (except for the first character as described above). For example, numeric variable names “TeMp”, “Temp”, and “TemP” all refer to the same numeric variable.
Initialization and Assignment
A variable does not exist until it is initialized. A simple variable is initialized when it is first referenced; if no value is assigned to it at that time, a numeric variable is initialized to zero, and a string variable to the null string (""). An array must be initialized by a dim statement.
When a variable or an array is initialized, space is reserved for it in the system workspace; that variable or array cannot then be initialized again, nor can the space be reallocated, until the workspace has subsequently been cleared, by the scratch statement, for example. When a program run terminates, any variables generated by that program retain the last values assigned to them. When the workspace is cleared, or when a new program‑run starts, all variables in the workspace cease to exist; the space occupied by those variables is released for general use.
Example 2-5 shows examples of variable identification and assignment:
Example 2-5 Examples of variable identification and assignment
   Real_Variable      ! numeric variable id
   REAL_VARiable      ! same id as above
   Name$              ! string variable id
   A = 6              ! assigns value of 6 to numeric variable, A
   Title$ = "Test1"   ! assigns string to string variable, Title$
   print Value        ! prints  0 — no value was assigned
