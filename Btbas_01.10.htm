Numeric Variable
A numeric variable contains a number. A variable is given a value, or its current value is changed, when a constant, a variable, or the result of a computation is assigned to it. Assignment is made by the assignment operator (=). When a variable is first initialized, it has a value of zero unless some other value is assigned at that time.
The identifier for a numeric variable is a label. Example 2-6 contains some examples of variable use.
Example 2-6 Examples of variable use
  A                    ! simple variable named "A"
  Final_total          ! simple variable named "Final_total"
  B = 48.2e12          ! assigns a value to B
  Freq = 32k           ! assigns a value to Freq
  Omega = 2*pi*Freq    ! assigns a value (of the expression)
                       ! to Omega
  A=‑2 | B=3 | B=A*B   ! B equals ‑6
