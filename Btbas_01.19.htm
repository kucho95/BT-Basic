Substring Identifiers
The identifier (I.D.) of a substring consists of a string expression, which identifies the parent, followed by information specifying the starting position and length of the substring. The syntax of a substring reference (I.D.) is:
  <string expression>[<start>]
  <string expression>[<start> ; <length>]
 
  ! <start> and <length> are <numeric
  expressions>
The <string expression> is the parent string. The substring within that string is then specified by the <start> and <length> parameters.
If the substring is to be printed or output to a file, then the <string expression> can be any type of string—a constant, a variable, an expression, etc. However, if characters are to be assigned to the substring, then <string expression> must be a variable I.D.
If the parent string is a variable, it can be a simple variable or an array element. If it is an array element, the id must include the location of the element within the array.
Example 2-10 specifies a substring, which starts at character‑7 and contains 6 characters from the variable (element) in position 3‑8‑5 in a 3‑dimensional string array, Scores$.
Example 2-10 Substring identifiers
  Scores$(3,8,5)[7;6]
 
The <start> and <length> parameters define the substring. <start> specifies the position in the parent string of the first character of the substring. <length> specifies the number of characters in the substring, starting with the <start> character.
The <start> value can be anything from one (1) to the maximum number of characters in the parent. If the parent is a variable, the maximum <start> value is the same as the current length. However, if the variable's dimensioned length is greater than its current length, then the maximum <start> value is one character more than the current length (that is, current length plus 1). Any characters beyond the current length contain the null string.
The <length> value can range from zero (0) up to the maximum possible length, which depends on the length of the parent and where the start character is located, as indicated below. An error occurs if the value specified is larger than the maximum possible.
• The maximum length of a substring is the length of the parent minus the number of characters preceding the <start> character (the length of parent minus <start> value plus 1).
• If the parent is a variable, then the maximum substring length is the dimensioned length of the variable minus the characters preceding the <start> character (the dimensioned length minus <start> value plus 1).
The <length> parameter is optional. If <length> is omitted, then it defaults to one of two values:
• Output: <length> defaults to the maximum possible length for the substring as described above, except that, if the parent is a variable the substring will not extend beyond the current length of that variable.
• Input: <length> defaults to the length of the string of characters to be input to the substring—an error occurs if the string to be input is longer than the maximum possible length for that substring.
