Global Parameters
Global parameters are variables and @<name>'s which exist in the main program but which can be accessed directly by the subroutine. These parameters must be declared global in each subroutine that is to use them; the global statement(s) must immediately follow the sub statement.
Array variables, and any simple variables which must be dimensioned, must be dimensioned in the main program before they can be declared global in a subroutine. However, simple numeric variables and simple string variables, can be declared in a global statement in a subroutine even if they do not exist in the main program. When that global statement is executed, those variables will then exist in the main program environment and will remain in existence after the exit from the subroutine.
Global parameters are most useful if the same variables, or @<name>'s, are to be used by several subroutines, and the subroutines are to be called many times from many different places in the program. Having the parameters named in the subroutines, saves you from having to name them in every call statement. Global parameters can also be used if you need to pass more than 31 parameters to a subroutine. Since a call cannot pass more than 31 parameters, you can arrange the subroutine so that the extra parameters are global.
Example 4-14 shows a subroutine using a global variable, A; B is a local variable.
Example 4-14 Subrouting which uses a global variable
   ! Main Program:
   A = 64  | call Half_Sqrt
   print  A; B           ! prints    4  0
     . . .
   end
 
   sub Half_Sqrt
   global A
      A = sqr(A)/2  |  B = sqr(64)/2
      print A; B         ! prints    4  4
   subend
 
The call statement executes the subroutine, Half_Sqrt. Since A is global, it can be accessed directly by the subroutine; after the exit, A retains its new value in the main program. Since variable B is local to the subroutine, the main program cannot access it; instead it initializes its own variable B, and assigns to it a value of zero.
