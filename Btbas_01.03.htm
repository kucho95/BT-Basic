Numeric Constant
A numeric constant is a number whose value is fixed, such as 5, or ‑34.67. Constants are output (displayed, printed, etc.) in either the standard or imaged format, described in Input/Output.
The description of numeric constants presented here applies mostly to input; that is, to describing the ways that you can type (enter) numbers at the workstation keyboard. This description also applies to input from devices. Output is described in Input/Output.
As a rule of thumb, you can type a number in almost any of the ways that people use to represent numbers on paper, and the system will accept it. Even if you do make a mistake, it is usually not a problem since an error message appears so that you can correct the error immediately. Because there are so many possible variations in the way a number can be typed, the syntax description of a constant makes entering numbers look harder than it really is. Therefore, unless you need the syntax described in Example 2-1 for a special purpose you can find what you need in the general description of a constant and in the examples.
Example 2-1 Syntax of numeric constants
  <value>
  <sign><value>
  <value><suffix>
  <sign><value><suffix>
      <sign> can be:   +
                       ‑
      < suffix> can be:  M (Mega‑ or 10^6)
                         k (kilo‑ or 10^3)
                         m (milli‑ or 10^‑3)

                         n (nano‑ or 10^‑9)

                   any number of leading zeros
 
Description of a Numeric Constant
A constant can have some number of significant digits, a radix point, a sign (+ or ‑), an exponent, and a suffix.
The number of (nonzero) significant digits is limited by the range of numbers that the system can process.
If too many digits are input, the system rounds the value but locates the decimal point correctly. The system outputs up to twelve significant digits.
The exponent consists of E (or e) followed by a sign and 1, or 2 significant digits. Exponents with 3 significant digits can be input if the image statement is used (refer to Input/Output).
The sign of either the number or the exponent must be included if the sign is negative. If a sign is positive, it inclusion is optional.
The (optional) suffix can be any one of the following characters, representing power‑of‑10 multipliers; Table 2-1 describes the standard symbols normally used to represent values in electronics.
