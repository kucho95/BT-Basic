File Structure
A file or device consists of one or more records which contain the data in that file. The length of a record depends on the amount of data in it. A record can contain between 0 and 2044 characters inclusive, with a space also counting as a character. A record which exists, but which has nothing in it, is referred to as a null record. An error occurs if an attempt is made to store more than 2044 characters in a record. If you attempt to input a record which is longer than 2044 characters, the extra input characters are truncated and not processed.
Data is written into a file or device by an output or print statement. During the write process, the current record ends when an EOL (End Of Line) sequence is sent. This causes an EOR (End Of Record) mark to be made in the record. Assuming there is more data, a new record is then started.
If the output operation uses free‑field formatting, the maximum possible record length is 80 characters.
However, the actual maximum record length depends on the maximum line‑length of the device to which the output data is to be sent. If the record to be sent is longer than the device can accept, then that record is automatically divided into two or more records of the proper length, so that the data is sent without loss. If imaged format is used, then records of up to 2044 characters can be transferred.
