Substrings
A substring is a part of a string. The substring consists of either a single character or a set of contiguous characters from within that string. The string of which a substring is a part, is referred to as the substring's parent. The parent string can be a string variable, the result of a string expression, or a string constant.
Here are some examples of substrings. In the first example, a substring is read from a variable, A$; the substring starts at character 9 and is 8 characters long:
  A$ = "This is a string variable"
  print A$[9;8]  ! prints:  a string
  print A$       ! prints:  This is a
                 !  string variable
Now a substring in the variable is changed:
  A$[11;6] = "normal"
  print A$    ! prints:  This is a normal
              !  variable
  A$[11] = "stop"
  print A$    ! prints:  This is a stop
This example uses the substring operator ([]) to read a substring from an expression:
B$ = "Test" | C$ = "Record"
print (B$ & " " & C$)[4;3] ! prints  t R
The characters in the parent string are numbered consecutively from left to right, with the first character being number 1. If the parent string is a variable, then the number of the last (right‑hand) character is the same as the current length of that variable, or, if the variables's dimensioned length is greater than its current length, then the number of the last character is the same as the dimensioned length.
Substrings enable you to specify a portion of a string without having to reference all of it. Using substrings, you can read (output) any part of a parent string, or, if the parent is a variable, you can change (input to) any part of it.
When a substring is output, characters are read from the part of the parent which is specified by the substring, as shown in the examples above. Reading a substring does not change the parent in any way. For example, after the first substring from A$ was printed (above), A$ still contained This is a string variable—that is until new characters were input to A$.
If the parent string is a variable, you can input characters to a substring within that variable. When you do this, the contents of the parent string variable are changed. The characters are copied into the parent string's character‑positions which are specified by the substring's id, as shown in the second of the preceding examples.
It is also possible to change (shorten or lengthen) the current length of the parent variable, provided that its dimensioned length is not exceeded.
