String Operators
These operators are used with strings. & concatenates (joins) strings, and [ ] defines a substring.
• Operands — string
• Result — string
• Priority — shown in third column (1 is lowest priority)

A$ = "ABC" & "XYZ"

A$ = "ABCDEFGHIJ"
 
print A$[3;5]
prints CDEFG
print A$[3]
prints CDEFGHIJ
print ("QRS" & "XYZ)[2;4]
