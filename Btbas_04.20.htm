Reference Description: Imaged INPUT & OUTPUT
The specifications used to format data are listed and described with the image statement, so they are not repeated here. Refer to the description of the image statement for complete details. The image specifications operate in exactly the same way, and the same rules apply, whether they appear in the I/O statement which references them, or in a separate image statement. The advantage of using an image statement is that more than one I/O statement can then reference the same set of specifications.
An image statement in a program is ignored until an I/O statement which references it is encountered. Then the I/O and the image statements are executed as a pair. However, an image statement is local to the environment in which it is located—an image in a subroutine cannot be referenced from the main program, for example. It is possible to generate a pseudo‑global image statement by storing the image specifications in a string variable and then passing that variable to a subroutine or specifying it as a global variable.
Example 5-21  
   Form$ = "dd.dd, 4a, x, 3d"  !
   call OUTPUT (Form$)   ! main program
     ...   !
 
   sub OUTPUT (A$)
        ...   ! subroutine
      print using A$; Q, R$, P
   subends
