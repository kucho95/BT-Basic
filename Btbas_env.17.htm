Redefining the Softkeys
The softkeys can be re-defined from a BT-Basic program so that data entry or program control can be simplified for a user. An example of where this would be useful is to display PC board versions on the softkeys. Then the user can select a particular board version by pressing the corresponding softkey rather than typing the version string on the keyboard. The statements in Table 1-7 are used to manipulate softkey definitions.
For detailed information about redefining the softkeys from a BT-Basic program, see softkey (BT-Basic) in Syntax Reference.
 
Table 1-7 Softkey manipulation statements 
Statement
Definition
softkey
Changes a softkey definition.
softkey clear
Selects the default softkey definition for a single softkey.
softkeys clear
Globally selects the default softkey definitions for all softkeys.
softkeys
Activates a redefined softkey.
softkeys on & off
Switches between default and modified softkeys.
softkeys to & over
Stores modified softkey definitions.
