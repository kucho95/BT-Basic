String Functions
The string functions are classified into four groups: Numeric‑to‑String, String-to-Numeric, String Manipulation, and Miscellaneous.
The first two groups (numeric‑to‑string, string‑to‑numeric) complement each other; for each function in one group, its complement exists in the other group. The first group manipulates numbers and generates strings; the second group manipulates strings and generates numbers. The operations performed by these functions assume 16‑bit or 32-bit (as determined by the "option bit" statement), twos‑complement representation of all values.
