String‑to‑Numeric Functions
The functions in this group complement the functions in the preceding group. These functions have string arguments and return decimal values. Twos‑complement representation of the values is assumed.
Functions in this group are described in Table 3-11.
.
Table 3-11 String-to-numeric functions 
Function
Description
bti
binary‑string to integer
oti
octal‑string to integer
hti
hexadecimal‑string to integer
num
single‑character‑string to ASCII equivalent integer
val
decimal‑string to value
The argument of each of the first three functions is a string representing an integer—binary, octal, or hexadecimal format. These strings can contain only characters normally allowed in the respective formats; leading and trailing spaces are allowed. Hexadecimal format strings are case-insensitive. If there is an embedded space in the string of characters, the space terminates the number; any remaining characters are ignored. The strings can represent numbers in the (decimal) range:
16-bit operation: ‑2^15 <= integer <= 2^15‑1
                  (2^15 = 32768)
 
32-bit operation: -2^31 <= integer <= 2^31-1
                  (2^31 = 2147483648)
Here are some examples of the string-to-numeric functions, assuming 16‑bit operation:
  bti ( " 11101")         ! returns   29
  bti ( " 11101 10110")   ! returns   29
  bti("1111111111011010") ! returns  ‑38
  hti ("FffF")            ! returns  ‑1
The num function returns the decimal number which is the ASCII equivalent of the single character in the function's argument:
  num ("w")         ! returns 119
The argument of the val function can contain any valid decimal value:
  val ("‑123.456")  ! returns ‑123.456
