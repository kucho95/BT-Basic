Inhibiting the Termination Sequence
Different devices require different termination sequences to properly terminate the data being written to them. The system knows what sequences are required for all of the standard devices and for all of the standard options which can be connected to it. However, since the system has GPIB and RS‑232 capability, the system may not necessarily recognize some devices connected to the auxiliary bus or to the RS‑232 port. Because of this, the image statement has a suppress‑EOL (<inhibit EOL spec>) specification which you can use it to prevent the system from sending its EOL sequence to an GPIB or RS‑232 device. You can then send the proper character‑sequence required to terminate the data to that device. The suppress‑EOL specification can be used only with GPIB and RS‑232 devices.
A Note About Parity Checking
The test system does not perform any parity checking on data during I/O operations.
