Simple‑if
The simple‑if is really two statements combined: an if then followed by the statement to be conditionally executed. For example:
   if X = 20 then print "Last one"
Here, the print statement is to be conditionally executed. When the simple‑if is encountered, the expression following the if keyword is evaluated. If the expression is true (in this case, if X does equal 20), the statement following the secondary keyword then is executed. If the expression is false (if X equals some other value), the statement following then is skipped. As can be seen from the example, in the simple‑if, the if statement and its associated statement are combined into one statement—they do not have a statement separator (| or \).
Any single statement can follow the then in a simple‑if; except that statements which start some control structure, such as another if statement, or a loop, cannot be used. Here is an example of a simple‑if in a program:
   L6: input X
   if X < 0 then goto Somewhere_Else
   print sin(X) | goto L6
Once started, this program will continue to accept and print values until the user inputs a negative number; the program will then branch to a line labelled Somewhere_Else.
