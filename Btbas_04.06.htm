The Report Device
Each workstation where testing takes place (i.e., a test station) must have an associated report device. In many cases this will be a strip printer, but another device or a file can be designated. When you log in to a workstation, the report device automatically defaults to report is *, which discards report output. However, you can change the default with the report is statement.
The report device is accessed automatically by the system to print test reports and, when a component test fails, to print the component failure messages entered in the Board Description Forms. You can also use the report statement (or report using) to send any other test data to the same report printer. Or you can designate a file as the report printer and report to that.
Reporting can be turned off by executing report is *. All report statements will then be ignored (unless buffered reporting is turn on; see Buffered Reporting) and, until reporting is again turned on, the automatic failure messages will no longer be printed.
If desired, you can use the report level is statement to direct failure messages to the report device, to the log buffer, to both the report device and the log buffer, or to discard the messages. To determine the current report level, use the rli$ function.
