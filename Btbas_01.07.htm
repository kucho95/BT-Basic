Evaluating a Numeric Expression
When a numeric expression is evaluated, the order in which the elements are considered depends on the precedence of the operators. Higher‑priority items take precedence over lower‑priority items (1 is lowest, 7 is highest).

The rules governing the order in which an expression is evaluated are:
• Elements of equal priority are evaluated in turn from left to right.
    6 + 3 ‑ 2 = 7 ! + and - are equal priority
• A higher‑priority element is evaluated before any lower‑priority elements which precede it.
    6 + 3 * 2 = 12 ! * has a higher priority
• When one or more elements are enclosed in parentheses, evaluation of the (main) expression is suspended while the items in parentheses are evaluated. The result is then treated as a single value within the main expression.
    (6 + 3) * 2 = 18 ! 6 + 3 is done first
The elements within parentheses are themselves evaluated as an expression, and parentheses can be nested (i.e., parentheses within parentheses).
• A function and its argument is treated as a single value.
    A = 3
    B = 4
    4 * sqr(A^2 + B^2) + 6 = 26
(This also applies to the user‑definable functions described in Branching, Looping, and Subprograms).
