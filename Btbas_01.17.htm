Summary of the Rules for Arrays
• An array I.D. can have different formats:
• The id of a numeric array is a label.
• The id of a string array is a label with a dollar sign ($) appended.
• The id of an array element is the id of the array followed by the positions of the element in the dimensions of the array.
• The I/O statements can use the asterisk to specify all elements in an array at once, e.g., Scores(*).
• Each label used to identify an array, or a simple variable, must be unique (i.e., Test and Test$ cannot both exist at the same time).
• The array must be dimensioned before any element can be accessed.
maximum dimensions per array = 6
maximum elements per dimension = 32767
maximum elements per array = 131072
(131072 = 2^17, or approximately 4 * 32767)
• The elements in any one dimension are numbered consecutively in ascending order and must be in the range: -32767, 0, 32767
• The dim statement establishes the element numbers by specifying the upper and lower bounds of each dimension. The upper bound must be greater than the lower bound; if the lower bound is not specified it defaults to zero (0).
• All elements in a string array have the same dimensioned length, established by the dim statement. The dimensioned length can be up to 2048 characters; if not specified, the dimensioned length defaults to 80 characters.
• Also use dim to specify a simple string variable with a dimensioned length other than 80 characters (a simple numeric variable cannot be specified in a dim statement).
Example 2-9 contains more examples of array elements, showing how they are dimensioned and used.
Example 2-9 More examples of array elements
  dim Alpha(1:10,1:20)         ! dimensions a 10 by 20 numeric array named Alpha
  Alpha(3,7) = 132             ! assigns a value to the 7th element in the
                               !   3rd row of array Alpha
  print Alpha(3,7)             ! prints  132
  dim Test$(12,32)[40]         ! dimensions a string array, Test$, with
                               ! 429 strings, each a maximum of 40 characters
                               ! long; there are 13 sets of 33 strings.
  Test$(8,1) = "Resistors"          ! assigns characters to the 2nd string in
                                    !   the 9th row in array Test$.
  print Test$(8,1)                  ! prints  Resistors
  print A(*)                        ! print all values in numeric array A
  print L$(*)                       ! print all strings in string array L$
  dim Results(10, 7, 15, 6, 3, 2)   ! dimensions a 6‑dimensional array with
                                    ! 118272 elements
  dim Square$(1:40,1:40)[25]        ! A 40*40 string array; each string variable
                                    ! element can contain up to 25 characters
  Square$(9,15) = "Peter's math score"  ! assigns string to the 15th variable
                                        !  in the 9th row of array Square$
  dim Time_box$(20,30,15,6)     ! A multi‑dimensioned string array; each string
                                ! can contain up to 80 characters (by default)
