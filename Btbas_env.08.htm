Editing and File Manipulation
This section describes the following:
• Editing Statements
The editing statements are used to prepare text, files, and programs on the workstation.
• File Manipulation Statements
The file manipulation statements provide a link between the system workspace and the file structure.
 
 
You should not use an editor such as vi to edit board test files on your test system. Board test files include a header that contains information used by the board test software including a file time stamp. The BT-Basic editor prevents you from altering or removing this header information, but other editors do not. If this header information is not properly maintained, your test system may not function correctly.
