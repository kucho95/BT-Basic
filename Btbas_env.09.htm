Editing Statements
The editing statements are used with the workstation’s editing keys and softkeys to enhance the workstation’s editing capability. None of these statements are programmable. They can be executed only from the workstation command line.
Some commands (chamgem, delete, duplicate, and listm) refer to a “marked” area. This marked area is created by using the following procedure:
1 Place the cursor on a line in the work area that you want as one border for the marked area and pressing the mark softkey (F5). This defines the start or end of the marked area and is included in the marked area. The line that the cursor is on changes to inverse video. Also note that the softkey definition for F5 changes from mark to second mark.
2 You then position the cursor on a second line in the work area and press the second mark softkey (F5). That defines the marked area and is included in the marked area. The line that the cursor is on changes to inverse video. Also note that the softkey definition for F5 now changed from second mark to clear marks.
3 Once the marked area has been defined, you can procede with the command you wanted to do (chamgem, delete, duplicate, or listm).
4 After completing the operations you want on that marked area, you can clear the markers by pressing the clear marks softkey (F5). Note that this does not delete any information in the work area. It does, however, change the two lines that defined the marked area from inverse video to normal video. The softkey definition for F5 now reverts back to mark.
Table 1-1 contains a list and a brief description of the BT-Basic editing statements. More detailed information about each command can be found in Syntax Reference.
 
Table 1-1 BT-Basic editing statements 
Term
Definition
change
(change all) Replaces all occurrences of an existing string with a new string, throughout the workspace. Not case sensitive. Wildcards are not available. Only literal strings can be used.
changem
(change marked) Replaces all occurrences of an existing string with a new string, throughout the area defined by the mark softkey. Not case sensitive. Wildcards are not available. Only literal strings can be used.
changen 
(change next) Replaces the next occurrence of an existing string with a new string. Not case sensitive.
delete
Deletes the marked lines in the workspace.
duplicate
Duplicates the marked lines in the workspace. Inserts duplication immediately above the line where the cursor is positioned.
edit
Positions the cursor at the beginning of the specified line.
fetch
Copies a specified line from the workspace into the workstation command line.
find 
(find first) Finds the first occurrence of a given string within the entire workspace. Not case sensitive.
findm 
(find marked) Locates the first occurrence of a given string within the marked area of the workspace. Not case sensitive.
findn 
(find next) Locates the next occurrence of a given string within the workspace. Not case sensitive.
list 
(list all) Lists the entire workspace to the default print device with line numbers.
listm 
(list marked) Lists the marked portion of the workspace to the default print device with line numbers.
listn 
(list to end) Lists, to the default print device, all lines from the current line to the end of the workspace.
move
Moves the marked segment of workspace to immediately above the current line.
number
Returns information to the user about the current line number and cursor position.
scratch
Clears the workspace only. Erases any text, program, or variables currently stored there.
