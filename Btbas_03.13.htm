Evaluating the Expression
In its simplest form, the if statement contains an expression followed by a secondary statement (for example, goto Finish in the preceding example); the expression is logically evaluated to determine whether or not to branch. If the expression is true, the secondary part of the statement is executed; if the expression is false, that secondary part is skipped.
The expression to be logically evaluated usually consists of two values and a relational operator (for example, A > B). The two values are compared to determine if the relationship is true or false. If the relationship is met (in this case, A is greater than B), then the expression is true (1); if the relationship is not met (A is equal to, or less than, B), then it is false (0).
As an example, consider this if statement:
   if A = 25 then print A
Here the expression (A = 25) is true, and has a value of 1, if variable A does equal 25—the value of A, 25, is then printed. If A is equal to any other value, then the expression is false and has a value of zero—in this case, the print instruction is ignored.
Notice that it is not the value of the variable, but the value of the expression, that must be equal to 1 or 0.
   if P = 0 then print P
In the preceding example, the value in variable P will be printed only if it is equal to zero. The expression is true (its value is 1) only when P is equal to zero; otherwise, the expression is false and P is not printed.

In the next statement the expression to be logically evaluated contains just one value; the second value and the relational operator are implied.
if J then print J
   ! e.g., if J = ‑51.6, the statement
   !  prints ‑51.6
Here, if the value of J is zero, the expression is false and the print operation is not executed. If J has any other value, then the expression is true and the value of J is printed. Notice that the value of J and the value resulting from the logical evaluation of J are not necessarily the same: provided that J has any nonzero value, then the value of the logical evaluation is 1.
Because the operator and the second value are implied, the preceding example is equivalent to:
   if J <> 0 then print J
Any of the relation operators can be used in the if statement. These are described in Operators and Functions but are listed here for reference:
• = equal to
• < less than
• <= less than or equal to
• <> not equal to
• > greater than
• >= greater than or equal to
Similarly, any of the logical operators can be used:
• and
• not
• or
• exor
For example, the statement if P = 0 then print P (used earlier) could have been written as:
   if not P then print P
As another example:
   if A and B print "Yes"
