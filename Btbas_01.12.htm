Environment Variable
The top-level directory for i3070 In-Circuit Test Software is user-definable. To allow the software and documentation to accommodate any chosen top-level directory, an environment variable is used. The environment variable, $I3070_ICT_ROOT, replaces the upper path names. For example, the $I3070_ICT_ROOT factory default value is C:/I3070_ICT on the Windows system.
In order to use the environment variable in a BT-Basic window, you must use the btgetenv$ command before invoking the environment variable.
Table 2-3 illustrates path equivalents using the system config file in a BT-Basic window.
 
Table 2-3 Absolute & Environment Variable file path usage in BT-Basic
Absolute addressing
Environment Variable Addressing
msi "C:/I3070_ICT/diagnostics/th1"
msi btgetenv$ ("I3070_ICT_ROOT") & "/diagnostics/th1"
get "C:/I3070_ICT/diagnostics/th1/config"
get btgetenv$ ("I3070_ICT_ROOT") & "/diagnostics/th1/config"
 
 
btgetenv$ ("I3070_ICT_ROOT") is only required for BT-Basic commands which are referenced to the root.
If the BT-Basic command msi btgetenv$ ("I3070_ICT_ROOT") & <command> is used prior to the next BT-Basic command (for example compile or faon), use of the environment variable to define the root path is unnecessary.
BT-Basic commands which normally contain paths (msi, load, copy, save, get, store, unlink, rcall) for example, will require:
btgetenv$ ("I3070_ICT_ROOT") & <rest of path>
