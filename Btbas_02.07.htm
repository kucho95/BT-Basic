Mathematical Functions
The mathematical functions — arithmetic functions, logarithmic and exponential functions, and trigonometric functions — can be used anywhere a numeric expression is appropriate. They are described in detail in the following sections:
• Arithmetic Functions
• Logarithmic and Exponential Functions
• Trigonometric Functions
• Miscellaneous Numeric Functions
User definable functions are used in exactly the same way as the standard functions described in this chapter. The user definable functions are described in Branching, Looping, and Subprograms.
The syntax of most functions is:
  <function keyword> ( <numeric expression> )
where <numeric expression> is the function’s argument
However, some functions have no argument and the function dround has two.
