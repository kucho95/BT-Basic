Substring Input
Substring input consists of assigning characters to substrings within string variables; the assignment operator (=) is used for this. Input differs from output in that the input changes the characters in the parent variable, and can change the variable's length. Whether or not the length changes depends on the length of the substring, and on its position in the parent variable. Exactly how the length changes is explained with the examples below.
As explained above (see Substring Identifiers), the substring can start anywhere in the variable from one (1) to the current length, or, if the dimensioned length is greater than the current length, to current length plus 1.
The length of the substring is determined by the optional length parameter; if that parameter is not included, it defaults to the length of the string of characters to be assigned to the substring. However, the substring cannot extend beyond the dimensioned length of the parent variable.
This variable (S$) is used to explain the different aspects of substring input. See Example 2-13.
Example 2-13 Example of different aspects of substring input
  dim S$[25]        ! dimensions S$; the dimensioned length is 25
  Source$ = "ABCDEFGHIJ"
  S$ = Source$      ! parent variable, S$; current length is 10
 
• Optional <length> parameter is specified and the substring is located wholly within the current length of the parent variable. See Example 2-14.
Result: Current length does not change.
Example 2-14 Substring located wholly within current length of parent variable
  S$[4;3] = "def"
  print S$, len(S$)      ! prints ABCdefGHIJ  10
  S$[9;2] = "ij"
  print S$, len(S$)      ! prints ABCdefGHij  10
 
• Optional <length> parameter is specified and the substring is located beyond (to the right), or partially beyond, the current length of the parent. See Example 2-15.
Because of this, current length increases. (Note that the current length cannot be shortened if the length parameter is specified.)
Example 2-15 Substring located beyond current length of parent variable
  S$ = Source$
  print S$, len(S$)      ! prints ABCDEFGHIJ  10
  S$[9;4] = "ijKL"
  print S$, len(S$)      ! prints ABCDEFGHijKL  12
  S$[13;6] = "MNOPQR"
  print S$, len(S$)      ! prints ABCDEFGHijKLMNOPQR  18
 
• Optional <length> parameter is not specified—the length of the substring defaults; that is, it is the same length as the length of the string of characters to be assigned to that substring. See Example 2-16.
Regardless of its length, the assigned string replaces the start character and all subsequent characters in the parent variable. Depending on the length of the string to be assigned, this can shorten the parent string, lengthen it, or leave its length unchanged, as shown in the next examples. If the parent variable would be lengthened beyond its dimensioned length, a runtime error occurs, and the assignment is not made.
Example 2-16 Substring length default
  S$ = Source$
  print S$, len(S$)        ! prints ABCDEFGHIJ  10
  S$[5] = "efg"            ! shortened
  print S$, len(S$)        ! prints  ABCDefg  7
  S$[3] = "cdEFG"          ! same length
  print S$, len(S$)        ! prints  ABcdEFG  7
  S$[6] = "fghijklmn"      ! lengthened
  print S$, len(S$)        ! prints  ABcdEfghijklmn  14
  S$[13]="MNOPQRSTUVWXYZ"  ! error — exceeds 25‑character
                           !    dimensioned length
 
• The string of characters to be assigned to a substring may be different in length from the specified length of that substring.
If the string of characters is shorter than the substring, it is left‑justified in the substring. The rest of the substring is filled with spaces (a space counts as a character, but a null does not). Substring length does not change. See Example 2-17.
Example 2-17 String of characters shorter than the substring
  S$ = Source$
  print S$, len (S$)    ! prints  ABCDEFGHIJ  10
  S$[3;6] = "***"
  print S$, len(S$)     ! prints  AB***   IJ  10
                        !  spaces      ^^^
  S$[8;12] = "98765"
  print S$, len(S$)     ! prints  AB***   98765         19
                        !  spaces      ^^^     ^^^^^^^
 
If the string of characters is longer than the substring, extra characters in the string are truncated. Substring length does not change.
Example 2-18 String of characters longer than the substring
  S$ = Source$
  print S$, len (S$)      ! prints  ABCDEFGHIJ  10
  S$[3;6] = "cdefghij"
  print S$, len (S$)      ! prints  ABcdefghIJ  10
  S$[9;5] = "ijklmnop"
  print S$, len(S$)       ! prints  ABcdefghijklm  13
