Arithmetic Functions
• Argument — numeric or none
• Result — numeric
 
Table 3-5 Arithmetic functions
Function
Description
Examples
sqr
Returns the square root of a (nonnegative) argument.
sqr(64) = 8
sqr(-64) — error
-sqr(64) = -8
abs
Determines the absolute value of its argument.
abs(-8.65) = 8.65
abs(8.65) = 8.65
sgn
The sign function returns:
  1 if argument > 0
  0 if argument = 0
–1 if argument < 0
sgn (.00000005) = 1
sign(0) = 0
sgn(-18) = -1
int
Returns the next lower integer value from the argument.
int(2.718) = 2
int(-36.28) = -37
dround
Rounds its first argument to the number of digits specified by its second (integer) argument. Second argument <= 17; if less than 1, returns a value of 0.
dround(34576215, 4) = 34580000
dround(32.6758612, 5) = 32.676
pi
Returns the value pi; function has no argument.
print 2*pi
prints: 6.28318530718
rnd
The random function returns a pseudo-random number less than 1 and greater than or equal to zero. It has no argument. Each access to the function uses a seed based on the result of the previous access. Use the randomize statement to change the seed.
A_Random_Number = rnd
randomize
Recomputes the seed for the random number generator (rnd).
randomize 8.23
