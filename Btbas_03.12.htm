Conditional If
The if statement causes a branch if a specified set of conditions are true. There are two forms of the if statement: the Simple‑if, and the Structured‑if. When an if statement is executed, it evaluates an expression (the condition) to determine whether or not to branch.
This example program continues to loop, and prints any numbers entered, until you input a zero.
  L3: input "Next number", A
    if A=0 then goto Finish
    print A | goto L3
  Finish: end
The if statement checks the input value to see if it is equal to zero. As long as A does not equal zero, the second half of the if statement is skipped; the program prints the value of A and returns to L3 to wait for the next input. When A is equal to zero, the second half of the if statement is executed—the program goes to Finish and stops.
