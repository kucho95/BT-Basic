Numeric‑to‑String Functions
Each function in this group has a numeric argument; it converts the argument to a string constant and returns that string as the value of the function.
Except for two of the functions (chr$ and val$), the arguments are assumed to be decimal integers.
These integers must be in the range:
16-bit operation: ‑2^15 <= integer <= 2^15‑1
                  (2^15 = 32768)
32-bit operation: -2^31 <= integer <= 2^31-1
                  (2^31 = 2147483648)
Functions in this group are described in Table 3-10.
 
Table 3-10 Numeric-to-string functions 
Function
Description
itb$
integer to binary‑string
ito$
integer to octal‑string
ith$
integer to hexadecimal‑string
chr$
value to single‑character‑string ASCII equivalent
val$
decimal value to decimal‑string
The first three functions return a string which contains the binary‑, octal‑, or hexadecimal‑equivalent of the decimal argument. For example, assuming 16‑bit operation:
  itb$ (26)  = "11010"
  itb$ (968) = "1111001000"
  itb$ (‑26) = "1111111111100110"
(Example 2 under Bit Manipulation Functions shows how a negative number is represented in twos‑complement form.)
  ito$ (968) = "1710"
  ito$ (‑26) = "177746"
  ith$ (968) = "3C8"
The chr$ function returns a string containing the character which has the ASCII equivalent of the argument. This function first calculates modulo 256 of its (integer) argument and uses the result as its new argument:
  chr$(87)    ! returns "W"
  chr$(368)   ! returns "p"
              ! [same as chr$(112)]
The val$ function returns a string containing the decimal number in its argument:
  val$(‑115.67) = "‑115.67"
  val$(74.6)    = "74.6"
