Calling Subroutines
The following statements are used to call and execute a subroutine; these statements can appear in the main program or they can be used in one subroutine to call another.
Table 4-9 Statements used to call and execute a subroutine
Statement
Description
call
Calls and starts execution of the subroutine; optionally passes parameters (data) to it.
on - call
Computed branch statement can selectively call subroutines; see Computed Branch.
on break call
Specifies the subroutine to be called if a break occurs; see Break and Error Trapping.
on error call
Specifies the subroutine to be called if an error occurs; see Break and Error Trapping.
A subroutine is called (executed) by its name (a label). The name appears in the first statement (sub) of the subroutine; it is then referenced in the call statement. In the first of the preceding examples, the name of the subroutine is Printer; the subroutine is executed by the statement call Printer.
When a subroutine is called, program control transfers to that subroutine; its statements are then executed. When the exit is made from the subroutine, control returns to the calling point—exactly where control returns to depends on which statement called the subroutine:
• call and on ‑ call — control returns to the next statement following the statement which called the subroutine.
• on break call and on error call — control returns to the next line following the line on which the break or error occurred. If there are more statements following, and on the same line as, the statement being executed when the break or error occurred, then those statements will not be executed after the exit from the subroutine.
Either a subexit or subend statement can cause the exit from the subroutine; use of subexit is optional, but subend must be the last statement in the subroutine.
Of the four statements which can call a subroutine, only the call statement can pass parameters to the subroutine (see Formal Parameters and Passed Parameters). As a workaround to not being able to pass parameters the the subroutine, use globals if needed (see Global Parameters).
