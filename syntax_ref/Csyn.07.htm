cards (CONFIGURATION)
Title: CARD TYPE
The cards function defines which type of cards are installed in each testhead module and where they are installed. This function must be used within a block defined by module and end module statements. The cards function is used in both the testhead configuration file and the board configuration file.
Each module to be used must have:
• an ASRU Card installed in slot 1,
• a Module Control Card in slot 6, and
• at least one Hybrid Pin Card.
The pin cards and any other cards are installed in the remaining slots; slots 2 through 5 and slots 7 through 11.
Syntax
  cards <card range> <card type>
  cards <card range>, <card range> <card type>
  cards <card range>, <card range>, . . . . <card range> <card type>
     <card type>: defined in Table C-2
     <card range> can be:  <slot number>
                           <slot number> to <slot number>
        <slot number> is an <integer>
Parameters
<card type>
The type of card installed in the module slot(s).
<slot number>
The identifier of the module slot (1 to 11) in which the card is installed.
Example
  module 1
     cards 1 asru n revision
     cards 2 to 5 unmuxed hybrid
     cards 6 control xtpb
     cards 9 to 11 unmuxed hybrid
     supplies 1 to 4
  end module

General Information
Table C-4 lists the pin cards and their targeted Mux systems. The cards are grouped into classes. Within each class, any specific card includes the functionality of any card listed below it, which provides upward compatibility with respect to the hardware. For example, a board test which runs using 6 MP/s (Million Patterns per second) cards also run on a system with corresponding 20 MP/s cards in the same slots.
 
 
All pin cards in a test system must be the same speed.
