display nodes (DEBUG)
Title: DISPLAY NODE RESPONSE
The display nodes function runs the test and displays the states on the specified board nodes; these nodes must be part of the circuit in the digital test currently being debugged.
The function’s <response code> parameter specifies the type of data to be displayed, as listed next (actual states are displayed in green, expected states in white, and failed states in red):
• No parameter: actual states on receivers and bidirectional nodes (for drive and receive); expected states on drivers.
• a (actual): actual states on receivers and bidirectional nodes (for drive and receive); for the drivers, the user is prompted to place the probe to see the actual states.
• e (expected): expected states on all nodes (drivers, receivers and bidirectional nodes)—does not run the test.
• f (failed): same as e but runs the test; where a failure occurs, the expected state is highlighted in red.
• s (setups): lists the pin channel setups to the printer is device. The listing indicates whether the channel is driving or receiving, the events (FCLKs) in the machine vectors on which the channel is strobed, what the offsets are (if any), and the high and low driver or receiver voltages on that channel.
• v (vector drive/receive status): shows the direction, for each vector, of bidirectional pins—displays a series of D's (drive), R's (receive) and spaces (X or Z).
Syntax
  display nodes <node list>
  display nodes <node list> <space> <response code>
  display nodes <node list> <space> <response code> <space> <display line>
     <node list> can be:   <node id>
                           <node id>,<node id>
                           <node id>,<node id>, . . . <node id>
        <node id> is a <string expression>
     <response code> can be:   a
                               e
                               f
                               s
                               v
     <display line> is a <numeric expression>
Parameters
<node id>
The identifier of a node to display.
<response code>
Specifies the type of data to display; if not specified, displays the defaults (see the introductory text above):
• a – actual
• e – expected
• f – failed
• s – setups for the pin channels
• v – vector drive/receive status
<display line>
The line number to start the display. If not specified, the display starts at line 1.
Examples
  display nodes "clk_1", "out_2" , "out_4"   ! display actual data for specified nodes
  display nodes "u29_3" f                    ! display failed data
  display nodes "ctr1" e 12       ! display expected data, starting at line 12
  display nodes "2_way" v         ! display directions of bidirectional nodes
