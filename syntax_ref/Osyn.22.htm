outputs reference clock (VCL)
Title: DESIGNATE AN EXTERNAL CLOCK LINE
The outputs reference clock function declares which board output pin is to be used to synchronize the reference clock for the test. On Mux systems, the period of the clock is established by the vector cycle function in tests without timing sets, or by the events every function in tests with timing sets.
Syntax
  outputs reference clock <group id>
     <group id> is a <label>
Parameters
<group id>
The identifier of the pin group. The group must contain only one pin.
Example
  ! in the Declaration section
        . . .
  assign Sync_Clock to device "U81" pins 4
        . . .
  outputs Counts                           ! Hybrid card outputs
  outputs reference clock Sync_Clock
General Information
Only one pin can be specified for any VCL test. Two pins on the Module Control Card for each module are available as receivers to synchronize the reference clock. These are pins 2 and 3, with pin 1 as the reference clock ground. Since there are two pins per Module Control Card, a board test on a 4‑module system could have up to eight reference clocks.
