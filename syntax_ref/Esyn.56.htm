exor (BT-Basic)
Title: EXCLUSIVE‑OR
The exor operator is used to evaluate Boolean expressions. It returns a value of 1 if either the expression on the left or the expression on the right, but not both, is true (non‑zero). If both expressions are true, or if both are false (zero), the operator returns a value of zero. This operator has a priority of 1.
Syntax
  <numeric expression> exor <numeric expression>
Parameters
<numeric expression>
The quantities to be evaluated.
Examples
  print 12 exor ‑123.4        ! prints   0
  print 0 exor 345            ! prints   1
  print 0*20 exor 0           ! prints   0
  A = 25 \ print A exor 0     ! prints   1
