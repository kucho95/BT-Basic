output using (BT-Basic)
Title: OUTPUT DATA IN IMAGED FORMAT
The output using function sequentially outputs data to files and devices, using imaged formatting.
The file or device to which the data is to be sent is specified in the function’s <destination> parameter. A device is assumed to be part of the file system. A file or device can be addressed either by its <file id> or by an @<name> associated with that <file id>. If <file id> is used, the file or device opens for access and closes when that access is complete. If an @<name> is used, the file or device is opened when the @<name> is first assigned and remains open so that each new access can start where the previous access stopped.
The data to be output is contained in the function’s <print list>. The specifications to format that data are referenced by the <image data> parameter. This parameter can itself contain the formatting specifications, or it can reference an image function which contains the specifications.
The output using function outputs data to the destination file or device sequentially, record by record. The maximum length a record can have is 2044 characters; an attempt to generate a longer record results in an error when the program is run. The actual length of each record is determined by the EOL (End Of Line) sequences generated. An EOL is generated each time a <line spec> (/) is encountered in the image specifications, or, provided the last spec was not a line spec, when all data items have been output.
Each time an EOL occurs, an appropriate sequence is sent to the file or device. The system automatically sends the proper sequence to all of the recognized standard and optional devices. For example, if the data is being printed, the printer executes a CR/LF (Carriage Return/Line Feed). If the data is being written to a file, an EOR (end of record) is sent. The end of the current record is marked and, if there is more data, a new record is started. However, if the image specifications include an <inhibit EOL spec> (#), then the EOL is not generated (this spec applies only to GPIB or RS‑232 operations).
During the output operation, the system tracks the write position in the output file or device by means of a pointer. Provided that the file or device is not closed, the pointer remains at the current position when the output operation is completed. The next output operation starts at the current write position. Whether this starts a new record, or continues the record from the previous output operation, depends on whether or not the last EOR (EOL) was sent.
Syntax
  output <destination> using <image data>
  output <destination> using <image data>;<print list>
  output <destination>,,<error variable> using <image data>
  output <destination>,,<error variable> using <image data>;<print list>
     <destination> can be:
        @<name>
        <file id>
           <name> is a <label>
           <file id> is a <string expression>
     <image data> can be:
        <image id>
        <image specifications>
           <image id> is a <label>
           <image specifications> is a <string expression>
     <error variable> is a <numeric variable>
        [Note the double comma preceding <error variable>]
     <print list> can be:
        <expression>
        <expression>,<expression>
        <expression>,<expression>, . . . <expression>
           <expression> can be numeric or string
              [If <expression> is an array, use <array id>(*)]
Parameters
 
<destination>
The file or device where the output data is to be sent. If a <file id> is specified, the file or device is first opened and then closed when the output operation is completed, regardless of whether or not the output was successful. If an @<name> is specified, the file or device remains open for further access after the output. If used, the @<name> must have previously been assigned.
<image id>
The identifier of the image function containing the specifications to be used to format the print list.
<image specifications>
The list of specifications to be used to format the print list. Refer to the description of the image function for a complete description of these specifications.
<error variable>
The identifier of an error variable.
<print list>
The list of data items to be output. These will be formatted by the specifications referenced in the <image data> parameter. If this list is omitted, the image specifications will determine the output.
Example
  Form1: image 2d.2d, sd.ddd, ddd.dd
  A = 6.34 \ B = 7.325 \ C = 2
  output "/dev/tape" using Form1; A,B,C
     ! Outputs    6.34+7.325 2.00
     !       ‑‑5‑>‑‑6‑‑>‑‑6‑‑>
  Form2: image 2d.2d,x,a,2d.3d,3x,"Total = ",4d.3d
  output @Printer using Form2; A, "+", B, A+B
     ! Prints    6.34 + 7.325  Total =  13.665
     !       ‑‑5‑>>>‑‑6‑‑>‑3>‑‑‑‑9‑‑‑>‑‑‑8‑‑‑>
  Form3: image 4(ddd.dd)
  output "/dev/ptr" using Form3; R,S,T,U
  output "/dev/ptr" using "4(ddd.dd)"; R,S,T,U     ! Same as above
  P$ = "/dev/ptr"
  output P$ using Form3; R,S,T,U                   ! Same as above
  F$ = "4(ddd.dd)"
  output "/dev/ptr" using F$; R,S,T,U              ! Same as above
  output "/dev/ptr",,Check using Form3; R,S,T,U
     ! Note error variable, "Check"
