edit (edit)
Title: EDIT AT A SPECIFIED LINE
The edit function positions the cursor at the beginning of the specified line and, optionally, at a specific column in that line.
Syntax
  edit
  edit <line number>
  edit <line number>,<column>
     <line number> and <column> are <numeric expression>s
Parameters
<line number>
The (integer) number of the line where the cursor is to be positioned. If omitted, line #1 is assumed.
<column>
The (integer) number of the column where the cursor is to be positioned in the specified line. If omitted, column #1 is assumed.
Examples
  edit 154                     ! Positions cursor at line 154, column 1
  edit                         ! Positions cursor at line 1, column 1
  Line = 132 \ edit Line       ! Positions cursor at line 132, column 1
  edit 10,5                    ! Positions cursor at line 10, column 5
General Information
The edit function is not programmable.
