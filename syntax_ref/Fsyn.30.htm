fixture tooling (BT-Basic)
Title: RUN FIXTURE TOOLING
The fixture tooling function executes the Fixture Tooling process of the Fixture Generation Software. The Fixture Tooling process writes the fixture wiring and building instructions. With the fixture tooling function, you can instruct Fixture Tooling to write terse reports. You can also instruct Fixture Tooling to minimize the extra drilled and socketed holes by only partially drilling the extra holes.
You can use Fixture Tooling in the incremental mode to incorporate changes to the board under test.
Syntax
  fixture tooling
  fixture tooling <option list 1>
  fixture tooling; <option list 2>
  fixture tooling <option list 1>; <option list 2>
     <option list 1> can be:   <directory name>
                               <directory name>, <error variable>
                               <error variable>
        <directory name> is a <string expression>
        <error variable> is a <numeric variable>
     <option list 2> can be:   <item>
                               <item>, <item>
                               <item>, <item>, . . . , <item>
        <item> can be:   terse
                         minimize
                         cartesian
                         <window>
                         <wait>
                         <experience level>
                         <backup level>
                         <socket>
           <window> can be:   window
                              nowindow
           <wait> can be:   wait
                            nowait
                            failwait
           <experience level> can be:   standard
                                        advanced
                                        expert
           <backup level> can be:   numbered
                                    unnumbered
                                    nobackup
           <socket> can be:  no
                             yes
Parameters
 
<option list 1>
Can be either the directory pathname, or an error variable, or both.
<option list 2>
A list of optional parameters that determine how the function works. The options are listed in Table F-3.
 
Table F-3 Optional parameters
Option
Description
terse
Instructs Fixture Tooling to produce reports without headings and white space.
minimize
Instructs Fixture Tooling to assign only partially drilled holes for extra resources instead of drilled and socketed.
cartesian
Instructs Fixture Tooling to output X-Y data on a vertical Y axis and horizontal X axis. Fixture Tooling is run with the parameters specified in the .hp3070 file. If cartesian is not specified, the X-Y data is on a vertical X axis and horizontal Y axis.
<window>
Specifies whether or not a new window is automatically opened when the function is executed. Values are:
• window – A new window is opened.
• nowindow – Suppresses the opening of a new window.
<wait>
Specifies how the command executes. Values are:
• failwait – The function executes and, if a failure occurs, the results remain on the screen so you can examine them.
• nowait – The function executes and does not pause for you to examine the results.
• wait – The function executes and the results remain on the screen so you can examine them.
<experience level>
Sets the length (thoroughness) of the error messages the user receives and can also be used to restrict the user to a subset of the full system features. Permissible values are: standard, advanced, and expert.
<backup level>
Determines if the compiler stores an unchanged copy (a backup) of files before modifying them, and how the backup is stored. Permissible values are:
• nobackup – No file backup is made.
• numbered – Makes up to nine backups, each numbered sequentially with .#~, such as file.1~. Number one is the most recent backup. When more than nine backups occur, the oldest file is discarded, and the others are renumbered.
• unnumbered – A single backup is made. The backup file name is appended with a tilde (~); for example, file~.
<socket>
Specifies whether to maximize the number of socketed personality pins for all installed cards.
Examples
  fixture tooling "/boards/cpu_board",E
     ! "/boards/cpu_board" is the board directory. E is the error variable.
  fixture tooling; unnumbered
     ! Run Fixture Tooling on the current directory and make a single backup
     ! of any files that get modified.
General Information
This function is run automatically during test development.
