spmc (BT-Basic)
Title: CONFIGURE POWER MONITORING CIRCUIT
The spmc statements are used to configure and control the Power Monitoring Circuit (PMC) that is available on the ASRU Revision N Card. PMC provides three channels for detecting and reporting power supply failures during digital testing. Different voltage limits can be set for each channel.
Syntax
spmc <channel>, <voltage limit>     ! Turn on and configure a channel on the PMC
   <channel> is an <integer>
   <voltage limit> is a <numeric expression>
spmc <channel>, off             ! Turn off failure flag for a channel
spmc <off/reset>                ! Turn off or reset failure flag for all channels
spmc interrupt <on/off>         ! Set interrupt on or off for all channels
Parameters
<channel>
The channel number from 1 to 12. See Table S-4.
<voltage limit>
The voltage limit that indicates a power failure. The valid range is 1.0 V to 50 V.

Examples
spmc 2, 3.3          ! Turn PMC on for channel 2 and set a 3.3 V limit for
                     ! channel 2.
spmc 2, off          ! Turn PMC off for channel 2.
spmc reset           ! Reset failure flag to 0 for all channels.
spmc off             ! Turn PMC off for all channels and reset all failure flags.
spmc interrupt on    ! Turn interrupt on for all channels.
spmc interrupt off   ! Turn interrupt off for all channels.
