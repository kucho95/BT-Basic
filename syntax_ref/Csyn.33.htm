compile Syntax for Connect Check
compile <test id>
compile <test id>; <learn flag>
compile <test id>; <learn flag> device <device id>
compile <test id>; <learn flag> device <device id> pin <response pin id>
compile <test id>; <learn flag> device <device id> pin <response pin id>
    stimulus <stimulus pin id>
 
    <test id> is a <string expression>
    <learn flag> can be:
         clear values
         clear stimulus
    <device id> is a string expression
    <response pin id> is a string expression
    <stimulus pin id> is a string expression
Parameters
 
<test id>
Identifies the Connect Check test file.
<learn flag>
The learn flag can be:
• clear values – Instructs the compiler to re-learn the values of existing stimulus pins.
• clear stimulus – Instructs the compiler to determine new stimulus pins.
<device id>
Identifies the device.
<response pin id>
Iidentifies the device response pin.
<stimulus pin id>
Identifies the stimulus pin for the clear values learn flag only.
Examples
• To compile the test with no changes that require learning (note that if the test file contains no stimulus pins, this statement executes complete learning):
  compile "connectcheck"
• To compile the test and learn new values for existing stimulus pins:
  compile "connectcheck"; clear values
• To compile the test and learn new values for the existing stimulus pins on the designated device only:
  compile "connectcheck"; clear values device "U2"
• To compile the test and learn new values for the existing stimulus pins on the designated device response pin only:
  compile "connectcheck"; clear values device "U2" pin "2"
• To compile the test and learn the new value for the designated stimulus pin on the designated device and response pin only:
  compile "connectcheck"; clear values device "U2" pin "2" stimulus "13"
• To compile the test and determine all new stimulus pins:
  compile "connectcheck"; clear stimulus
• To compile the test and determine new stimulus pins for the designated device only:
  compile "connectcheck"; clear stimulus device "U2"
• To compile the test and determine new stimulus pins for the designated response pin on the designated device only:
  compile "connectcheck"; clear stimulus device "U2" pin "2"
