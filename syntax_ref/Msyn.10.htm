minimum wait (BT-Basic)
Title: SPECIFY ANALOG SETTLING TIME
The minimum wait function is used to specify a settling time before an analog measurement is made. This function can be added to the testplan and applies globally to all analog (unpowered) tests.
The minimum wait function has the same effect as the wait option used within an analog test. If an analog test contains the wait option, and that wait is less than the minimum wait specified, the minimum wait is used for the test. If the wait specified in an analog test is greater than the minimum wait, the wait is used for the test. If an analog test does not contain the wait option, the minimum wait is used. The default value is zero.
Syntax
  minimum wait <time>
     <time> is a positive number
Parameters
<time>
Positive number indicating the time, in seconds, to wait before an analog measurement is made.
Example
 minimum wait .007  ! adds a wait of 7 ms to all analog (unpowered) measurements
