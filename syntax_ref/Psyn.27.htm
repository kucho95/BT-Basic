power pins (ANALOG)
Title: DECLARE POWER PINS IN ANALOG FUNCTIONAL AND MIXED TESTS
The power pins function declares which pins of a device are connected to power nodes. This function is used in library tests for analog functional and mixed tests. The function is optional in executable tests.
Syntax
  power pins <pin id>
  power pins <pin id>, <pin id>
  power pins <pin id>, <pin id>, ... <pin id>
     pin id can be an:   <integer>
                         <string constant>
Parameters
(none)
Example
  test powered mixed
     power pins 3, 14
     connect rcva to pins 12
     test "u2908_312khz"
     continue digital
           .
           .
           .
  end test
