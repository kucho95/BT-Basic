clear (BT-Basic)
Title: CLEAR A DEVICE
The clear function issues clear commands to an GPIB device.
A clear issues the interface message that clears (sets to some predefined state) the devices connected to the bus.
The message can be in two forms: device clear (DCL), which clears all devices, or selected device clear (SDC), which clears only the device which is specifically addressed.
Syntax
  clear <GPIB>
  clear <GPIB device>
     GPIB> and <GPIB device> can be:   <file id>
                                       @<name>
          <file id> is a string expression
          <name> is a <label>
Parameters
<GPIB>
The address of the bus. This clears all devices on the bus (DCL).
<GPIB device>
The address of the selected GPIB device. Clears only the selected device (SDC).
Examples
Shortcut Method:
  assign @DVM to "/dev/dmm"
  clear @DVM                 ! Issues SDC to the DVM on the bus
  clear "/dev/hpib1"         ! Issues DCL to clear all devices on bus card 7.
 
Absolute Path Method:
  Bus$ = btgetenv$("I3070_ICT_ROOT")
     assign @DVM to Bus$&"/dev/dmm"
     clear @DVM                 ! Issues SDC to the DVM on the bus
     clear Bus$&"/dev/hpib1"    ! Issues DCL to clear all devices on bus 7.
General Information
 
 
These examples assume the dev file hpib1 contains the SICL interface name hpib7.
