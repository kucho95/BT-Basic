trst (ITL)
Title: IDENTIFIES TEST RESET NODE
The trst statement identifies the test reset node of the boundary-scan chain (if one exists). A name is assigned to this node using the trst statement.
Syntax
  trst <node name>
  trst <node name> <card list>
     <node name> is a <string expression>
     <card list> can be:  hybrid
                          channel          ! On Mux systems only
                          hybrid; channel  ! ";" indicates first choice preferred
                          channel, hybrid  ! "," indicates no preference
Parameters
<node name>
The name of the node assigned to trst.
Examples
  trst "Buffer-5"
  trst "D_5" hybrid
