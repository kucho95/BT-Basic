source (ANALOG)
Title: SOURCE SET UP
The source statement establishes a source to provide stimulation for an analog functional test. It selects a system source and specifies its operating characteristics.
The source is turned on with the on option, or a digital trigger, or the initiate statement. The AC source is set to its DC (offset) level when it is set up, but is not running until it is turned on or triggered.
See the syntax description of the auxiliary statement for details about the auxiliary source.
Syntax
  source none
  source <type>,<option>
  source <type>,<option>,<option>
  source <type>,<option>,<option>, . . . <option>
     <type> can be:   arb
                      dcv
                      sine
                      square
                      triangle
     <option> can be:   amplitude <value>
                        digital
                        frequency <value>
                        icompliance <value>
                        phoffset <value>
                        dutycycle <value>
                        offset <value>
                        on
                        terminated <resistance>
                        samples <value>
                        repetition <value>
                        single step
                           voltages <data id>
        <value> is a <numeric expression>
        <resistance> can be:   5, 50, 500, or 5K
        <data id> can be:   <data block id>
                            <numeric array id>
           <data block id> is a <string expression>
           <numeric array id> is a <label>
Parameters
 
<type>
This element selects the source. It can be:
• arb - Arbitrary Waveform Generator
• dcv - DC voltage source
• sine - AC sine wave voltage source
• square - square wave voltage source
• triangle - triangle wave voltage source
<option>
The options set up the operating characteristics of the selected source. Some options allow for a specified value and may have unit, range, and default parameters associated with it. The options and their parameters are explained in Table S-1.
For a data block, the number of samples specified by the samples <value> option must equal the number of samples in the specified data block.
For an array, if the number of samples specified is less than the number of elements in the array, the source ignores the extra samples in the array. If the number of samples specified is greater than the number of elements in the array, the source assumes values of 0 (zero) for the remaining samples.
 
Table S-1 Options 
Option
Description
amplitude <value>
Specifies the source amplitude, where <value> is a <numeric expression>. It is required with all sources except none, and it cannot be used with none. The range of values and the unit depend on the source (see Table S-2).
digital
Sets up the source to receive digital triggers. This option is not valid for the DCV source.
frequency <value>
Selects the source frequency for the sine, square, and triangle sources, where <value> is a <numeric expression>. The unit is Hz. You can specify any frequency from 1 Hz to 20 KHz in 1 Hz steps.
icompliance <value>
Sets the source current compliance, where <value> is a <numeric expression>. It cannot be used with none. There are two ranges: 0 specifies low current compliance, approximately 30 ma; 1 specifies high current compliance, approximately 150 ma. The default is 1 (0 for auxiliary dcv).
phoffset <value>
Specifies a phase shift, where <value> is a <numeric expression>. It is used with the sine, square, and triangle sources. The range of values is from 0 to 360. If you do not specify a value, 0 is used.
dutycycle <value>
Specifies the duty cycle, where <value> is a <numeric expression>. It is used with the square sources only. The range of values is from 5 to 95, in increments of 5. If you do not specify a value, 50 is used.
offset <value>
Specifies a DC offset, where <value> is a <numeric expression>. It is used with the sine, square, and triangle sources. The range of values is from -10 volts to 10 volts. The sum of the amplitude and offset must not exceed this range. If you do not specify an offset value, a value of 0 volts is used.
on
Turns the source on immediately rather than waiting for a trigger from the digital subsystem or for the initiate statement.
terminated <value>
Places a resistor in series with the source. Here, <value> is a numeric constant that determines the value of the resistor. <value> can be: 5, 50, 500, or 5K. If the word terminated is included with no value specified, a 50 ohm resistor will be used. If the word terminated is not included, no termination resistor will be used.
samples <value>
Used with the arb source to specify the number of voltage samples in the waveform. The <value> can be 1024 or 4096 if the single step option is not included. The <value> can be from 1 to 1024 if the single step option is included (the number of samples must match the number of digital triggers). If no samples <value> is specified, the source uses 1024.
repetition <value>
Used with the arb source to specify the frequency (in Hertz) of application of the entire waveform. The <value> can be whole integers from 1 to 32768 for waveforms with 1024 samples; from 1 to 8192 for waveforms with 4096 samples. If <value> is not a whole integer, the system rounds the <value> to the nearest whole integer. If no repetition <value> is specified, the arb source uses 512. This option is not valid with the single step option.
single step
Instructs the arb source to single step through the waveform samples. The arb steps to the next sample each time it receives a digital trigger. The number of samples must match the number of digital triggers. This option requires the digital option.
voltages <data id>
Instructs the arb source to use the voltage samples in the analog data block or array specified by the <data id>. The samples <value> option must be included with the voltages <data id> option.

Examples
! Set up a sine wave source with 6 volts amplitude, 100 Hz, current compliance of 150 mA,
! and offset of 2 VDC.
    source sine, amplitude 6, frequency 100, icompliance 1, offset 2
 
! Set up an arbitrary waveform generator to use the 1024 samples defined in the
! "waveform" data block, and repeat the waveform 2048 times every second.
    source arb, samples 1024, repetition 2048, voltages "WaveForm"
 
! Set up a sine wave source with phase offset of 90 degrees, offset 0 VDC, with 1 volt
! amplitude, frequency 15 kHz, compliance of 150 mA, and to turn on source immediately.
    source sine, phoffset 90, offset 0, amplitude 1, frequency 15000, icompliance 1, on
 
! Set up a triangle wave source with phase offset of 270 degrees, with 20 volt
! amplitude (-10V to +10V), frequency 15 kHz, compliance of 150 mA, and to turn on
! source immediately.
    source triangle, phoffset 270, amplitude 20, frequency 15000, icompliance 1, on
 
! Set up a square wave source with duty cycle of 90, phase offset of 90 degrees, with
! with 1 volt amplitude, frequency 15 kHz, compliance of 150 mA, and to turn on source
! immediately.
    source square, dutycycle 90, phoffset 90, amplitude 1, offset 0, frequency 15000, icompliance 1, on
General Information
Connect only the S bus for the source. The source low is automatically connected to digital and switched receiver ground.
