default device (VCL)
Title: DEFAULT DEVICE NAME
The default device function appears in the Declaration section of the test to identify the reference designator (e.g., U46) of the device to be tested. The function is used only in executable tests.
A test can have more than one default device function. Each one applies to the assign to statements which follow it. If an executable test does not have a default device function, then each assign to function in that test must completely identify each pin: that is, it must use the device <designator>, nodes or relays formats.
Syntax
  default device <designator>
     <designator> is a <string constant>
Parameters
<designator>
The reference designator of the device to be tested. The string can contain up to 48 printable characters, but with no spaces. The designator must be different from all other reference designators in the board test.
Examples
  default device "U46"
  default device "RAM_Circ"
General Information
The i3070 In-Circuit Test Software inserts the default device function into the test, using the device designator entered when creating the board information. It also uses the same name in the test digital (BT-Basic) function in the testplan, and for the file in which the test is stored (e.g., the test for U46 is stored in digital/u46).
The device designator is required only by the compiler, to cross‑map device pins to actual nodes on the PC board. Therefore, it is possible to use one designator in the test, but use a different designator to execute the test. If you edit the test, then for readability, we suggest that you use the same names; however, the system does not require you to do so.
