segment (VCL)
Title: SEGMENT A TEST THAT USES VARIABLE VECTORS
The segment statement appears in the Vector Execution section of a test to segment tests that contain variable vectors that must be executed many times. The segmented section is terminated by the end segment statement. This feature is designed to aid in testing FlashRAM devices.
Variable vectors are not compressed because they are loaded into the vector RAM at runtime. Each variable vector is treated as a unique vector each time that it is executed. Each unique vectors require one location in the vector RAM, which has 8192 locations. Segmenting prevents overflowing the RAM by allowing the test vectors to be downloaded and executed in segments without exiting the test.
There can be only one segmented portion in the test and it must contain a repeat loop. The variable vectors in the segmented part will be downloaded to the vector RAM each time the segment is executed. All other vectors in the test will be downloaded at the beginning of the test and will remain there until the test ends.Other vectors includes all fixed vectors, in or out of the segmented part, and variable vectors that are located before or after the segmented part.
When the test is executed, all vectors in the vector RAM are executed for each download of segmented vectors. All drivers are set to their high-impedance state while the next set of vectors are downloaded. This enables you to structure the test in three parts, all of which are executed each time a segment is downloaded:
1 Initialize the device.
2 Program and test the device (segmented part of the test).
3 Cleanup to shut the device down while the next segment is downloaded.
Syntax
  segment <number of vectors>
  <number of vectors> is an <integer constant>
Parameters
<number of vectors>
The number of times each variable vector will be saved during each download. Refer to the description of segments in Digital Testing for an explanation of this value and how to select it.
Example
  ! in the Declaration section
     . . .
  data S_Record_Address to groups Address1
     file "S_records" 32768 s record address
  end data
  data S_Record_Data to groups Data1
     file "S_records" 32768 s record data
  end data                  . . .
  ! in the Vector Execution section
     . . .
  segment 2048
     repeat 32768 times          ! program and test FlashRAM
        homingloop 25 times
           . . .
           execute Write
           execute Data_Write drive data S_Record_Address    ! variable vector
           execute End_Cycle
              . . .
           execute Write
           execute Data_Write drive data S_Record_Data       ! variable vector
           execute End_Cycle
              . . .
           execute Verify
           execute Data_Read receive data S_Record_Data  exit if pass
                                                             ! variable vector
           execute End_Cycle
              . . .
        end homingloop
        next Address1
        next Data1
     end repeat
  end segment
        . . .
