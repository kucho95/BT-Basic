fetch (VCL)
Title: FETCH CAPTURED DATA TO THE FORMAL VARIABLES
The fetch function is used in the Vector Execution section of a VCL test to transfer the captured data from the capture RAM and save it in the formal variables, designated by the test digital statements.
Tests with parallel capture can have more than one fetch function. Each fetch writes over the existing data in the specified variable(s)—you cannot append data to a variable. The fetch also resets the capture RAM so that the same data cannot be fetched more than once.
Tests with serial capture can have only one fetch function and it must be the last function executed in the test.
The fetch function specifies just one variable and the actual results are fetched from the capture RAM and stored in the specified variable. Refer to Vector Control Language (VCL) in Digital Testing for more information on data capture.
The following table shows the relationship between received states and actual results (rh is the receiver‑high threshold set in the test).
 
Table F-2 Received states and actual results

1 (above rh)

0
The way the fetched data is formatted in the variable depends on the pack parameter in the capture—pack function.
Because the time that a fetch takes cannot be predetermined, the test pauses during the fetch and the driver states are held from the previous vector. Therefore, the test requires a test time function or the test is inhibited by the SAFEGUARD safety analysis routine. If this is not acceptable, use the with delay for cooling keyword; the drivers are set to their high‑impedance states during the delay.
Syntax
  fetch <variable>
  fetch <variable> with delay for cooling
     <variable> is numeric and can be:   <label>
                                         <label>(*)
Parameters
 
<variable>
The identifier of a numeric variable. The identifier must represent either a simple variable or a one‑dimensional array. Individual array elements and multi‑dimensional arrays cannot be specified.
Use an asterisk to specify an array, as in A(*). The same variable cannot be used twice in the same function
Examples
  test digital; Serial_Number, A(*)
  test digital; B(*)
     . . .
  fetch Serial_Number
     . . .
  fetch A(*)
     . . .
  fetch B(*)
General Information
If you need to use the same variable more than once, you must halt or pause the test and return to BT-Basic to process the data after each fetch. If you halt the test, or if you use the with delay for cooling, the drivers are set to their high‑impedance states. Therefore, you may need to reinitialize the device or re‑execute the preconditioning vectors after the pause or delay.
