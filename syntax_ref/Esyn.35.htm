end unit (VCL) (ITL)
Title: END DIGITAL UNIT
The end unit function marks the end of a digital unit in the Vector Execution section of the test (see the unit function).
In ITL, this is used in the disables section and in the silicon nails test.
Syntax
  end unit
Parameters
(none)
Examples
  unit "Testing Preset Line of the Flip‑Flop"
     execute Clear_high
     execute Preset_low
     execute Testpreset
  end unit
General Information
(none)
