display format (DEBUG)
Title: DEFINE CHARACTERS IN THE STATES DISPLAY
The display format function changes the characters used in the states display (see the display states function). The standard display characters are 1's, 0's and X's, representing high (H), low (L) and don't care (X), respectively. These can be changed to any printable ASCII characters.
The display format function also changes the characters used to represent failures with the display dump function. The standard characters are F for failed high; and f for failed low. These too can be changed to any ASCII characters.
Each state is represented by two characters: a transition character and a repeat character. The transition character is the character used when the state changes—from a 0 to a 1, for instance. The repeat character is used to represent the state when it does not change; for example, in a series of 0's following a 1 (1000 . . .), the first 0 is the transition state and the remaining 0's are repeat states. In the standard display set, each state uses the same character for the transition and repeat states.
As an example, a high state is currently represented by 1 for both the transition character and the repeat character; the low state is represented by 0 for both characters; and a typical string of states might be displayed as 001011110001. Assume that the repeat character for the high state is changed to * (display format H=1*). The string would now appear as 00101***0001. Similarly, if the repeat character for the low state is then changed to a period (display format L=0.), the string would appear as 0.101***0. .1 in the display.
The standard character groups, each of which uses the same character for the transition and repeat states, are:
• L = 0 represents low state
• H = 11 represents high state
• X = XX represents off or don't care state
• FL = ff represents failed low state
• FH = FF represents failed high state
Syntax
  display format <string constant>
     <string constant> consists of <character groups> separated by spaces
        <character groups> can be:   L=<ab>
                                     H=<cd>
                                     X=<ef>
                                     FL=<gh>
                                     FH=<ij>
           a c e g i are <transition characters>
           b d f h j are <repeat characters>
              <characters> are printable, ASCII characters
Parameters
<character group>
A state and the characters to be used in the display to represent that state. Only the states that are to be changed need to be included in the string; however, the other states can be included. The groups can be arranged in any order.
Letters L, H, X, FL, FH represent the states, as described in the introductory text, above. Either uppercase or lowercase letters can be used.
<characters>
Any printable ASCII characters. The two characters in any one group can be different or the same, but the characters used to represent the states in any one group must be different from the characters used to represent the states in all other groups.
Examples
     ! original display                  X000000111100111XXX0010
  display format "L=\. H=/' X=--"
     ! new display                       -\...../'''\./''---\./\
  display format "X=XX H=11 L=00"        ! returns to the original display
