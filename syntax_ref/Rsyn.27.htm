report fault syndrome (BT-Basic)
Title: REPORT HOW THE TEST EXECUTED
The purpose of this information is to help you to look for inconsistencies while you run an intermittent test several times.
With report fault syndrome on, the following messages are reported when the find start node statement is executed (note that vector number refers to user vectors and not to machine vectors):
  Test failed vector <failing vector number>, <tester channels that failed>
     Test failed vector   206,     21118, 21162
  Active fault syndrome:
  Test failed vector <vector number of active fault syndrome>, <tester channels that failed>
     Active fault syndrome:
     Test failed vector   161,     21137, 21118, 21162
Fault Dictionary syndromes:
     <failing vector number>:<syndrome in Mentor Graphics format>
     Fault Dictionary syndromes:
        161:----X XX-XX
        206:----- f-X-f
With report fault syndrome on, the following types of messages are reported each time the test node statement is executed:
  Node passed
     Node passed
  Node <node name>     failed vector <failing vector number>
     Node "high1"      failed vector   9
  Test passed
     Test passed
  Test failed vector <failing vector number>, <tester channels that failed>
     Test failed vector     3, 21606, 21607
  Test failed CRC, <brc’s that failed>
     Test failed CRC, 10968, 15387
If you are using a fault dictionary to make the diagnosis, the report fault syndrome on statement prints the Primary Faults Syndrome section of the repair report. This section shows the vector number and failed nodes used as the initial fault syndrome for a multiple vector analysis. This section appears as follows:
  Primary Faults Syndrome:
  Test failed vector <first failing vector number>
  Failed output nodes:
     <failing node>
     <failing node>
        .
        .
        .
     Primary Faults Syndrome:
        Test failed vector 18
        Failed output nodes:
           OUT1
           OUT4
Syntax
  report fault syndrome off
  report fault syndrome on
Parameters
(none)
Example
  report fault syndrome on
