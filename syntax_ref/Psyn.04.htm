panelfailed (BT-Basic)
Title: RETURN NUMBER OF FAILING BOARDS ON A PANEL
The panelfailed function returns the number of boards that failed while testing a panel of boards. Each time this function is invoked, its value is calculated from the value of the Boardfailed variable for each board on the panel.
 
 
When testing a multi-board panel, a separate Boardfailed variable is maintained for each board on the panel.
Syntax
  panelfailed
Parameters
(none)
Example
     ! Print the status of each board on the panel. Then print the status of the panel.
  for I = 1 to Number_Of_Boards
     board number is I
     if boardfailed then
        print "board "; I; " failed"
     else
        print "board "; I; " passed"
     end if
  next I
  if panelfailed then
     print panelfailed; " BOARDS ON THE PANEL FAILED"
  else                              ! For example, the line above might print:
     print "PANEL PASSED"           ! "5 BOARDS ON THE PANEL FAILED"
  end if
  board number is *
General Information
The panelfailed function is most meaningful when testing multi-board panels. When testing single boards, that is, board number is, the panelfailed function returns the same results as the boardfailed function.
