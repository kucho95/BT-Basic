recall display from (DEBUG)
Title: RECALL DEBUG SETTINGS FROM A FILE
The recall display from statement recalls the debug data previously saved by a save display statement. Recalling the data enables you to continue debugging from the point where you saved the data.
When you use the recall display from statement, you must be currently debugging the same device as you were when the data was originally saved. The statement then recalls the debug data from the file. Any information currently in the display window is overwritten.
The save display statement does not save data for the device itself. Therefore, after recalling the display, execute a display update statement.
Syntax
  recall display from <file id>
     <file id> is a <string expression>
Parameters
<file id>
The identifier of the file from which the display data is to be recalled.
Example
  debug "digital/u37"
     . . .
  save display to "debug_37"
  ! later that night
     . . .
  debug "digital/u37"
  recall display from "debug_37"
  display update
     . . .
