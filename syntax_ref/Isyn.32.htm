inputs scan (VCL)
Title: BOUNDARY-SCAN SHIFT REGISTER INPUTS
The inputs scan function appears in the Declaration section of a VCL test. It identifies a boundary-scan resource needed to test boundary-scan devices. This resource type can be defined only once in a boundary-scan test. The group must have only one node specified for this resource.
Syntax
  inputs scan <group id>
     <group id> is a <label>
Parameters
<group id>
The identifier of a single-node group that declares the input to the boundary-scan chain. The group must have been defined in an assign function. This is typically assigned as TDI.
Examples
  inputs scan  TDI
General Information
This function can only be used with the InterconnectPlus software option.
