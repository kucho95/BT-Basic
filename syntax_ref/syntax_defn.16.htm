Label
A label is used as a name. It appears in several different elements such as identifiers for variables, and as labels for program lines, subroutines and user‑definable functions.
A label can have from one to thirty-two characters; the first character must be an uppercase letter. The remaining characters can be letters, numbers or underscores. Upper and lower case letters used in a label are the same, except the first letter. For example, HELLO and Hello are equivalent.
A label placed at the beginning of a program line can be referenced by other statements (for example, goto) to access that line (see Line Label).
Example 8 contains examples of labels.
Example 8  
  Start:         ! a label followed by a colon is a line label; in this
                 ! case it identifies the point called "START"
                 ! in the program
  Test1            ! label as an identifier of a numeric variable
  Test_Heading$    ! label followed by "$" identifies a string variable
 
File names do not contain labels. File names can have a maximum of 255 characters and they are case sensitive (that is, myfile and Myfile are different files).
