test powered (ANALOG)
Title: MARK THE BEGINNING OF AN ANALOG POWERED TEST BLOCK
The test powered statement and a corresponding end test statement mark the beginning and end of an analog functional test block. The test powered analog statement marks the beginning of an analog test block. The test powered mixed statement marks the beginning of a mixed analog and digital test block.
Analog powered test blocks are executed from the testplan with the test (BT-Basic) statement. The test (BT-Basic) statement specifies the test block by path name.
To pass parameters to and from the test block, the variable id must be included with the test (BT-Basic) statement.
Syntax
  test powered analog
  test powered analog; <variable>
  test powered analog; <variable>, <variable>
  test powered analog; <variable>, <variable>, . . <variable>
  test powered mixed
  test powered mixed; <variable>
  test powered mixed; <variable>, <variable>
  test powered mixed; <variable>, <variable>, . . <variable>
     <variable> is a <numeric variable>
Parameters
<variable>
A numeric variable.
Example
  test powered analog; R
     clear connect s to "node_1"; i to "node_2"; l to "node_3"
     source dcv, amplitude 5, icompliance 0
     detector dcv, expect 2
     measure 2.1, 1.9, R
  end test
General Information
Any variables in the test powered statement must match the variables in the corresponding test (BT-Basic) statement in number.
