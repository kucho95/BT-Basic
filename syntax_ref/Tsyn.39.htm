time$ (BT-Basic)
Title: DATE AND TIME
The time$ function returns a 26‑character string containing the current date and time. This is the date and time as maintained by the system.
Syntax
  time$
Parameters
(none)
Example
  print "** "; time$;" **"     ! prints   **   Sun Dec 25, 1988   4:29 pm **
General Information
(none)
