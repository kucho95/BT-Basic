trigger (ANALOG)
Title: SET UP AN ANALOG TEST TRIGGER
The trigger statement controls the triggering for analog functional tests.
Triggers to, and from, external instruments use the functional ports on the testhead:
• The trigger <instrument name> statement sends a trigger to the specified instrument.
• The trigger <instrument name> from analog statement specifies which instrument is to be triggered. The trigger is sent by the initiate trigger (analog) statement.
• The trigger analog from <instrument name> statement prepares the test to receive a trigger from the specified instrument. The trigger is armed with the arm statement. The wait for trigger statement instructs the test to wait up to the specified number of seconds for the trigger to occur before executing the next statement.
Triggers from the device under test use the rcva bus:
• The trigger analog from rcva statement prepares the test to receive a trigger (falling edge) from the device under test. There must be a connect statement to connect the specified node to the rcva bus. The trigger is armed with the arm statement, and the wait for trigger statement instructs the test to wait up to the specified number of seconds for the trigger to occur before executing the next statement. This statement resets any detectors that use the rcva bus for their input.
Syntax
  trigger <instrument name>
  trigger <instrument name> from analog
  trigger <instrument name> from digital
  trigger analog from rcva
  trigger analog from <instrument name>
     <instrument name> is a <string expression>
Parameters
 
<instrument name>
The designator of the external instrument.
Example
This test measures the voltage on node out when node Trig goes low:
  1.  connect rcva to node Trig.
  2.  connect i and l to the signal you want to measure.
  3.  set up the detector.
  4.  instruct the test to trigger from rcva.
  5.  arm the trigger.
  6.  instruct the system to wait up to 5 seconds for rcva (node Trig) to go low.
  7.  when rcva does go low, execute the measurement.
  test powered analog
     connect reva to "Trig"
     connect i to "out"
     connect l to "GND"
     detector dcv, expect 5.05
     trigger analog from rcva
     arm trigger
     wait for trigger 5
     measure 5.05, 5
  end test
This test waits for a trigger from an external instrument named dcsource. Upon receiving the trigger, the test sends a trigger to the external instrument dvm.
  test powered analog; Result
     source none
     detector none
     clear connect "dcsource" to "node_1"; "dvm" to "node_2"
     trigger analog from "dcsource"
     arm trigger
     pause             ! Return to BT-Basic to program the external instruments.
     wait for trigger 5
     trigger "dvm"
     pause             ! Return to BT-Basic to read the result from the DVM.
     report analog 5.05, 5, Result
  end test
General Information
Any external instrumentation must be declared in the board configuration file.
