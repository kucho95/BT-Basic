print (ANALOG)
Title: SEND A MESSAGE TO THE SPECIFIED DEVICE
The print function outputs a message to the current printer is device.
Syntax
  print
  print <message>
     <message> is a <string expression>
Parameters
<message>
Message to be sent to the current printer is device.
Example
  on failure
     report "Part Num: 1145-0916; Location: L2"
     exit test
  end on failure
  print "Set Switch to Position 1"
  clear connect s to "SW1-1"; i to "SW1-2"
  switch "1", 5, ad
  clear connect s to "SW1-2"; i to "SW1-3"
  switch "2", 100k, op
  print "Set Switch to Position 2"
  switch "3", 5, ad
  clear connect s to "SW1-1"; i to "SW1-2"
  switch "4", 100k, op
