wait for start (BT-Basic)
Title: WAIT FOR START KEY
The wait for start function pauses the program and waits for the operator to press the START key, or the ENTER key if the or enter parameter added. What occurs next depends on which key is pressed: The selected key continues the program (see the next paragraph), STOP stops it, and BREAK (on the terminal keyboard) breaks the program. During the wait, the system also responds to the fixture vacuum control statements such as faon and faoff.
The purpose of wait for start is give the operator time to load the board to be tested while the test program is running. The wait for start function resets the boardfailed and dutfailed functions, clears all buffered log data, and any failure data for the probe failures function. When the operator presses the respective key, the system executes auxdisconnect 1 through auxdisconnect 5 to open the external relays; to prevent this, add the keep aux parameter to the wait for start function.
Syntax
  wait for start <optional parameter>
  wait for start <optional parameter>; keep aux
Parameters
<optional parameter>
or enter
Example
  ! program set‑up statements
        . . .
  Start_Test:
        . . .
  ! test board
        . . .
  print "Place new board on fixture and press START."
  ! wait for start
  wait for start or enter
  goto Start_Test
        . . .
  end
General Information
In the testplan, wait for start is used so that a batch of boards can be tested in one run. This speeds up the throughput of your test because of the overhead time which is saved. It also enables data logging and failure reporting for batches of boards.
