include (SAFEGUARD)
Title: INCLUDE STATEMENTS FROM ANOTHER FILE WHILE COMPILING
The include function is used in a SAFEGUARD file to reference another file. The function instructs the compiler to read the code from that other file and treat it as if it were a part of the original file.
A file can contain any number of include statements. include files can be nested up to 9 deep.
Syntax
  include <file id>
     <file id> is a <string constant>
Parameters
<file id>
The identifier of the SAFEGUARD file to be included. (Except for file ids that start at the root,) the include assumes that the file id is specified with respect to the current directory. If it then cannot find the file, the include assumes that the file id is specified with respect to directory $I3070_ICT_ROOT/standard/safeguard (that directory contains all of the parameter files for the standard libraries).
Examples
  ! Safeguard file for custom library "my_lib"
     parameters "my devices"
        package ceramic
     end parameters
     include "my_parameters"        ! in directory "my_lib"
     include "standard_ttl"         ! in directory "$I3070_ICT_ROOT/standard/safeguard"
     use parameters "my devices" for "my_74wb99"
     use parameters "standard_ttl" for "my_counter"
     use parameters "my_parameters" for "my_adder"
General Information
The safeguard files in the standard libraries include all of their parameter blocks from files in directory $I3070_ICT_ROOT/standard/safeguard. If you wish, you can include the same blocks in your custom libraries, as shown in the example above.
