translate faults (BT-Basic)
Title: FAULT DICTIONARY TRANSLATOR
The translate faults statement translates a fault dictionary file created on a design system by Mentor Graphics’s QuickFault simulator into a fault object file. This fault object file can be used by the Keysight ICT system.
When you execute this statement, your current working directory should contain the fault configuration file.
If it does not, you must specify the pathname to the directory containing this file.
The window option causes the translator to open another BT-Basic window where it will run the translation. If you do not specify this option, the translator runs in the BT-Basic window from which you type the command.
Syntax
  translate faults
  translate faults <directory id>
  translate faults; <options>
  translate faults <directory id>; <options>
     <directory id> is a <string expression>
     <options> can be:   window
Parameters
<directory id>
The directory that contains the fault configuration file, fault.config.
Example
  translate faults "../fault_data"
  translate faults; window
