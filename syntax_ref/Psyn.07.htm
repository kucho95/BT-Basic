partforms (BT-Basic)
Title: INVOKE THE PART DESCRIPTION EDITOR
The partforms function is executed from basic mode to invoke the Part Description Editor, which is used to enter or modify the descriptions of devices in part description libraries.
Syntax
  partforms
  partforms, <error variable>
  partforms, <error variable>;<option list>
  partforms;<option list>
     <error variable> is a <numeric variable>
     <option list> can be one or more of the following, separated by commas:
        <experience level>
        <backup level>
        <experience level> can be:
           standard
           advanced
           expert
        <backup level> can be:
           numbered
           unnumbered
           nobackup
Parameters
 
<error variable>
A numeric variable that indicates if the Part Description Editor could not be accessed, or if the Part Description Editor was aborted before it completed.
<option list>
A list of optional parameters that determine how the function works. (How these parameters work is also affected by how their defaults are defined in the .hp3070 environment file associated with each login.). The options are described below.
<experience level>
Can be used to restrict the user to a subset of the full system features. Permissible values are standard, advanced, and expert.
<backup level>
Determines whether unchanged copies (backups) of files are stored before modifying them, and how the backup is stored. Permissible values are:
• nobackup – No file backup is made
• numbered – Multiple backups are made as files change. To identify a numbered backup file, its name has a period, a tilde (~), and a unique number from 1 to 9 appended to its name; for example, file.1~. Number 1 is the most recent backup, and number 9 is the oldest. When more than 9 backups occur, the oldest backup file in the set is discarded and those remaining are renumbered. A numbered backup offers the greatest chance to recover from an error, but it also consumes the most disk space.
• unnumbered – A single backup is made as files change. Each new backup file overwrites the contents of the previous backup file. To identify an unnumbered backup file, a tilde (~) is appended to its name; for example, file~.
Example
  partforms, E !      Call the Part Description Editor; use an error variable.
General Information
The partforms function is not programmable.
