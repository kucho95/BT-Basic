board graphics highlight nodes (BT-Basic)
Title: CAUSES THE BOARD GRAPHICS VIEWER TO HIGHLIGHT NODE LOCATIONS
The board graphics highlight nodes function causes the board graphics viewer to highlight all locations on a specified node. The highlighting color denotes the node's status as active, fail, or pass.
Syntax
  board graphics highlight nodes <node list>
  board graphics highlight nodes <node list>, <error variable>
  board graphics highlight <status> nodes <node list>
  board graphics highlight <status> nodes <node list>, <error variable>
     <status> can be:   active
                        fail
                        pass
     <node id> is a <string expression>
     <error variable> is a <numeric variable>
     <node list> can be:   <node id>
                           <node id>, <node id>
                           <node id>, <node id>, . . . <node id>
Parameters
<status>
The optional status of the highlighted node, which can be:
• active – Highlight the node in yellow to draw attention to it.
• fail – Highlight the node in red to denote that it has failed.
• pass – Highlight the node in green to denote that it has passed.
If no value is specified for <status>, it defaults to active (yellow).
<node list>
A list of one or more nodes whose locations are to be highlighted.
<error variable>
The identifier of an optional error variable.
Examples
  board graphics highlight nodes "SIG_2"
                 ! Highlight in yellow (the default) all locations associated
                 ! with node SIG_2.
  board graphics highlight fail nodes "SIG_2", "V8", Error
                 ! Highlight in red all locations on nodes SIG_2 and V8.
                 ! Includes an error variable.
