val (BT-Basic)
Title: STRING TO DECIMAL VALUE
The val function returns the decimal value which is contained in the function's string argument. The number in the string must represent a valid decimal constant.
Any leading and trailing spaces and leading zeros are ignored.
Syntax
  val ( <string expression> )
  val ( <string expression> , <error variable> )
     <error variable> is a <numeric variable>
Parameters
<string expression>
String containing the decimal constant to be returned as the value of the function. If a conversion error occurs and there is an error variable, a value of zero is returned.
<error variable>
Identifier of an error variable.
Example
  print val( "  12345.6 ")               ! prints    12345.6
  print val( "‑4.500")                   ! prints    ‑4.5
  print val("23.23") + val(  "17.18  ")  ! prints    40.41
  print val ("32.4e‑3")                  ! prints    .0324
  A$ = "15.6" \ print val(A$)            ! prints    15.6
  print val("123 456", Err)              ! prints    0
