detector (ANALOG)
Title: DETECTOR SET UP
The detector function sets up a system detector to take a reading during an analog functional test. The function selects a detector and specifies its operating characteristics.
Syntax
  detector none
  detector <detector>, <options>
     <detector> can be:   dcv
                          acv
                          frequency
                          pulse falling
                          pulse rising
                          interval
                          digitizer
     <options> can be:   <option>
                         <option>,<option>
                         <option>,<option>, . . . <option>
        <option> can be:   a falling <value>
                           a rising <value>
                           average <value>
                           b falling <value>
                           b rising <value>
                           digital
                           expect <value>
                           fast <value>
                           gate <value>
                           rejection <value>
                           threshold <value>
                           timeout <value>
                           falling <value>
                           interval <value>
                           rising <value>
                           samples <value>
                           single step
                           terminate rcva
                           terminate rcvb
           <value> is a <numeric expression>
Parameters
 
<detector>
This element selects the detector. It can be:
• none – This is the default detector. It is used when a non‑ASRU detector is specified with an ASRU source.
• dcv – DC voltmeter.
• acv – AC voltmeter.
• frequency – Frequency counter. The frequency detector is connected to the device under test with the rcva or rcvc bus. The rcvc bus is used for the high speed frequency detector.
• pulse falling – Pulse width detector, falling leading edge.
• pulse rising – Pulse width detector, rising leading edge.
• interval – Dual channel time interval counter. The interval detector must be connected to the device under test with the connect rcva and connect rcvb statements. rcva is the start signal, and rcvb is the stop signal.
• digitizer – Performs multiple measurements on the input signal or waveform.
<options>
These are optional parameters which set up the operating characteristics of the selected detector. All options can be used with the ASRU detectors. The options are given in Table D-2.
 
Table D-2 Optional parameters
Option
Description
expect <value>
This option sets the detector range for the expected measured value. This option is used with the detectors listed below. <value> is a required <numeric expression>. The digitizer detector does not autorange so the expect option is mandatory and the <value> must be set properly. The unit depends on the detector
To avoid time-consuming autoranging, set the expect <value> equal to the high test limit. For a differential measurement with either input voltage greater than 10 volts with respect to system ground, set the expect value equal to the larger of the expected value with respect to system ground, or the input voltage with respect to system ground.
average <value>
This option directs the detector to take <value> number of measurements and average the sum. <value> is a <numeric expression>. This option is used with the dcv, frequency, pulse, and interval detectors. Do not use the average option with the digital option.
a falling <value>
This option specifies the falling threshold for the a channel. a falling is used with the interval detector. The range for <value> is –3.5 volts to 5.0 volts.
b falling <value>
This option specifies the falling threshold for the b channel. b falling is used with the interval detector. The range for <value> is –3.5 volts to 5.0 volts.
a rising <value
This option specifies the rising threshold for the a channel. a rising is used with the interval detector. The range for <value> is –3.5 volts to 5.0 volts.
b rising <value>
This option specifies the rising threshold for the b channel. b falling is used with the interval detector. The range for <value> is –3.5 volts to 5.0 volts.
fast <value>
This option directs the acv detector to take a fast reading. This option changes the range and accuracy of the measurement. The <value> is an optional flag that determines whether or not this option is used. A <value> of 0 instructs the system to ignore the option. A <value> of 1 instructs the system to use the option.
gate <value>
This option specifies a long or a short gate for the pulse and frequency detectors. A <value> of zero specifies a short gate (750uS), and a <value> of one specifies a long gate (150mS).
rejection <value>
This option directs the detector to reject 50 Hz and 60 Hz line frequency noise by integrating the measurement over a complete line cycle. <value> is an optional flag that determines whether or not the option is used. A <value> of 0 instructs the system to ignore the option. A <value> of 1 instructs the system to use the option.
digital
This option sets up the detector to receive digital triggers. It can be used on all detectors. Do not use the digital option with the average option.
timeout <value
This option sets the maximum length of time to wait on channel a for a trigger. It is used with the frequency, pulse, and interval detectors. The value of timeout can be from 0 to 9.9999 seconds. The timeout is 150m seconds unless otherwise specified.
For the digitizer detector, the timeout <value> option specifies the minimum length of time (in seconds) to wait for the measurements to complete before timing out. <value> can be from 0 to 4260. If no timeout <value> is specified, the digitizer detector waits 1 second for the measurements to complete before timing out.
threshold <value>
This option specifies the threshold value for the rcva input (the rcvc input is fixed at a TTL level). It is used with the pulse, time interval, and frequency detectors. The range is from –3.5 volts to 5.0 volts. If you do not specify a threshold value, a value of 1.4 volts is used.
falling <value>
Specifies that the digitizer detector be triggered when the measured waveform is on a falling edge and crosses the voltage specified by the <value> in volts. <value> can be from –100 to 100.
The falling <value> option cannot be used with the single step option.
interval <value>
Specifies the time interval between voltage samples (in seconds) for the digitizer detector. <value> can be from 25u to 31.2m. If no interval value is specified, the digitizer detector samples the waveform every 100u seconds.
The interval <value> option cannot be used with the single step option.
rising <value>
Specifies that the digitizer detector be triggered when the measured waveform is on a rising edge and crosses the voltage specified by the <value> in volts. <value> can be from –100 to 100.
The rising <value> option cannot be used with the single step option.
samples <value>
Specifies the number of samples the digitizer detector takes of the measured waveform. <value> can be whole integers from 1 to 8192. If <value> is not a whole integer, the system rounds the value to the nearest whole integer. If no samples <value> is specified, the digitizer detector takes 1024 samples of the measured waveform.
single step
Instructs the digitizer detector to take one sample of the measured waveform each time it receives a digital trigger.
The single step option requires the digital option to be included. The single step option cannot be used with the falling, rising, or interval options.
terminate rcva
Specifies that the terminators should be connected to the receiver rcva for the pulse, frequency, or interval detectors to improve the stability of the measurement.
terminate rcvb
Specifies that the terminators should be connected to the receiver rcvb for the interval detector to improve the stability of the measurement.
Examples
  detector dcv, expect300m     ! Set up a DC Volts Detector with a maximum
                               ! expected voltage of.3 volts.
  detector digitizer, interval 100u, samples 500
                ! Set up a digitizer detector to sample the measured waveform
                ! every 100u seconds, expect a maximum voltage of 10 volts,
                ! and to take a total of 500 samples.
