testhead is (BT-Basic)
Title: OPEN TESTHEAD
The testhead is 1 statement gives you access to, and control of, the test station hardware from any work station in the system.
The testhead is * statement releases control of the testhead.
When testhead is 1 is executed, the currently‑open testhead, if there is one, is closed. The referenced testhead is opened exclusively; if it is already open, a runtime error occurs. The statement is global so it can be executed from the terminal, from the main program, or from a subprogram and it will be in effect for all environments. In addition, it remains in effect until another testhead is statement is executed or until you log off the system (exit statement).
The testhead is 1 statement does the following:
• Checks for a valid fixture enable if a fixture is currently locked on the testhead.
• Reads the board configuration file (config) and verifies that the hardware needed to test the board is listed.
• Sets the DUT power supplies to 0 volts.
• Turns off vacuum and resets the vacuum well defaults.
• Opens the auxiliary relays.
• Enables the operator foot switch and displays the operator keypad.
• Sets the system variables and statements including:
• safeguard all
• boardfailed and dutfailed to false (0)
• save failures off
• acknowledge all failures
• learn off
• autoadjust on
• autoadjust on — for a Mux system which does not include a Board Handler
• autoadjust off — for a Mux system which includes a Board Handler
• Issues the handler recover statement if a Board Handler is present but has not been booted (Mux systems only).
• Turns object checking on; see the syntax description of the object checking statement.
Syntax
  testhead is <number>
  testhead is <number>, <error variable>
  testhead is *
  testhead is *, <error variable>
     <number> is a <numeric expression>
     <error variable> is a <numeric variable>
Parameters
<number>
The number of the selected testhead. This is a positive integer, the only legal value is 1.
*
Releases control of the testhead.
Example
  testhead is 1     ! accesses testhead 1   ("/dev/th1")
  testhead is *     ! releases testhead 1
General Information
When the testhead power on statement turns on the power to the testhead it also executes a testhead is 1 statement.
