btgetenv$ (BT-Basic)
Title: RETURN THE VALUE OF THE ENVIRONMENT VARIABLE
Use the btgetenv$ command before invoking the environment variable "I3070_ICT_ROOT" in a BT-Basic window.
There are two uses for this syntax.
• To return the value of the environment variable
• Use after a BT-Basic command that is referenced to the root directory.
Commands which normally contain paths, and therefore require the use of btgetenv$, include the following: msi, load, copy, save, get, store, unlink.
Syntax
To return the value of the environment variable, enter the following.
   btgetenv$ ("I3070_ICT_ROOT")
To use a command that references the root directory, enter the following.
   <command> btgetenv$ ("I3070_ICT_ROOT") & "<rest of pathname>"
Parameters
<command>
The command which uses a path name, and therefore, requires the use of the btgetenv$ command in a BT-Basic window.
<rest of pathname>
The path name related to the command, excluding "I3070_ICT_ROOT" which has already been specified.
Example
To return the value of the environment variable, enter the following.
   btgetenv$ ("I3070_ICT_ROOT")
To use a command that references the root directory, enter the following.
   msi btgetenv$ ("I3070_ICT_ROOT") & "/diagnostics/th1/"
   get btgetenv$ ("I3070_ICT_ROOT") & "/diagnostics/th1/config"
General Information
The environment variable is used to enhance portability between UNIX and Windows systems, and between Windows systems with the software on different drives.
BT-Basic testplans use the environment variable with the btgetenv$ statement. This allows testplans created on an Windows controller or a UNIX controller, which have been converted, to normally run without modification on either operating system.
