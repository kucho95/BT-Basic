fetch (edit)
Title: FETCH A LINE FROM THE WORKSPACE
The fetch function copies the specified line from the workspace into the command line on the screen. Once in the command line, the line can be executed. The fetched line remains unchanged in the workspace.
Syntax
  fetch
  fetch <line number>
     <line number> is a <numeric expression>
Parameters
<line number>
The (integer) number of the line to be copied into the command line. If omitted, the line which the cursor is currently on in the workspace is used.
Example
  fetch 34
  Line = 132 \ fetch Line
General Information
The fetch function is not programmable.
fetch is the complement of the store line softkey.
