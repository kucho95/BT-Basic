tdi (ITL)
Title: IDENTIFES TEST DATA IN NODE
The tdi statement identifies the test data in node of the boundary-scan chain. A name is assigned to this node using the tdi statement.
Syntax
tdi <node name>
tdi <node name> <card list>
  <node name> is a <string expression>
  <card list> can be:   hybrid
                        channel          ! On Mux systems only
                        hybrid; channel  ! ";" indicates first choice preferred
                        channel, hybrid  ! "," indicates no preference
Parameters
<node name>
The name of the node assigned to tdi.
Examples
  tdi "Buffer-2"
  tdi "D_1" hybrid
