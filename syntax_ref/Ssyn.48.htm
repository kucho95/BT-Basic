softkey (BT-Basic)
Title: REDEFINE A SOFTKEY
Each softkey, at the top of the keyboard, has a system default definition. However, with the softkey statement you can change the definition of any softkey.
This statement allows you to specify a particular softkey and enter a (new) definition. You can also identify it as an immediate execute or text‑type softkey. An immediate execute softkey executes its definition as soon as you press the key.
A text‑type softkey inserts its definition in the text (on the screen) at the pending line when you press the key. Finally, the softkey statement allows you to enter a label, to appear on the screen, for the new definition.
New definitions are stored locally until they are saved with a softkeys to or softkeys over statement.
Syntax
  softkey <key>,<process>,<label>
  softkey <key>,<process>,<label>,<definition>
  softkey <key>,<process>,<label>,,<error variable>
  softkey <key>,<process>,<label>,<definition>,<error variable>
     <key> is a <numeric expression>
     <process>, <label>, and <definition> are <string expressions>
     <error variable> is a <numeric variable>
Parameters
 
<key>
A numeric expression which identifies a particular softkey (f1, f2, etc.). It must resolve to a number from one to eight inclusive, after rounding.
<process>
A string expression which identifies the definition type: immediate execute or text‑type. It must start with e, r, or t (after leading blanks are removed) to specify one of three types:
• e – The definition string is an executable BT-Basic command (immediate execute). If the cursor is not on the command line, then it is placed there when the key is pressed. The definition is typed and executed. If the cursor was in the workspace, it is returned there after execution.
• t – The definition string is text‑type. When the key is pressed, the definition is typed at the current cursor location. The cursor remains at the end of the string after the key is pressed.
• r – The definition string is text‑type. When the key is pressed, the definition is typed at the current cursor location. However, unlike t, a carriage return is issued after the string is typed.
<label>
A string expression which defines the softkey label. It must resolve to no more than 16 characters after trailing blanks are removed. It is displayed as two lines on the screen, with 8 spaces each for the top and bottom. For proper spacing, keep this in mind when you enter a label in the statement.
<definition>
A string expression which defines the softkey. It can be an executable BT-Basic command or a text string. It can consist of up to 256 printable characters.
<error variable>
The identifier of an error variable.
Example
  softkey 2,"e"," Resave File ","re‑save"
  softkey 4,"t","Reminder","Adjust pot to defined value"
General Information
Softkey definitions can be used in the test monitor mode and program monitor mode. In the test monitor mode, you are limited to calling subroutines, executing individual commands, or loading and running a new program. You cannot continue the test program or goto a label.
