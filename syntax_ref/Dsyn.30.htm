disabled device (VCL) (ITL)
Title: DESCRIPTION OF DISABLED DEVICES
The disabled device statements are placed by the i3070 In-Circuit Test Software in the Declaration section of an executable test to indicate which devices are disabled while that test is being executed.
These statements are used by the SAFEGUARD analysis routines in determining the safe time that the test can run. If you change the disabling vectors in the executable test so that the disabled outputs change, you should modify the associated disabled device function accordingly and recompile the test.
Syntax
  disabled device <designator> pins <pin list>
     <designator> is a <string constant>
     <pin list> can be:   <pin id>
                          <pin id>,<pin id>
                          <pin id>,<pin id>, . . . . <pin id>
        <pin id> can be:   <numeric constant>
                           <string constant>
Parameters
<designator>
The reference designator of the device to be disabled; the designator can have up to 48 characters. This is the device designator name entered in the i3070 In-Circuit Test Software.
<pin id>
The identifier of a disabled output pin from the disabled device.
Examples
  disabled device "U3" pins 2,3,5,"08"     ! Disabled device pins.
