confirm (misc)
Title: SCHEDULE CONFIRMATION SOFTWARE
The confirm function is used to run the confirmation routines that verify proper system operation. While these routines are running, users cannot access the testhead.
The confirmation program automatically senses the presence of the Confirmation/Diagnostics fixture. If the fixture is not present, a subset of the full set of confirmation tests is run. Because this subset of tests excludes any tests that require the fixture, confirmation is more thorough when the fixture is present.
Syntax
  confirm
  confirm, <error variable>
     <error variable> is a <numeric variable>
Parameters
<error variable>
The identifier of an error variable.
Examples
  confirm            ! Runs the "confirmation" routines
  confirm, Err       ! Includes an error variable
General Information
The confirm function is typically not used by operators of the test system. Instead, system verification is done by placing the Confirmation/Diagnostics fixture on the testhead, pressing start on the operator keypad, and letting the system's autofile feature automatically load and run the confirmation routines.
The confirmation routines do not verify system specifications.
