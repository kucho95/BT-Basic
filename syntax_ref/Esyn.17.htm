end homingloop (VCL)
Title: END HOMING LOOP
The end homingloop function is used in the Vector Execution section of a digital test to mark the end of a homing loop, both the counted and uncounted loops. Refer to the homingloop function for more information.
Syntax
  end homingloop
Parameters
(none)
Examples
  homingloop 4 times
     execute Clock0
     execute Clock1 exit if pass
  end homingloop
General Information
(none)
