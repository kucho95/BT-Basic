silicon node (ITL)
Title: IDENTIFIES SILICON NODE TO BE TESTED OR HELD
The silicon node statement is used within a nodes block to identify an un-nailed boundary-scan node to be tested or held in a fixed state. This statement typically appears in interconnect, buswire, powered shorts, Cover-Extend or custom test blocks. Only the hold high and hold low formats may appear in connect tests. The unqualified hold action can only appear in the Cover-Extend nodes block.
Syntax
  silicon node <node name> <action> <device.pin>, <device.pin>,...<device.pin>
     <action> can be:   test
                        hold
                        hold high
                        hold low
  <node name> is a <string expression>
  <device.pin> is a <string expression>
Parameters
<node name>
The name of the node that will be tested.
<action>
Defines how the node will be treated: either tested or held. Only nodes with a boundary scan output or bidirectional can be held. The hold action without a qualifier (high or low) is only valid in a Cover-Extend test.
<device.pin>
Identifies the device connections to the node to be tested.

Refer to the ITL sample files in Boundary-Scan Testing for an example in context.
