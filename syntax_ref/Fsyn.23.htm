findm (edit)
Title: FIND A STRING IN THE MARKED AREA OF THE WORKSPACE
The findm function (find marked) finds the first occurrence of a string of characters in the marked area of the workspace. findm operates exactly like the find function except that findm works only in the marked area; see the description of the find function for details.
Syntax
  findm <string expression>
  findm <string expression>,<error variable>
     <error variable> is a <numeric variable>
Parameters
<string expression>
The string of characters to be found.
<error variable>
The identifier of an error variable.
Examples
  findm "Test2"
  F$ = "test U1" \ findm F$
  findm "Test2", Err         ! Includes error variable
