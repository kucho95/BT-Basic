dutfailed (BT-Basic)
Title: DUTFAILED VARIABLE
The dutfailed function returns the current value of the Dutfailed variable. This variable indicates if currently executed test passes or fails. The Dutfailed variable is set to 0 at the start of each test, and to 1 if the test fails. Use the dutfailed function anywhere in the testplan to determine if any device test fails.
If you are testing a panel of boards, the dutfailed function applies only to the current board defined by the board number is function.
The boardfailed variable performs the same function on a board level. It indicates if an previously tests have failed. The boardfailed function returns the current value of the Boardfailed variable. See the syntax description of the boardfailed function.
The Boardfailed and Dutfailed variables are also controlled by the pass device, fail device, and clear failures statements. See the syntax descriptions of these statements for more details.
Syntax
  dutfailed
Parameters
(none)
Examples
  ! DO NOT TEST ANY MORE DEVICES IN THIS SUBROUTINE IF THIS DEVICE FAILS.
     if dutfailed then
        subexit
     end if
