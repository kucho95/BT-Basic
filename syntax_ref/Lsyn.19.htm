load (BT-Basic)
Title: BRING A FILE INTO THE WORKSPACE
The load function clears the system workspace and copies the specified file into it. If the mode parameter is included, the workspace is forced to that mode; if the mode parameter is omitted, the mode recorded in the file is set.
If the specified mode differs from the mode recorded in the file, then the contents of the file are syntax checked (except in text mode) based on the specified mode. If the file is of a type for which there is no syntax checking—for example, bcf—it is retrieved as a text file.
Any characters which cannot be printed by the system are converted to question marks (?). Lines longer than 2048 characters are truncated to 2048 characters.
Syntax
  load <file id>
  load <mode> <file id>
  load <file id>;<option>
  load <mode> <file id>;<option>
     <file id> is a <string expression>
     <mode> can be:   analog
                      basic
                      bsdl
                      configuration
                      digital
                      pins
                      safeguard
                      serial
                      shorts
                      states
                      testorder
                      text
                      wirelist
     <option> can be:   window
                        nowindow
Parameters
 
<file id>
The identifier of the file to be brought into the workspace. The file must exist, it cannot represent a device, and it must be an ASCII file.
<mode>
Specifies the operating mode for syntax checking.
<option>
Either window or nowindow.
• window opens a new window
• nowindow suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Examples
  load "my_file"
  load digital "/library/ttl/7400/"   ! Change mode to digital
  load text "myfile";window           ! Edit "my_file" in a new window in "text" mode.
General Information
The load function is not programmable. The load and get statements are identical.
