display user vectors (DEBUG)
Title: INCLUDE USER VECTOR NUMBERS ON THE DISPLAY
The display user vectors function creates a new header area containing user vector numbers. If user vectors are not displayed, then only machine vector numbers are displayed.
Machine vector numbers may be difficult to interpret if the digital test contains any no-op vectors. The display user vectors off function removes the user vector number header.
Syntax
  display user vectors
  display user vectors off
Parameters
(none)
Examples
  display user vectors
  display user vectors off
General Information
The .hp3070 file contains a debug function which controls whether user vector numbers are displayed. The default for the function in the .hp3070 file is set to no which causes no user vector numbers to be displayed. If the function is set to yes, user vector numbers are displayed:
  DigitalDebug.UserVectors: yes
Use the display user vectors function to override the setting of the debug function in the .hp3070 file.
