global (BT-Basic)
Title: DECLARE GLOBAL VARIABLES
The global function is used in a subprogram (a subroutine or a user‑definable function) to declare which parameters in the main program can be accessed by that subprogram. A subprogram can operate directly on global parameters, without their having to be passed to the subprogram when it is called.
Global parameters are standard variables and @<names> in the main program: they have no special characteristics. They become global only when they are listed in a global function in a subprogram. A parameter must be declared as global in each subprogram in which it is to be used.
A subprogram can have any number of global statements (including none). They follow immediately after the sub (subroutine) or def (user‑definable function) statements. Any arrays appearing in a global function must have been defined in the main program before that function is executed.
Simple variables that do not yet exist can be declared global in a subprogram. Those variables then exist in the main program, and can be declared as global in other subprograms. A global function can be executed only in a subprogram.
Syntax
  global <parameter>
  global <parameter>,<parameter>
  global <parameter>,<parameter>, . . . <parameter>
     <parameter> can be:   <variable id>
                           @<name>
        <variable id> can be numeric or string
        [use <array id>(*) to specify a complete array]
        <name> is a <label>
Parameters
<variable id>
The identifier of a variable to be declared as global. A variable must be either a simple variable, or a complete array; array elements and substrings cannot be declared global.
@<name>
An @<name> to be declared as global. An @<name> represents a file or device; see assign to (BT-Basic) for more information about @<names>; also see the definition of <label>.
Examples
  sub Xxxx
     global A, B(*), C$, D$(*), @E
      . . .
  subend
The next example shows global variables being passed between subroutines even though they do not appear in the main program.
  ! Main program
     call Sub_1            ! prints    76
                           !            Trombones
     end
     Sub_1
        global Numbers, Things$
        Numbers = 76       |  call Sub_2
        print Things$
     subend
     Sub_2
        global Numbers, Things$
        print Numbers      |  Things$ = " Trombones"
     subend
