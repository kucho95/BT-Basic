relay controls vacuum (CONFIGURATION)
Title: VACUUM RELAY DEFINITIONS
The relay controls vacuum statement defines the relay to vacuum port connections for the testhead. There are five relays and four ports available on the testhead.
This statement can only be used in the testhead configuration file—not in the board configuration file. The relay controls vacuum statement cannot be used within a bank definition block: marked by a bank and end bank statement.
Syntax
  relay <relay #> controls vacuum <port list>
     <relay #> is an <integer> (from 1 to 5)
     <port list> can be:   <range>
                           <range>, <range>
                           <range>, <range>, . . . . <range>
        <range> can be:   <port number>
                          <port number> to <port number>
           <port number> is an <integer> (from 0 to 3)
Parameters
<relay #>
Is the number of the relay being defined. There are five vacuum relays available, numbered 1 through 5.
<port number>
Is the number of the vacuum port to be connected to the relay. There are four vacuum ports available, numbered 0 through 3.
Example
  ! Testhead Configuration File
     ! CONFIGURATION FOR TESTHEAD
     relay 1 controls vacuum 0, 1
     relay 2 controls vacuum 2
     relay 3 controls vacuum 3
     bank 1
        board handler    ! Mux systems only
        module 1
           debug port
           cards 1 asru n revision
           cards 2 to 5 hybrid high accuracy double density
           cards 6 control xtpb
           cards 7, 9 to 11 hybrid high accuracy double density
           supplies 1 to 4
           ports ext1, ext2
        end module
     end bank
