report level is (BT-Basic)
Title: SELECT WHAT TO DO WITH FAILURE MESSAGES NOT SENT TO THE REPORT DEVICE
The report level is statement tells BT-Basic what to do with failure messages which would otherwise be directed to the report device.
Syntax
  report level is <option>
     <option> can be:
        none
        report
        log
        all
Parameters
<option>
Determines what happens to the failure message:
• none – The failure message is discarded.
• report – The failure message is sent to the report device only. This is the default.
• log – The failure message becomes log data, appended to the log buffer.
• all – The failure message is sent to the log buffer and to the report device.
Example
  report level is none
     ! The failure message is discarded.
  report level is report
     ! The failure message is sent to the report device.
  report level is log
     ! The failure message is sent to the log buffer.
  report level is all
     ! The failure message is sent to the log buffer
     ! and to the report device.
General Information
You can use rli$ to find the current report level; see the description of rli$ for details.
