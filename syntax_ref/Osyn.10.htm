on failure report (VCL) (ITL)
Title: REPORT ADDITIONAL FAILURE MESSAGE
The on failure report function enables you to specify a message that will be sent to the report is printer if the test fails. This message will be sent in addition to the standard messages generated when a test fails.
Syntax
  on failure report <message>
     <message> is a <string constant>
Parameters
<message>
The message to be printed with the standard failure report.
Example
  on failure report "If U16 has to be replaced, replace its associated capacitors."
