bineor (BT-Basic)
Title: BINARY EXCLUSIVE‑OR OF TWO INTEGERS
The bineor function returns a decimal, integer value which corresponds to the binary exclusive‑OR of the function's two decimal, integer arguments. Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. Values in the following ranges can be processed:
  16-bit operation: -2^15 <= value <= 2^15 - 1  (2^15 = 32768)
  32-bit operation: -2^31 <= value <= 2^31 - 1  (2^31 = 2147483648)
The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Syntax
  bineor ( <numeric expression> , <numeric expression> )
Parameters
<numeric expression>
The decimal, integer values which are to be exclusive‑OR’d.
Examples
  print bineor(3 ,10)             ! prints    9
  print bineor (3,‑11)            ! prints    ‑10
  R = ‑12 \ print bineor (R,‑4)   ! prints    8
