list source (BT-Basic)
Title: LIST A FILE TO THE DEVICE SPECIFIED BY THE PRINTER IS FUNCTION
The list source function copies a file to the device specified by the printer is function.
Syntax
  list source <source file id>
    <source file id> is a <string expression>
Parameters
<source file id>
A string expression that identifies the source file.
Examples
  list source "board"           ! Copies "board" file to the device specified by the
                                ! "printer is" function.
  list source "analog/r1"       ! Copies IPG Summary to the device specified by the
                                ! "printer is" function.
