input prompt (BT-Basic)
Title: INPUT DATA
The input prompt function reads in free-field format data input from the default input device. At login the default input device is the workstation keyboard but it can be changed to another device, or to a file, by the keyboard is function.
The function has a required prompt. When the workstation is the default input device, the prompt appears on the input dialog box or BT-Basic window to inform you what data to input.
When inputting from the keyboard, you respond to the prompt by typing the requested data. The easiest way to respond is to input one item at a time. Simply type each number or string and follow it with a RETURN. However, you can input more than one item at a time by following the rules listed below. The input data are assigned, in the order typed, to the variables listed in the function's variable list. The data must correspond, item for item, to the types (numeric or string) of the listed variables.
The rules applying to the data input are listed next. At least one data item must be input for each input prompt function.
Rules for numerical input
1 Numbers must contain only valid characters, in the proper order.
2 The delimiter between numbers can be a comma, a space, or a RETURN (EOL or EOR). Extra spaces before or after the delimiter are ignored.
3 A null input can be made to any one numeric variable-i.e., the variable retains its current value-by omitting the number and inputting just a comma (with or without spaces).
4 When all input variables are satisfied, any remaining input, up to the next EOR, is read and discarded. The input then terminates.
5 A blank line (a null record) also terminates the input. Any remaining input variables retain their current values.
6 Input data can cross record boundaries, but an individual item cannot.
Rules for string input
1 The RETURN (EOL or EOR) is a delimiter between strings. After the input, the input variable is the same length as the string assigned to it (the dimensioned length of the string cannot be exceeded; see the next step).
2 If an input string is longer than the dimensioned length of the variable to which it is assigned, the extra characters are assigned to the next variable, if there is one.
3 When all input variables are satisfied, any remaining input, up to the next EOR, is read and discarded. The input then terminates.
4 A blank line (a null record) also terminates the input. Any remaining input variables retain their current contents.
5 Input data can cross record boundaries, but an individual item cannot.
6 If the input prompt statement is looking for multiple string or numeric variables to be entered, each string or number entered will display a new input dialog box until all variables are satisfied.
String and numerical input
When both strings and numbers are to be input, the rules listed above apply. During the input, if a number follows a string on the same line, then the string must be the same length as the dimensioned length of the string variable to which it is assigned.
Syntax
input prompt <prompt>; <variable list>
 
<prompt> can be a <string constant> or an expression>
    <variable list> can be:   <variable>
                              <variable>,<variable>
                              <variable>,<variable>, . . . <variable>
          <variable> can be numeric or string
               [Use <array id>(*) to specify a complete array]
Examples
The first three examples are sequential:
input prompt "Enter three values"; A, B, C   ! User types   22.56,  -13,+0.3200
print A,B,C                     ! Prints    22.56              -13             .32
PROMPT$="Next three"  
input prompt PROMPT$; A,B,C     ! User types   12,,18
                                ! Note null input for variable B
print A,B,C                     ! Prints    12                 -13             18
input PROMPT$ ; A,B,C           ! User inputs     ,,99
print A,B,C                     ! Prints    12                 -13             99
The next example shows different ways to input the same data to three variables:
dim B$[8]
input prompt "next", A, B$, C
print A; B$; C
   ! 1. User types--   36
   !                   test
   !                   60
   !      Prints    36 test 60
   ! 2. User types--   36,test
   !                   60
   !      Prints    36 test 60
   ! 3. User types--   36 test     60
              ! (spaces)     ^^^^^
              ! Prints       36 test     60
   ! 4. User types--   36 test, 60
   !   A contains 36 | B$ contains the string "test, 60"
   !   a question mark appears, requesting input to variable C
General Information
Note that data entered from the keyboard is checked for errors, such as entering a string where a number is required, and can be corrected (edited) immediately.
