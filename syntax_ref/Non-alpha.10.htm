<= (BT-Basic)
Title: LESS THAN OR EQUAL TO
The less than or equal to operator compares two expressions to determine if the first is less than, or equal to, the second. If the relationship is true (the first is less than, or equal to, the second), a value of 1 is returned; if the relationship is false (the first expression is greater), a value of zero is returned. Relational operators have a priority of 4.
Syntax
  <expression> <= <expression>
     <expression> can be numeric or string
Parameters
<expression>
The quantities to be compared. Expression types cannot be mixed in the same statement; both expressions must be numeric, or both must be strings.
Numeric expressions are compared by value; strings are compared, character by character, according to the ASCII numerical equivalent of each character.
Example
  A=6.25 \ B= (-32) \ C= 6.25       ! assigns values to variables
  print B <= A                      ! prints  1
  print C <= A                      ! prints  1
  print A <= B                      ! prints  0
  if A<=B then print "not"          ! "if" statement checks relationship;
  print "greater"                   !   condition is not met, so skips to
                                    !   next statement
  Q$ = "dog" \ D$ = "dog"
  print "cat" <= Q$                 ! prints  1
  print D$ <= Q$                    ! prints  0
  N$ = "7401" \  P$ = "74001"
  print N$ <= P$                    ! prints  0 (remember this is a string evaluation)
