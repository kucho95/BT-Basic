shorts (BT-Basic)
Title: INVOKE SHORTS MODE
The shorts statement clears everything currently in the workspace and sets the workstation to shorts mode. This mode must be selected to edit the shorts test file, shorts, which is generated by the i3070 In-Circuit Test Software and stored in the test program files for the PC board to be tested.
The statements entered in this mode are syntax‑checked to ensure that they are valid shorts statements. However, editing and other mode selection statements can be executed as usual in the command line.
Syntax
  shorts
  shorts;<option>
     <option> can be:
        window
        nowindow
Parameters
<option>
Either window or nowindow.
• window opens a new window in shorts mode
• nowindow suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Example
  msi "/pc_test/scopes/a9842c"     ! Selects board under test
  shorts                           ! Sets "shorts" mode
  get "shorts"                     ! Can also set "shorts" mode
     !
     ! Edit shorts file in the workspace
     !
  compile "shorts"             ! Recompiles and re-saves in original file
  basic                        ! Establishes "basic" mode
  shorts;window                ! Opens a new window and sets it to "shorts" mode.
General Information
The shorts statement is not programmable.
