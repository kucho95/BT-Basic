capture-pack (VCL)
Title: DESIGNATE DATA TO BE CAPTURED
The capture—pack function is used in the Declaration section of a VCL test. It determines the following:
• the pins (nodes) to be captured
• whether serial or parallel capture is selected
• the format of the fetched data (see the fetch function)
The pins to be captured are listed in the function's group list. Any type of pin (drivers, receivers and bidirectional pins) can be captured. However, clock pins and formatted pins cannot be captured. If bidirectional pins are designated, both their driven and received states are captured. The executable test does not compile if any of the groups of pins to be captured contain a pin that was assigned an asterisk (*) by the development software (see the VCL assign to function).
Serial or parallel capture is designated by the number of nodes in the capture—pack group list. A single node selects serial capture; more than one node selects parallel capture. Serial and parallel capture cannot both be used in the same digital test.
The function's optional pack parameter determines the number of vectors that are packed in each group in the data fetched from the capture RAM (refer to Vector Control Language (VCL) in Digital Testing).
Syntax
  capture <group list>
  capture <group list> pack <pack value>
     the format of <group list> is:
        <group id>
        <group id>,<group id>
        <group id>,<group id>, . . . <group id>
           <group id> is a <label>
Parameters
<group id>
The identifier of a group of pins to be captured. Data is captured for all of these pins whenever capturing is turned on in the test.
<pack value>
A value indicating the number of vectors that are packed together when the captured data is fetched.
If this value is omitted, it defaults to 1.
Example
  ! selects serial capture (only one pin)
       assign In to pins 1
       assign Out to pins 2 default "X"
          . . .
       inputs In
       outputs Out
       capture Out pack 16
  ! selects parallel capture (more than one pin)
       assign C1 to pins 3, 5, 7 default "XXX"
       assign C2 to pins 8, 10, 16, 22 default "XXXX"
       assign C3 to device "U6" pins 2, 7
          . . .
       outputs C1, C3
       bidirectional C2
       capture C1, C2
       capture C3         ! the "pack" value defaults to 1
General Information
The captured received pins must be set to X in all vectors that receive those pins when data is being captured. This prevents the pins from failing the test.
