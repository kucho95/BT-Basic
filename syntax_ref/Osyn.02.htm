object checking (BT-Basic)
Title: TURN OBJECT CHECKING ON OR OFF
Use the object checking function in the testplan to turn object checking on or off.
When object checking is on, every time a test is run the timestamp of the test object file is checked to determine if the object has been updated. If the test object has been updated, it is reloaded into the testhead.
When object checking is off, test object files are downloaded the first time they are run; they will not be checked on subsequent runs. If a test is updated, the new version will not be downloaded into the testhead.
We recommend that you turn object checking on during test development. Note that during debug, object checking is automatically turned on. Turning object checking off during production testing may increase throughput, particularly if the test is being run across a network.
If no object checking function is present, object checking is turned on.
The testhead is 1 and load board statements turn object checking on. See the syntax description of these statements.
Syntax
  object checking <action>
     <action> can be:   on
                        off
Parameters
(none)
Example
  object checking on
  object checking off
