recall plus (SOFTKEY)
Title: RECALL A COMMAND FROM THE COMMAND STACK
The recall plus softkey is used on the command line to recall a previously executed statement. As you execute statements on the command line, each unique statement (or line, if more than one statement is executed at a time) is automatically added to the bottom of a command stack which can contain up to 50 lines. Once the stack is full the earlier statements drop off the top, and are lost, as new statements are added at the bottom.
The f2 softkey lets you step downward through the stack, bringing each statement in turn into the command line. A beep sounds when you reach the bottom of the stack.
Only unique statements are stored in the command stack. For example, if you enter the same statement twice in a row, only the most recent entry is retained.
When a statement is in the command line you can execute it again simply by pressing the f4 (execute) softkey. A recalled statement can also be edited and then executed. In this case, the edited version of the statement is added to the stack as if it were a new statement, and the original version of the statement remains in the stack.
The recall minus softkey (f3) is the opposite of the recall plus; f3 steps upwards through the stack.
