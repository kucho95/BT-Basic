display moa (DEBUG)
Title: DISPLAY MOA
The display moa function executes the specified analog in-circuit device test and displays the measuring operational amplifier (MOA) circuit and the test results. If the test includes the fi (filter) option, the display moa function executes the test the specified number of times (by the fi option), but only displays the results of the first measurement. The MOA circuit and test results are displayed on the printer is device.
The display moa function displays the results of a DC measurement in a DC format; it displays the results of an AC measurement in either a polar format or a rectangular format. The AC format is specified by the analogdebug.moa parameter of the .hp3070 file. You can also specify the AC format with the display moa function.
Syntax
  display moa
  display moa <subtest name>
  display moa; <format>
  display moa <subtest name>; <format>
     <subtest name> is a <string expression>
     <format> can be:   polar
                        rectangular
Parameters
<subtest name>
The name of the subtest to execute for the measurement. The default is to execute all the subtests in a test.
<format>
Specifies the format of the values of AC measurement results. The format can be:
• polar – Presents the data in polar format (a value at a phase angle).
• rectangular – Presents the data in rectangular format (a value with the j operator).
Examples
  display moa                   ! Execute displayed test and display results
                                ! and MOA configuration to "printer is" device.
  display moa "r1_1"            ! Execute subtest "r1_1" and display results and
                                ! MOA configuration.
  display moa; polar            ! Execute displayed test and display results in
                                ! polar format.
  display moa; rectangular      ! Execute current test and display results in
                                ! rectangular format.
  display moa "c1_3"; polar     ! Execute subtest "c1_3" and display results in
                                ! polar format.
