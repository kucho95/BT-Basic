link (BT-Basic)
Title: LINK TO AN EXISTING FILE
The link function allows an existing file to be named in (linked to) any directory. Either the same file name, or a different file name can be used, except that the same name cannot appear more than once in the same directory. A file can have any number of links, and can be linked to any number of directories, at any level in the hierarchy. A directory cannot be linked to a directory.
The file can be referenced through any of the links. This is useful when the same data needs to be referenced by different names. For example, in digital testing one test often applies to several devices with different names; the test developer can reference that test by any of the names.
Regardless of how many links there are to a file, that file is still the same file. If the contents of the file are changed via one link, the change is seen at all of the other links.
Syntax
  link <new file id> to <existing file id>
  link <new file id> to <existing file id>,<error variable>
     <file id> is a <string expression>
     <error variable> is a <numeric variable>
Parameters
<new file id>
The new identifier by which the existing file can be referenced. The identifier must not already exist.
<existing file>
The identifier of the file which is to be linked. This file must exist.
<error variable>
The identifier of an error variable.
Examples
  link "sn74ls75" to "sn7475"      ! File now has two links to current directory
                                   ! Existing file is "/test/ttl/sn74/ls208"
 
  mass storage is "/test/ttl/sn54"
  link "ls208" to "../sn74/ls208"
 
  ! File can now be referenced via two paths:
  ! "/test/ttl/sn74/ls208"  or  "/test/ttl/sn54/ls208"
