silicon nail (ITL)
Title: IDENTIFIES BOUNDARY SCAN CHAIN TEST TYPE AS SILICON NAIL
The silicon nail statement is used at the beginning of the file to identify that a silicon nail test type is desired. Silicon nail tests are ones in which one or more non-boundary-scan devices are tested via the boundary scan chain.
Syntax
  silicon nail <device name>
     <device> is a <string constant>
Parameters
<device>
Provides the name of the device or cluster that will be tested. This will be used in the failure repair message and log reports. This name must be used in each node and silicon node test statement in the file, along with a pin number.
Examples
  silicon nail "U6"
Refer to the ITL sample files in Boundary-Scan Testing for an example in context.
