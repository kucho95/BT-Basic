exit if pass (VCL)
Title: EXIT HOMING LOOP
The exit if pass function is a secondary keyword used by the vector execution statements execute, preset counter and count. It is used to exit a homing loop. If the actual response received from the device under test matches the expected response for the vector, a pass is recorded and the exit is made from the homing loop. At this point, it is assumed that the device has been brought to a known state and testing can proceed. The exit is not made if the actual response is different from the expected response in the vector with the exit if pass keyword.
Refer to the descriptions of the vector execution statements listed above and to the homingloop function for more information.
