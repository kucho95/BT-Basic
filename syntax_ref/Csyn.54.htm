controllerloop (VCL)
Title: START A CONTROLLER LOOP
The controllerloop function is used in a digital unit to mark the beginning of a controller loop; the end of the loop is marked by the end controllerloop function. Controller loops can be used only in mixed tests.
The loop passes control to the analog part of the mixed test, and repetitively executes a series of vectors. When a continue digital is received from the analog test, the loop completes its current iteration (if it has not already done so) and then exits. The digital test then continues with the function following the end controllerloop function.
Failure checking is turned off during the loop. The DUT clock, if any, continues to run during the loop.
The rules that apply to controller loops are:
• vectors can be executed only by the following statements,
• execute
• execute sync
• preset counter
• preset counter sync
• and, in PCF blocks:
– pcf
– use timing set (Mux systems only)
– include (Mux systems only)
– end pcf
• (Mux systems only) Timing sets executed during the loop cannot have waits (at event wait for function).
• Calls can be made to subroutines (the rules listed above also apply to these subroutines).
No other activities can occur during a controller loop.
Controller loops cannot be executed in homing loops, in unit disable tests, or in other controller loops.
Syntax
  controllerloop
Parameters
(none)
Examples
  ! in the Vector Execution section
        . . .
     unit
        . . .
        controllerloop        ! Measure voltage at TP12
           execute V1
           execute V2
           pcf
              "0011110HLHHL"
           end pcf
           execute V3
        end controllerloop
        . . .
     end unit
        . . .
General Information
Tests with controllerloops should have a test time function if SAFEGUARD safety analysis is required.
