+ (BT-Basic)
Title: ADDITION
This arithmetic operator, Plus, adds two numeric expressions together. The priority is 5.
Syntax
  <numeric expression> + <numeric expression>
Parameters
<numeric expression>
The quantities to be added.
Example
  print 34; +34            ! prints    34    34
  print 10+13.62           ! prints    23.62
  print 8+(‑5)             ! prints    3
  print 2+8*5              ! prints    42 ( + has lower priority than * )
  print (2+8)*5            ! prints    50
  A = 21 \ print A+3;A     ! prints    24    21
