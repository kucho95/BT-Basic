display device-polarity (DEBUG)
Title: DISPLAY DEVICE DATA FOR AN POLARITY CHECK TEST
The display device-polarity function tests the specified device in the Polarity Check test, and displays the results in ASCII or graphical format.
Syntax
  display device <device name> a
  display device <device name> g
  display device <device name> g <count>
     <device name> is a <string expression>
     <count> is a <numeric expression>
Parameters
<device name>
The name of the device whose data is to be displayed.
a or g
The type of data to display:
• a – ASCII
• g – graphical
<count>
The number of times to execute the test. This can be from 1 to 50. If you don’t specify a value, the system uses a value of 20.
Examples
  display device "c1" a         ! display ASCII data for C1.
  display device "c2" g 10      ! display graphical data and execute the test 10 times.
General Information
To zoom in on part of the graphical display, drag the mouse to define the area.
To close windows opened by display device-polarity, put the cursor in the window and press Ctrl+D.
