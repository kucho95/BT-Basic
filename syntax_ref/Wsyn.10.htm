wirelist (edit)
Title: INVOKE WIRELIST MODE
The wirelist function clears everything currently in the workspace and sets the workstation to wirelist mode. In this mode all statements entered into the work area of the screen are syntax‑checked to ensure that they are valid wirelist statements.
Syntax
  wirelist
  wirelist;<option>
     <option> can be:
        window
        nowindow
Parameters
<option>
Either window or nowindow.
• window opens a new window in wirelist mode
• nowindow suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Example
  text                 ! Sets "text" mode; all syntax checking is off
  wirelist             ! Sets "wirelist" mode
  wirelist; window     ! Opens a new window and sets "wirelist" mode in it.
General Information
The wirelist function is not programmable.
