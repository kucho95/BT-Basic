use pcf order (VCL)
Title: ASSIGN A SET OF PCF PINS TO A VECTOR
The use pcf order function is used in a PCF block to indicate which of the previously defined sets of PCF pins applies to the vectors in that block (see the pcf order is function). Within the block, all the vectors following the function are associated with the same set of PCF pins, until the next use pcf order function or until the end of the PCF block. There can be more than one use pcf order function in a PCF block.
Within a PCF block, vectors which are not preceded by a use pcf order function use the default set of PCF pins.
The length of the PCF vectors must be the same as the length of the set of PCF pins with which they are associated.
Syntax
  use pcf order <name>
     <name> is a <label>
Parameters
<name>
The identifier of the selected set of PCF pins.
Example
  ! in the Declaration section
           . . .
     assign In to nodes "A", "B", "C", "D"
     assign Out to nodes "G", "H", "I", "J"
     assign Bidirs to nodes "E", "F"
        . . .
     inputs In
     outputs Out
     bidirectional Bidirs
        . . .
     pcf order default All is In, Bidirs, Out
     pcf order Inputs is In, Bidirs
     pcf order Outputs is Bidirs, Out
        . . .
  ! in the Vector Execution section
        . . .
     pcf
           "0001 HH LLLL"    ! uses default set of PCF pins ("All")
           "0111 HH LLHH"
        use pcf order Inputs
           "1010 10"
           "1111 00"
        use pcf order All
           "0001 1H LLLL"
           "0100 L0 LHLH"
        use pcf order Outputs
           "LH LLLH"
           "LH HLLH"
     end pcf
     pcf
           "0101 0L LHLL"     ! uses default set of PCF pins ("All")
           "0111 0H LLHH"
           . . .
     end pcf
