outputs limited to (VCL)
Title: LIMIT ACTIVE OUTPUTS
The outputs limited to function can appear in the Declaration section of a library test. The function provides device‑specific data to the SAFEGUARD safety analysis routines which might allow them to relax safety timing restraints to some extent.
The function specifies the maximum number of output pins that can be high, and the maximum number that can be low, at any one time during normal operation of the device being overdriven. Note that, in this case, normal operation refers to the way in which the part is normally used on PC boards: it is not referring to how the part might be handled during the board test.
Separate maximum numbers are needed for the high and low levels. If a maximum value is not specified in a test, then that value defaults to the total number of output pins (including bidirectional pins) identified in the test.
Syntax
  outputs limited to <maximum> at <state>
  outputs limited to <maximum> at <state>, <maximum> at <state>
     <maximum> is a <numeric constant>
     <state> can be:   "1"
                       "0"
Parameters
<maximum>
Positive integer indicating the maximum number of output pins which can be at the specified level at one time. The default is the maximum number of output pins plus bidirectional pins specified in the test.
<state>
String constant indicating the 1 or 0 logic level.
Example
  outputs limited to 3 at "1", 4 at "0"
