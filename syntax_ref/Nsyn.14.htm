not (BT-Basic)
Title: NEGATION
The not operator is used to evaluate a Boolean expression. It returns a value of 1 if the expression is false (zero); it returns a value of zero if the expression is true (non‑zero). This operator has a priority of 3.
Syntax
  not <numeric expression>
Parameters
<numeric expression>
The quantity to be evaluated.
Example
  print not  ‑123.4            ! prints    0
  A = 0\ print not A           ! prints    1
  A=0\B=0\print A or not B     ! prints    1
  D=0\ print not D * 8.3       ! prints    1     (* has higher priority)
     print (not D) * 8.3       ! prints    8.3
