line frequency (CONFIGURATION)
Title: DECLARE THE LINE FREQUENCY
The line frequency function declares the line frequency for the testhead. This function can appear only in the testhead configuration file, not the board configuration file. The line frequency function must be outside the bank-end bank block.
Syntax
  line frequency 50
  line frequency 60
Parameters
(none)
Examples
  relay 1 controls vacuum 0
  line frequency 60
  bank 1
     module 1
        cards 1 asru n revision
        cards 6 control xtpb
        cards 9 to 11 high accuracy double density
        supplies 1 to 4
     end module
  end bank
