probe (BT-Basic)
Title: FAILURE PROBE STATEMENTS
The probe function has two forms; the probe device form and the probe failures form.
The probe device function invokes the probe function for the specified device. The probe function insures that all used pins of a device have connections. This function checks devices that have up to 650 pins. It displays the pins of the device on the screen. The display indicates the pins that are used with an *, and the pins that are not used with a .. As you probe each pin with the guided probe, the * changes to a p. After you remove the guided probe the p changes to a T. If no contact is detected to a used pin, the * remains on the screen. This does not require the use of the start softkey or the foot switch. You can probe the pins in any order and repeat any that you want. Probe the devices carefully so that you do not damage any device leads, especially on SMT devices.
The probe failures function invokes the probe function on devices which failed during testing. This determines if a failed device is defective, or if it was not contacting the fixture properly. To do this, you instruct the system when to start saving failure data with the save failures on function, and when to stop saving failure data with the save failures off function. Place the probe failures at the end of the subroutine to initiate probing of the devices that failed while save failures was on.
Both the probe failures and the probe device statements must be preceded by an unpowered function.
If buffered reporting is turned on, the probe function applies to the current board defined by the board number is function.
Syntax
  probe <device>
  probe failures
     <device> is a <string expression>
Parameters
<device>
The id of the device that is to be probed.
Example
  unpowered
  probe "U112"             ! Probe device U112.
  sub digital_tests        ! Digital test subroutine in testplan.
  save failures on         ! Save failure data.
  test "digital/U1"
     test "digital/U2"
     test "digital/U3"
     save failures off     ! Stop saving failure data.
     test "digital/U4"
     test "digital/U5"
     unpowered
     probe failures        ! Probe U1, U2, and U3 if they failed.
  subend
General Information
The probe statements are NOT intended to be used for verifying fixture wiring. Use the verify and find pins statements to test and debug fixture wiring.
The probe routines will not check guard nodes, sense nodes, GP relay nodes, enable lines, or any pin not connected to a hybrid card.
Saved failure data will not be retained from one execution of a program to the next. The wait for start function causes any previously stored failure data to be cleared.
