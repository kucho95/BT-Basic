special aux_(BT-Basic)
Title: SPECIAL AUXILIARY RELAY FEATURE
Auxiliary relays are automatically disconnected when certain BT-Basic commands are executed (such as run, stop, abort, start, and wait for start). To prevent an auxiliary relay from being disconnected when such commands are executed, it can be declared as “special”.
Use the commands in Table S-3 to specify and control special auxiliary relays. Note the following:
• The special auxconnect and special auxdisconnect must be used for special auxiliary relays. An error will result if they are used on:
• an auxiliary relay not yet declared as special.
• an auxiliary relay whose special setting has already been cleared.
• A special auxiliary relay cannot be controlled with the auxconnect and auxdisconnect commands.
• The following command sequence will cause an error; aux 1 has to be disconnected first:
auxconnect 1
special aux set 1
• The following command sequence opens aux 1 and sets it back to normal:
special auxconnect 1
special aux clear 1
Syntax
 
Table S-3 Special auxiliary relay commands
Command
Description
special aux set <relays>
Declare the specified auxiliary relay(s) on the system card to be special relays.
special aux clear <relays>
Clear the special setting of the specified auxiliary relay(s).
special aux clear all
Clear the special setting of all auxiliary relay(s).
special auxconnect <relays>
Close the specified special auxiliary relays on the system card.1
special auxconnect all
Close all special auxiliary relays on the system card.1
special auxdisconnect <relays>  
Open the specified special auxiliary relays on the system card. 1
special auxdisconnect all
Open all special auxiliary relays on the system card.1
   <relays> can be: <relay>
                    <relay>, <relay>, ... <relay>
       <relay> can be: 1,2,3…9
1. These auxiliary relays must not be specified as vacuum ports in the testhead config file.
