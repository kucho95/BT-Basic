default device (ANALOG)
Title: DECLARE THE DEFAULT DEVICE IN ANALOG FUNCTIONAL AND MIXED TESTS
The default device function declares the default device for analog functional and mixed tests. If no default device function is included in an analog functional test, the device id is taken from the test file name. If no default device function is included in a mixed test, the device id is taken from the test directory name.
The default device function is not allowed in library tests; it is allowed only in executable tests.
Syntax
  default device "<device id>"
     "<device id>" is a <string constant>
Parameters
(none)
Examples
  test powered mixed
     default device "U1"
     connect rcva to pins 12
     test "u2908_312khz"
     continue digital
     test "u2908_160khz"
     continue digital
           .
           .
           .
  end test
