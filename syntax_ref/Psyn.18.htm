pi (BT-Basic)
Title: THE CONSTANT PI
pi represents the standard constant pi (3.14159265359). It has no argument.
Syntax
  pi
Parameters
(none)
Example
  print pi                       ! prints   3.14159265359
  print 1/(2*pi)                 ! prints   .159154943092
  Cap=1000p \ Freq=5.4M \ Xc= 1/(2*pi*Freq*Cap)
     print using "5a, mdd.dd, 5a"; "Xc = ", Xc, " ohms"
                        ! prints   Xc =  29.47 ohms
