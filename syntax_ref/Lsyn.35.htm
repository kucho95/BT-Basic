log out (BT-Basic)
Title: WRITE ALL ACCUMULATED LOG RECORDS
When the log out function is executed, all log records generated because the last run or wait for start function are written to a log file. The records are sent to the default log file (established by a log is function), unless log out specifies another file.
If log out tries to write to the default, but there is no default, then the function is ignored. If log out references a log file, that file is opened, the log records are written to it, and the file is then closed.
Syntax
  log out
  log out,<error variable>
  log out <file id>
  log out <file id>,<error variable>
  log out <file id>,<error variable>;<access>
  log out <file id>;<access>
     <error variable> is a <numeric variable>
     <file id> is a <string expression>
     <access> can be:   <a/n/o>
                        <e/s>
                        <a/n/o>,<e/s>
                        <e/s>,<a/n/o>
        <a/n/o> can be:   append
                          new
                          over
        <e/s> can be:   exclusive
                        shared
Parameters
 
<file id>
The identifier of the file or device where the logged data is to be sent. The file is opened, written to, and then closed. If no file is specified, the logged data is sent to the current default log file.
<a/n/o>
Determines how the data is written:
• append – Adds data to the existing file;
• over – Replaces data in the existing file;
• new – Creates a new file; an error occurs if it already exists.
If omitted, this parameter defaults to over.
<e/s>
Determines whether the file is opened for exclusive use or for shared use. If omitted, this parameter defaults to exclusive.
The file should be opened shared only so that one user can write to it, and the other(s) read from it. If more than one user writes to the file, the results can be unpredictable.
<error variable>
The identifier of an error variable.
Examples
  log is "logger"; append        ! Open default log file
  . . .
  log out                ! Output is added to any existing data in the default log file
  log out "/dev/log" & th$, Err1
General Information
If log out references a file, then that file is opened and closed each time the function is executed; therefore, we recommend that you use the default log file during board test. If you are running a test for debugging purposes, then you may prefer to log to another file so that the debug data is not sent to the file containing the test data.
To save on total test time, the log out function should follow the faoff or fboff function in the testplan. This allows the log file writing time to overlap the board swap time.
When using multiple board states (board number is function) to test a multi‑board panel, the log out function sends log records to the log buffer for the current board.
