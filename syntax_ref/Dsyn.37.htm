display clear (DEBUG)
Title: CLEAR DISPLAY LINES
The display clear function clears the display, or specific lines from the display. The data associated with the cleared lines is cleared from memory.
If no line numbers are specified the entire display is cleared. If one line number is specified, only that line is cleared. If two line numbers are specified, those lines and all lines between them are cleared.
Syntax
  display clear
  display clear <line number>
  display clear <line number>,<line number>
     <line number> is a <numeric expression>
Parameters
<line number>
An integer, specifying a line number. If the numbers are omitted, the complete display, including all lines currently rolled off the screen, is assumed.
Examples
  display clear           ! deletes all lines
  display clear 30        ! deletes line 30
  display clear 12,47     ! deletes 36 lines—12 through 47
