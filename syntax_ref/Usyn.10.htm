use cards on (VCL)
Title: SPECIFY PIN CARD PREFERENCES FOR A VCL TEST
(Mux systems only)
The use cards on function appears in the declaration section of a VCL test. It specifies which type of pin card should be used as the resource for a pin group during a VCL test. This function also specifies a preference, or priority, in how the types of pin cards should be used.
Syntax
   use cards <card type> on <group id>
      <card type> can be:  channel; hybrid
                           hybrid; channel
                           channel, hybrid
                           hybrid, channel
      <group id> is a <label>
Parameters
<card type>
The type of pin card—abbreviated as hybrid or channel—to be used as a resource for this pin group.
• hybrid is the abbreviation for HybridPlus Pin Card.
• channel is the abbreviation for ChannelPlus Pin Card.
The punctuation between the names can be used to set priorities for pin card usage. A semicolon means the first choice is preferred over the second. If there is no preferred choice, a comma between the types means the priorities are equal—i.e., either type of pin card can be used interchangeably.
<group id>
The identifier assigned to a group of pins.
Example
    ! Simplified excerpts from the declaration section of a digital test:
   assign Channel_Input_TTL to pins 72,73,74,75,76,77,78
   assign Channel_Input_TTL to pins 2,11,12,13,14,31,32,33,34
   inputs Channel_Input_TTL
   use cards channel; hybrid on Channel_Input_TTL
           ! Preferred choice is "channel". If no "channel" resources are available,
           ! then use "hybrid".
   assign Channel_Input_TTL to pins 72,73,74,75,76,77,78
   assign Channel_Input_TTL to pins 2,11,12,13,14,31,32,33,34
   inputs Channel_Input_TTL
   use cards channel, hybrid on Channel_Input_TTL  
           ! No preference; use "channel" or "hybrid".
