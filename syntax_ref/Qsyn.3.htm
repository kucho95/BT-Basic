question (BT-Basic)
Title: OPERATOR QUERY
The question function prompts the operator for a response. It resets the operator controls, displays a prompt on the screen, and waits for a yes or no operator control response.
There is no wait after execution of this function before the operator controls are read.
Syntax
  question <prompt>
  question <prompt>,<return>
     <prompt> is a <string expression>
     <return> is an <alphanumeric variable>
Parameters
<prompt>
A user‑defined expression displayed on the screen as instructions to the operator. Program execution is halted until the yes or no operator control button is pressed.
<return>
An alphanumeric variable which is set to the returned value; 0 for no, 1 for yes.
Example
  ! Query the operator:
     question "Are LED's on? (press YES or NO)",A
     if A = 1 then print "LED's are on"
     if A = 0 then print "LED's are off"
