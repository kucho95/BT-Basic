run (BT-Basic)
Title: RUN A PROGRAM
The run statement initializes and runs the BT-Basic program currently in the system workspace. When a program is initialized, any workspace previously reserved for variables is released for general use. The program then starts running from the beginning.
Syntax
  run
Parameters
(none)
Example
  run            ! Initializes and runs the program currently in the system workspace
  load "test2"   ! Clears the workspace, loads the program from file "test2"
  run            ! Initializes and runs the program
General Information
If successive runs of the program are made, the subsequent runs will be faster than the first run. During the first run the system gathers information about the program—where to find the labels, where the subprograms are located, etc. The subsequent runs of the program are then faster since the system knows where to go for information and does not have to search, as it did during the first run.
Each time the program is brought into the workspace by the load or get statements, or each time the program in the workspace has been edited, a new first run will be made.
The learning process cannot be controlled by the user. It is entirely automatic and is invisible to the user, the only outward sign being that subsequent runs are faster than the first run. The nrun statement can be used to determine if the program has been run since it was last loaded or edited.
The run statement is not programmable.
