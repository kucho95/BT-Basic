Differentiating Between Modes
BT-Basic is the primary board test mode and is used to control the test environment. BT-Basic statements can usually be executed on the command line, regardless of which mode has been set in the workspace (text, digital, shorts, basic, etc.). The exceptions occur when the system is busy or when the current mode requires the complete window, including the area normally available to the command line.
Except for the modes which use the entire window, when a mode is set, it affects only the workspace. It does not affect the command line. So if digital mode is set, only VCL statements can be typed in the workspace but BT-Basic statements can still be executed on the command line. However, VCL statements can never be executed on the command line, even though the mode is currently digital. Only BT-Basic statements can be executed on the command line. The exception is the debug mode, which can be set concurrently with BT-Basic.
Notice that none of the statements can be executed in the workspace. In BT-Basic, the statements in the workspace are part of a program and executed when that program is run from the command line. For most other modes, the statements in the workspace must be compiled and then run by the BT-Basic test statement.
