set load (VCL) (ITL)
Title: CHANGE THE LOAD ON A RECEIVER
The set load statement is optional; you can use it in the Declaration section of a VCL library test to change the pull‑up or pull‑down loads on the receiver pins (outputs and bidirectional pins from the board under test). The default load for the receivers—pull‑up, pull‑down or no load—must be established in a family statement before the set load can be used.
The pull‑up load is a current source of 2 mA; the pull‑down load, of 5 mA. The current sources are connected directly to the receiver circuits in the testhead.
Syntax
  set load on <identifiers> to pull up
  set load on <identifiers> to pull down
  set load on <identifiers> to no load
     <identifiers> can be:
        pins <pin-id list>
        device <designator> pins <pin-id list>
        nodes <node-id list>
        relays <relay-id list>
        groups <group-id list>
           <designator> is a <string constant>
           the format of the <id lists> is:
              <item>
              <item>,<item>
              <item>,<item>, . . . <item>
                 <items> can be:
                    a. for <pin-id list> — <numeric constant>
                                           <string constant>
                    b. for <node-id list> — <string constant>
                    c. for <relay-id list> — <5-digit numeric constant>
                      (represents brrcc)
                    d. for <group-id list> — <label>
Parameters
 
<identifiers>
The list of pins (groups, nodes, etc.) whose loads are to be changed. Only output pins and bidirectional pins can be specified.
<designator>
String constant representing a device under test. This is the same as the device designator entered in the i3070 In-Circuit Test Software. It can contain up to 48 printable characters, but with no space.
<id list>
A list of pins represented by the following types of id:
• <pin id>
• <node id>
• <relay id>
• <group id>
These parameters are the same as the ids used to identify the pins in the assign to statements in the test. See the parameters described under the assign to (VCL) statement for details.
Example
  family TTL
  set load on device "U68" pins 13, "11" to no load
  set load on relays 10962, 10403 to pull down
  set load on groups Control to no load
General Information
The standard families have the following loads:
• TTL — pull up
• CMOS — no load
• ECL — pull down (Mux systems only)
