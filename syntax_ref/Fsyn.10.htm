fcdon (BT-Basic)
Title: TURN ON VACUUM SYSTEMS C & D
The fcdon function controls the C and D vacuum systems. If neither vacuum system has been previously turned on, the fcdon function turns on both vacuum systems. If either vacuum C, or vacuum D, has been turned on, the fcdon function turns on the other vacuum (so that both vacuum systems are on at the same time). This function is useful for dual stage fixtures.
Any of the four vacuum off statements (faoff, fboff, fcoff, fdoff), turns off any vacuum which is currently turned on; they do not open GP relays that were previously connected.
Syntax
  fcdon
Parameters
(none)
Examples
  fcon      ! Turns on vacuum system C.
  fcdon     ! Turns on vacuum D (vacuum C remains on).
  fdoff     ! Turns off both vacuums C and D.
