for-to-step/next (BT-Basic)
Title: THE COUNTED LOOP
Counted loops are executed a specified number of times. for marks the beginning of a loop and identifies the variable which is to act as the loop counter; next marks the end of the loop. The number of times the statements contained in the loop are executed, depends on the loop counter.
The two secondary keywords to and step define the counter: to establishes the initial value and range of the counter, and step establishes the amount by which the counter is incremented after each iteration of the loop. If step is omitted, the step value defaults to +1.
In operation, for monitors the value of the counter variable and determines whether or not to exit the loop; next increments the counter and returns execution back to for. When the exit is made, program execution resumes at the step immediately following the next function.
It is possible to exit the loop by means of a goto function, in which case the loop is cancelled, just as if a normal exit had occurred.
The Counter
Each time the for function is executed it looks at the counter variable to determine if the counter is within its established range: if it is within its range, the statements in the loop are executed; if the counter is not within its range, the exit is made immediately from the loop. The counter is within its range if the following is true (note that if the increment value is not specified, it defaults to +1):
• the increment is positive and the counter value <= stop value, or
• the increment is negative and the counter value >= stop value.
Note that it is possible for the statements in the loop never to be executed at all. For example, if the increment value is negative and the counter start value is less than the stop value, then for immediately exits the loop without executing any of the statements in the loop.
Values are established for the start, stop and increment parameters when the loop is encountered. If those parameters are variables, their values can be changed during the loop without affecting loop operation: their initial values are held in buffers once the loop has started. However, the value of the counter variable must not be changed by any function except next while the loop is running.
Syntax
The for/next loop has two possible formats:
   for <counter variable> = <start> to <stop>
      <one or more statements>
   next <counter variable>
Or:
   for <counter variable> = <start> to <stop> step <increment>
      <one or more statements>
   next <counter variable>
      <counter variable> is a <numeric variable>
      <start>, <stop> & <increment> are <numeric expressions>
Parameters
<counter variable>
A simple numeric variable which acts as the counter during loop execution. The variable is set to its initial value, <start>, when for is first encountered; it is then incremented by the <step> value each time next is encountered. During the loop, the value of the variable can be changed only by the operation of the next function.
The variable may or may not exist before the loop starts. After the exit, the variable retains its last incremented value, which is outside the range of the <start> and <stop> values. If a goto caused the exit, the variable retains the value it had when the goto was executed.
<start>
Numeric expression specifies the initial value assigned to the counter variable.
<stop>
Numeric expression specifies the stop value. This value and the start value together define the counter's range. As long as the value of the counter variable is within this range, the program repetitively executes the statements in the loop.
<increment>
Numeric expression specifies the step value by which next increments the counter variable after each pass. If this parameter is omitted, it defaults to +1.
Examples
  for W = 1 to 5
  print W        ! takes 5 passes to print values 1 through 5
  next W
  print W        ! prints 6
  ! loop prints voltage and power for .01v, .02v . . . 4.99v, 5.00v
     L=0  \  Current = .05
     for Volts = 0.01 to 5 step 0.01
        print "Voltage = "; Volts
        print "Watts = "; Volts * Current
        L = L+1                ! shows the number of times the loop executes
     next Volts
        print L                ! prints   500
        print Volts            ! prints   5.01
  dim A(1:20), B(1:20), T(1:20)
                      ! assuming arrays A and B have values assigned, this loop adds
                      ! each value in array A to its corresponding value in array B
  for I = 1 to 20
     T(I) = A(I)+B(I)
  next I
  dim C(1:25, 1:30)   ! after array C has values assigned, two nested loops can be used
                      ! to clear the array to all zeros
  for J=1 to 25
     for K=1 to 30   ! the K‑loop is executed 30 times for every once through the J‑loop
        C(J,K) = 0
     next K
  next J
  ! the print function is never executed, because the counter is out of range
  ! when initialized
        for Q = 1 to 10 step ‑1
           print Q
        next Q
 
The next two examples are not allowed; in a. the loops overlap, and in b. the two structures overlap.
     a.   for I = 1 to 10          b.   for I = 1 to 10
          for J = 1 to 10               if I = 4 then
          next I                        next I
          next J                        end if
