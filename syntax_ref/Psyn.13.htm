pcf (ITL)
Title: START PCF BLOCK
The pcf (Pattern Capture Format) function is used to start a PCF block either in the disables section of any ITL test or in a unit block within the nodes block of a silicon nail test; the end of the block is marked by the end pcf function. The block contains a series of PCF strings, representing a series of vectors and their execution statements.
PCF blocks cannot be nested: that is, one block cannot be located within another. In addition to the PCF strings, only the message and ! (comment) statements are allowed inside a PCF block.
These statements can be located anywhere in the block, except that only the comment can be inserted between two strings which define a single vector.
Syntax
  silicon nail "U6"
  chain "chain_tc"
     ...
  end chain
  disables
     node "oc_2" hybrid                ! For UnMux systems
     node "oc_4", hybrid default "1"   ! For UnMux systems
     node "oc_2" bybrid, channel       ! For Mux systems
     node "oc_4", channel default "1"  ! For Mux systems
     pcf order is nodes "oc_2", "oc_4"
     unit "Disable"
        pcf
           "11"
        end pcf
     end unit
  end disables
Parameters
(none)
