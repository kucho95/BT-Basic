cfps (BT-Basic)
Title: CONNECT FIXTURE POWER SUPPLIES
The cfps function connects fixture power supplies to the fixture via pins defined by the ASRU Revision N Card.
Syntax
  cfps
  cfps <logicID>
  cfps <logicID>, <logicID>, ...<logicID>
  cfps <logicID> to <logicID>
     <logicID> is an integer from 101 to 108
Parameters
<logicID>
The power supply number (from 101 to 108); it must be unique across the modules.
Examples
  cfps             ! Connect all fixture power supplies configured in board config file
  cfps 101         ! Connect the specified fixture power supply
  cfps 101, 102, 104
  cfps 101 to 104
