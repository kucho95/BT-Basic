keyboard is (BT-Basic)
Title: SET DEFAULT INPUT DEVICE
The keyboard is function changes the default input device or file, that is, the source of the data input in response to the input and input using statements.
At login the default input device is the user's workstation. If a keyboard is function is used to select another source (file), then that becomes the default until another keyboard is function is executed, or until the user logs off the system. The function is global, which means it can be executed in any environment—from the keyboard, from the main program, from a subroutine, etc.—and it is in effect for all other environments.
When keyboard is is executed, it closes the existing source before opening the new one. Depending upon the <access> parameter, the source is opened either exclusively (it cannot be accessed by any other user), or shared (more than one user can access the file). If the open is not successful, the default input device becomes the workstation keyboard.
Syntax
  keyboard is <file id>
  keyboard is <file id>;<access>
  keyboard is *
  keyboard is <file id>,<error variable>
  keyboard is <file id>,<error variable>;<access>
  keyboard is *,<error variable>
     <file id> is a <string expression>
     <error variable> is a <numeric variable>
     <access> can be:   exclusive
                        shared
Parameters
<file id>
The identifier of the file or device to be the new default input source. The old source is closed before the new source is opened. If the new source cannot be opened—e.g., it does not exist or it is already opened exclusively—then the workstation keyboard becomes the default.
<access>
Determines whether the file is for exclusive or for shared use. If this parameter is omitted, it defaults to exclusive.
*
An asterisk specifies the original default; that is, the user's workstation.
<error variable>
The identifier of an error variable.
Examples
  keyboard is "tsdata"; exclusive            ! Default input device is file "tsdata"
  T$ = "tsdata"
  keyboard is T$                             ! Same as above
  keyboard is "/dev/prt1", Err1; exclusive   ! Includes error variable
  keyboard is *                              ! Default is the workstation keyboard
General Information
The enter and enter using statements, which also affect the input and output of data, designate their own source and do not use the default.
