chr$ (BT-Basic)
Title: VALUE TO SINGLE CHARACTER STRING
The chr$ function returns the character whose ASCII decimal equivalent is represented by the decimal, integer value in the function's argument. If the value is greater than 256, it is divided by 256 and the remainder is then used (i.e., integer modulo 256).
This function enables the test programmer to send 8‑bit bytes to external equipment. If the value in the function's argument is positive, the byte is the binary equivalent of the value. If the value is negative, the byte consists of the twos‑complement of the value.
Syntax
   chr$ ( <numeric expression> )
Parameters
<numeric expression>
Decimal value to be converted to its equivalent character. If a conversion error occurs, the null string is returned. ( 0 <= decimal value )
Examples
  Word$[1] = chr$(104)
  Word$[2] = chr$(83)
  Word$[3] = chr$(50)
  print Word$              ! prints    hS2
  G = 81
  Word$ = chr$(G)
  print Word$              ! prints    Q
  print chr$(340.34)       ! prints    T (note: 340 mod 256 = 84)
  print chr$(75)           ! prints    K
  print chr$(‑75)          ! prints    5 (printer ignores left‑most bit)
  print num(chr$(‑75))     ! prints    181 (includes all eight bits)
