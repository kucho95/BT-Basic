list (edit)
Title: LIST THE CONTENTS OF THE WORKSPACE
The list function prints the entire workspace on the default print device, unless the default has been changed by a printer is function.
Line numbers are printed to the left of each line, as shown in the example below.
Lines longer than 72 characters are split into two lines when printed.
Syntax
  list
Parameters
(none)
Example
     ! Line one
     ! Line two
     ! Line three
     ! Line four
     ! Line five
     ! Line six
  list
     ! Prints    1: Line one
     !           2: Line two
     !           3: Line three
     !           4: Line four
     !           5: Line five
     !           6: Line six
General Information
The list function is not programmable. Also see the listm and listn statements.
