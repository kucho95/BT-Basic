oti (BT-Basic)
Title: OCTAL STRING TO INTEGER
The oti function returns a decimal, integer value which is equivalent to the octal number contained in the function's string argument. With 16‑bit operation, the number in the string can have up to 6 contiguous, octal digits (11 with 32‑bit operation); if there are less, leading zeros are assumed. Leading and trailing spaces are ignored. If the number in the string contains an embedded space, the number terminates at the space and any remaining characters are ignored.
Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Values in the following ranges can be processed:
• 16-bit operation: -2^15 <= value <= 2^15 - 1 (2^15 = 32768)
• 32-bit operation: -2^31 <= value <= 2^31 - 1 (2^31 = 2147483648)
Syntax
  oti ( <string expression> )
  oti ( <string expression> , <error variable> )
     <error variable> is a <numeric variable>
Parameters
<string expression>
Octal string to be converted to its equivalent decimal value. If a conversion error occurs and there is an error variable, the function returns a zero.
<error variable>
Identifier of an error variable.
Example
  Num = oti("37")                   ! Num = 31
  Val = oti("  16  ")               ! Val = 14
  Negnum = oti(" 177717 ")          ! Negnum = ‑49  (16-bits)
  print oti("562 433")              ! prints    370 [same as oti("562")]
  loop                              ! converts octal numbers to decimal
     input "Type octal string:" , Pattern$
     Val = oti (Pattern$, Err)
     if Err <> 0 then print "Improper number, please try again."
  exit if not Err \ end loop \ print Val
