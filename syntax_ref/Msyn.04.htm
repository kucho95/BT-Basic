marker start (DEBUG)
Title: MARK A VECTOR
The marker start function positions the marker (a vertical, yellow bar) at the specified point in the test. The point is identified as a vector or, in tests with timing sets1, an event or scale (subcycle) of an event. If the specified position is not displayed, the marker will not appear until the display is scrolled to the marker area.
If no parameters are specified, the marker will appear at the cursor position. The status area of the window contains information on the position of the marker relative to the cursor.
The marker can be moved by another marker start function, and cancelled by the clear marker function.
Syntax
  marker start
  marker start at <vector>
  marker start at <vector>,<event>
  marker start at <vector>,<event>, <scale>
     <vector>, <event>, and <scale> are <numeric expressions>
Parameters
<vector>
The vector number where the marker is to be located.
<event>
The number of the event where the marker is to be located. The number is related to the events which start with the vector drive (event 0), and continue up to, but not including, the next vector drive. The numbers are not necessarily the same as the event numbers in the timing set associated with the vector.
<scale>
The scale (subcycle of the specified event) where the marker is to be located. This is used in tests with timing sets only.
Example
  marker start
  marker start at 2
  marker start at 86, 10
  marker start at 35, 0, 3
  marker clear
General Information
(none)
 
1. Mux systems only.
