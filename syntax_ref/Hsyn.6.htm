hti (BT-Basic)
Title: HEXADECIMAL STRING TO INTEGER
The hti function returns a decimal, integer value which is equivalent to the hexadecimal number contained in the function's string argument. The number in the string can have up to 4 contiguous hexadecimal digits—8 with 32‑bit operation. Letters A through F can be either upper or lower case. If the number has less than 4 (8) digits, leading zeros are assumed. Leading and trailing spaces are ignored. If the number in the string contains an embedded space, the number terminates at the space and any remaining characters are ignored.
Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. Values in the following ranges can be processed:
• 16-bit operation:
     -2^15 <= value <= 2^15 - 1
     (2^15 = 32768)
• 32-bit operation:
     -2^31 <= value <= 2^31 - 1
     (2^31 = 2147483648)
The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Syntax
  hti ( <string expression> )
  hti ( <string expression> , <error variable> )
     <error variable> is a <numeric variable>
Parameters
<string expression>
Hexadecimal string to be converted to its equivalent decimal value. If a conversion error occurs and there is an error variable, the function returns a zero.
<error variable>
Identifier of an error variable.
Examples
  Num = hti("9A")                ! Num = 154
  Val = hti("    E    ")         ! Val = 14
  Negnum = hti("  fFD3  ")       ! Negnum = ‑45  (16-bit)
  print hti("4c 30")             ! prints    76 [same as hti("4C")]
  loop                           ! converts hexadecimal numbers to decimal
     input "Type hexadecimal string:" , Pattern$
     Val = hti (Pattern$, Err)
     if Err<>0 then print "Improper number, please try again."
  exit if not Err\ end loop \ print Val
