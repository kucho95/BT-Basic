safeguard <type> (BT-Basic)
Title: SELECT SAFEGUARD LEVEL
The safeguard <type> statement sets the SAFEGUARD level to be applied to the digital tests. As can be seen from the syntax, below, the four levels are all, digital, cool, and none (off).
When digital tests are compiled, the compiler performs safety analysis based on the information in the safeguard file under the board directory, and on the information in the board.o file. The safety analysis routines determine the time-out for each test and cool‑down delays to be inserted between tests.
With safeguard none, no digital test will be prevented from running (inhibited) for safety reasons, and the cool‑down delays are not enforced.
With safeguard cool, no digital test is prevented from running (inhibited) for safety reasons, but the cool‑down delays are enforced.
With safeguard digital, a digital test will be inhibited if that test would damage either the device under test or an upstream digital device; in addition, the established cool‑down delays are enforced.
With safeguard all, a digital test will be inhibited if the device under test has any upstream, non‑digital devices connected to it (you can use this to determine if there are any such devices and then alter the testplan accordingly). safeguard all also inhibits tests for the same reasons that safeguard digital inhibits tests, and enforces the cool‑down delays.
The default safety level automatically switches to safeguard all whenever a new run of the testplan starts.
Syntax
  safeguard all
  safeguard digital
  safeguard cool
  safeguard none
Parameters
(none)
Example
  safeguard all           ! safeguard all devices
  safeguard digital       ! safeguard only digital devices
  safeguard cool          ! turn off safeguard; enforce cool‑downs.
  safeguard none          ! turn off all safeguard controls
