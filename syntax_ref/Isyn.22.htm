initiate (ANALOG)
Title: INITIATE A SOURCE, DETECTOR, OR A TRIGGER
The initiate function turns on a source or instructs a detector to make a measurement. The initiate function can be used to send a trigger pulse to an external instrument.
The initiate trigger function sends a trigger pulse to an external instrument. The external instrument must have been previously set up with the trigger from analog function.
The initiate source and initiate auxiliary turn on the source that was previously set up.
The initiate detector function instructs the previously set up detector to make a measurement. The frequency, pulse, and interval detectors are not initiated; they are armed with the arm function.
Syntax
  initiate trigger
  initiate detector
  initiate source
  initiate auxiliary
Parameters
(none)
Examples
  test powered analog
     clear connect s to "node_6"; i to "node_1"; l to "node_3"
     source sine, amplitude 6, frequency 100, icompliance 1, offset 2, on
     detector dcv, expect 5
     initiate detector
     fetch Result
     report analog 5.0, 4.9, Result
  end test
General Information
The initiate function is used together with the fetch and report analog statements.
