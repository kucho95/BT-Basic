display renumber (DEBUG)
Title: RENUMBER THE DISPLAY
The display renumber function renumbers the lines in the display, starting with line 1 at the top and numbering the lines consecutively. This function is useful if you have been deleting, adding, and swapping lines in the display.
Syntax
  display renumber
Parameters
(none)
Examples
  display renumber
