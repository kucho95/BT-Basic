pass device (BT-Basic)
Title: SET DUTFAILED VARIABLE TO FALSE
The pass device function sets the Dutfailed variable to a 0 (false). The pass device function also sets the Boardfailed variable to 0 (false) if there has been only one test failure. If there has been more than one test failure, the pass device function still sets the Dutfailed variable to 0, but the Boardfailed variable remains 1 (true).
If you are testing a panel of boards, the pass device function applies only to the current board defined by the board number is function.
The fail device function sets the Dutfailed and Boardfailed variables to 1 (true). The clear failures function resets both variables to a 0 (false). The boardfailed and dutfailed statements return the current value of the variables. Refer to these functions syntax descriptions for more information.
Syntax
  pass device
Parameters
(none)
Example
  fail device
  dutfailed         ! Returns a "1".
  pass device
  dutfailed         ! Returns a "0".
General Information
If buffered reporting is on, this function does not clear the report buffer. Use report clear to clear this buffer. Also, this function does not clear the data logging buffer; use log clear to clear the data logging buffer.
