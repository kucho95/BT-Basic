display device-vtep (DEBUG)
Title: DISPLAY PIN DATA FOR A VTEP TEST
The display device-vtep function tests the specified device in the VTEP test, and displays the results in ASCII or graphical format.
Syntax
  display device <device name> a
  display device <device name> g <low value> <high value>
  display device <device name> g <low value> <high value> <count>
     <device name> is a <string expression>
     <low value> and <high value> are <numeric expressions>
     <count> is a <numeric expression>
Parameters
<device name>
The name of the device whose data is to be displayed.
a or g
The type of data to display:
• a – ASCII
• g – graphical
<low value> <high value>
The low and high values (in femtoFarads) for the Y axis for the graphical display.
<count>
The number of times to execute the test. This can be from 1 to 50. If you don’t specify a value, the system uses a value of 1.
Examples
  display device "u181" a               ! display ASCII data for U181.
  display device "u181" g 20 5000 25  ! display graphical data with the Y axis from 20
                                      ! to 5000 and execute the test 25 times.
General Information
Marginal passes or failures are indicated by an asterisk (*) in the ASCII data.
To zoom in on part of the graphical display, drag the mouse to define the area.
To close any of the windows opened by the display device-vtep function, place the cursor in the window and press Ctrl+D.
