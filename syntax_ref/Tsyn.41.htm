timing set (VCL)
Title: START TIMING SET DEFINITION
(Mux systems only)
The timing set statement is used in the Timing section of a VCL test to mark the start of a timing set definition. The end of the set is marked by the end timing set statement. Each set contains the statements which define that timing set.
A timing set controls the state changes on one or more formatted pins; it also controls the timing of the vectors which reference that timing set (see the use timing set statement). Any number of vectors can reference the same timing set. If timing sets are used, then all vectors are controlled by the timing sets.
A VCL test can have any number of timing sets. The sets consist of some number of events, numbered, from left to right, 0 through n‑1 (n = number of events in the timing set. The length of a timing set is n times the spacing between events (i.e., n times the reference clock period). A timing set can have any number of events, up to a maximum of 255, and the sets in any one VCL test can have different lengths.
A test using timing sets must have one, and only one, default timing set (if the test has only one timing set, it must be the default). The secondary keyword default defines the default timing set (see the syntax, below). The default timing set need not set states on any pins, but it must contain a drive vector and a receive vector statement. The default set is automatically referenced by any vector—including Disablevector generated by the program generator—which does not specifically reference a timing set.
The following rules apply to the timing sets:
• there must be at least one set (it can be the default);
• there must be a default set;
• there can be any number of sets (of varying lengths);
• formatted states allowed: 0, 1, K, X, Z
• states not allowed: T
• if the state of a formatted pin is not specified for event 0, it retains its current state until specifically changed;
• a set need not have any at event set to statements;
• when a bidirectional formatted pin group is to be driven by the timing set, the group must be declared in a drive formatted or receive formatted statement in the set.
Syntax
   timing set <set id> is <number of> events
   timing set default <set id> is <number of> events
      <set id> is a <label>
      <number of> is an <integer constant>
Parameters
<set id>
The identifier of the timing set. Other statements reference the timing set by its <id>.
<number of>
The number of events in the timing set. The range is:
2 <= number of events <= 255
Example
  ! in the Timing section
        . . .
     timing set T1 is 10 events
           drive vector at event 2
           receive vector at event 7
        at event 0 set CS1 to "1"      ! ACK and RDWR retain their current values
        at event 3 set ACK to "0"
        at event 5 set RDWR to "1"
        at event 8 set CS1 to "0"
     end timing set
