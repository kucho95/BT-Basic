debug end (DEBUG)
Title: END TEST DEBUG
The debug end function ends a debug session. The function cancels all debug data, removes all resources connected to the debug ports and closes all debug windows.
If you are debugging more than one test during the session, it is not necessary to execute debug end between the tests. The debug function acts like debug end and then start debugging on the next test.
