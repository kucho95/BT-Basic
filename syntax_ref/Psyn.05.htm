parameters (SAFEGUARD)
Title: MARK THE START OF A PARAMETER BLOCK
The parameters function marks the beginning of a parameter block in a SAFEGUARD file; the end of the block is marked by the end parameters function. A SAFEGUARD file can have any number of parameter blocks.
A parameter block contains all of the SAFEGUARD parameters for a specific class of digital devices. These parameters are used by the safety analysis routines to calculate the safe test time and the necessary cooldown delays for those devices. Devices are associated with a specific parameter block by the use parameters function.
Parameters which are not included in a block, are automatically assigned their default values for that block.
Syntax
  parameters <block name>
     <block name> is a <string constant>
Parameters
<block name>
The name of the block must contain at least one non‑space character and must be unique. Any leading or trailing spaces in the string will not be considered as part of the name when evaluating that name's uniqueness.
Example
  parameters "TTL_custom_devices"
     backdrive current of 125m for "0", 270m for "1"
        . . .
     thermal resistance 60
  end parameters
  !  in this block, all parameters have their default values
  !
        parameters "defaults"
        end parameters
General Information
If a parameter appears more than once in a block, only the last value(s) assigned to that parameter are valid. If a parameter does not appear in a block, then its defaults are automatically assumed for that block.
The SAFEGUARD statements that set the parameters are listed below:
backdrive current            package
bond wire                    thermal resistance
heat source
operating temperature
overdrive power
Refer to the descriptions of the individual statements for details.
