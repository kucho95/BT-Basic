changen (edit)
Title: CHANGE NEXT OCCURRENCE OF A STRING
The changen (change‑next) function replaces the next occurrence of the first string of text <first string> with the <second string>. The search for <first string> begins at the current position of the cursor on the screen.
changen operates exactly like the change function except that changen does not change multiple strings; see the description of the change function for details.
Syntax
  changen <first string> to <second string>,<error variable>
     <first string> and <second string> are <string expressions>
     <error variable> is a <numeric variable>
Parameters
<first string>
The string of characters to be replaced.
<second string>
The string of characters to replace the first string.
<error variable>
The identifier of an error variable.
Examples
     ! first line
     ! second one  <‑‑‑‑ cursor positioned at this line
     ! third line
     ! fourth line
  changen "line" to "string", Err
     ! first line
     ! second one
     ! third string
     ! fourth line
General Information
The changen function is not programmable.
