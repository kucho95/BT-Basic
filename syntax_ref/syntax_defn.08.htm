Comment
A comment is simply text used to annotate a program; it has no effect on program operation, but it appears in any listing of the program.
A comment begins with an exclamation point (!) and can contain any printable characters. The comment can be on a line by itself or it can follow a statement on the line; however, it must be the last item on the line. A comment is terminated by the end of the line.
Many of the examples of program statements in this book use comments as explanatory text.
Example 7 contains some comments that you might include in a program to make the program more readable.
Example 7  
  D$ = "He said 'Hello' to his friend."
  print D$              ! prints He said 'Hello' to his friend.
  E$ = 'He said 'Hello' to his friend.'  ! error
 
When an existing file is brought into the workspace and syntax checked (see the get and load statements), the syntax checker identifies lines with errors by inserting two exclamation points at the beginning of those lines. The use of the double exclamation marks distinguishes those lines from other comments, which usually have just one exclamation mark.
