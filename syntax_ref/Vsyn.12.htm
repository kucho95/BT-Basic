verify channels (DEBUG)
Title: VERIFY THE CONDITION OF DIGITAL CHANNELS (DEBUG)
The verify channels command scans digital channel resources on all hybrid pin cards in the testhead and identifies those channels which may be exposed to voltages from the board under test that are outside the supported voltage range. Any channels identified are listed to the report device as BRC and node pairs. The command can only be run after issuing a powered command statement.
Typically the verify channels command is used during debug and after setting up all the DUT power supplies to scan for unsupported voltage levels. If a channel is identified, it is protected from being used in subsequent digital or mixed tests that require the digital channel resource. In the event this channel is used during test execution, a fatal error will be issued that indicates an over/under voltage condition exists and the device test will halt.
If the node is required for test, fixture electronics will be necessary to buffer the digital channel’s inputs and/or outputs appropriately to handle these higher voltages.
See Test Methods and Specifications for more information about the voltage ranges supported on pin cards.
