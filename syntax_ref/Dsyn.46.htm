display hex (DEBUG)
Title: CHANGE DISPLAY TO HEXADECIMAL FORMAT
The display hex function changes the display format from its current format to the hexadecimal format. There are three display formats: graphics, states and hexadecimal—also see the display graphics and display states statements.
The hex format is like the states format except that each group of four lines is combined into one line. For each vector, the four states on the combined lines form a hexadecimal digit, with the top state being the most significant bit of that digit. For instance, if the four digits from top to bottom are 0100, then the digit 4 is displayed; if the combined states are 1011, then a B is displayed.
The groups of four lines always start on set boundaries of multiples of 4, plus 1; that is, starting on lines 1, 5, 9, . . . 133, 137, . . . etc.
All four states in each group assume the same type as the top state. For instance, if the first line in the group was displaying expected data, and the other three, actual data, then the combined data for all four lines is expected.
Different colors are used in the display to denote the different types of data:
• Green represents actual states; that is, states that have been received by a system receiver or by the probe.
• White represents expected driver and receiver states read from the test.
• Red represents failed states. When a state fails, the expected level of that state is displayed.
Syntax
  display hex
Parameters
(none)
Examples
  display hex
General Information
The hex display is used with VCL tests which use hexadecimal format in the vector definitions. Hex is most useful for looking at bus lines, such as address lines.
