fbon/fboff (BT-Basic)
Title: VACUUM SYSTEM MANIPULATION
The fbon function turns on vacuum B. The fboff function turns off any vacuum that is currently on; it does not open GP relays that were previously connected.
There are four vacuum systems—A, B, C, and D—in the testhead. These vacuum systems are controlled by the external port relays. The external port relays are mapped to the vacuum systems by the vacuum statements in the system config file. The testhead configuration function includes a description of the vacuum to relay mapping in its report.
You can use the vacuum well (BT-Basic) function in the testplan to specify mapping of vacuum wells to the fxon statements. See the syntax description of the vacuum well (BT-Basic) function.
The system turns off the DUT supplies and disconnects them prior to turning vacuum on or off.
 
 
Execute a powered or unpowered statement before using this statement.
Syntax
  fbon
  fbon <delay>
  fboff
  fboff <delay>
  fboff <delay>, <error variable>
  fboff, <error variable>
     <delay> is a <numeric expression>
     <error variable> is a <numeric variable>
Parameters
<delay>
Numeric expression which specifies (in seconds), how long to wait after executing the function, before continuing.
– Range is 0 to 327.00 s.
– Default for fbon is 1.5 s.
– Default for fboff is 0 s.
Examples
  fbon 2          ! Turn on vacuum B and wait 2 seconds before continuing.
  fboff           ! Turn all vacuum off.
General Information
If autoadjust is turned on, an autoadjust is executed during an fboff if there has been 1000 hours of cpu time, or + or - five degrees centigrade of temperature change, since the last autoadjust.
