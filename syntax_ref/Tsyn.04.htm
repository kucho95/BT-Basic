target (CONFIGURATION)
Title: SPECIFY WHICH SYSTEM IS USED TO TEST A BOARD
The target statement specifies which kind of board test system will be used to test a board. This statement is valid in the standard configuration file or in board configuration files, but it must not appear in the testhead configuration file.
Note that the target statement is optional. If no target statement appears in the configuration file, the system defaults to target unmux for UnMux systems and target mux advanced for Mux systems. If this statement is used, it must be the first line in the configuration file.
Syntax
  target <system type>
     <system type> can be:  unmux                ! UnMux system
                            mux advanced         ! Mux system
                            mux standard         ! Mux system
                            mux high accuracy    ! Mux system
                            mux unpowered        ! Mux system
 
Parameters
<system type>
Specifies the type of board test system to be used.
