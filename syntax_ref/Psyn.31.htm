prerun (BT-Basic)
Title: PRERUN A PROGRAM
The prerun function initializes the BT-Basic program currently in the system workspace. When a program is initialized, any workspace previously reserved for variables is released for general use. After you have used prerun to initialize the program, you can call subroutines from the command line.
Syntax
  prerun
Parameters
(none)
Example
  prerun             ! Initializes the program currently in the system workspace.
  load "test2"       ! Clears the workspace, loads the program from file "test2".
  prerun             ! Initializes the program.
General Information
During a prerun the system gathers information about the program—where to find the labels, where the subprograms are located, etc.
The learning process cannot be controlled by the user.
It is entirely automatic and invisible to the user, the only outward sign being that subsequent runs are faster than the first run. You can use the nrun function to determine if the program has been run or prerun since it was last loaded or edited. The prerun function is not programmable.
