<inhibit EOL spec>
The <inhibit EOL spec> is used to prevent the automatic end of line sequence at the end of the data output; it is ignored on input. This spec can be used only with devices on GPIB or RS-232. The # cannot appear by itself in an image function; it must be preceded by at least one <alpha spec> or <digit spec>.
 
 
This spec cannot use a <repeat factor>.
INPUT using <inhibit EOL spec>
An <inhibit EOL spec> is ignored during data input.
Example of data input with <inhibit EOL spec>
  ! File "tfile" contains the following:
  !         "abcdefghijklmnopqr"(EOR)
  Read4: image 6a, 2#, 4a
  enter "tfile" using Read4; T$, D$
  print T$; tab(9) D$
  !
  ! prints    abcdefghij
OUTPUT using <inhibit EOL spec>
When an <inhibit EOL spec> is used to output data, it inhibits the EOL sequence when the current line is output.
Example of data output with <inhibit EOL spec>
    ! This routine measures a voltage six times
    ! and prints the results
    for I = 1 to 6
    !
    ! *** These lines contain the instructions to
    ! *** make a measurement and store the measured
    ! *** value in the variable "Voltage"; that value
    ! *** is then printed by the next two statements
    !
       Volts: image 4x, d.ddd, a, #     ! suppressed EOL
       assign @Printer to "/dev/hpib01/06"
       output @Printer using Volts; Voltage, "V"
    next I
    output @Printer                     ! outputs only an EOL
    !
    ! prints    (with assumed values):
    ! 1.003V    1.002V    1.003V    1.001V    1.002V    1.003V
