set slew rate (VCL) (ITL)
Title: CHANGE THE SLEW RATE ON A DRIVER
(Mux systems only)
The set slew rate statement is optional; you can use it in the Declaration section of a VCL library test to change the slew rate on selected drivers (inputs and bidirectional pins) to the board under test.
The default slew rate for the test must be established in a family statement before the set slew rate statement can be used.
Syntax
   set slew rate on <identifiers> to <speed>
   set slew rate on <identifiers> to fastedge
   set slew rate on <identifiers> to slowedge
      <speed> is a <numeric constant>
      <identifiers> can be:
         pins <pin-id list>
         device <designator> pins <pin-id list>
         nodes <node-id list>
         relays <relay-id list>
         groups <group-id list>
            <designator> is a <string constant>
            The format of the <id lists> is:
               <item>
               <item>,<item>
               <item>,<item>, . . . <item>
                  <items> can be:
                     a. for <pin-id list> — <numeric constant>
                                            <string constant>
                     b. for <node-id list> — <string constant>
                     c. for <relay-id list> — <5-digit numeric constant>
                                              (represents brrcc)
                     d. for <group-id list> — <label>
Parameters
 
<speed>
The slew rate for the selected pins. The units are volts/microsecond, with increments of 25.
25 <= speed <= 250
fastedge = 100
slowedge = 50
<identifiers>
The list of pins (groups, nodes, etc.) whose slew rates are to be changed. Only input pins and bidirectional pins can be specified.
<designator>
String constant representing a device under test. This is the same as the device designator entered in Board Consultant. It can contain up to 48 printable characters, but with no space.
<id list>
A list of pins represented by the following types of id:
• <pin id>
• <node id>
• <relay id>
• <group id>
These parameters are the same as the ids used to identify the pins in the assign to statements in the test. See the description of the parameters in the assign to (VCL) statement.
Example
   family CMOS
   set slew rate on device "U68" pins 13, "11" to 125
   set slew rate on relays 00962, 00403 to 80             ! rounds to 75 v/usec
   set slew rate on groups Control to fastedge            ! 100 v/usec
General Information
The standard families have the following slew rates:
• TTL — 100
• CMOS — 50
• ECL — 150
