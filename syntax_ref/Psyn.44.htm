processor (VCL)
Title: IDENTIFY THE PROCESSOR
(Mux systems only)
The processor function is used in the Declaration Section of the test to specify what type of digital compilation will occur. High-speed systems with a maximum vector rate of 20 MHz can use the vpuplus processor to compile digital tests. This processor compiles tests using a pipe-depth of 14 vectors. Systems whose maximum vector rates are less than 20 MHz must use the vpu processor to compile digital tests. This processor compiles tests using a pipe-depth of 12 vectors. To control which processor is used to compile a digital test, use the processor function.
If you target a high-speed system in the board configuration file, you can specify either the vpuplus processor or the vpu processor in a digital test. For an executable test, if no processor function is used, the high-speed systems use the vpuplus processor. You must specify the processor in a library test.
Digital tests that are compiled using the vpuplus processor are compatible only with high-speed systems. To be compatible with all Mux systems, digital tests must be compiled with the vpu processor.
Systems other than a high-speed system always compile tests using the vpu processor. You do not need to specify the processor in the test.
Syntax
   processor vpuplus
   processor vpu
Parameters
(none)
Example
   ! in the Declaration section
      processor vpu
