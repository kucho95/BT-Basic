select boards on panel (BT-Basic)
Title: DETERMINES WHICH BOARDS ON A PANEL ARE SELECTED FOR TESTING
The select boards on panel statement lets you use the mouse or softkeys to specify which boards on a multi‑board panel are to be tested, and which are not.
If no board graphics statement is executed before executing this statement, the selection status of boards is textually displayed. The select boards on panel statement temporarily redefines the softkeys so you can use them to select or deselect boards, and later restores their previous definitions. If a board graphics statement is executed before executing this statement, the panel is displayed graphically by the board graphics viewer.
Besides using the softkeys, this lets you select boards by clicking on them with the mouse. Boards that have been selected are identified by hashed yellow lines.
After using either method to choose the desired boards, press or click the softkey labeled Done (you can quickly select all boards by pressing Done without making any choices).
This returns your choices to an integer array used to store board selection information associated with this statement (see the example below).
Syntax
  select boards on panel <array id>
  select boards on panel <array id>, <error variable>
     <array id> is a <string variable>
     <error variable> is a <numeric variable>
Parameters
 
<array id>
The identifier of an integer array whose elements correspond to individual boards on a multi‑board panel. Each element receives a zero if the board is not highlighted and a 1 if the board has been highlighted.
<error variable>
The identifier of an optional error variable.
Example
Excerpt from a testmain used to test multi-board panels:
  dim BoardSet(0:256)               ! Array used to store status information.
     ...
  board graphics, Err               ! Ignore error produced by small monitor.
     ...
! Determine which boards are selected/deselected.
  select boards on panel BoardSet(*)
     ...
  for I = 1 to Number_Boards_On_Panel
     if BoardSet(I) then
        Status(I) = Passed
     else
        Status(I) = Xed_Out          ! 'Xed_Out' = deselected board.
     end if
  next I
     ...
  test "u1" on boards BoardSet(*)
     ...

! boards in green (pass) or red (fail):

        ...

Mux system only: Because the select boards on panel statement requires operator intervention, it cannot be used when a board handler is used in an automated production line. Instead, you might call a custom subroutine that determines which boards should be tested, like this:
 
if Using_Board_Handler then
   if Using_Pass_Through then
      call Get_Boards_To_Test_On_Panel     ! Call user-written subroutine that
   else                                    ! specifies which boards to test.
      select boards on panel BoardSet(*)
   end if
else
   select boards on panel BoardSet(*)
end if
General Information
If your system has a small (12”) monitor installed and you use the select boards on panel statement, you cannot use the board graphics statements. Instead, you must use only the softkeys to select boards to be tested.
Note that the integer array includes array element zero, which refers to the panel itself. This information is used by datalogging and is unaffected by the select boards on panel statement.
