verify vtep (BT-Basic)
Title: VERIFY nanoVTEP PROBES, MUX CARDS, AND CET SIGNAL CONDITIONER CARDS
Verify nanoVTEP probes and MUX cards
Use the verify vtep function and the guided probe to verify the nanoVTEP (and VTEP) probes and mux cards in your test fixture.
The nanoVTEP mux card verification automatically checks the mux card wiring, filter circuit, and orientation of the nanoVTEP probes; this requires no user intervention.
The nanoVTEP probe verification checks the wiring and DC operation of each nanoVTEP probe; this requires you to manually contact each nanoVTEP probe sensor plate with the guided probe. If manual start is on (set by softkey f7), you need to either press the start softkey (f1) on the terminal, or step on the foot switch while contacting the probe with the guided probe. If auto start is on (set by softkey f7), you do not need to press the start softkey or step on the foot switch.
Pass and failure information is sent to the printer is device.
You can use the find vtep probes function to identify the nanoVTEP probe that you are contacting with the guided probe. See the syntax description of the find vtep probes function.
Verify CET signal conditioner card
The verification of CET signal conditioner cards checks the connections to the CET signal conditioner cards, address settings, and general functionality. A diagnostic report summarizes any problems found.
Because both the mux card and CET signal conditioner card have shared wiring, verify first the shared wiring with verify all mux cards. Then verify the CET signal conditioner card. The CET signal conditioner card requires access to a power source, such as a DUT supply or supply associated with an auxconnect source available on the system card (available with the USB Interface Kit) or fixture power supply on the ASRU-N card. BT-Basic must be in powered mode and the supply enabled before verifying the CET signal conditioner cards.
Alternatively the unique wiring to the CET signal conditioner card can be verified without applying power by using the verify pins command. Verify pins will report the BRCs probed on the CET signal conditioner card.
Syntax
  verify all mux cards
  verify mux <mux card number> port <port number>
  verify mux <mux card number> port <port number> module <module number>
  verify all cet cards
  verify all vtep probes
  verify vtep probes from <device name>
  verify vtep probes <device id list>
     <mux card number> is an <integer>
     <port number> is an <integer>
     <module number> is an <integer>
     <device name> is a <string expression>
     <device id list> can be:   <device id>
                                <device id>, <device id>
                                <device id>, <device id>, . . ., <device id>
        <device id> is a <string expression>
Parameters
<mux card number>
An integer from 1 to 15 that identifies the mux card address.
<port number>
An integer from 1 to 64 that identifies the port on the mux card.
<module number>
An integer from 0 to 3 that identifies the testhead module. This is used for PanelTest and Throughput Multiplier or Advanced Throughput Multiplier.
<device name>
A <string expression> that identifies the device at which to start the nanoVTEP probe verification.
<device id>
A <string expression> that identifies the device for which to verify the nanoVTEP probe.
Example
  verify all mux cards                   ! Automatically verify each mux card.
  verify mux 3 port 22                   ! Verify only the specified mux port.
  verify mux 3 port 22 module 0          ! Verify only the specified mux port in
                                         ! the specified module.
  verify all vtep probes                 ! Verify each nanoVTEP probe as it is listed
                                         ! on the screen.
  verify vtep probes from "U18"          ! Start the verification process from a
                                         ! specified device.
  verify vtep probes "U18"               ! Verify the nanoVTEP probe for U18.
  verify vtep probes "U18", "U22"        ! Verify nanoVTEP probes for U18 and U22.
  verify vtep probes "U2", "U5", "U12", "U18"      ! Verify nanoVTEP probes for
                                                   ! U2, U5, U12, and U18.
General Information
The softkeys are redefined for nanoVTEP probe verification.
 
Table V-1 Softkeys for nanoVTEP probe verification
Softkey
Description
f1 Start
Verify the nanoVTEP probe that you are contacting with the guided probe. Pressing this softkey is the same as stepping on the foot switch.
f2 Skip Probe
Skip (do not verify) the nanoVTEP probe currently specified on the screen and proceed to the next nanoVTEP probe in sequence.
f3 Re-try Probe
Verify the currently specified nanoVTEP probe again.
f4 Backup Probe
Re-verify the previous nanoVTEP probe.
f7 Auto Start / Manual Start
Instruct the system to start automatically or to wait for you to press the Start softkey or foot switch.
f8 Quit Verify
End the verify process.
