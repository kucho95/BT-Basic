len (BT-Basic)
Title: LENGTH OF A STRING
The len function returns a decimal integer equal in value to the length of the function's string argument; that is, equal to the number of characters in the string. If the argument is a variable, the length returned is the current length, not the dimensioned length, of the variable.
Syntax
  len (<string expression> )
Parameters
<string expression>
The string whose length is to be determined.
Examples
  len ( "A man and his dog." )        ! returns    18
  len ("")                            ! returns    0
  Canis$ = "dog"
  print len(  Canis$ & "star")        ! prints    7
  K$ = "Apple"
  Rations$ = " pie"
  K$[len(K$) + 1] = Rations$
  print K$; len(K$)                   ! prints    Apple pie 9
  K$[6] = "s" \ print K$; len (K$)    ! prints    Apples 6
