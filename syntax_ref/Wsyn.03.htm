wait (BT-Basic)
Title: PROGRAM WAIT
The wait function causes the program to pause the specified number of seconds before the next function is executed.
Syntax
  wait <numeric expression>
Parameters
<numeric expression>
The duration, in seconds, of the wait period. The value must be greater than or equal to 0. Positive values of less than 25 ms are treated as a no operation, and negative values produce an error. Due to system overhead processes, the practical minimum value is about 50 ms. Thus, a value of 25–80 will yield about 80 ms, 80–130 will yield about 130 ms, 130–180 will yield about 180 ms, etc.
Example
  wait 6                 ! Waits 6 seconds
  A=150m \ wait A        ! Waits 180 milliseconds
  wait 2m                ! Ignored (no‑op)
  wait ‑100m             ! Produces an error
