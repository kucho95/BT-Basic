<page spec>
• @
• @@
• @@ . . . . @
The <page spec> represents one or more page ejects (ejections) or form feeds.
INPUT using <page spec>
A <page spec> is ignored during data input.
Example of data input with <page spec>
      ! File "tfile" contains the following:
      !             "abcdefghijklmnopqr"(EOR)
      Read4: image 6a, 2@, 4a
      enter "tfile" using Read4;  T$, D$
      print T$; tab(9) D$
      !
      ! prints    abcdef ghij
OUTPUT using <page spec>
When a <page spec> is used to output data, each @ specifies one page‑eject. The current page is the first page to be ejected. Output then resumes at the top of the next page after the last one ejected (starting in column 1).
Example of data output with <page spec>
      Chap: image 20x, 18a, 2@, 25x, 9a
      print using Chap;  "(End of Chapter 3)", "CHAPTER 4"
      !
      !      ‑‑‑‑‑‑20 spaces‑‑‑‑>‑‑‑‑‑18 spaces‑‑‑>
      ! prints:
      !                          (End of Chapter 3)
      !
      !      ......ejects current (first) page and second page
      !              and continues at top of third page........
      !
      !                                CHAPTER 4
      !      ‑‑‑‑‑‑‑‑‑-‑25 spaces‑‑‑‑‑>‑‑‑‑9‑‑‑>
