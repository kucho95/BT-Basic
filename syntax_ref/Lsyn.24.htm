log — function (BT-Basic)
Title: NATURAL LOGARITHM
The log function returns the natural logarithm (to the base e—2.71828182846) of the function's argument.
Syntax
  log(<numeric expression>)
Parameters
<numeric expression>
The argument of the function; it must be positive and greater than zero.
Examples
  print log(8001)      ! prints     8.98732181285
  print log(.0026)     ! prints    ‑5.95224383395
  print log(0)         ! error
General Information
If the log function by itself is to be executed in the command line, enclose the function in parentheses [as in — (log (8001)) ], otherwise the system assumes that the log function is intended. It is not necessary to do this in a program because program‑logic distinguishes the function from the function.
