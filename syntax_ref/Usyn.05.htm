unit disable test (VCL)
Title: DETERMINE IF DEVICE CAN BE DISABLED
The unit disable test function starts a digital unit containing statements to verify operation of the disabling lines on a device, such as a busable device. Normal pass/fail logic is reversed during the execution of the unit disable test. That is, if the vectors pass, then the device was not disabled and the test fails. As soon as any vector fails (the device is disabled), the rest of the unit is skipped.
The unit cannot have homing loops.
Syntax
  unit disable test
  unit disable test <unit id>
     <unit id> is a <string constant>
Parameters
<unit id>
A string of characters identifying the unit. The id can contain any printable characters. The id is not used in the test but it does help you to identify the unit for editing purposes.
Example
  ! vectors for the unit disable test
        . . .
     vector Ones_with_Disable
        set Enable to "0"
        set Inputs to "1111"
        set Outputs to "1111"
     end vector
     vector Zeros_with_Disable
        set Enable to "0"
        set Inputs to "0000"
        set Outputs to "0000"
     end vector
  ! vector execution
        . . .
     unit disable test
        execute Ones_with_Disable
        execute Zeros_with_Disable
        execute Ones_with_Disable
     end unit
General Information
There is some delay after each vector in this unit. Therefore, if the device has any critical timing requirements, the critical vectors should be executed before the disablevector unit is started.
