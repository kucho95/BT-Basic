supplies (CONFIGURATION)
Title: DUT SUPPLY CONFIGURATION
The supplies statement specifies which DUT power supplies are used in a certain module. The DUT power supplies available are:
• N5747A – one output (high voltage and high current)
• N6751A – four outputs
• N6752A – four outputs
• N6746A – four outputs
• N6773A – two outputs
The supplies statement must be used within a block defined by a module and end module statement. This statement is used in both the testhead configuration file and the board configuration file.
Syntax
supplies <logical supply range>
supplies <supply type> <logical supply range>
supplies <supply type> <logical supply range> asru channels <channel range>
supplies <supply type>.<ps-output-id> <logical supply range>
supplies <supply type>.<ps-output-id> <logical supply range> asru channels <channel range>
 
  <supply type> depends on DUT power supply model installed. See Table S-6.
    <logical supply range> can be:
          <logical supply>
          <logical supply>, <logical supply>
          <logical supply>, <logical supply>, <logical supply>, <logical supply>
          <logical supply> to <logical supply>
          <logical supply> to <logical supply>, <logical supply> to <logical supply>
      <logical supply> is an integer from 1 to 24
      <channel range> can be:  <channel number>
                               <channel number>, <channel number>
                               <channel number> to <channel number>
        <channel number> is an integer from 1 to 6
Parameters
<supply type>
Specifies which type of DUT supply is being used. See Table S-6.
<channel number>
Specifies an ASRU channel on the ASRU card. These channels route outputs from a DUT power supply to the fixture. See Table S-6.
<logical supply>
Specifies individual DUT power supply outputs. Other statements use this number to identify power supply outputs.
<ps-output-id>
The output ID for the specified power supply:
• For ps6752 – an integer from 1 to 4
• For ps6746 – an integer from 1 to 4
• For ps6773 – an integer from 1 to 2

Example
  module 3
     cards 1 asru n revision
     cards 2 to 5 hybrid high accuracy double density
     cards 6 control xtpb
     cards 7 to 11 hybrid high accuracy double density
     supplies ps6752 15 asru channels 5 to 6
  end module

  supplies ps6773.1 18 asru channels 5 to 6
For i3070 Series 5 systems
DUT power supplies on the i3070 Series 5 systems may include the following:
• 6621A – two outputs
• 6624A – four outputs
• 6634A – one output (high voltage)
• 6642A – one output (high current)
The old 66xx power supplies cannot be used together with the newer N67xx or N5747 power supplies.
