start vector numbering at (TEXT)
Title: FAULT DICTIONARY CONFIGURATION FILE
(Mux systems only)
The start vector numbering at statement is used in the fault configuration file, fault.config. This statement is used to ensure that vector numbers in the fault dictionary correspond to the actual test vector numbers. For example, some initialization sequences, such as homingloops, cannot be simulated. If the test engineer uses a homingloop to initialize parts, the fault dictionary vector numbers will not be in sync with the actual test vector numbers.
You can account for these extra vectors by specifying in the configuration file the number of initialization vectors. The number you specify in the start vector numbering at statement is the first vector number after initialization is done. The default number is one, which has no effect on the fault dictionary vector numbering.
Syntax
   start vector numbering at <vector number>
      <vector number> is a positive <integer>
Parameters
<vector number>
Positive integer indicating the vector number in the test that corresponds to the first vector in the fault dictionary.
Example
      ! start vector numbering at      ! Defaults to "1"
   start vector numbering at 51        ! First 50 vectors in the test are not
                                       ! assigned a vector number
