nrun (BT-Basic)
Title: NUMBER OF PROGRAM RUNS
The nrun function returns the number of times a program has run since it was last brought into the workspace (or subsequently edited). The value of the function is incremented each time the run function is executed.
The initial value at login is zero (no runs). The function is reset to zero if the workspace is saved or if a new file is brought into the workspace, or if the workspace is modified.
Syntax
  nrun
Parameters
(none)
Example
  print "Board Test Run#"; nrun; "successfully completed."
     ! Prints (with assumed value):
     ! Board Test Run# 13 successfully completed.
  if nrun = 1 then
     mass storage is "/board‑test/1145‑47"
     load board   ! Loads digital test data for first run only
  end if
