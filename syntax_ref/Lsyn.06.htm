learning (BT-Basic)
Title: LEARN FLAG STATUS
The learning function returns a value representing the status of the learn flag (see the examples, below). The learn flag is used in digital testing to learn CRCs from a known good board. The flag is set on to learn and off for testing. The learning function provides a way to interrogate the learn flag to find its current state.
Syntax
  learning
Parameters
(none)
Examples
  learn off
  print learning       ! prints    0
  learn on
  print learning       ! prints    1
  learn 6 times
  print learning       ! prints    6
