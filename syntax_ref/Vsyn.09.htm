vector cycle (DEBUG)
Title: CHANGE THE VECTOR CYCLE TIME
The vector cycle function temporarily changes the vector cycle time in the test; that is, the time between starting one vector and starting the next. The vector cycle function cannot be used with tests which have timing sets (on Mux systems only).
Except that it is temporary, vector cycle in debug is the same as vector cycle in VCL.
Syntax
  vector cycle <time>
     <time> is a <numeric constant>
Parameters
<time>
The vector cycle time, in seconds. See your system’s specifications for the range of valid vector cycle times.
Example
  vector cycle 600n          ! 600 nanosecs
  vector cycle 0.00125       ! 1.25 msecs
  vector cycle 3u            ! 3 microsecs
General Information
safeguard none must be specified before the vector cycle function can be used.
