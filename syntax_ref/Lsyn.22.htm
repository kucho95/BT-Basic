local lockout (BT-Basic)
Title: GPIB LOCAL LOCKOUT
The local lockout function sends the Local Lock‑Out (LLO) message to the GPIB interface. This prevents any device on the bus from being locally operated; that is, all devices are completely under system control.
Syntax
  local lockout <GPIB>
     <GPIB> can be <file id> or an @<name>
        <file id> is a <string expression>
        <name> is a <label>
Parameters
<GPIB>
The address of the bus. All devices on the bus are affected.
Examples
Shortcut Method:
  local lockout "/dev/hpib1"          ! Sends Local Lock-Out (LLO) to the bus
  assign @Auto to "/dev/hpib1"
  local lockout @Auto
 
Absolute Path Method:
  Bus$ = btgetenv$("I3070_ICT_ROOT")
  local lockout Bus$&"/dev/hpib1"     ! Sends Local Lock-Out (LLO) to the bus
  assign @Auto to Bus$&"/dev/hpib1"
  local lockout @Auto
General Information
 
 
These examples assume the dev file hpib1 contains the SICL interface name hpib7.
