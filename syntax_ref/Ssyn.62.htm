srq (BT-Basic)
Title: RETURNS STATUS OF SRQ LINE ON GPIB BUS
The srq statement returns 1 if the SRQ (service request) line on the GPIB bus is asserted and 0 if it is not.
Syntax
  srq <GPIB>
     <GPIB> can be a <file id> or an @<name>
        <file id> is a <string expression>
        <name> is a <label>
Parameters
<GPIB>
The address of the bus.
Example
Shortcut Method:
  Value = srq "/dev/hpib1"             ! Returns status of SRQ line
 
Absolute Path Method:
  Bus$ = btgetenv$("I3070_ICT_ROOT")
  Value = srq (Bus$&"/dev/hpib1")     ! Returns status of SRQ line
General Information
If an instrument on the bus has information of which the controller should be aware, it can assert the SRQ line to ask for the controller’s attention.
 
 
These examples assume the dev file hpib1 contains the SICL interface name hpib7.
