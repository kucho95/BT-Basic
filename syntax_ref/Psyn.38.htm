printer is (BT-Basic)
Title: SET DEFAULT OUTPUT DEVICE
The printer is function changes the default printer, which is the file, device, or window to which data is sent by the print and print using statements. At login the default printer is the active window on the workstation's screen, which is opened exclusively; i.e., it cannot be accessed by any other user.
If a printer is function selects another printer, then that becomes the default until another printer is function is executed, or until the user logs out. The function is global, which means it can be executed in any environment (from the keyboard, from the main program, from a subroutine, etc.) and it will then be in effect for all other environments.
When printer is is executed, it closes the current printer before opening the new one. If the printer is a file that does not exist, it will be automatically created. If new is specified and the file already exists, an error occurs. If the open is not successful, the active window (the screen) becomes the default printer.
If <printer list> includes lineprinter, the data is stored in a buffer (spooled) and sent to the line printer when a subsequent printer is * function is executed; unless a printer is * function is executed, the data is not sent to the line printer.
<access> parameters determine how the printer is opened. These parameters can be omitted and defaulted; see Parameters below.
Syntax
  printer is <printer list>
  printer is <printer list>;<access>
  printer is *
  printer is <printer list>,<error variable>
  printer is <printer list>,<error variable>;<access>
  printer is *,<error variable>
     <error variable> is a <numeric variable>
     <printer list> can be:
        <file id>
        lineprinter
        window
        window,<file id>
        <file id>,window
        window,lineprinter
        lineprinter,window
     <access> can be:
        <a/n/o>
        <a/n/o>,<e/s>
        <a/n/o>,<e/s>,echo
        <a/n/o>,echo
        <e/s>
        <e/s>,echo
        echo
           <a/n/o> can be:
              append
              new
              over
           <e/s> can be:
              exclusive
              shared
Note that the <access> parameters do not have to be in the order shown; they can be arranged in any order; see the examples below.
Parameters
 
<printer list>
A list containing the identifier(s) of the new default printer(s). The old printer is closed and the new printer is then opened. If the new printer cannot be opened, the old printer remains as the default. All identifiers in <printer list> share a single set of <access> parameters. <printer list> can contain the following identifiers in the combinations shown in the Syntax section:
• <file id> – The data is sent to the specified file.
• lineprinter – The data is sent to a buffer and from there sent to the line printer when a printer is * function is executed.
When <printer list> includes lineprinter, the data will not be printed unless a subsequent printer is * function is executed.
• window – A new window is opened and the data appears in that window.
*
An asterisk specifies the original default; that is, whichever window is active on the workstation screen.
<error variable>
The identifier of an error variable.
<access>
Determines how the new default printer is opened.
<a/n/o>
Determines how the data is written. If the new printer is a file, the file is created if it does not exist. <a/n/o> can be:
• append – Adds new data at the end of any existing data; if none is present, writes from the beginning.
• new – Creates a new file, device, or window and writes from the beginning. An error occurs if the new printer is a file that already exists.
• over – Writes from the beginning and destroys any existing data.
If none of the above is specified, <a/n/o> defaults to over.
<e/s>
Determines whether the new default printer is for exclusive or shared use. If not specified, defaults to shared.
echo
The output goes to the new default printer and to the workstation screen (only to the screen, if it is the default). If this parameter is not specified, echoing is not turned on.
Example
  printer is "tsdata"; exclusive, over     ! Output is sent to file
                                           ! "tsdata"; echo is off
  T$ = "tsdata"
  printer is T$                            ! Same as above
  printer is "/dev/tape2", Err1; echo, shared, append    ! function with error variable
  printer is window, "temp_file", Error; echo
                  ! Data is sent to a new window and to a file. The data is echoed
                  ! to the screen, and the function includes an error variable.
  printer is *    ! Default is the workstation screen. Closes the old printer.
                  ! Any buffered data sent to "lineprinter" is printed now.
