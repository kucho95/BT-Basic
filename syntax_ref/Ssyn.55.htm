softkeys to/over (BT-Basic)
Title: SAVE SOFTKEY DEFINITIONS
After softkeys have been defined with the softkey statement, they are stored locally. To save them in a text file, you must use the softkeys to and softkeys over statements.
The softkeys to statement writes the softkey definitions to a specified file. However, the file must not exist or a runtime error occurs. The softkeys over statement writes the definitions to the specified file, whether it exists or not. If it exists, then it is overwritten and the previous contents are lost.
Syntax
  softkeys to <file id>
  softkeys to <file id>,<error variable>
  softkeys over <file id>
  softkeys over <file id>,<error variable>
     <file id> is a <string expression>
     <error variable> is a <numeric variable>
Parameters
<file id>
Identifies a file to hold the softkey definitions.
<error variable>
The identifier of an error variable.
Example
  softkeys to "softkeys1"
  softkeys over "/board/sdevs"
General Information
If desired, you can create a softkey definition file from scratch in text mode. Or, you can edit an existing file. A text file containing the softkey definitions is formatted as follows:
1 The first line contains a single numeric character in the first column to indicate how many softkey definitions are saved.
2 Each softkey definition contains five lines as follows:
• Line 1 – Contains the softkey number in column 1, the process in columns 3‑10, the length of the definition string (how many characters) in columns 11, 12 and 13, and the label starting in column 15.
• Lines 2, 3, 4 – Each contain 80 characters of the definition string.
• Line 5 – Contains the final 16 characters of the definition string.
All or portions of lines 3 through 5 may be blank if the softkey definition string is brief. For example, lines 3 through 5 are blank if the entire softkey definition string fits on line 2.
A sample softkey definition file looks like this:
  2
  1 E        007 Resave File
  re-save
     .
     . (3 blank lines)
     .
  2 T        027 Reminder
  Adjust pot to defined value
After loading this file with a softkeys statement, softkey f1's label reads Resave File and pressing the softkey executes a re-save. Softkey f2’s label reads Reminder and pressing the softkey places the text Adjust pot to defined value on the command line as a typing aid. If desired, you can create a softkey definition file from scratch in text mode. Or, you can edit an existing file.
