balanced ports (CONFIGURATION)
Title: BALANCED PORTS CONFIGURATION
The balanced ports function declares the existence of balanced ports on the Utility Card. The balanced ports function is used in the board configuration file.
The balanced ports function must be within a block defined by the module and end module statements.
Syntax
  balanced ports bp<port number> to bp<port number> on card <slot number>
  balanced ports bp<port number>, bp<port number> on card <slot number>
     <port number> is an integer
     <slot number> is an integer
Parameters
<port number>
Port number is an integer value from 1 to 8 (see Table B-1).
<slot number>
The identifier of the module slot in which the Utility Card is installed.

Example
module 2
  cards 1 asru n revision
  cards 2 to 5 hybrid high accuracy double density
  cards 6 control xtpb
  cards 7 to 9 hybrid high accuracy double density
  cards 10 utility   ! Utility Card
  supplies 1 to 4
  ports ext1, ext2
  balanced ports bp3 to bp4 on card 10
            ! Makes the logical connection of bp<x> to an instrument name.
            ! User can then connect a node name to an instrument name in an analog test.
  connect "dvm" balanced to bp3
  connect "VXI" balanced to bp4
end module
