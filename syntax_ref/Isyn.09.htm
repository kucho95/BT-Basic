<freefield spec>
   k
A <freefield spec> allows I/O operations on data regardless of whether it is ASCII characters or numeric data.
 
 
This spec cannot use a <repeat factor>.
INPUT using <freefield spec>
When a <freefield spec> is used to input data, the following usage rules apply:
1 If the data is numeric data:
a Numeric characters include digits, the decimal point, +, -, e, E, k, m, M, n, p and U when their order is meaningful.
b Blanks or trailing non-numeric characters serve as delimiters.
2 If the data is string data:
a A carriage return (CR) not immediately followed by a line feed (LF) is placed in the string.
b Entry to a string terminates on CR/LF, LF, or when the dimensioned length of the string is reached.
Example of data input with <freefield spec>
  dim C$[5]
  Format1: image k, k, k
  input using Format1; A, B, C$
  !
  ! You input the data: 1.42 9 frank
  !
  print A;B;C$
  ! prints  1.42 9 frank
OUTPUT using <freefield spec>
When a <freefield spec> is used to OUTPUT data, either a number or a string with no trailing blanks is sent.
Example of data output with <freefield spec>
     dim B$[3]
     B$ = "ABC"
     A = 3
     Format1: image k, k, k
     print using Format1; A, B$, 2.5
        ! prints  3 ABC 2.5
