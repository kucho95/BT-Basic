cat (BT-Basic)
Title: CATALOG DIRECTORY ENTRIES
The cat function lists the contents of the specified directory. The list shows the names of the files and directories which are linked to the specified directory, and which are immediately below it in the hierarchy.
The cat function can be programmed, but it is normally executed from the command line.
Syntax
  cat
  cat <parameters>
  cat <parameters>;<option>
  cat;<option>
     <parameters> can be:   <instructions>
                            <instructions>, <error variable>,
                            <error variable>
     <instructions> can be:   <directory id>
                              <directory id> over <file id>
                              to <file id>
        <directory id> and <file id> are <string expressions>
        <error variable> is a <numeric variable>
     <option> can be:   select <string expression>
                        <short/protect>
                        select <search string>, <short/protect>
                        <short/protect>, select <search string>
          <search string> is a <string expression>
          <short/protect> can be:   short
                                    protect
Parameters
<directory id>
The <id> of the directory whose entries are to be listed. If not specified, the working directory is assumed.
<file id>
The <id> of the file where the listing is to be sent. The file cannot already exist; the function creates it. If <file id> is omitted, the list goes to the default output device.
<error variable>
The identifier of an error variable.
<option>
If an option is not specified, just the standard catalog information is listed. If short is specified, the listing shows only the file names. If protect is specified, the listing shows the level of protection (security) assigned to each file. The usage of short and protect is shown in the examples below.
If select <search string> is specified, only the files whose names begin with or match <search string> are listed. Note that <search string> is case-sensitive; i.e., Myfile is not the same as myfile.
Examples
  cat                  ! List entries from working directory to default printer
  cat "/production/voltmeters/board_test" to "listing"
                       ! List entries from specified directory to file "listing"
  cat "tests" to "list", A               ! Includes error variable, A
  cat "/production/voltmeters"; protect
  cat "/production", Errors; short
  cat; select "a", short                 ! Show a short listing of only those
                                         ! files whose names begin with "a"
  cat "tests"; select "test", protect
                       ! List only those files whose names begin
                       ! with "test"; also, show the file protection.
General Information
The following is an example catalog when an option is not specified.
  Date         Time    Size    Type             Name
  Thu Oct 27   10:55   2048    dir              testfiles
  Tue Dec 13   11:33   31086   src basic        my_program
  Mon Dec 12   17:43   657     obj config sys   config.o
Note that Size is the size of the directory entry if the file is a directory. Otherwise, it is the number of Kbytes used by the file.
An example catalog when the protect option is specified is shown below:
  Own/Grp/Oth   Owner   Group    Type             Name
  rwx/r-x/r-x   brian   i5000   dir              testfiles
  rwx/r-x/r-x   tom     i5000   src basic        my_program
  rwx/r-x/r-x   sue     i5000   obj config sys   config.o
The Own/Grp/Oth heading identifies the owner, group, and other user classes. Each user class lists the permissions (read, write, and execute) allowed to users in that class; a - in a field indicates that the permission is not allowed. The owner of the file is usually the person who created the file and assigned the security.
An example catalog when the short option is specified is shown below:
  autofile   board.l   mystuff   testfile   voltmeters
The listing is done in a left to right sequence in five columns.
The select <search string> option is useful when you want to see if a certain file exists; that is, you can use select <search string> to search for a specific file rather than list all of the files in the directory.
