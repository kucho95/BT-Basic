board graphics highlight clear (BT-Basic)
Title: CLEARS THE BOARD GRAPHICS VIEWER'S HIGHLIGHTING
The board graphics highlight clear function selectively clears highlighting provided by the board graphics viewer.
Syntax
  board graphics highlight clear <status>
  board graphics highlight clear <status>, <error variable>
     <status> can be:   active
                        all
                        fail
                        pass
     <error variable> is a <numeric variable>
Parameters
<status>
The status(es) to be cleared, which can be:
• active – The highlight color is yellow.
• all – All highlight colors.
• fail – The highlight color is red.
• pass – The highlight color is green.
<error variable>
The identifier of an optional error variable.
Examples
  board graphics highlight clear pass      ! Clear only the green highlighting.
  board graphics highlight clear all       ! Clear all highlighting.
  board graphics highlight clear fail, Error
                 ! Clear only the red highlighting. Includes an error variable.
