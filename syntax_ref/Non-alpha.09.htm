< (BT-Basic)
Title: LESS THAN
The less than operator compares two expressions to determine if the first is less than the second. If the relationship is true (the first is less) a value of 1 is returned; if the relationship is false (the first expression is not less) a value of zero is returned. Relational operators have a priority of 4.
Syntax
  <expression> < <expression>
     <expression> can be numeric or string
Parameters
<expression>
The quantities to be compared. Expression types cannot be mixed in the same statement; both expressions must be numeric, or both must be strings.
Numeric expressions are compared by value; strings are compared, character by character, according to the ASCII numerical equivalent of each character.
Example
  A=6.25 \ B= (-32) \ C= 6.25       ! assigns values to variables
  print B < A                       ! prints  1
  print C < A                       ! prints  0
  if A<C then print "not"           ! "if" statement checks relationship;
  print "the same"                  !   condition is not met, so skips
                                    !   to the next line and prints:  the same
  Q$ = "dog"
  print "cat" < Q$                  ! prints  1
  N$ = "7401" \ P$ = "74001"
     print N$ < P$                  ! prints  0 (remember this is a string evaluation)
