display start at (DEBUG)
Title: POINT IN THE TEST TO START THE DISPLAY
The display start at function begins the lines in the display at the specified point in the test. The point is identified as a vector.
If the specified starting point is outside the currently displayed window, the test is run again, and new display data is collected.
Syntax
  display start at <vector>
  display start at <vector>,<event>
  display start at <vector>,<event>,<scale>
     <vector> & <event> are <numeric expressions>
Parameters
<vector>
The vector number where the display is to start.
<event>
The number of the event where the display is to start. The event numbering in debug is relative to the drive strobes.
Examples
  display start at 31
  display start at 17,4
  display start at 201,3,5
