diagnose faults (DEBUG)
Title: DIAGNOSE FAULTY TESTS BY CHANGING PARAMETERS
The diagnose faults function attempts to diagnose faults in tests that are marginal, or that run in systems with single-density pin cards but not in systems with double-density pin cards. The function selectively changes test Parameters and then reruns the test several times to determine if it passes and if it is stable. It then prints out the results. If the diagnostics are successful, the function prints a list of parameter changes that you can make to the test's VCL source code. If the verbose parameter is used, the function prints more detailed information.
Syntax
  diagnose faults
  diagnose faults; verbose
Parameters
(none)
Examples
  diagnose faults; verbose
General Information
This function is available on the Util/Admin pulldown menu in device-level debug. Before running diagnose faults, make sure that the system is ready to run the test. For example, DUT power supplies should be on and any gp relays required for the test must be closed.
