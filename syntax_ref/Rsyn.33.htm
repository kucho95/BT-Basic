resistor (ANALOG)
Title: RESISTOR TEST
This statement is used within an analog in-circuit test block to test fixed and variable resistors. Potentiometers, which have two of their three legs connected together, are considered to be variable resistors.
To test variable resistors, include the ad, adjust, option in the resistor statement. This will prompt the operator to adjust the resistor to approximately half its value.
Syntax
  resistor <specs>
  resistor <designator>,<specs>
    <designator> is a <string constant>
     <specs> can be:   <value>,<+tol>,<‑tol>
                       <value>,<+tol>,<‑tol>,<return>
                       <value>,<+tol>,<‑tol>,<options>
                       <value>,<+tol>,<‑tol>,<options>,<return>
        <value> is a <numeric expression>
        <+tol> & <‑tol> can be <numeric expressions> or *
        <return> is a <numeric variable>
           <options> can be one or more options, separated by commas.
Parameters
 
<designator>
A string constant of up to 16 characters which identifies the a subtest.
If the component fails, the system will include the <designator> in the failure message sent to the report is device.
<value>
A numeric expression which represents the expected value in ohms. Note that numeric expressions used in analog statements do not allow user-definable statements.
<+tol> & <-tol>
Numeric expressions which specify the plus and minus tolerances, respectively, as percentages. Note that numeric expressions used in analog statements do not allow user-definable statements.
The upper and lower test boundaries are computed as shown:
• upper = <value> * (1 + (<+tol>/100))
• lower = <value> * (1 – (<–tol>/100))
An asterisk (*) can be used in place of zero. If zero , or *, is specified for both tolerance values, test results are not compared to any limits; the test will not fail.
<options>
The test uses the default option values in Table R-1 when the DC source is used (fr is not specified), unless otherwise specified.When the AC source is used, the options are the same except that fr is specified and pm (parallel mode) is used.
<return>
A numeric variable which holds the measured value.
