looptest (BT-Basic)
Title: TEST UNTIL PASS
The looptest function repeats (loops) a test until it passes or reaches the specified loop count, whichever occurs first. At the end of the loop, a single pass/fail result is generated. If there were failures, data is logged for every failed test.
• looptest works with digital, unpowered analog and powered analog tests.
• looptest does not work with Shorts, Pins, VTEP, Polarity_Check, Connect_Check (Mux systems), BScan, BScan_Silicon_Nails, or PanelTest.
Syntax
  looptest <loop count> <test identifier>
  looptest <loop count> <test identifier>; <parameter list>
     <loop count> can be 1 to 32767
        <test identifier> see Parameters below
           <parameter list> can be: <parameter>,<parameter>, . . . <parameter>
              <parameter> is a <numeric variable>
Parameters
<test identifier>
The identifier of the test to be executed. Except for mixed tests, this is always the id of the file containing the source code for the test. For a mixed test, the <directory id> of that test is required; the object code in the test.o file beneath that directory is then executed.
The identifier usually consists of the pathname of the file (or directory) from the board test directory.
<parameter list>
One or more variables passed to the test to be executed.
Example
  looptest 5 "analog/r7";A
General Information
The above syntax may be used from the command line or in a testplan. Looping will only affect the test specified in the immediate command.
