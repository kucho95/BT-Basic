test isolated analog (ANALOG)
Title: MARK THE BEGINNING OF AN ISOLATED ANALOG TEST BLOCK
The test isolated analog statement and a corresponding end test statement mark the beginning and end of an isolated analog in-circuit test block. The isolated analog in-circuit test is executed in serial mode instead of parallel mode.
Isolated analog in-circuit test blocks are executed from the testplan with the test on boards and test (BT-Basic) statements.
To pass parameters to and from the test block, the variable id must be included with the test isolated analog statement.
Syntax
  test isolated analog
  test isolated analog; <parameter>
  test isolated analog; <parameter>, <parameter>
  test isolated analog; <parameter>, <parameter>, . . . . <parameter>
     <parameter> can be:   <numeric variable id>
                           <string variable id>
                           <numeric array id>
        <numeric variable id> is a <label>
        <string variable id> is a <label>$
        <numeric array id> is a <label>(*)
Parameters
<parameter>
This formal parameter can be a numeric variable, a string variable, or a numeric array.
Example
  test isolated analog; R
     clear connect s to "C1-1"; i to "C1-2"
     capacitor 50p, 20, 20, re6, fr1024, wb, R
  end test
General Information
To pass parameters into, or out of, test blocks, the test blocks must be explicit. That is, the test block must be delimited with the test isolated analog and end test (ANALOG) statements.
