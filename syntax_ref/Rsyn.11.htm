receive vector at event (VCL)
Title: SET VECTOR‑RECEIVE IN TIMING SET
(Mux systems only)
The receive vector statement is used in a timing set to indicate at what point in the set to strobe the vector receivers (i.e., the receive states specified in the vectors which reference that timing set).
Syntax
   receive vector at event <event#>
   receive vector at event <event#> offset <time>
      <event#> is an <integer constant>
      <time> is a <numeric constant>
Parameters
<event#>
The number of the event where the vector receive is to occur. The event# must be zero (0) or greater, up to the highest event number in the timing set.
<time>
The offset, in seconds, from the event on which the vector receive is to occur. The value can range from ‑30 ns to 100 ns. A value cannot be used if it would place two transitions (state changes) on the same pin closer than 50 ns, or if the transition would then occur in the next vector.
When an offset is specified for a pin, that offset applies to all activities which occur on that pin throughout the VCL test.
Example
   ! in the Timing section
         . . .
      timing set T4 is 15 events
         drive vector at event 0 offset 25n
         receive vector at event 8
         . . .
            at event 13 set Enable to "11"
      end timing set
General Information
Following are the minimum times between the components of the vectors:
• drive to drive — 80 ns
• receive to receive — 80 ns
