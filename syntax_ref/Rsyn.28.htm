report is (BT-Basic)
Title: SET DEFAULT REPORT PRINTER
The report is statement changes the default report printer, which is the file, device, or window to which failure data and messages are sent by a report statement. At login the default is report is *; i.e., report output is discarded.
report is opens the report printer exclusively; i.e., no one else can access the report printer. Once the default is established, it remains in effect until changed by another report is statement, or until the user logs out. The report is statement is global, which means it can be executed in any environment (from the keyboard, from the main program, from a subroutine, etc.) and it will then be in effect for all other environments.
When report is is executed, it closes the existing report printer before opening the new one. If the report printer is a file that does not exist, it is created automatically. However, if new is specified, an error occurs if the file already exists. If the open is not successful, the active window (the screen) becomes the new report device.
<access> parameters determine how the report printer is opened. These parameters can be omitted and defaulted; see Parameters below.
Syntax
  report is <report list>
  report is <report list>;<access>
  report is *
  report is <report list>,<error variable>
  report is <report list>,<error variable>;<access>
  report is *,<error variable>
     <error variable> is a <numeric variable>
     <report list> can be:
        <file id>
        window
        <file id>,window
        window,<file id>
     <access> can be:
        <a/n/o>
        <a/n/o>,<e/s>
        <a/n/o>,<e/s>,echo
        <a/n/o>,echo
        <e/s>
        <e/s>,echo
        echo
     <a/n/o> can be:
        append
        new
        over
     <e/s> can be:
        exclusive
        shared
 
 
 
The <access> parameters do not have to be in the order shown. They can be arranged in any order; see the examples below.
Parameters
 
<report list>
A list containing the identifier(s) of the new default report printer(s). The old printer is closed and the new printer is then opened. If the new printer cannot be opened, <report list> defaults to the screen.
All identifiers in <report list> share a single set of <access> parameters. <report list> can contain the following identifiers in the combinations shown under Syntax.
<error variable>
The identifier of an error variable.
<access>
Determines how the new report printer is opened.
• <file id> – The data is sent to the specified file.
• window – A new window is opened and the data appears in that window.
• * – An asterisk closes the default report printer and discards report output (except under some conditions; see General Information below), and subsequent report statements are ignored. This is the default at login.
<a/n/o>
Determines how the data is written. If the new report printer is a file, the file is created if it does not exist. <a/n/o> can be:
• append – Adds new data to the end of any existing data in the file, device, or window. If none is present, writes from the beginning.
• new – Creates a new file, device, or window and writes from the beginning. An error occurs if the new report printer is a file that already exists.
• over – Writes from the beginning and destroys any existing data.
If none of the above is specified, <a/n/o> defaults to over.
<e/s>
Determines whether the report printer is for exclusive or shared use. If not specified, defaults to shared.
echo
Output goes to the report printer and to the workstation screen (only to the screen if it is the default). If this parameter is not specified, echoing is not turned on.
Example
  report is "/scopes/test_data";exclusive, over
  T$ = "/scopes/test_data"
  report is T$             ! Same as above, using the defaults
  report is "/dev/rpr1", Err1; echo, append, exclusive
                           ! statement with error variable
  report is window, "temp_file", Error; echo
                           ! Data is sent to a new window and to a file.
                           ! The data is echoed to the screen, and the
                           ! statement includes an error variable.
  testhead is 2      ! Closes existing report printer and opens "/dev/rpr2"
  report is *        ! Closes the report printer (unless buffered reporting is enabled).
General Information
When using buffered reporting (buffered reporting on/off statement), report is * does not discard report output. Instead, report data is sent to the report buffer.
When using multiple board states (board number is statement) and buffered reporting to test a multi‑board panel, report is * sends report data to the report buffer for the current board.
