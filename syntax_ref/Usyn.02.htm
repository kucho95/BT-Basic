unit (ITL)
Title: START DIGITAL UNIT
The unit function is used in ITL to mark the start of a digital unit; the end unit function marks the end of the unit. In ITL, the unit statement can appear in the disables section of any of the chain tests and it must appear as the last section in the nodes block of a silicon nail test. Refer to the VCL syntax for more details about the purpose of the statement.
Each disables block can have only one unit block. The silicon nail tests can use any number of the unit blocks.
Within the silicon nail test vector section, the allowable statements within a unit, end unit block are:
• ! (comment)
• pcf
• end pcf
• message     (within pcf block only)
• repeat      (within pcf block only)
• end repeat  (within pcf block only)
Syntax
  unit
  unit <unit id>
     <unit id> is a <string constant>
Parameters
<unit id>
The identifier of the unit. Since it is a string, this parameter can be any length and can contain any printable characters, including spaces. The identifier is not required, but it helps you to identify the unit when you are editing the program. Also, if the program generators discard that unit, they will print the identifier in the test summary report.
Example
  silicon nail "U6"
  ...
  nodes
  pcf order is ...
  unit "Testing Preset Line of the Flip‑Flop"
     pcf
        "11ZZZ  ZZZLXX"
        message "repeat loop failure"
        repeat 10 times
           "01ZZZ  ZZZLXX"
           "11ZZZ  ZZZLZZ"
        end repeat
        message ""
     end pcf
  end unit
 
  unit "Testing Clear Line of the Flip‑Flop"
     pcf
        message "Clear line failure"
           "10ZZZ  ZZZHXX"
     end pcf
  end unit
