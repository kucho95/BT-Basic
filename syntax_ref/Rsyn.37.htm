rewind (VCL)
Title: RESET THE COUNTER TO THE BEGINNING OF A DATA BLOCK
The rewind statement appears in the Vector Execution section of a test to reset the data counter to the beginning of the specified data block. Data is read by vector execution statements (count, execute, and preset counter) from the block sequentially, starting with the first value in the block. The next statement increments the counter so that the next sequential value will be read. The rewind statement returns the counter to the first value in the block.
 
 
The rewind statement does not work with dynamic vectors of flash programming using external data files.
Syntax
  rewind <data block id>
Parameters
<data block id>
The name of the data block whose counter is to be reset.
Example
  ! in the Vector Execution section
        . . .
     repeat 179 times
        ! program and test FlashRAM
        homingloop 25 times
              . . .
           execute Write
           execute Keep_Control drive data Device_Data
           execute End_Cycle
              . . .
           execute Verify
           execute Keep_Control receive data Device_Data exit if pass
           execute End_Cycle
              . . .
        end homingloop
        next Device_Data
     end repeat
        . . .
     rewind Device_Data
        . . .
