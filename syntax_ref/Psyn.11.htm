pause (VCL)
Title: TEMPORARILY STOP A DIGITAL PROGRAM
The pause function is used in the Vector Execution section of a digital test to stop the test and return control to the testplan. When the test stops, the current states of the drivers are maintained on the input pins. If the test is using a DUT clock, the clock continues to run during the pause.
Provided that digital timeout does not occur during the pause, the test can be continued from the point at which it stopped by a (BT-Basic) test cont function. When the test is continued the timeout timer resets and begins timing from the beginning of its cycle. If digital timeout occurs during a pause, the pause changes to halt and the outputs are three‑stated. See the halt (VCL) function.
For SAFEGUARD considerations, refer to General Information below.
Syntax
  pause
  pause with clocks running
Parameters
(none)
Example
  unit
        . . .
        . . .
     pause
        . . .
  end unit
General Information
When a test is paused, the drive states from the latest vector are maintained on the inputs to the device. If the test remains in the paused state too long, there is a possibility of damage occurring to the device under test, or to any other device connected to the inputs of the device under test.
When a digital test is generated, if that test contains a pause function, then the SAFEGUARD safety analysis routines will flag the test as inhibited. The test can then be executed only if you set the safety protection to safeguard cool or safeguard none (see the BT-Basic safeguard <type> function). However, if digital timeout occurs during a pause, then the pause reverts to a halt (i.e., drivers are three‑stated, as described for the halt function).
