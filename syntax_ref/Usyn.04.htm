unit disable method (VCL)
Title: MULTI‑VECTOR PRECONDITIONING METHOD
The unit disable method function is used in the library test for a device that may have to be preconditioned and that requires multi‑vector preconditioning. The function starts the unit that contains the preconditioning statements. The unit is terminated by an end unit function. The unit can contain the following:
• condition with statements
• disable with statements
• execute statements (for vectors in the Vector Definition section)
• pcf/end pcf statements (with PCF vectors)
• use pcf order statements
No other statements can be used in the unit.
Note that the unit can be used for disabling, or for conditioning, or for both at the same time. If there is more than one way to disable or condition the device, the test can have more than one unit disable method.
These units are ignored when the program generator creates the executable version of the tests in which they (the unit disable methods) reside.
Syntax
  unit disable method <unit id>
     <unit id> is a <string constant>
Parameters
<unit id>
A string of characters identifying the unit. The id can contain any printable characters. The id is not used in the test but it does help you to identify the unit for editing purposes.
Example
  unit disable method "Disable ASIC"
     disable Out with Reset hold "0"
     disable Out with Clk hold "T"
     disable Out with Test
     pcf
        use pcf order ASIC_Disable
        "000"
        "010"
        . . . . .
        "000"
     end pcf
  end unit
