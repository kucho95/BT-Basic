delay for cooling (VCL)
Title: DIGITAL TEST DELAY
The delay for cooling function causes a digital test to halt for a normal cooldown. After the cooldown, the test automatically continues. If you suspect that heat damage might occur during a digital test, this function allows you to segment the test with adequate cooling delays. This function cannot be used in a test which uses the DUT clock (see Advanced Testing With VCL in Digital Testing).
Note that after you execute a delay for cooling function, you must re‑execute the necessary disabling vector and re-initialize the device. Therefore, if possible, place the delay function at the beginning of units where these procedures can be performed conveniently.
