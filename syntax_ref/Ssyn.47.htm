sin (BT-Basic)
Title: SINE
The sin statement returns the sine of the statement's argument. The argument is in radians.
Syntax
  sin (<numeric expression>)
Parameters
<numeric expression>
The argument of the statement:
–2.98^8 <= argument <= 2.98^8
Example
  print sin(pi/4)          ! prints   .707106781187
  print sin(pi/6)          ! prints   .5
  print 10+4*sin(pi/6)     ! prints   12
