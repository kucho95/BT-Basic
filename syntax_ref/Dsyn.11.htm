debug port (CONFIGURATION)
Title: DEBUG PORT CONFIGURATION
The debug port function defines a debug port in a module. The debug port function can be used in the testhead configuration file, but not in the board configuration file. The debug port function can only be used within a block defined by a module and end module function.
There must be only one debug port declared per testhead. If multiple debug ports are declared within a configuration file, a warning is issued and the last debug port declared is the debug port for that configuration.
Syntax
  debug port
Parameters
(none)
Examples
  module 1
     debug port
     cards 1 asru
     cards 2 to 5 hybrid
     cards 6 control
     cards 7, 9 to 11 hybrid
     supplies 1 to 4
     ports ext1, ext2
  end module
