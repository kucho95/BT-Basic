test monitor (BT-Basic)
Title: INVOKE TEST MONITOR MODE
This function is only valid in a BT-Basic window.
The test monitor mode limits users to performing only a few test-oriented operations. It does not give access to the full range of functions used by test developers.
When test monitor is in effect and a program is not running, the following keys are active:
Softkeys — The sofkey definitions change to:
• f1 (start) — Begins the execution of a testplan.
• f8 (exit) — Exits BT-Basic and returns to the Login: prompt.
• Operator Keypad (if present) — All keys.
When test monitor is in effect and a program is running, the program acts normally. It will also allow normal data entry from the workstation keyboard, via the enter, input, and question statements. However, the function of the Break key changes slightly to:
Break (on the keyboard) — If pressed, halts the program. Once the program is halted, you have two choices:
• Begin execution of the program by pressing softkey f1, start.
• Exit BT-Basic by pressing softkey f8, exit.
The test monitor mode is cancelled by the program monitor statement, which restores normal operation and returns the softkey definitions to normal.
