tab (BT-Basic)
Title: TAB
The tab statement can be invoked by the print, output, and report statements, all of which output data using free‑field format. The statement can be included in the list of data items to be output by those statements. The statement causes the field for the next data item to start at the column specified by the statement’s argument, instead of immediately after the previous field.
If the column specified by the statement is to the left of the current print position, then the next field starts at the specified column, but on a new line—i.e., a line‑feed occurs. The current print position is the next column to the right of the previous field. If no data has yet been output, or if an EOL (End Of Line) was output, then the current position is at the first column of the current line. If the column number specified is greater than 80, then one or more line feeds occur.
Syntax
  tab (<column>)
     <column> is a <numeric expression>
Parameters
<column>
The column in which the first character of the next field is to be located. Columns are numbered, from left to right, 1 through 80. To determine the column number, the value of the numeric expression is rounded to an integer and then taken mod 80, that is, it takes the remainder after dividing the integer value by 80.
To determine the number of line feeds, the value of the expression is divided by 80, and the integer of the result is taken.
The value of the expression must be positive.
Example
  print "  NAME", tab(25), "ID", tab(3), "===="; tab(25), "=="
     !
     ! Prints      NAME                  ID
     !             ====                  ==
     !           ‑‑‑‑‑‑‑1 thru 24‑‑‑‑‑‑‑>‑‑‑25 thru 44‑‑‑‑
  print "Line 1:", tab(165), "Line 3:"
     !
     ! Prints        Line 1:
     !
     !               Line 3:
  tab (18)        ! These three tab statements all specify column #18;
  tab (177.7)     ! the second and third statements also cause two line feeds
  tab (178.2)
