binior (BT-Basic)
Title: BINARY INCLUSIVE‑OR OF TWO INTEGERS
The binior function returns a decimal, integer value which corresponds to the binary inclusive‑OR of the function’s two decimal, integer arguments. Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. Values in the following ranges can be processed:
  16-bit operation: -2^15 <= value <= 2^15 - 1  (2^15 = 32768)
  32-bit operation: -2^31 <= value <= 2^31 - 1  (2^31 = 2147483648)
The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Syntax
  binior ( <numeric expression> , <numeric expression> )
Parameters
<numeric expression>
The decimal, integer values to be inclusive‑OR’d.
Examples
  print binior( 5,2 )                  ! prints    7
  print binior ( 5,1 )                 ! prints    5
  S=‑8 \ print binior ( S,5 )          ! prints    ‑3
