beep (BT-Basic)
Title: SOUND A BEEP AT THE WORKSTATION
The beep function sounds a beep at the workstation.
Syntax
  beep
Parameters
(none)
Examples
  if Error_var = 0 then goto OK
  print "Measurement Error‑‑Please notify your supervisor."
  beep \ stop     ! Beep draws operator's attention to message.
  OK :            ! No error, program continues
General Information
The beep is primarily used to draw the test operator’s attention to a message on the workstation screen.
