discharge (ANALOG)
Title: DISCHARGE BOARD
The discharge function is used within an analog test block to discharge stored charges on the board under test. The discharge block is very similar to an analog test block. It must include a clear connect function to connect the L and G buses across the device to be discharged. The discharge block is executed with the test (BT-Basic) function from the testplan. The discharge blocks are stored under the analog directory.
The i3070 In-Circuit Test Software writes a discharge block for the devices that it determines need discharging. You can add other discharge blocks for problem areas on the board under test.
The discharge function can include: a string constant id, the entry and exit voltage levels, and a return variable which indicates the status of the test. If you do not specify entry or exit voltages the system uses 1 V.
Syntax
  discharge
  discharge <name>
  discharge <name>, <specs>
  discharge, <specs>
     <name> is a <string constant>
     <specs> can be:   <voltages>
                       <voltages>, <status>
                       <status>
        <voltages> can be:   entry <level>
                             exit <level>
        <status> is a <numeric variable>
           <level> is a <numeric expression>
Parameters
 
<name>
Included in the failure report.
<level>
The entry level specifies the voltage level above which to start discharging. The maximum voltage that can be discharged is 100 volts. This minimum entry level that can be specified is 0.1 volt.
The exit level specifies the voltage level below which to stop discharging. This voltage must always be less than or equal to the entry voltage level. The minimum exit level that can be specified is 0.005 volts.
If no levels are specified, the function uses 0.1 volts for entry and 0.05 volts for exit.
<status>
The numeric variable that is returned to indicate the discharge function status:
• 0 – No discharge was needed.
• 1 – The discharge was successful.
• 2 – The voltage was too high to discharge (> 50 volts).
• 3 – The voltage was not decreasing.
• 4 – The voltage was decreasing but did not reach the exit level.
• 5 – The voltage could not be measured due to a hardware failure.
• 6 – Discharge was not executed due to a over-voltage error in the testhead.
Example
  test analog; Return
     clear connect l to "C1-1"; g to "C1-2"
     discharge "C1", entry 0.1, exit 0.1, Return
  end test
General Information
The discharge blocks are executed during the unpowered and dps statements.
