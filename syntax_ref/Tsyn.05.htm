tck (ITL)
Title: IDENTIFIES TEST CLOCK NODE
The tck statement identifies the test clock node of the boundary-scan chain. A name is assigned to this node using the tck statement.
Syntax
tck <node name>
tck <node name> <card list>
  <node name> is a <string expression>
  <card list> can be:   hybrid
                        channel          ! On Mux systems only
                        hybrid; channel  ! ";" indicates first choice preferred
                        channel, hybrid  ! "," indicates no preference
Parameters
<node name>
The name of the node assigned to tck.
Examples
  tck "Buffer-4"
  tck "clk" hybrid
