include (BT-Basic)
Title: TEMPORARILY MERGE A FILE INT0 THE WORKSPACE
The include function starts an include block, which is used to temporarily merge the lines from a file into the program currently in the workspace. The block consists of the include function on one line, followed by the end include function on the next line. The include function specifies the name of the file that is to be merged.
When a file containing an include block is brought into the workspace, the lines in the file named in the include function are inserted between the lines containing the include and end include statements. This does not affect the source code in the file containing the program that is currently in the workspace.
If you subsequently re‑save the program that is in the workspace, the merged lines are discarded and not saved. If you want them to be saved, delete the include and end include statements that bound the merged lines before re‑saving. If you edit the merged lines (without re‑saving the workspace), the changes are lost unless you re‑save the merged lines in their original file.
If the workspace is re‑saved, any statements on the same line as the include function is re‑saved (i.e., they are not discarded with the merged lines).
Syntax
  include <file id>
     <file id> is a <string constant>
Parameters
<file id>
The identifier of the file to be merged. The identifier must be an absolute path name, or must be made with respect to the directory in which the file containing the include resides.
Examples
  include "mixed/gain/basic"
  end include
  include "mixed/noise/basic | TstName$ = "noise"
  end include
