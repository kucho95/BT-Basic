Break key (misc)
Title: INTERRUPT A PROGRAM
The Break key is used to interrupt a running program. There are no parameters or syntax associated with Break.
How Break operates depends on whether the system is currently in test monitor mode or program monitor mode, as follows:
• When in test monitor mode:
If a program is not running when Break is pressed, nothing happens. If a program is running when Break is pressed, execution of the program is interrupted. Then you can either press softkey f1, start, to restart the program or softkey f8, exit, to exit BT-Basic.
• When in program monitor mode:
If a program is not running when Break is pressed, nothing happens. If a program is running when Break is pressed, program execution is paused. Once the program has paused, you can do either of the following:
• Continue it by entering cont on the command line.
• Abort it by entering stop on the command line or selecting stop on the operator keypad (if the keypad is on the screen).
