report (ANALOG)
Title: SEND A MESSAGE TO THE SPECIFIED DEVICE
The report statement outputs a message to the current report is device.
Syntax
  report
  report <message>
     <message> is a <string expression>
Parameters
<message>
A message to be sent to the current report is device.
Example
  on failure
     report "PART NUM: 1145-0116: LOCATION: B9"
     report "C15 failed, please check C14."
  end on failure
  clear connect s to "C15-1"; i to "C15-2"
  capacitor 15.01u, 12.6, 12.2, re2, fr128, ed
