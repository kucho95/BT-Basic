set load (DEBUG)
Title: TEMPORARILY CHANGE THE LOAD ON A RECEIVER
The set load statement changes the load on one or more receivers to pull‑up, pull‑down, or no load.
Except that it is temporary, this statement is the same as the set load (VCL) statement.
Syntax
  set load on <identifiers> to pull up
  set load on <identifiers> to pull down
  set load on <identifiers> to no load
     <identifiers> can be:   device <designator>
                             device <designator> pins <pin‑id list>
                             groups <group-id list>
                             nodes <node-id list>
                             pins <pin-id list>
        <designator> is a <string expression>
        <pin-id list> can be:   <pin id>
                                <pin id>,<pin id>
                                <pin id>,<pin id>, . . . <pin id>
           <pin id> is a <string expression>
        <group-id list> can be:   <group id>
                                  <group id><group id>
                                  <group id><group id>, . . . <group id>
           <group id> can be:   <label>
                                <string expression>
        <node-id list> can be:   <node id>
                                 <node id>,<node id>
                                 <node id>,<node id>, . . . <node id>
           <node id> is a <string expression>
Parameters
<identifiers>
The list of receivers whose loads are to be changed. Only output pins and bidirectional pins can be specified.
<designator>
String constant representing a device. The device must be referenced in the test being debugged.
<id list>
The list of pins or nodes to be changed.
Example
  set load on device "U25" to pull up
  set load on device "U68" pins "13", "11" to no load
  set load on groups Data_out, "Out" to pull up
  set load on nodes "out_1", "out_2", "out_3", "out_4" to pull down
