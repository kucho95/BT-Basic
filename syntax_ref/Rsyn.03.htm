rcall (ANALOG) (BT-Basic)
Title: CALL A REMOTE ENTRY POINT
The rcall statement lets you specify the entry point (usually the name of a subprogram) on a measurement server. It also lets you pass information (parameters) to and from the entry point.
The rinit statement has a debug option that starts the Keysight VEE instrument server to its debug mode. If debug is in effect, rcall opens a window that contains the called statement for debugging, using the Keysight VEE debugging tools. When you finish debugging the statement, close the window to continue running the BT-Basic or analog program. (The debug option operates with Keysight VEE version 3.2 and later.)
Syntax
   rcall <entry point>
   rcall <entry point>(<parameters>)
   rcall <entry point>(<parameters>); service <server name>
      <entry point> is a <label>
      <parameters> can be:   <parameter>
                             <parameter>, <parameter>
                             <parameter>, <parameter>, . . . <parameter>
         <parameter> can be:   <numeric expression>
                               <string expression>
                               <numeric variable id>(*)
      <server name> is a:
                         <string expression> (when "rcall" is used in BT-Basic)
                         <string constant> (when "rcall" is used in ANALOG)
Parameters
<entry point>
The name of an entry point in the measurement server. This is usually the name of an Keysight VEE subprogram executing on the measurement server.
<parameters>
One or more parameters, separated by commas, to be passed to a service executing on the measurement server.
<server name>
A string expression containing the unique name of a measurement server. If no value is specified, <server name> defaults to the last server that was referenced; i.e., whichever measurement server is currently in use.
Example
  rcall VOLTMETER ("SETUP", Reading)
           ! Call a subprogram named "VOLTMETER" on the measurement server currently
           ! in use. Pass it two parameters, one string and the other numeric.
  rcall FREQ_CNTR ("READING", A(*))
           ! Call a subprogram named "FREQ_CNTR" on measurement server currently in use.
           ! Pass it two parameters, one of which is the name of a numeric array.
  rcall FREQ_CNTR (X, Z); service "vee"
           ! Call a subprogram named "FREQ_CNTR" on the measurement server named "vee".
           ! Pass two parameters to the subprogram.
General Information
Before you can use rcall to call an entry point on a measurement server, you must execute an rinit statement to initialize that server.
<numeric expressions> and <numeric arrays> are passed by reference and <string expressions> are passed by value. The subprogram being called cannot alter data in the BT-Basic environment when data is passed by value. The subprogram being called can alter data in the BT-Basic environment when data is passed by reference.
The types of data an rcall statement can pass between BT-Basic and Keysight VEE are:
• strings
• reals
• single-dimensional array of strings
• single-dimensional array of reals
