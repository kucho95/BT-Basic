triml$ (BT-Basic)
Title: STRIP LEADING SPACES FROM A STRING
The triml$ (trim left) function returns a string which is a copy of the argument string but with its leading spaces removed.
Syntax
  triml$ (<string expression>)
Parameters
<string expression>
The string to be copied, but with leading spaces removed.
Example
  A$ = "    Test1    "
  len (A$)                   ! returns     13
  len (triml$(A$))           ! returns     9
  print triml$(A$) & "Z"     ! prints      Test1     Z
  print A$; len(A$)          ! prints      Test1     13
