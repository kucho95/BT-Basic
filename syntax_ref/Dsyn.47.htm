display histogram (DEBUG)
Title: DISPLAY HISTOGRAM
The display histogram function displays the results of the specified test or subtest in Q-STATS histogram format.
The function specifies the number of times to execute the test, the position of the histogram on the display, and the name of the subtest if applicable.
Syntax
  display histogram
  display histogram <Parameters>
     <Parameters> can be:   <number>
                            <number> <position>
                            <number> <position> <subtest id>
        <number> is <numeric expression>
        <position> is an <integer>
        <subtest id> is a <string expression>
Parameters
<number>
The number of times to execute the test. For statistical data integrity, the number should be at least 30. The default value is 50.
<position>
The position to place the histogram in the display. Positions are 0 through 6.
<subtest id>
Name of the subtest to execute for the histogram. Default is to execute all the subtests in a test.
Examples
  ! Execute subtest "R1_1" 40 times and display the histogram in position five.
     display histogram 40 5 "R1_1"
