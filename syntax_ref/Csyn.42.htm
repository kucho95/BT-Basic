Connect Buses
You can connect multiple nodes or multiple device pins with the g bus only. To make multiple connections with the other buses, you must specify the connections as brc's.
See also the syntax description of the following statements:
• connect-unpowered (ANALOG)
• disconnect-powered (ANALOG)
• disconnect-unpowered (ANALOG)
• clear connect-powered (ANALOG)
• clear connect-unpowered (ANALOG)
Syntax
  connect <bus> to <relay list>
  connect <bus> to <relay list>; <bus> to <relay list>
  connect <bus> to <relay list>; <bus> to <relay list>; . . . <bus> to <relay list>
                   (recommended method for maximum throughput)
    <bus> can be:   s
                    i
                    a
                    l
                    g
                    rcva
                    rcvb
                    rcvc
                    <ext instrument name>
       <ext instrument name> is a <string constant>
                    <acc instrument name> high
                    <acc instrument name> low
                    <acc instrument name> shield
                    <acc instrument name> low shield
                    <acc instrument name> high direct
                    <acc instrument name> low direct
                    <acc instrument name> shield direct
                    <acc instrument name> low shield direct
              <acc instrument name>high using bus x (use only in executable file)
              <acc instrument name>low using bus x (use only in executable file)
              <acc instrument name>shield using bus x (use only in executable file)
              <acc instrument name>low shield using bus x (use only in executable file)
          <acc instrument name> is a <string constant>
          <x> can be the numbers 0 - 3.
              If x = 0, the connection is a direct connection, no internal bus
                        is used.
              If x = 1, 2, or 3, the connection is made using the internal bus.
    <relay list> can be:  ground
                          <explicit relay list>
                          <implicit relay list>
          <explicit relay list> can be: pins <pin list>
                                        relays <brc list>
                                        nodes <node list>
                                        device <device name> pins <pin list>
               <pin list> can be: <pin>
                                  <pin>, <pin>
                                  <pin>, <pin>, . . . <pin>
               <brc list> can be: <brc>
                                  <brc>, <brc>
                                  <brc>, <brc>, . . . <brc>
               <nodes list> can be: <node>
                                    <node>, <node>
                                    <node>, <node>, . . . <node>
               <pin> can be:  <pin number>
                              <pin name>
               <brc> is an <integer constant>
               <node> is a <string constant>
               <device name> is a <string constant>
               <pin number> is an <integer>
               <pin name> is a <string constant>
          <implicit relay list> can be: <relay>
                                        <relay>, <relay>
                                        <relay>, <relay>, . . . <relay>
               <relay> can be: <node>
                               <brc>
Parameters
 
ground
Specifies that the bus be connected to the node on the board under test which is designated as ground in the i3070 In-Circuit Test Software.
<acc instrument name>
(Mux systems only) A string constant that describes the instrument connected to the AccessPlus Card port. This name is declared in the board configuration file.
• high - Specifies the high side connection.
• low - Specifies the low side connection.
• shield - Specifies the shield connection.
• low shield - Specifies the low side and shield are connected together.
• direct - Specifies that the connection be made with no internal multiplexing on the AccessPlus Card.
• using bus - Specifies the internal bus to use when connecting a port to a node through the AccessPlus Card.
<ext instrument name>
A string constant that describes the instrument connected to the external port. This name is declared in the board configuration file.
<pin number>
An integer constant that describes the pin.
<pin name>
A string constant that describes the pin.
<brc>
A numeric constant describing the physical location (coordinate) of the module pin that connects to the specified node. A coordinate consists of five numeric characters that are expressed in a brc (Bank Row Column) format:
• The first numeric character (B) designates the testhead bank, either 1 or 2. Bank 1 consists of the two modules on the right side of the testhead, and bank 2 is the two modules on the left side (as viewed from the front of the testhead).
• The next two numeric characters (R) designate the X-axis row, beginning with row 01 at the rear of the testhead and ending with row 23 at the front of the testhead (leading zeros are required). Note that row 12 is unused.
• The last two numeric characters (C) designate the Y-axis column, beginning with column 01 at the right side of the bank and ending with column 78 at the left side of the bank (leading zeros are required).
<node name>
A string constant identifying the node to which the specified bus is to be connected. The node name must be the same one entered for that node in the board description forms.
Examples
  connect s to "node_1"
  connect s to pins 1
  connect g to pins 1,4
  connect l to ground
  connect g to "node_1', "node_2", "node_3"
  connect rcva to relays 11422
  connect i to "node_3"
  connect g to device U1 pins 1, 4, 6
  connect "dcsource" to "node_1"
  connect "dvm" to "node_2"
  connect "dcsource" to "node_1"; "dvm" to "node_2"
  connect "pcm4_rxtx" high to "ch1H"
  connect "pcm4_rxtx" low to "ch1L"
  connect "synth" high direct to "clockin"
  connect "synth" shield direct to "ground"
General Information
You can use only an explicit relay list or an implicit relay list within one connect-powered function. You cannot use a combination of explicit and implicit connections within one function.
Be careful when using brc locations, instead of node names, to avoid multiplexing conflicts.
Unlike the unpowered form of the connect function, the powered form connects the buses simultaneously if the connect statements are combined; it connects the buses individually if the connect statements are separate.
For example:
  connect s to "NODE_1"; i to "NODE_2"     ! Both nodes connected at once.
  connect s to "NODE_1"                    ! Nodes connected one at a time.
  connect i to "NODE_2"
You can use the G bus to connect multiple nodes together as in the following example:
  connect g to "node_1", "node_2", "node_3"
When specifying connections in analog powered tests, be careful not to exceed the voltage, current, and power ratings of the pin card relays.
Unlike unpowered testing, the G bus is not automatically connected to ground in powered testing; the G bus is floating in powered testing but connected to ground in unpowered testing.
(Mux systems only) Use the using bus parameter only in an executable file. Use this parameter to specify a bus, on the AccessPlus Card, that you are using to connect nodes to ports.
 
 
When using the using bus parameter, use it with all connect statements in a test, or not at all.
