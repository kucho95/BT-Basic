log timestamp on (BT-Basic)
Title: BEGIN LOGGING TEST TIMES FOR A PC BOARD TEST
The log timestamp on function begins logging test times for every test run on the PC board under test.
 
 
This function is not recommended for production usage, as logging the test time for every test will affect test throughput.
Logging is only recommended during test development, when it can be used to determine if any tests take a long time to run, so that those tests can be optimized.
Syntax
log timestamp on <SerialNumber>
Parameters
 
<SerialNumber>
The serial number of the board being tested.
Example
log timestamp on 12345678
General Information
The log file can be found in C:\I3070_ICT\board\<user board directory>\log. The filename has the format testtime_$Version_$Date.csv where $Version is the board version.
If the log timestamp off function is used to end logging, the next time log timestamp on is run, a new log file will be created.
If log timestamp off is not used, log timestamp on appends new logs to the existing log file.
