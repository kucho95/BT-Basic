display subvector (DEBUG)
Title: SCALE THE DISPLAY TO VIEW TIMING EVENTS
(Mux systems only)
The display subvector function scales the display to show subvectors, with each column representing one period of the reference clock, or, in tests with timing sets, one event‑space.
The event numbering in debug is relative to the drive strobes which start each vector. In tests with timing sets the drive strobes do not necessarily occur at the beginning of the timing sets.
In a timing set definition, event 0 always occurs at the start of the timing set; in debug, event 0 coincides with the drive strobe, no matter where the strobe occurs in the timing set.
Use the display scale function to view subcycles of the events.
Syntax
   display subvector
Parameters
(none)
Examples
   display subvector           ! displays events
   display scale 10            ! the scale is 10 ns
   display vector              ! the scale reverts to "vectors"
General Information
