topology node connection count (BT-Basic)
Title: GET A CONNECTION COUNT FOR A NODE FROM THE BOARD FILE
The topology node connection count statement returns the number of connections that are attached to the specified node.
Syntax
  topology node connection count (<node name>)
     <node name> is a <string expression>
Parameters
<node name>
The name of the node.
Example
  topology node connection count ("U100-1")
     ! Tells you the number of connections attached to node "U100-1".
General Information
To use any of the topology access functions you must first load the board file into memory.
To load a board object file, board.o, into memory execute the load board statement.
To remove a board file from memory use the scratch board statement.
The load board statement automatically scratches any file that is presently in memory.
