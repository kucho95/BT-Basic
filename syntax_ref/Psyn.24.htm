pos (BT-Basic)
Title: POSITION OF STRING WITHIN A STRING
The pos function returns an integer whose value corresponds to the first position in one string of a second string. The value returned is the position in the first string of the first character of the second string. A value of zero results if the first string does not contain an exact copy of the second string, or if either string is the null string.
Syntax
  pos ( <in string> , <of string> )
     <in string> and <of string> are <string expressions>
Parameters
<in string>
The string to be searched to determine if it contains the second string. The characters are numbered from left to right; the first (most left) character position is #1.
<of string>
If this string exists in the first string, the value returned represents the position of its first character in the first string. If it does not exist, zero is returned. If the second string exists more than once in the first string, only its first (lowest valued) position is returned.
Example
  pos ( "A man and his dog." , "dog" )       ! returns    15
  pos("abcababab","ba")                      ! returns    5
  pos ("cats and dogs","rain")               ! returns    0
  pos("CASE" , "case" )                      ! returns    0
  F$="Time is XXXXX"
  input "Time?", A$                          ! user inputs, say, 11.30 a.m.
  F$[pos(F$,"XX")] = A$ \ print F$           ! prints    Time is 11.30 a.m.
