boards (CONFIGURATION)
Title: SPECIFY BOARD-TO-MODULE OR BOARD-TO-BANK MAPPING
Use the boards function in the board configuration file to specify either of the following:
• board-to-module mapping when using Throughput Multiplier. This specifies which boards are to be tested in which modules.
• board-to-bank mapping when using Advanced Throughput Multiplier. This specifies which boards are to be tested in which banks of the four-module system.
The boards function must appear after the module/end module block to which it is referring. See the examples below. The boards function cannot appear in the testhead configuration file.
Syntax
For Throughput Multiplier
  boards <board #> in module <module #>
  boards <board #>, <board #> in module <module #>
  boards <board #>, <board #>, . . . <board #> in module <module #>
    <board #> can be an integer from 1 to 256
    <module #> can be an integer from 0 to 4
For Advanced Throughput Multiplier
  boards <board #> in bank <bank #>
  boards <board #>, <board #> in bank <bank #>
  boards <board #>, <board #>, . . . <board #> in bank <bank #>
    <board #> can be an integer from 1 to 256
    <bank #> can be an integer from 1 to 2
 
Parameters
<board #>
An integer that identifies the board in the panel.
<module #>
An integer that identifies the module of the testhead.
<bank #>
An integer that identifies the bank of the testhead.
Examples
Throughput Multiplier: In this example, boards 1 and 3 are to be tested in module 0; boards 2 and 4 are to be tested in module 1.
   module 0
      cards 1 asru n revision
      cards 2 to 5 hybrid high accuracy double density
      cards 6 control xtpb
      cards 7 to 11 hybrid high accuracy double density
      supplies 1 to 4
   end module
   module 1
      cards 1 asru n revision
      cards 2 to 5 hybrid high accuracy double density
      cards 6 control xtpb
      cards 7 to 11 hybrid high accuracy double density
      supplies 5 to 8
   end module
   boards 1,3 in module 0
   boards 2,4 in module 1
 
Advanced Throughput Multiplier: In this example, board 1 is to be tested in bank 2; board 2 is to be tested in bank 1.
   module 0
   . . .
   module 3
      cards 1 asru n revision usb
      cards 2 hybrid standard double density
      cards 3 hybrid standard double density
      cards 4 hybrid standard double density
      cards 5 hybrid standard double density
      cards 6 control xtpb
      cards 7 hybrid standard double density
      cards 9 hybrid standard double density
      cards 10 hybrid standard double density
      cards 11 hybrid standard double density
      supplies ps6751 1 to 4 asru channels 1 to 4
   end module
   boards 1 in bank 2
   boards 2 in bank 1
