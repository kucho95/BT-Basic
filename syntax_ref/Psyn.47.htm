pwd (BT-Basic)
Title: LOCATE THE WORKING DIRECTORY
 
 
The pwd and msi$ functions are not equivalent, in that the returned value of pwd is not treated as a variable, but pwd was added for user convenience.
The pwd function identifies the working (current) directory in the file system. It returns the pathname from the root to the current directory. Note that execution of this function does not change the working directory.
The maximum length of the string produced by this function is 256 characters.
If the pathname is longer, pwd will return as many characters as possible, starting from the end, to include the last complete node name before the 256 character limit. In this case, several node names may be truncated from the beginning, and the pathname will not begin with the root (/).
Syntax
  pwd
Parameters
(none)
