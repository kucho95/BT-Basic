disconnect-powered (ANALOG)
Title: DISCONNECT RESOURCES FROM NODES
The disconnect-powered function is used within analog functional and mixed tests to disconnect specified resources (buses or balanced ports) from specified nodes. The disconnect-powered function includes a delay to allow the relays to settle. See:
• Disconnect Buses
• Disconnect Balanced Ports (Utility Card)
