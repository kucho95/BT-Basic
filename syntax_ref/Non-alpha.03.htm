% (BT-Basic)
Title: COMMON DELIMITER
The percent symbol (%) is the delimiter character for panelized boards and parent/child device notation in the part description library.
Syntax
  <text>%<text>
Examples
The following are examples of non-delimiter use.
Panelized board notation example:
  analog/2%r55
Parent/child device part description example:
  rpack2%r3
