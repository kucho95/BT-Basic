testhead status (BT-Basic)
Title: RETURN THE STATUS OF THE TESTHEAD
The testhead status statement returns the values of up to seven testhead status parameters. These values are returned into the variables that are listed following the testhead status keyword. The parameters that can be returned include information about: autoadjust status, time since the testhead was last booted, module temperature, available memory to store test objects, and whether or not the fixture is locked.
The <variable list> can contain from one to seven variables. The position of the variable in the <variable list> determines which parameter value is returned to that variable.
To instruct the testhead status statement to skip any of the parameters, you must include a comma (,) in the appropriate position(s) in the <variable list>. See the Examples section.
Syntax
  testhead status <variable list>
     variable list can be:   <variable 1>
                             <variable 1>, <variable 2>
                             <variable 1>, <variable 2>, . . . <variable 7>
        <variables 1 through 7> are <numeric variables>
Parameters
 
<variable 1>
Specifies if autoadjust needs to be run by returning a non-zero value. The value returned is a three-bit binary value. The bits represent:
• LSB – Is 1 if the temperature difference from the calibrated temperature, for at least one module, is greater than five degrees centigrade.
• CENTER – Is 1 if more than 1000 hours of CPU time has accrued.
• MSB – Is 1 if autoadjust has failed since the testhead was last booted.
<variable 2>
Indicates the time (in seconds), since the last successful autoadjust.
<variable 3>
Indicates the time (in seconds), since the testhead was last booted.
<variable 4>
Checks, for each module listed in the config file, the difference between the module’s calibrated temperature and its actual temperature. Returns, in degrees centigrade, the greatest of the temperature differences.
<variable 5>
Indicates the temperature (in degrees centigrade), of the module with the highest temperature.
<variable 6>
Specifies the number of free bytes of available memory for storing test objects, of the module with the least amount of available memory.
<variable 7>
A 0 if the test fixture is not locked. Is non-zero if the test fixture is locked.
Example
  ! This statement lists variables for all seven parameters.
     testhead status Ad, At, Bt, Td, Tm, By, Lk
  ! This statement lists variables for the first and second parameters.
     testhead status Ad, At
  ! This statement lists variables for the second and fourth parameters.
     testhead status , At, , Td
General Information
The testhead status statement must be preceded by a testhead is 1 statement.
