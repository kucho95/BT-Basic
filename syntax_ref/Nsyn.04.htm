next (VCL)
Title: INCREMENT THE COUNTER IN A DATA BLOCK
The next function appears in the Vector Execution section of a test to increment the data counter in the specified data block. Data is read by vector execution statements (count, execute, and preset counter) from the block sequentially, starting with the first value in the block. Until next is executed, all vectors that access the data block will read the same value. The rewind function returns the counter to the first value in the block.
Syntax
  next <data block id>
Parameters
<data block id>
The name of the data block whose counter is to be incremented.
Example
     ! in the Vector Execution section
     . . .
  repeat 179 times! program and test FlashRAM
     homingloop 25 times
           . . .
        execute Write
        execute Keep_Control drive data Device_Data
        execute End_Cycle
           . . .
        execute Verify
        execute Keep_Control
        receive data Device_Data exit if pass
        execute End_Cycle
           . . .
     end homingloop
     next Device_Data
  end repeat
     . . .
  rewind Device_Data
     . . .
