atn (BT-Basic)
Title: ARCTANGENT
The atn function returns the arctangent of the function's argument. The result is the principal value of the angle, in radians.
Syntax
  atn (<numeric expression>)
Parameters
<numeric expression>
The argument of the function:
‑pi/2 <= result <= pi/2
Examples
  print atn(20)         ! prints    1.52083793107
  print atn(‑.56)       ! prints    ‑.510488321917
  print 10+4*atn(.5)    ! prints    11.854590436
