remote (BT-Basic)
Title: ENABLE REMOTE OPERATION
The remote statement sends the remote message to the GPIB interface, setting the interface line REN (Remote ENable) to 0. This allows devices connected to the bus to be operated remotely; e.g., under the control of the test program.
If the bus is addressed, REN is set to 0 but the devices do not switch to remote operation until they are addressed.
If the device addressed is a current listener, the statement sets REN to 0 and the device switches to remote. If the device is not a current listener, the statement sets REN and then addresses the device to listen. The device then switches to remote.
Syntax
  remote <GPIB>
  remote <GPIB device>33
     <GPIB> and <GPIB device> are @<names>
        <name> is a <label>
Parameters
<GPIB>
The address of the bus, which this sets the interface line REN (Remote ENable) to 0 but has no effect on the individual devices.
<GPIB device>
The address of the selected GPIB device. Sets REN to 0 and, if the device is not already a listener, addresses it to listen. The device then switches to remote.
Example
Shortcut Method:
  assign @DVM to "/dev/dmm"
  remote "/dev/dmm"                ! Switches the DVM to remote operation
  remote @DVM                      ! On the bus, sets REN to 0
  assign @Auto to "/dev/hpib1" | remote @Auto
 
Absolute Path Method:
  Bus$ = btgetenv$("I3070_ICT_ROOT")
  assign @DVM to Bus$&"/dev/dmm"
  remote Bus$&"/dev/dmm"           ! Switches the DVM to remote operation
  remote @DVM                      ! On the bus, sets REN to 0
  assign @Auto to Bus$&"/dev/hpib1" | remote @Auto
General Information
 
 
These examples assume the dev file hpib1 contains the SICL interface name hpib7.
