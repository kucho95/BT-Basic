repeat (ITL)
Title: START REPEAT LOOP
The repeat statement is used in the Vector Execution section of a digital test to mark the start of a repeat loop; the end repeat statement marks the end of the loop. The <number of> parameter indicates the number of passes made through the loop; that is, the number of times the statements in the loop will be executed.
Loops can be nested; that is, one loop can appear inside of another loop. For Flash ISP, repeat without indicating the number of times to do so, will cause the loop to repeat until the end of the data.
Syntax
  repeat                   ! It is optional to list the number of repeats
                           ! for a Flash ISP test.
  repeat <number of> times
     <number of> is a <numeric constant>
  repeat hexadecimal <hex number of> times     ! May be used for Flash ISP tests.
Parameters
<number of>
Positive, integer value indicates the number of times the statements in the loop are to be executed. The loop can be repeated up to 231 – 1 times; the value must be 1 or greater.
<hex number of>
This performs the same purpose as <number of> but specifies the number in hexadecimal format. <hex number of> is a string constant, such as "FF23".
Example
  repeat hexadecimal "FFFF" times     ! Repeats 65536 times.
     execute Address
  end repeat
