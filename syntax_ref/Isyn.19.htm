include (VCL)
Title: INCLUDE STATEMENTS FROM ANOTHER FILE WHILE COMPILING
The include function enables the digital compiler to merge the compiled code for two or more source files into one file. The object code is merged into one file, but the source files remain separate.
During compilation, when an include function is encountered, the compiler temporarily suspends compiling the current file and compiles the file identified by that include. The object code for the second file is added to the object code for the first file, just as if the second file were a part of the first file. When the second file is completely compiled, the compiler resumes compiling the first file, at the next line after the include function.
If the compiler's list option is specified, the list file contains the statements from the include file in their included order.
The following rules apply to include (VCL) statements:
• A VCL test can contain any number of include statements.
• include statements can appear anywhere in a VCL test.
• An include cannot appear in a library test.
• include statements can be nested; i.e., a file which is to be included (it appears in an include function) can itself contain an include function. A file cannot call itself, or call a file which is currently at a higher level in the stack of nested files. Included files can be nested up to 10 deep.
• The include assumes that the path to the file to be included starts at the directory of the file being compiled.
Syntax
  include <file id>
     <file id> is a <string constant>
Parameters
<file id>
The identifier of the file to be included.
Examples
     . . . .
  include "file_1a"
     . . . .
  include "pattern_1"
     . . . .
  ! during the compile, first "file_1a" is included and
  ! then, later, file "pattern_1" is included
     . . . .
General Information
The purpose of the include feature is to enable you to segment a very large VCL test into multiple files, editing several small files is often easier than editing one large file. Therefore, the statements in an included file must be VCL‑compatible, and must make sense at the point in the test where they are to be inserted; otherwise, the included file causes compile‑errors.
