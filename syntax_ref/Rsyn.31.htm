report using (BT-Basic)
Title: REPORT DATA IN IMAGED FORMAT
The report using statement outputs data, using the image format, to the report printer, which is established by a report is statement. Except that it uses image‑formatting, report using is the same as the report statement.
The data to be printed is contained in the statement’s <print list>. The specifications to format the data are referenced by the statement’s <image data> parameter. This parameter can contain the formatting specifications, or it can reference an image statement which contains the specifications.
Operation of the report using statement is the same as the operation of the print using statement.
Refer to the description of the print using statement for details.
The two operating differences are:
• report using writes to the report printer and print using writes to the default printer.
• report is * closes the report printer so that subsequent report using statements are ignored, while printer is * closes the current default printer but designates the user’s workstation as the new default; i.e., subsequent print using statements are not ignored.
Syntax
  report using <image data>
  report using <image data>;<print list>
     <image data> can be:
        <image id>
        <image specifications>
           <image id> is a <label>
           <image specifications> is a <string expression>
     <print list> can be:
        <expression>
        <expression>,<expression>
        <expression>,<expression>, . . . <expression>
           <expression> can be numeric or string
           [If <expression> is an array, use <array id>(*)]
Parameters
 
<image id>
The identifier of the image statement containing the specifications to be used to format the print list.
<image specifications>
The list of specifications to be used to format the print list. Refer to the description of the image statement for a complete description of these specifications.
<print list>
The list of data items to be output. These will be formatted by the specifications referenced in the <image data> parameter. If the list contains nothing, the image specifications will determine the output.
To output a complete array of data, use <array id>(*).
Example
  report is "/dev/rpr02"                  ! Selects the report printer
  report using FAIL; "Failed Resistor‑‑measured", Res6 ,"ohms"
  FAIL: image 25a, 2x, 6d, x, 4a  ! Prints   Failed Resistor‑‑measured  1470 ohms
General Information
When using multiple board states (board number is statement) and buffered reporting (buffered reporting on/off statement) to test a multi‑board panel, the report using statement sends data to the report buffer for the current board.
