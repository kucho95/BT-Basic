fail device (BT-Basic)
Title: SET FAILURE FUNCTIONS TRUE
The fail device function sets the Dutfailed and Boardfailed variables to 1 (true).
If you are testing a panel of boards, the fail device function applies only to the current board defined by the board number is function.
The fail device function causes the board failure heading (date, time and failure message) to be printed the first time the function is executed. However, subsequent executions and failures do not cause the heading to be printed until a wait‑for‑start occurs or the program terminates. Also, the heading is not printed if a prior test function detected a failure which caused the heading to be printed (unless there was an intervening wait‑for‑start or a program termination).
The pass device function sets the Dutfailed variable to 0 (false). The clear failures function resets both variables, Dutfailed and Boardfailed, to a 0 (false). The boardfailed and dutfailed statements return the current value of the variables. Refer to syntax descriptions of these statements for more information.
Syntax
  fail device
Parameters
(none)
Example
  fail device
  boardfailed     ! Returns a "1".
