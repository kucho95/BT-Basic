end <test type> (ITL)
The end <test type> statement marks the end of a test block. The <test type> can be powered shorts, interconnect, buswire, connect, or custom. The <test type> specified must match that specified to begin the block.
Syntax
  end <test type>
     <test type> can be:   powered shorts
                           interconnect
                           buswire
                           connect
                           custom
Parameters
<test type>
Provides the name of the test type. This must match the test type specified at the beginning of the test block.
