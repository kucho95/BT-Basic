change (edit)
Title: CHANGE TEXT IN THE ENTIRE WORKSPACE
The change function replaces all occurrences of the first string of text (<first string>) with the second string of text (<second string>) throughout the entire workspace. The two strings need not be of the same length because the space occupied by <first string> is shortened or lengthened, if necessary, to accommodate <second string>. However, an error occurs if this would result in lengthening the line beyond 2048 characters. The function is not case sensitive, so all occurrences of <first string>, with either upper‑ or lowercase characters, are replaced.
Syntax
  change <first string> to <second string>,<error variable>
     <first string> and <second string> are <string expressions>
     <error variable> is a <numeric variable>
Parameters
<first string>
The string of characters to be replaced.
<second string>
The string of characters to replace the first string.
<error variable>
The identifier of an error variable.
Examples
  change "Tom" to "Brian"        ! Change all occurrences of "Tom" to "Brian".
 
  A$ = "Brian"                   ! Change using a string variable.
  change "Tom" to A$, Err
General Information
The change function is not programmable. Also see the changem and changen statements.
