gpconnect (BT-Basic)
Title: GENERAL-PURPOSE RELAY CONNECT
gpconnect statements are used to close general purpose (GP) relays. See the corresponding gpdisconnect (BT-Basic) function for opening GP relays. GP relays are used in powered and in unpowered testing to do things such as: disable clocks, hold an enable line high or low for several tests, connect a load to a motor drive circuit.
The BT-Basic gpconnect and gpdisconnect statements coincide with the ANALOG gpconnect and gpdisconnect statements. See the syntax descriptions of these statements for more information.
The function verifies that the specified nodes are connected to opposite ends of the same GP relay and then closes that relay.
GP connections are maintained during testing. Once a GP relay is closed, it remains closed until a corresponding gpdisconnect function occurs. Other statements which open GP relays are: testhead is, fixture lock, fixture unlock, unpowered, and powered.
GP relay connections on the Module Control Card can be made or changed at any time. GP relay connections on the AccessPlus Card (Mux systems only) or Utility Card can be made or changed at any time except during an active controllerloop.
The ANALOG gpconnect and gpdisconnect statements, and the BT-Basic gpconnect and gpdisconnect statements are interactive. That is, GP relay connections made with ANALOG statements can be opened with BT-Basic statements and vice versa.
Executing the unpowered statement will open all GP relays.
Syntax
  gpconnect <relay> to <relay>
     <relay> can be:   <node name>
                       <brc>
        <node name> is a <string constant>
        <brc> is a <numeric constant>
Parameters
<node name>
A string constant that describes the name of the node to which the GP relay connects. The name must be the one entered for that node in the i3070 In-Circuit Test Software.
<brc>
A numeric constant that describes the physical location (coordinate) of the module interface pin that connects to the specified node and GP relay. A coordinate consists of five numeric characters that are expressed in a brc (bank row column) format:
• the first numeric character (b) designates the testhead bank, either 1 or 2. Bank 1 covers modules 0 & 1, Bank 2 covers modules 2 & 3.
• the next two characters designate the horizontal row from the bottom of the testhead.
• the last two characters designate the vertical column from the right side of the testhead.
Examples
  gpconnect "Jumper_1" to "Jumper_2"
  gpconnect "Node_2" to 11818
  gpconnect 11816 to 11817
General Information
BT-Basic uses the wirelist to translate a node name into its brc designation. Since the brc's of GP relays are not included in the wirelist, you must manually edit the wirelist to include these brc's.
The gpconnect function closes only one relay. To close multiple relays requires multiple statements.
