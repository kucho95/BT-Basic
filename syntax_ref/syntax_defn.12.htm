Error Variable
An error variable is an optional parameter which can be specified in many of the BT-Basic statements. In a program, when a statement with an error variable is executed and a runtime error occurs, the variable is set to that error's number and the program continues to run. If that statement does not cause an error, the error variable is reset to zero, regardless of its previous contents.
If an error occurs and the statement associated with that error does not have an error variable, then the program stops. The display then shows the error number, together with the appropriate message describing the nature of the error. If an on error statement is in effect, the program executes an error‑trapping routine instead of stopping; see the on error statement for details.
The syntax description for each individual statement indicates whether or not that statement can have an error variable; for example, one variation of the printer is syntax is shown as:
  printer is <file id>, <error variable>
Typical statements might be:
  printer is "lineprinter", Error
  printer is "myfile", Whoops
The variable itself is just a standard numeric variable, so it can be accessed like any other variable. Its special use as an error variable occurs only because it is specified as a parameter in the statement.
