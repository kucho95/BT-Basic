changem (edit)
Title: CHANGE MARKED SEGMENT OF THE WORKSPACE
The changem function (change‑marked) replaces all occurrences of the first string of text (<first string>) with the second string of text (<second string>) throughout the marked area of the workspace.
Except for the workspace area which it affects, changem operates exactly like the change function; see that function for details.
Syntax
  changem <first string> to <second string>,<error variable>
     <first string> and <second string> are <string expressions>
     <error variable> is a <numeric variable>
Parameters
<first string>
The string of characters to be replaced.
<second string>
The string of characters to replace the first string.
<error variable>
The identifier of an error variable.
Examples
     ! unmarked line
     ! marked line
     ! .......
     ! marked line
     ! unmarked line
  changem "line" to "portion", Err
     ! unmarked line
     ! marked portion
     ! .......
     ! marked portion
     ! unmarked line
General Information
The changem function is not programmable.
