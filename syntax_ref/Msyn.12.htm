model (SAFEGUARD)
Title: SELECT SAFEGUARD MODEL
The model function appears in a SAFEGUARD file to specify the name of the standard on which the SAFEGUARD analysis routines are based. The function applies to the parameter blocks which follow that model function, until the end of the file, or until the next model function in the file. The model specifies the standard to be used for SAFEGUARD calculations. If default is specified, or if the function is omitted, then hp.standard is assumed (see General Information below).
Syntax
  model default
  model <standard>
     <standard> is a <string constant>
Parameters
<standard>
The name of the standard to be used.
Example
  model default
  model "hp.standard"
General Information
Two standards are available:
• hp.standard
• def.stan.00.53 - based on a provisional standard for the Ministry of Defence, U.K.
