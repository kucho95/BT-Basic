cps (BT-Basic)
Title: CONNECT DUT POWER SUPPLIES
The cps function sets all DUT power supplies to 0 V and connects them to the testhead. When power supplies are configured on the Utility Card, this function also handles the connection of the sub-channel relays for those power supplies.
Once all supplies are connected, specified supplies can be set up to power the board under test. See the sps function for details about setting up the DUT power supplies and the dps function for disconnecting DUT power supplies.
Syntax
  cps
  cps <ps_number>.<subchannel_id>     ! For muxed power supplies on Utility Card.
     <ps_number> can be: an integer from 1 to 24 for DUT power supplies
                         an integer from 25 to 32 for muxed power supplies
     <subchannel_id> is an integer from 1 to 6
Parameters
<ps_number>
An integer that identifies the power supply to be connected. This is the logical supply number as declared in the board configuration file.
• 1 to 24 for DUT power supplies
• 25 to 32 for muxed power supplies
<subchannel_id>
The sub-channel relay number (1 to 6).
Examples
  cps       !  Connect all DUT power supplies to the testhead,
            !  but not muxed power supplies
  cps 25    !  Connect all sub-channel relays on power supply 25
  cps 25.1  !  Connect sub-channel relay 1 on power supply 25
