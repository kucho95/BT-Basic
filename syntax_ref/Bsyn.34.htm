board version is (BT-Basic)
Title: BOARD VERSION IS
Use the board version is statement to establish an identifier for a board. The identifier is a string that is used to determine which version of a test should be run if multiple versions is enabled in the board config file. To retrieve the board version, use the bvi$ function.
Syntax
  board version is "string"
  board version is *
                    ! Sets the board version to the null string which indicates
                    ! the base version for multiple version boards.
Parameters
(none)
Example
  board version is "A"     ! Sets the board version to "A"
  board version is *       ! Sets the board version to the base version
  board version is ""      ! Sets the board version to the base version
General Information
The board version is statement requires a preceding load board statement in the testplan. Also, this statement validates the version identifier against those in the testplan.
BT-Basic displays the board version on the title bar of the BT-Basic term. The board version is enclosed in square brackets. For example, version 1234 is displayed on the title bar as:
     BT-BASIC [1234]
If the base board version is set, BT-Basic displays:
     BT-BASIC [**BASE**]
The board version is displayed after a load board statement is executed, and removed when a scratch board statement is executed.
