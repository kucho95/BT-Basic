off error (BT-Basic)
Title: TURN OFF BRANCH ON ERROR
The off error function turns off an active on error function (refer to that function for details).
Syntax
  off error
Parameters
(none)
Example
  on error recover Fault
     . . .
  Fault:
           off error
           print "Error "; errn;" on Line "; errl
              . . .
           goto Next_Test
