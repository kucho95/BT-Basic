dut clock period (DEBUG)
Title: CHANGE THE PERIOD OF THE DUT CLOCK
The dut clock period function changes the period of the DUT clock. The function can be used only if the test uses a DUT clock.
Syntax
  dut clock period <time>
     <time> is a <numeric expression>
Parameters
<time>
The period, in seconds, of the DUT clock. See your system's specifications for the range of the DUT clock.
Examples
  dut clock period 110n
