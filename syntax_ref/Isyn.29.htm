inputs collapsed (VCL)
Title: COLLAPSE SPECIFIC BOUNDARY-SCAN NODE ASSIGNMENTS FOR POWERED SHORTS TESTING
The inputs collapsed function appears in the Declaration section of a VCL test. It identifies a group of nodes that are tested during a series of iterations in a powered shorts test. This group of nodes first appears in the assignments section. The entire group of nodes is assigned the same group name because all nodes are in the same state at a given time during testing. The software tests an established number of nodes during each iteration. Multiplexing is used to conserve resources.
Using the inputs collapsed function allows you to specify a single column in the pcf order and keeps the bitstream narrow. Without the inputs collapsed function, you would have to assign one column for each node in the group.
Syntax
  inputs collapsed <group id>
     <group id> is a <label>
Parameters
<group id>
The identifier of a single-node group that declares the input to the boundary-scan chain. The group must have been defined in an assign function.
Examples
  inputs collapsed  N000
General Information
This function can only be used with the InterconnectPlus software option during powered shorts testing.
