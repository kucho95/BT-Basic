board graphics highlight board (BT-Basic)
Title: CAUSES THE BOARD GRAPHICS VIEWER TO HIGHLIGHT A BOARD
The board graphics highlight board function switches the board graphics viewer to a panel view (if it is not already there) and causes it to highlight either a specified board or all the boards on a multi‑board panel.
Syntax
  board graphics highlight board <board number>
  board graphics highlight board <board number>, <error variable>
  board graphics highlight <status> board <board number>
  board graphics highlight <status> board <board number>, <error variable>
     <status> can be:   active
                        fail
                        pass
     <board number> is a <numeric expression>
     <error variable> is a <numeric variable>
Parameters
<status>
The optional status of the highlighted board, which can be:
• active – Highlight the board in yellow to draw attention to it.
• fail – Highlight the board in red to denote that it has failed.
• pass – Highlight the board in green to denote that it has passed.
If no value is specified for <status>, it defaults to active (yellow).
<board number>
The identifier of a specific board on a multi‑board panel.
<error variable>
The identifier of an optional error variable.
Examples
  board graphics highlight board 1        ! Highlight board #1 in yellow (default)
  board graphics highlight pass board 4, Error
                     ! Highlight board #4 in green. Includes an error variable.
  board graphics highlight fail board 2   ! Highlight board #2 in red.
