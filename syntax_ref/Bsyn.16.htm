bni (BT-Basic)
Title: DETERMINE THE CURRENT BOARD NUMBER WHEN TESTING A MULTI-BOARD PANEL
The bni function returns a number that is equal to the board number set by the most recently executed board number is function. If no board number is set (i.e., after a board number is * function), bni returns a value of zero. bni also returns a value of zero when testing multi‑board panels and the status information pertains to an overall panel.
 
 
This function does not change the board number; it simply indicates what that number is.
Syntax
  bni
Parameters
(none)
Examples
  board number is 3    ! The board being tested is number 3 on a panel of boards.
                       ! Status information for this board is separated from the
                       ! status information for the other boards on the panel.
  bni                             ! Returns "3".
  print "Board number is", bni    ! Prints "Board number is   3".
  board number is *               ! Test single boards, not panels.
  bni                             ! Returns "0".
