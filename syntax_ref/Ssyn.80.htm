switch (ANALOG)
Title: SWITCH TEST
This statement is used within an analog in-circuit test block to test open and close switch contacts.
Syntax
  switch <specs>
  switch <designator>, <specs>
     <designator> is a <string constant>
     <specs> can be:   <threshold>
                       <threshold>,<return>
                       <threshold>,<options>
                       <threshold>,<options>,<return>
        <threshold> can be a <numeric expression> or *
        <return> is a <numeric variable>
        <options> can be one or more of options, separated by commas.
Parameters
 
<designator>
A string constant of up to 16 characters which identifies the a subtest. If the component fails, the system will include the <designator> in the failure message sent to the report is device.
<threshold>
A numeric expression which specifies a value in ohms. If the test measures a value less than or equal to the specified <threshold>, the test will pass. Note that numeric expressions used in analog statements do not allow user-definable statements.
An asterisk (*) can be specified instead of a value in ohms. If an asterisk is specified, the results of the test are not compared to any limits; the test will not fail (if the op option is specified and an asterisk is used, the <threshold> is effectively 0).
<options>
The test uses the default option values given in Table S-8, unless otherwise specified.
<return>
A numeric variable which holds the measured value.

Example
  clear connect s to "SW1-1"; i to "SW1-2"
  switch "1", 5
  clear connect s to "SW1-2"; i to "SW1-3"
  switch "2", 100k, op
  question "Set Switch to Position 1 (Press Yes or No)", Q
  if Q=0 then goto Skip1
  clear connect s to "SW1-1"; i to "SW1-2"
  switch "1", 5, ad2
  clear connect s to "SW1-2"; i to "SW1-3"
  switch "2", 100k, op
  Skip1:
  question "Set Switch to Position 2 (Press Yes or No)", Q
  if Q=0 then goto Skip2
  switch "3", 5, ad2
  clear connect s to "SW1-1"; i to "SW1-2"
  switch "4", 100k, op
  Skip2:
General Information
A switch is measured like a resistor. The result of the switch measurement are compared against a threshold instead of high and low tolerances. If the measured resistance is less than or equal to the threshold, the test passes. If the measured resistance is greater than the threshold, the test fails.
To test for more than one position of switch contacts, you can use the op, opposite, and ad, adjust, options with the switch statement. The ad option will prompt the operator to change the position of the switch; the ad2 option instructs the test to automatically continue if the switch is already in the correct position. The op option specifies that the test will pass if the measured resistance is greater than the threshold. Without op, the test will pass if the measured resistance is less than or equal to the threshold.
You can use the pf option to specify that the test return only a pass or fail indication instead of an actual resistance value. This will make the failure report much clearer. With the pf option the test returns a:
• 0 — for a failing test.
• 1 — for a passing test.
