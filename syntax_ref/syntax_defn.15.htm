Keyword
A keyword is the action part of a statement; it defines what the statement does. For example, dim is the keyword of the dimension statement, as in:
  dim A$[30], Q(1:10)
This statement dimensions the listed variables, that is, it allocates space in the workspace for them.
Keywords can easily be distinguished from variable names because keywords have all lowercase letters, while variable names always start with an uppercase letter (see the definition of Label).
Some statements have keywords that are separated from each other by parameters (for example, link <new file id> to <existing file id>). Where it is necessary to distinguish between the first keyword and those following it, the latter are referred to as secondary keywords. Other than as a convenience, the word secondary, as used here, has no special significance.
The various statements in the system language are named in this book according to their keywords. For example, the statement which has keyword dim is referred to as the dim statement or as the dimension statement.
