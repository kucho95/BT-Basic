meter (BT-Basic)
Title: DISPLAY A METER
The meter function displays a labeled meter on the screen which indicates the high and low limits (square brackets) of a measurement, and the returned value of the measurement (asterisk) relative to the limits:
  [  *  ]
You can use the meter function in a loop to continuously update the position of the asterisk as the operator adjusts the circuit (a potentiometer for example).
You can use the YES key on the operator keypad to allow the operator to continue the test after adjusting the device.
To make the test run faster, you can use a flag to instruct the meter function to draw the entire screen on the first loop, then to only update the position of the asterisk each subsequent loop.
Syntax
  meter <message>,<hi>,<lo>,<return var>,<count>
     <message> is a <string expression>
     <hi> and <lo> are <numeric expressions>
     <return var> and <count> are <numeric variables>
Parameters
<message>
A user‑defined label which appears with the meter below the screen status line. It is a string expression which can have up to 80 characters.
<hi> & <lo>
Numeric expressions which define the upper and lower limits, respectively, of the adjusted value. The upper limit is represented on the screen as a right bracket, and the lower limit as a left bracket.
<return var>
A numeric variable which holds the measured value.
<count>
A numeric variable which you can set to 1 to instruct the meter function to draw the entire screen, or to 0 to instruct the function to update only the position of the asterisk.
Example
The following example shows how to use the meter function with an analog functional test to allow the operator to adjust a potentiometer that controls the output of a voltage controlled oscillator (VCO). The operator presses the YES key to continue the test after adjusting the device. The system compares the result of the test with the test limits and fails the device if appropriate.
TESTPLAN:
     .
     .
     .
  X = 1                                ! Set flag to 1 to draw meter screen.
  loop                                 ! Loop to execute test repeatedly.
     test "analog/vco_adj"; R          ! Call test.
     meter "Adjust R67 then press YES", 5k, 4k, R, X    ! Execute meter with value of R.
     X = 0                             ! Set flag to 0 to update asterisk only.
     exit if yes                       ! Operator response.
  end loop
  if R < 4k or R > 5k then
     fail device
     report "VCO Adjustment Failed"
     report "Measure: ";R
     report "High Limit: 5K"
     report "Low Limit: 4K"
     report "----------------------"
  end if
     .
     .
     .
ANALOG FUNCTIONAL TEST "vco_adj":
  test powered analog; R              ! Delimit test and pass parameter R.
     connect rcva to "VCO_OUT"
     detector frequency, expect5k     ! Setup detector.
     arm detector                     ! Turn on detector.
     fetch R                          ! Fetch result without logging data.
  end test
