check board (BT-Basic)
Title: CHECK THE SYNTAX OF A board FILE
The check board function checks the syntax of a board file. This is important if you have edited your board file with an editor other than the Developer Interface (on UnMux systems) or Board Consultant (on Mux systems).
You can instruct the check board function to place a listing of the checked file under another name; otherwise, it overwrites the original file.
In any case, the check board function produces a backup of the original file; the file is backed up regardless of the instructions in the .hp3070 file or in the function itself.
You can also use the list option to instruct the check board function to produce a list of errors found in the board file in a new file called board.e.
Syntax
  check board <file name>
  check board <file name> <option list 1>
  check board <file name>; <option list 2>
  check board <file name> <option list 1>; <option list 2>
     <file name> is a <string expression>
     <option list 1> can be:   over/to <list file name>
                               over/to <list file name>, <error variable>
                               <error variable>
         <list file name> is a <string expression>
         <error variable> is a <numeric variable>
     <option list 2> can be:   <item>
                               <item>, <item>
                               <item>, <item>, . . . , <item>
         <item> can be:   list
                          <experience level>
                          <backup level>
           <experience level> can be:   standard
                                        advanced
                                        expert
            <backup level> can be:   numbered
                                     unnumbered
                                     nobackup
Parameters
 
<option list 1>
Can be either a list file name, or an error variable, or both.
<option list 2>
A list of optional parameters that determine how the function works. The options are described below.
list
Produces a list of errors found in the board file. The list is placed in a file called board.e.
<experience level>
Sets the length (thoroughness) of error messages the user receives; also can restrict the user to a subset of the full system features. Permissible values are: standard, advanced, and expert.
<backup level>
Determines if the system stores an unchanged copy (a backup) of files before modifying them, and how the backup is stored. Permissible values are:
• nobackup – No file backup is made.
• numbered – Makes up to nine backups, each numbered sequentially with .#~ (file.1~). Number one is most recent. When more than nine occur, the oldest file is discarded, and the others are renumbered.
• unnumbered – A single backup is made; the file name is appended with a tilde (~); (file~).
Examples
  check board "/board_a/board",E
          ! Checks the syntax of the board file in the board_a directory.
  check board "/board_a/board"; unnumbered
          ! Checks the syntax of the board file and makes a single backup of any files
          ! that get modified.
  check board "board" to "bd_check"; list
          ! Places a listing of the checked file in a new file called "bd_check" and           ! places a list of errors from the board file in a new file called board.e.
