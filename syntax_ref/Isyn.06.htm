<alpha spec>
   a
   aa
   aa . . . . a
An <alpha spec> specifies the length of the field, i.e., the number of character spaces, to be occupied by a string from the I/O function. Each a (or A) represents one character space (for one ASCII character).
INPUT using <alpha spec>
When an <alpha spec> is used to input data, the following usage rules apply:
1 If the field is larger than the maximum length of the string variable into which the input is to be read, then an I/O error occurs and the contents of the variable remain unchanged.
2 If the field is not larger than the maximum length of the string variable, characters are read into the variable until field‑length characters have been read. The length of the variable is then the same as the field‑length specified in the image spec. If an EOL (End Of Line) is read before field‑length characters have been read, the characters are read into the variable and then, after the EOL, spaces are input. The length of the variable is then the same as the field‑length specified in the image spec.
Input then continues to the next variable, assuming that one is specified.
Example of data input with <alpha spec>
  dim A$[25], B$[6]
  Name1 : image  12a
  Name2 : image 10a
  enter "/dev/tape" using Name1 ; A$
     ! Assuming tape contains string
     ! "New Test", then string "New Test"
     ! is stored in A$; A$ is now
     ! 12 characters long as
     ! specified in the image (12a)
  enter "/dev/tape" using Name2 ; B$
     ! error: image field (10a) too long
     ! for B$
OUTPUT using <alpha spec>
When an <alpha spec> is used to output data, the following usage rules apply:
1 If the field is larger than the string to be output, the string is left‑justified in the field and the remaining space is output as blanks.
2 If the field is too small for the string, then the extra characters in the string are truncated. This does not cause an I/O error.
3 If the item being output is not a string, i.e., it is numeric, an I/O error occurs.
Example of data output with <alpha spec>
    L10 : image aaaaaa, 5x, 12a, 5a
    ! 5x = leave 5 spaces
    print using L10 ; "Test #","PASSED","FAILED"
    ! prints    Test #     PASSED      FAILE
    !           ‑‑6‑‑>‑5‑‑>‑‑‑‑‑12‑‑‑‑>‑5‑‑>
In the above example, Test # exactly fills its field and PASSED is left‑justified. The D in FAILED is lost because the word is too long for a five‑character field.
To output a character that is not printable, use chr$, the integer‑to‑character function:
Send_Char : image A
output "Counter" using Send_Char ; chr$(233)
