log board start (BT-Basic)
Title: BEGIN LOG RECORD FOR A PC BOARD
The log board start function begins an @BTEST log record for the PC board under test. The log record contains information needed by Pushbutton Q-STATS or (optional)  Q-STATS II to produce SQC reports. The @BTEST log record is ended by a log board end function later in the testplan.
Syntax
  log board start <SerialNumber>, <KnownGoodBoard>, <ParentPanelID>
  log board start external <SerialNumber>, <KnownGoodBoard> <ParentPanelID>
     <SerialNumber>, <KnownGoodBoard>, and <ParentPanelID> are <string expressions>
Parameters
<SerialNumber>
The serial number of the board being tested.
<KnownGoodBoard>
A string containing y if the board being tested is known to be good, and an n if it is not.
<ParentPanelID>
An optional parameter that uniquely identifies the multi‑board panel that contains this board. <ParentPanelID> is the serial number of that panel.
Examples
  input "What is the Serial Number of the PC board?", Ser$
  input "Enter "y" if it is a Known Good Board", KGB$
  if KGB$ <> "y" then KGB$ = "n"
  log board start Ser$, KGB$
     ! When testing a multi-board panel:
     !
  input "What is the Serial Number of the PC board?", Ser$
  input "What is the Serial Number of the panel?", Panel$
  input "Enter "y" if it is a Known Good Board", KGB$
  if KGB$ <> "y" then KGB$ = "n"
  log board start Ser$, KGB$, Panel$
General Information
The current log level (set by a log level is function) must be board, or higher, for this record to be generated.
When using multiple board states (board number is function) to test a multi‑board panel, an @BTEST log record begun by the log board start function is sent to the log buffer for the current board.
