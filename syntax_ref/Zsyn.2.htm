zener (ANALOG)
Title: ZENER MEASUREMENT
This function measures the reverse bias (breakdown) voltage of a zener diodes up to 18 volts.
Syntax
  zener <specs>
  zener <designator>,<specs>
     <designator> is a <string expression>
     <specs> can be:   <value>,<+tol>,<‑tol>
                       <value>,<+tol>,<‑tol>,<return>
                       <value>,<+tol>,<‑tol>,<options>
                       <value>,<+tol>,<‑tol>,<options>,<return>
        <value>, <+tol> & <‑tol> are <numeric expressions>
        <return> is a <numeric variable>
        <options> can be one or more of options, separated by commas.
Parameters
<designator>
A string constant of up to 16 characters which identifies the a subtest. If the component fails, the system will include the <designator> in the failure message sent to the report is device.
<value>
A numeric expression which specifies the expected value in volts.
<+tol> & <-tol>
Numeric expressions which specify the plus and minus tolerances, respectively, as percentages. The upper and lower test boundaries are computed as follows:
upper = <value> * (1 + (<+tol>/100))
lower = <value> * (1 ‑ (<‑tol>/100))
<options>
The zener test uses the option values given in Table Z-1, unless otherwise specified.
<return>
A numeric variable which holds the measured value.

Example
  connect s to "CR4‑Anod", i to "CR4‑Cath"
  zener "CR4", 5, 10, 10
General Information
The test for zeners that are greater than 8.9999 volts uses an auxiliary source. The voltage compliance, co, for these tests should be set to 10.
The idc option can be used to set the constant DC current. It has a range of 10 uA ‑ 100 mA for the zener function; if idc is not specified, the system will use 10 mA. Note that the source amplitude and the reference resistor are not selectable. The idc option automatically selects the proper value of source amplitude, sa, and reference resistor, re, to obtain the specified current.
