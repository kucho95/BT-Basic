on (BT-Basic)
Title: COMPUTED BRANCHING
The on function branches program execution to one of several places, depending on the value of the function's <number> parameter. If the function has a goto keyword, it selects a line from its list of line labels, and it goes to that line. If the function has a call keyword, it selects a subroutine from its list of subroutine labels, and it calls that subroutine.
The value of <number> determines to which line label, or subroutine label, the branch is made: to the first label in the list if the value is 1; to the second label, if the value is 2; and so on.
The on function cannot pass parameters to a subroutine. If a subroutine is called, the subroutine must operate on its local variables or on global variables.
Syntax
  on <number> goto <line list>
  on <number> call <subroutine list>
     <number> is a <numeric expression>
     <line list> can be:   <line id>
                           <line id>,<line id>
                           <line id>,<line id>, . . . <line id>
     <subroutine list> can be:   <sub id>
                                 <sub id>,<sub id>
                                 <sub id>,<sub id>, . . . <sub id>
        <line id> & <sub id> are <labels>
Parameters
<number>
Integer value determines which label to branch to. The value must range from 1 to the number of labels in the list.
<line id>
The label at the beginning of the line to which the branch is to be made. The specified lines cannot be in a different environment from the on function (e.g., on in the main program, and the lines in a subroutine).
<sub id>
The identifier of the subroutine to be called.
Example
  for I = 1 to 4
     . . .
  on I call TestA, TestB, TestC, TestD   ! calls one subroutine (in turn) for each pass
     . . .
  next I
  on A mod 8 + 1 goto L1, L2, L3, L4, L5, L6, L7, L8
