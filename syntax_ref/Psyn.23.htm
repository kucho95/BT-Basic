ports (CONFIGURATION)
Title: FUNCTIONAL PORTS CONFIGURATION
The ports function declares the existence of functional ports. The ports function is used in both the testhead configuration file and the board configuration file.
The ports function must be within a block defined by the module and end module statements.
Syntax
  ports <range>
  ports <range>, <range>
  ports <range>, <range>, . . . . <range>
     <range> can be:   ext<port number>
                       ext<port number> to ext<port number>
        <port number> is an <integer>
Parameters
<port number>
Port number is an integer value from 1 to 8. In a module, port numbers may range from 1 to 2, from 3 to 4, from 5 to 6, or from 7 to 8. The port numbering must begin at 1, 3, 5, or 7.
Example
  module 2
     cards 1 asru n revision
     cards 6 control xtpb
     cards 7 to 11 hybrid high accuracy double density
     ports ext3 to ext4
  end module
