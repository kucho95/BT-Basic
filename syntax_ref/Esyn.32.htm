end test (ANALOG)
Title: MARK THE END OF AN ANALOG IN-CIRCUIT TEST BLOCK
The end test function is used in an explicit analog test block to mark the end of the test block. end test must be used in conjunction with a corresponding test analog function.
Refer to the description of the test analog (ANALOG) function for more information about analog in-circuit tests and test blocks.
Syntax
  end test
Parameters
(none)
Example
  test analog
     clear connect s to "Enable"; i to "Vout"
     diode 800m, 400m, ar1, co1.5
  end test
General Information
