pslimit (BT-Basic)
Title: DETERMINE IF DUT POWER SUPPLY IS IN CURRENT LIMIT
The pslimit function determines if any of the DUT power supplies are in a current limit condition. The pslimit function returns a 32-bit integer whose binary representation has a 1 for each supply in current limit, and a 0 for those that are not in limit. The least significant bit represents the current limit status for power supply 1, and the most significant bit represents the current limit status for power supply 32.
Syntax
  pslimit
Parameters
(none)
Example
  ! Set three supplies, and if any are in current limit disconnect all supplies:
     sps 1,5,wa 10m
     sps 2,‑10
     sps 3,15,wa 300m
     if pslimit then dps
  ! Determine which power supplies are in current limit and report them:
     Pslimit=pslimit
     if binand (Pslimit,1) then report "PS 1 IS IN CURRENT LIMIT !!"
     if binand (Pslimit,2) then report "PS 2 IS IN CURRENT LIMIT !!"
                                   .
                                   .
                                   .
     if binand (Pslimit,64) then report "PS 7 IS IN CURRENT LIMIT !!"
General Information
It is often convenient to use pslimit as a boolean function (if pslimit then dps) since the function’s value is greater than zero if any power supply is in current limit.
