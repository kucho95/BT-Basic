recall minus (SOFTKEY)
Title: RECALL A COMMAND FROM THE COMMAND STACK
The recall minus softkey (f3) is used in the command line to recall a previously executed statement from the command stack. recall minus differs from recall plus (f2) only in that recall plus steps downwards through the stack, recall minus steps upwards. A beep sounds when you reach the top of the stack.
Refer to the description of recall plus for an explanation of the command stack and the operation of softkeys f2 and f3.
