auxiliary (ANALOG)
Title: SET UP AN AUXILIARY SOURCE
The auxiliary function sets up an auxiliary DC voltage source. The auxiliary source is turned on by the on option, or the initiate auxiliary function. You can specify the amplitude and current compliance of the auxiliary source.
The auxiliary source is connected to the A bus and can be used in addition to another source that uses the S bus.
Syntax
  auxiliary none
  auxiliary dcv, <options>
     <options> can be:   amplitude <value>, icompliance <level>
                         amplitude <value>, icompliance <level>, on
                            <value> is a <numeric expression>
                            <level> can be:   0
                                              1
Parameters
on
Turns the auxiliary source on immediately instead of using the initiate auxiliary function.
amplitude <value>
Specifies the amplitude (in volts), of the source. The range of amplitude is -10.0 to +10.0 volts DC.
icompliance <level>
Specifies the current compliance of the source. Low current compliance (30 mA), is indicated with a 0. High compliance (150 mA), is indicated with a 1.
Example
! Set the auxiliary source to +5 volts dc with current compliance of 150 mA,
! and turn the source on immediately.
     auxiliary dcv, amplitude 5.0, icompliance 1, on
