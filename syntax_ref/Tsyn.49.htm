topology get device pins (BT-Basic)
Title: GET THE NAMES OF THE PINS ON THE SPECIFIED DEVICE FROM THE BOARD FILE
The topology get device pins function fills an array with the names of the pins on the specified device. You can also get the name of the node on each pin.
Syntax
  topology get device pins <device id>, <pins array>
  topology get device pins <device id>, <pins array>, <err var>
  topology get device pins <device id>, <pins array>, <nodes array>
  topology get device pins <device id>, <pins array>, <nodes array>, <err var>
     <device id> is a <string expression>
     <pins array> is a <string array>
     <nodes array> is a <string array>
Parameters
<device id>
The reference designator of the device such as U100.
<pins array>
Is the name of the array in which to place the names of the device pins.
<nodes array>
Is the name of the array in which to place the names of the nodes.
Example
  dim Pins$(1:100)[8]                           ! Dimension an array.
  topology get device pins "U100", Pins$(*)     ! Place the names of the pins on
                                                ! U100 in array Pins$.
  dim Pins$(1:100)[8]                           ! Dimension an array.
  dim Nodes$(1:100)[48]                         ! Dimension an array.
  topology get device pins "U100", Pins$(*), Nodes$(*)
                  ! Place the names of the pins on U100 in array Pins$ and place
                  ! the corresponding node names in array Nodes$.
General Information
To use any of the topology access functions you must first load the board file into memory.
To load a board object file, board.o, into memory execute the load board statement.
To remove a board file from memory use the scratch board statement.
The load board statement automatically scratches any file that is presently in memory.
