fuse (ANALOG)
Title: FUSE TEST
This function is used within an analog in-circuit test block to test for the presence of a fuse. The test is essentially a resistor test that specifies a threshold value instead of tolerances. If the resistance measured is less than or equal to the threshold value, the test passes.
Syntax
  fuse <specs>
  fuse <designator>,<specs>
     <designator> is a <string constant>
     <specs> can be:   <threshold>
                       <threshold>,<return>
                       <threshold>,<options>
                       <threshold>,<options>,<return>
        <threshold> can be a <numeric expression> or *
        <return> is a <numeric variable>
           <options> can be one or more options, separated by commas (Table F-4)
Parameters
 
<designator>
A string constant of up to 16 characters which identifies the a subtest. If the component fails, the system includes the <designator> in the failure message sent to the report is device.
<threshold>
A numeric expression which specifies a value in ohms. If the test measures a value less than or equal to the specified <threshold>, the test passes. Note that numeric expressions used in analog statements do not allow user-definable functions.
An asterisk (*) can be specified instead of a value in ohms. If an asterisk is specified, the results of the test are not compared to any limit; the test does not fail.
<options>
If the mandatory option values are not specified, the test uses the default option values given in Table F-4.
<return>
A numeric variable which holds the measured value.

Example
   clear connect s to "F1-1"; i to "F1-2"
   fuse 10, re1, as
General Information
You can use the pf option to specify that the test return only a pass or fail indication instead of an actual resistance value. This makes the failure report much clearer. With the pf option the test returns a:
• 0 – for a failing test.
• 1 – for a passing test.
