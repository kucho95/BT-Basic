log using (BT-Basic)
Title: GENERATE A USER‑DEFINED, IMAGED LOG RECORD
The log using function generates user‑defined log records using image format. User-defined log records can duplicate existing log records, or they can be created from scratch for custom applications (which require custom routines to process the non-standard log records).
The data to be logged is contained in the function’s <log list>. The specifications to format the data are referenced by the function’s <image data> parameter. This parameter can itself contain the formatting specifications, or it can reference an image function which contains the specifications.
The operation of log using is similar to the operation of print using, except that print using prints to the default printer and log using prints to the log buffer. Refer to the description of the print using and image statements for details.
Syntax
  log using <image data>
  log using <image data>;<log list>
    <image data> can be:
        <image id>
        <image specifications>
           <image id> is a <label>
           <image specifications> is a <string expression>
     <log list> can be:   <expression>
                          <expression>,<expression>
                          <expression>,<expression>, . . . <expression>
        <expression> can be numeric or string
           [If <expression> is an array, use <array id>(*)]
Parameters
 
<image id>
The identifier of the image function containing the specifications to be used to format the log list
<image specifications>
The list of specifications to be used to format the log list. Refer to the description of the image function for a complete description of these specifications and of their operation.
<log list>
The list of data items to be output. These are formatted by the specifications referenced in the <image data> parameter. If the list contains nothing, the image specifications determine the output.
To output a complete array of data, use <array id>(*).
Examples
     ! Create an @A-CAP log record from scratch
  dim Designator$[3]
  Designator$ = "C1B"
  Status = 1
  Value = 1.25E+01
  log using "8a, d, a, sd.dde, a, 3a, a"; "{@A-CAP|", Status, "|", Value, "|", Designator$,
            "}"
     ! Log record looks like this: {@A-CAP|1|+1.25E01|C1B}
     ! Create a custom log record from scratch
  dim Name$[9]
  Names$ = "My_Record"
  Data1 = 3
  Data2 = 25
  Format1: image a, 9a, a, d, a, 2d, a
  log using Format1; "{", Name$, "|", Data1, "|", Data2, "}"
     ! Log record looks like this: {My_Record|3|25}
General Information
The log using function can output records of up to 2044 characters.
These records are generated for all log levels except none.
When using multiple board states (board number is function) to test a multi‑board panel, a log record produced by the log using function is sent to the log buffer for the current board.
