vacuum well (BT-Basic)
Title: MAP FIXTURE WELLS TO VACUUM PORTS
The vacuum well function specifies the relationship between fixture vacuum well(s) and vacuum port(s). If you do not specify the relationship with the vacuum well function, the relationships are:
 
If probe module is on the left:
• faon controls port 3
• fbon controls port 2
• fcon controls port 1
• fdon controls port 0
If probe module is on the right:
• faon controls port 1
• fbon controls port 0
• fcon controls port 3
• fdon controls port 2
Each vacuum well function overwrites any previous vacuum well function. You can specify more than one port by separating the port_ids with a comma. To specify more than one relationship, the vacuum well statements can be separated with a semicolon.
Syntax
  vacuum well <well_id> is <port_id>
  vacuum well <well_id> is <port_id>,<port id>
  vacuum well <well_id> is <port_id>; . . .<well_id> is <port_id>
     <port_id> can be:  0
                        1
                        2
                        3
     <well_id> can be:  a
                        b
                        c
                        d
Parameters
<well_id>
Specifies which vacuum well is connected to the specified port. The valid range of wells is a to d.
<port_id>
Specifies which port is connected to the specified vacuum well. The valid range of ports is 0 to 3.
Example
  vacuum well c is 0           ! The "fcon" function controls vacuum to port 0.
  vacuum well d is 0,1         ! The "fdon" function controls vacuum to
                               ! ports 0 and 1.
  vacuum well a is 3; b is 2; c is 0, 1
                         ! The "faon" function controls vacuum to port 3.
                         ! The "fbon" function controls vacuum to port 2.
                         ! The "fcon" function controls vacuum to ports 0 and 1.
