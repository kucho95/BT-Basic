append (BT-Basic)
Title: APPEND SYSTEM FILES
The append function is used to append one or more source files (or portions of files) to a destination file. All files specified must be local system files of the same type (BASIC, text, etc.). The source file(s) is left unaltered. The destination file cannot be a source file or a device.
When multiple source files are specified, they are appended in the order of their appearance in the function, left to right.
When first and/or last line numbers are included in a source file, only the specified lines are appended. If only a first line number is specified, the system appends from that line to the end of the file. (However, do not specify a first line number that is beyond the end of the file or an error results.) If only a last line number is included, the system appends from the beginning of the file to that line number. If you specify a last line number that is beyond the end of the file, the entire file is appended.
Syntax
  append <append list> to <file id>
  append <append list> to <file id>,<error variable>
     <file id> is a <string expression>
     <error variable> is a <numeric variable>
     <append list> can be:
          <append item>
          <append item>;<append item>
          <append item>;<append item>; . . . <append item>
             <append item> can be:  <file id>
                                    <file id>,<first line #>
                                    <file id>,<first line #>,<last line #>
                                    <file id>,,<last line #>
                                       <first line #> and <last line #>
                                          are <numeric expressions>
Parameters
<file id>
A string expression that identifies a system file.
<first line #>
Numeric expression which delineates a partial file to be appended. It must evaluate to positive number.
<last line #>
Numeric expression which delineates a partial file to be appended. It must evaluate to positive number.
<error variable>
The identifier of an error variable.
Examples
  append "/board/part2" to "/board/part1"
  append "file1",10,300 to "file2", Err
  append "file2";"file3",,200 to "file1"
