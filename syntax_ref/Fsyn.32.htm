flash assignments / end flash assignments (VCL)
Title: DEFINE FLASH ASSIGNMENT BLOCK FOR FLASH ISP
The flash assignments command begins a flash assignment block; the end flash assignments command signifies the end of the block.
The flash block is used by Flash ISP to assign dynamic data vectors, select the image file and type, and select how the last segment should be filled or not filled.
