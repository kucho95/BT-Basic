tdo (ITL)
Title: IDENTIFES TEST DATA OUT NODE
The tdo statement identifies the test data out node of the boundary-scan chain. A name is assigned to this node using the tdo statement.
Syntax
  tdo <node name>
  tdo <node name> <card list>
     <node name> is a <string expression>
     <card list> can be:   hybrid
                        channel          ! On Mux systems only
                        hybrid; channel  ! ";" indicates first choice preferred
                        channel, hybrid  ! "," indicates no preference
Parameters
<node name>
The name of the node assigned to tdo.
Examples
  tdo "Buffer-2"
  tdo "Out_4" hybrid
