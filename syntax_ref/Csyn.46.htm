connect (ITL)
Title: IDENTIFIES BOUNDARY SCAN CHAIN TEST TYPE AS CONNECT
The connect statement is used at the beginning of the file to identify that a connect test type is desired. Connect tests are ones in which a single boundary scan device in the chain is targeted for testing and it is tested between the device pins and tester nails, on any nodes that have electrical access.
Syntax
connect <device name>
   <device name> is a <string constant>
Parameters
<device name>
Provides the name of the device in the chain that will be tested. This will be used in the failure repair message and log reports. This name must be used in each node statement in the file, along with a pin number.
Examples
  connect "U1"
Refer to the ITL sample files in the Boundary Scan section for an example in context.
General Information
Refer to the connect-test-specific syntax: checkerboard and test inputs only.
