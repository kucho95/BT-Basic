<replication spec>
   ( <specification list> )
The <replication spec> allows a group of image specifications in the <specification list> to be executed, in sequence, a specified number of times. The group is delineated by parentheses, and a repeat factor precedes the parentheses to indicate how many times the group is to be executed before the next image specification is selected.
If the repeat factor is omitted, it is assumed to be a one and the group of specifications is executed only once; i.e., it is not repeated.
Replication acts the same for both data INPUT and OUTPUT.
Example of <replication spec>
      ! This routine makes three measurements and prints the values
      ! and the average; the values are stored in scalar array "V";
      ! the routine cycles twice.
      dim V(1:3)
      F7: image "Test ",d, ":", 3(3x, d.ddd), 4x, 10a, d.dddd, /
      for K = 1 to 2
      !
      ! ***these lines contain program statements to
      ! ***make the measurements and store the values
      ! ***in V(1), V(2) and V(3); the next function
      ! ***prints the values and the average of the
      ! ***three values:
      !
      print using F7; K,V(1),V(2),V(3),"Average = ",(V(1)+V(2)+V(3))/3
      next K
      !
      ! prints (using assumed values):
      ! Test 1:   1.523   1.525   1.524    Average = 1.5240
      !
      ! Test 2:   1.522   1.521   1.522    Average = 1.5217
