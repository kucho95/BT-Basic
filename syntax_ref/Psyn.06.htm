part (edit)
Title: INVOKE PART MODE
The part function clears everything currently in the workspace and sets the workstation to part mode. This mode is one way to create or edit part description libraries, which are written in PDL (Part Description Language). All statements you enter are checked for correct PDL syntax.
If you prefer a graphical user interface when creating or modifying part description libraries, use the Part Description Editor. It provides features similar to those in other software packages running on your test system—i.e., pull‑down menus, use of the mouse, resizable windows, and online help.
Syntax
  part
  part;<option>
     <option> can be:
        window
        nowindow
Parameters
<option>
• Either window or nowindow.
window opens a new window in part mode
• nowindow suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Example
  text            ! Sets "text" mode; all syntax checking is off.
  basic           ! Sets "part" mode, enables syntax checking for PDL statements.
  part;window     ! Opens a new window and sets "part" mode in it.
General Information
The part function is not programmable.
