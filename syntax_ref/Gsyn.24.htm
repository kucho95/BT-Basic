ground bounce suppression (ITL)
Title: Option to suppress ground-bounce in device under test
The ground bounce suppression statement is an optional ITL statement. It allows you to select yes or no to ground bounce suppression during test. Without the statement, the default is no ground bounce suppression.
The ground bounce suppression statement should appear in the Declaration section of a test to identify whether or not ground bounce suppression should be used during test.
Syntax
  ground bounce suppression <yes/no>
Parameters
<yes/no>
The identifier of the ground bounce suppression type to be referenced. The specifications for this function are to turn on ground bounce suppression (yes) or turn off ground bounce suppression (no).
Example
  interconnect "u1_u10"
  ground bounce suppression yes
  family "3v_CMOS"
  chain "Chain1"
     tdi "Buffer-1"
     tdo "Buffer-2"
     tck "Buffer-4"  family "3v_TTL" hybrid
     tms "Buffer-3"
     devices
        "u15", "74bct8374",  "DW_Package",  no
        "u34", "68040",      "PGA_18x18",   yes
        "u22", "74bct8374",  "FK_Package",  no
     end devices
  end chain
