merge (BT-Basic)
Title: MERGE FILES
The merge function lets you merge all or part of one or more files (called secondary files) into another file (called a primary file).
First, the primary file is brought into the workspace; e.g., get TestFile. Then a merge function specifying the secondary file(s) is executed. The specified secondary file material is then placed into the workspace in the line above the current line (cursor position). Finally, a store or re-store is executed to place the final, merged file (workspace) back into the file system.
Several secondary files can be specified to be merged. In this case, they are merged in the order of their appearance, left to right, in the merge function.
In addition, first and/or last line numbers of the secondary file(s) can be specified. If only a first line number is specified, the system merges from that line number to the end of the secondary file. Note that you must not specify a first line number that is out of range of the secondary file or an error results.
If only a last line number is specified, the system merges from the beginning of the secondary file to that (last) line number. If you specify a last line number that is beyond the end of the file, the entire file will be merged.
If no line numbers are specified, the entire file(s) will be merged.
Note that numeric expressions used as line numbers must evaluate to positive numbers or an error message is issued.
The mode (basic, text, etc.) of the workspace determines the mode of the final, merged file material. That is, regardless of the mode of the secondary file material, the final, merged file will be of the same mode as the workspace. In addition, if the workspace is in basic mode and the secondary file material is non‑BT-Basic or is not of a current revision, then syntax checking is turned on when the merge is executed. In this case, the screen is cleared and any syntax errors encountered are displayed.
Syntax
  merge <file>
  merge <file>;<file>
  merge <file>;<file>; . . . <file>
     <file> can be:
        <file id>
        <file id>,<1st line #>
        <file id>,<1st line #>,<last line #>
        <file id>,,<last line #>
           <1st line #> and <last line #> are <numeric expressions>
           <file id> is a <string expression>
Parameters
<file id>
A string expression representing a file in the file system.
<1st line #>,
<last line #>
Numeric expressions representing the first and last line numbers of the secondary file(s). See the function definition above for rules on proper line ranges.
Example
  get "TestFile1"              ! Place "TestFile1" in the workspace
  merge "TestFile2",5,10       ! Lines 5‑10 of "TestFile2" will be
                               ! merged into "TestFile1" above the
                               ! current line in the workspace.
