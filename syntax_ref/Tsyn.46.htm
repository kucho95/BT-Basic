topology device data$ (BT-Basic)
Title: GET AN ITEM OF INFORMATION ABOUT A DEVICE FROM THE BOARD FILE
The topology device data$ function returns an item of information about the specified device. This information comes from the board file. The information is returned as a string expression.
Ask for the information by item number. The item numbers are:
 
1
Is the device to be tested? Returned values can be: undefined, no, or yes.
2
Was the device entry crosschecked? Returned values can be: undefined, no, or yes.
3
Is the device replaceable? Returned values can be: undefined, no, or yes.
4
What is the part number of the device?
5
What is the failure message from the board function file? If there is no failure message the return string is null.
6
The pathname to the test for the specified device.
7
What is the device type? Returned values can be:
• undefined
• inductor
• capacitor
• jumper
• connector
• library
• diode
• potentiometer
• FET
• resistor
• functional
• switch
• fuse
• transistor
• zener
21
What is the value of the device? This item is valid for capacitors, inductors, resistors, potentiometers, and zeners.
22
What is the plus tolerance of the device? This item is valid for capacitors, inductors, resistors, potentiometers, and zeners.
23
What is the minus tolerance of the device? This item is valid for capacitors, inductors, resistors, potentiometers, and zeners.
24
Is the device fixed or variable? This item is valid for capacitors, inductors, and resistors. Returned values can be: undefined, fixed, or variable.
25
What is the maximum number of pins that can be driven high at any one time? This item is valid only for library devices.
26
What is the maximum number of pins that can be driven low at any one time? This item is valid only for library devices.
27
What is the high value for the device? This item is valid for diodes, FETs, and transistors.
28
What is the low value for the device? This item is valid for diodes, FETs, and transistors.
29
What is the maximum test current for the device? This item is valid only for fuses.
30
What is the series resistance (in ohms) of the device? This item is valid only for inductors.
31
Is the device present or not? This item is valid only for jumpers. Returned values can be: undefined, no, or yes.
32
What is the common pin of the device? This item is valid only for switches.
33
What are the contact pins of the device? This item is valid only for switches.
34
Is the device NPN or PNP? This item is valid only for FETs and transistors.
51
What type of adjustment is used for the device test? This item is valid only for potentiometers. Returned values can be:
• Accurate adjustment
• Fast adjustment
52
Is remote sensing turned on for the device? This item is valid for capacitors, inductors, potentiometers, resistors, and zeners. Returned values can be: undefined, no, or yes.
53
What is the test current for the device? This item is valid only for diodes.
54
What is the test threshold for the device? This item is valid only for fuses.
55
What tolerance multiplier is specified for the device test? This item is valid for capacitors, inductors, potentiometers, resistors, and zeners.
56
What is the test current for the device? This item is valid only for zeners.
57
Is upstream disable turned on for the device? This item is valid only for library devices and connectors that are to be tested with the Cover-Extend test technique. Returned values can be: undefined, no, or yes.
58
Is upstream condition turned on for the device? This item is valid only for library devices and connectors that are to be tested with the Cover-Extend test technique. Returned values can be: undefined, no, or yes.
59
What is the test strategy for Cover-Extend? This item is valid only for connector and library devices that are to be tested with the Cover-Extend test technique. Returned values can be:
• undefined
• bscan
• hybrid
• bscanguard
• hybridguard
Syntax
  topology device data$ (<device designator>, <item>)
     <device designator> is a <string expression>
     <item> is a <numeric expression>
Parameters
<device designator>
The name of the device.
<item>
A number (1 through 7, 21 through 34, or 51 through 59) that represents the item of information to be returned. The item numbers are described above.
Example
  topology device data$ ("U100", 57)               ! Is upstream disable turned
                                                   ! on for U100?
  Tested$ = topology device data$ ("R1", 1)        ! Is R1 tested?
  Value = val(topology device data$ ("C2", 21))    ! What is the value of C2?
  topology device data$ ("U12", 4)                 ! What is the part number of U12?
General Information
To use any of the topology access functions you must first load the board file into memory.
To load a board object file, board.o, into memory execute the load board statement.
To remove a board file from memory use the scratch board statement.
The load board statement automatically scratches any file that is presently in memory.
