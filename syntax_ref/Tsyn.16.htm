test inputs only (ITL)
Title: CHANGE CONNECT TEST TO ALLOW TESTING OF BIDIRECTIONAL PINS’ INPUT FUNCTIONS ONLY
The test inputs only statement is an optional ITL statement. It allows you to change Connect Test so that only the input functions are tested (the output functions are not tested). This feature is intended for use with PLD parts which have every pin’s BSDL showing a bidirectional capability. If this feature is used on a regular digital IC with a mix of inputs, outputs and bidirectionals, all coverage will be lost on the output pins. However, if the bidirectionals are grouped alone in a connect test file, this feature can still be of value. The.vcl file is changed as a result of compiling the ITL file with the test inputs only statement.
The test inputs only statement should appear after the test identification statement (the first statement in any ITL).
Syntax
  test inputs only
Parameters
(none)
Example
  connect "u1"
  test inputs only
  checkerboard
  chain "2u1_2u8"
General Information
The test inputs only is available to customers who have the Interconnect Plus software. It controls test generation for Connect Tests. If you have a connect test that fails because of missing disable information, then you can run it quickly by turning on the test inputs only option, removing the need for disables. Later, when you have the disables working, you can remove the option.
