def (BT-Basic)
Title: DECLARE USER‑DEFINABLE FUNCTION
The def function declares the name of a user‑definable function and the names and types of its formal Parameters. This function must be the first function in the function, and the first function on the line.
A function can be either numeric or string, as designated by its <id>. A numeric function returns a numeric value, and is invoked from a numeric expression. A string function returns a string, and is invoked from a string expression. Either type of function can be passed, and can operate on, either numeric or string data.
The parameters listed in the def function are the function's formal parameters; these represent variables, files or devices. Unless the function has no formal parameters, data is passed to the function when it is invoked. During execution of the function, all references to the passed data are made by referencing the formal parameters.
As well as operating on passed parameters, the function can operate on local parameters, and on global parameters (see the global function).
Syntax
  def fn<function id>
  def fn<function id> (<parameter>)
  def fn<function id> (<parameter>,<parameter>)
  def fn<function id> (<parameter>,<parameter>, . . . <parameter>)
     <function id> can be:   <label>
                             <label>$
     <parameter> can be:   <simple variable id>
                           <array id>(*)
                           @<name>
        <name> is a <label>
Parameters
 
<function id>
The name of the function. The function type is numeric unless it has a dollar sign ($) in which case it is a string function.
<parameter>
A formal parameter; can be a variable id, or an @<name>. A variable must be a simple variable or an entire array; individual array elements and substrings cannot be specified.
To specify an array use:
<array id>(*)
This allows the parameter to represent an array of any size, and with any number of dimensions. Both types of function (numeric and string) can have numeric and string parameters. The function can have up to 12 formal parameters.
Examples
  def fnCube_root (X)
  def fnAverage (A$, Sum, Test(*))
  def fnTranslate$ (Names$(*), Results(*), Entries, @Tape_Reader)
General Information
Refer to the description of the fn function for examples showing operation of user‑definable functions.
Arrays in the formal parameter list cannot be dimensioned. This is because a formal parameter is just a name used to temporarily represent an existing parameter passed to the function when it is invoked. Any arrays passed to the function must already have been dimensioned.
Arrays which are local to the function (i.e., they are not passed and are not declared global), must be dimensioned (dim function) in the function. Any global arrays must be dimensioned before the function is invoked.
