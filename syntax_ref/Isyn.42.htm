ith$ (BT-Basic)
Title: INTEGER TO HEXADECIMAL STRING
The ith$ function returns a string of characters representing the hexadecimal equivalent of the function's decimal, integer argument. With 16‑bit operation, the returned string can have a maximum of 4 characters (8 characters with 32‑bit operation). Leading zeros are suppressed. Hexadecimal digits A through F appear as upper case characters.
Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. Values in the following ranges can be processed:
• 16-bit operation:
  -2^15 <= value <= 2^15 - 1
  (2^15 = 32768)
• 32-bit operation:
  -2^31 <= value <= 2^31 - 1
  2^31 = 2147483648)
The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Syntax
  ith$ ( <numeric expression> )
  ith$ ( <numeric expression> , <error variable> )
     <error variable> is a <numeric variable>
Parameters
<numeric expression>
Decimal integer value to be converted to a hexadecimal string. If a conversion error occurs and there is an error variable, the null string is returned.
<error variable>
Identifier of an error variable.
Examples
  Word$ = ith$(12)
  print Word$              ! prints    C
  print ith$(‑1)           ! prints    FFFF  (16-bit operation)
  print ith$(968)          ! prints    3C8
  print ith$(‑9874)        ! prints    D96E  (16-bit)
  A = 2.675
  print ith$(A)            ! prints    3
  S$ = ith$(4e10, Err)     ! too large for 16 or 32 bits
     if Err > 0 then print "S$ contains the null string"
