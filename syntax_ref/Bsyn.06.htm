basic (edit)
Title: INVOKE BASIC MODE
The basic function clears everything currently in the workspace and sets the workstation to basic mode. In this mode all statements entered into the work area of the screen are syntax‑checked to ensure that they are valid BT-Basic statements. Regardless of the current mode, BT-Basic statements can always be executed (and syntax‑checked) in the command line.
Syntax
  basic
  basic;<option>
     <option> can be:
        window
        nowindow
Parameters
<option>
The options are:
• window – Opens a new window in basic mode.
• nowindow – Suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Examples
  text             ! Sets "text" mode; all syntax checking is off
  basic            ! Sets "basic" mode
  basic;window     ! Opens a new window and sets "basic" mode in it.
General Information
When you log in to the system, your workstation is automatically set to basic mode.
The basic function is not programmable.
