cover extend print level is (BT-Basic)
Title: SEND RESULTS OF COVER-EXTEND MEASUREMENTS TO SPECIFIED DEVICE
The cover extend print level is statement instructs the system to send a report of the results of Cover-Extend measurements to the current printer is device. The report includes:
• device designator
• pin number
• measured value
• pass/fail status
• low and high limits
If no cover extend print level is statement is executed, no Cover-Extend measurement information will be generated.
Syntax
cover extend print level is <status>
   <status> can be:  all
                     none
Parameters
<status>
Specifies what information to send to the printer is device, all Cover-Extend measurements or none.
Examples
  cover extend print level is all      ! Turn the reporting on.
  cover extend print level is none     ! Turn the reporting off.
  
sub Cover_Extend_Tests            ! Use the cover extend subroutine to
     printer is "measurements"    ! generate the report in a file called "measurements".
     cover extend print level is all
     test "j201"
     cover extend print level is none
     printer is *
  subend
