global (ANALOG)
Title: DECLARE GLOBAL VARIABLES IN ANALOG SUBTESTS
The global function declares numeric variables as global in analog subtests.
Syntax
  global <variable>
  global <variable>, <variable>
  global <variable>, <variable>, . . . <variable>
     <variable> is a <numeric expression>
Parameters
(none)
Examples
  subtest "part1"
     global First_Result
     connect i to "node_2"; l to "node_3"
     detector dcv, expect 2
     initiate detector
     fetch First_Result
     report analog 2.1, 1.9, First_Result
  end subtest
