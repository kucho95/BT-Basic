rename (BT-Basic)
Title: RENAME A FILE OR A DIRECTORY
The rename statement lets a test developer rename an existing file or directory. Only the name can be changed; the contents of the file or directory are not changed.
The new name must not create any conflicts in the directory that contains the old name. In other words, the new name cannot already exist in that directory.
Syntax
  rename <old name> to <new name>
  rename <old name> to <new name>,<error variable>
     <old name> and <new name> are <file id>'s
     <error variable> is a <numeric variable>
        <file id> is a <string expression>
Parameters
<old name>
The existing identifier that is to be changed.
<new name>
The identifier that is to replace the existing identifier.
<error variable>
The identifier of an error variable.
Example
  rename "infile" to "outfile"           ! Assumes the current directory.
     ! These two statements are equivalent if you are msi'd to "/test/costs":
  rename "/test/costs/proposed" to "/test/costs/projected"
  rename "/test/costs/proposed" to "projected"
  rename "a/b/c/d" to "k/b/c/d"         ! Rename a directory. "k/b/c" must exist and
                                        ! you must have write permission.
  Old$ = "Test/List" \ New$ = "Test/Results"
  rename Old$ to New$ , Err_Var
General Information
The rename statement changes the name of a file. Use the link statement to add a new name and retain the old one.
