mark (SOFTKEY)
Title: MARK LINES IN THE WORKSPACE
The mark softkey (f5) is used when editing in the workspace to delineate one or more consecutive lines which are to edited as a block by the editing statements listed below.
To mark a block of lines in the workspace, position the cursor on the first line in the block and press mark (f5) once. The line appears in inverse video and the mark key label changes to second mark. Then position the cursor on the last line in the block and press f5 again. That line also changes to inverse video and the key label changes to clear marks.
The block can now be edited as a block by any of the statements listed below. All the other editing keys and statements retain their normal functions and are not affected by the marks.
When the marks are no longer required they can be cleared by pressing f5 a third time. The key label then reverts to mark.
The marked block is not restricted to the lines which can appear on the screen at one time. The block can be any length, up to all the lines currently in the workspace. A line to be marked must be on the screen because the cursor has to be positioned on that line when the mark key is pressed. However, none of the marked block necessarily has to be on the screen when the (mark) editing statements are executed or when the marks are cleared.
The editing statements that require a marked block are:
• changem - Change a string in the marked block.
• delete - Delete all the lines in the marked block.
• duplicate - Copy all the lines in the marked block and insert the copy immediately above the line where the cursor is positioned.
• findm - Find the first occurrence of a string in the marked block.
• listm - List the marked block to the default printer.
• move - Move the marked block and insert it immediately above the line where the cursor is positioned.
