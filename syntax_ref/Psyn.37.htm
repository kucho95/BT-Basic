print using (BT-Basic)
Title: PRINT IMAGED DATA
The print using function outputs data, using the image format, to the default output device, which is established by a printer is function. Except that it uses image‑formatting, print using is the same as the print function.
The data to be printed is contained in the function's <print list>. The specifications to format the data are referenced by the function’s <image data> parameter. This parameter can itself contain the formatting specifications, or it can reference an image function which contains the specifications.
The primary purpose of the print using function is to format messages for the workstations’s screen, or to generate a hardcopy of data on the printer. However, the data can also be output to other devices and to files. The printer is function selects the file or device which is to be the new default. printer is also opens the file or device for the exclusive use of the test developer who executed that function.
Data is output to a file or device sequentially, record by record. The maximum length a record can have is 2044 characters; attempting to generate a longer record results in an error when the program is run.
The actual length of each record is determined by the EOL (End Of Line) sequences generated. An EOL is generated each time a line spec (/) is encountered in the image specifications, or, if the last specification is not a line spec, when all data items have been output.
Each time an EOL occurs, an appropriate sequence is sent to the file or device. The system automatically sends the proper sequence to all of the recognized standard and optional devices. For example, if the data is being printed, the printer executes a CR/LF (Carriage Return/Line Feed). If the data is being written to a file, an EOR (end of record) is sent. The end of the current record is marked and, if there is more data, a new record is started. However, if the image specifications include an <inhibit EOL spec> (#), then the EOL is not generated (this spec applies only to GPIB or RS‑232 operations).
During the output, the system tracks its position in the file or device by means of a pointer. Provided that the file or device is not closed, the pointer remains at the current position when the output operation is completed. The next output operation then starts where the previous one stopped. The pointer can be returned to the beginning of the file or device by closing and reopening it.
Syntax
  print using <image data>
  print using <image data>;<print list>
     <image data> can be:
        <image id>
        <image specifications>
           <image id> is a <label>
           <image specifications> is a <string expression>
     <print list> can be:
        <expression>
        <expression>,<expression>
        <expression>,<expression>, . . . <expression>
           <expression> can be numeric or string
              [If <expression> is an array, use <array id>(*)]
Parameters
<image id>
The identifier of the image function containing the specifications to be used to format the print list.
<image specifications>
The list of specifications to be used to format the print list. Refer to the description of the image function for a complete description of these specifications.
<print list>
The list of data items to be output. These will be formatted by the specifications referenced in the <image data> parameter. If the list contains nothing, the image specifications will determine the output.
To output a complete array of data, use <array id>(*).
Example
  A = 6
  print using Test; "Test Number " , A
  Test: image 12a, dd
     ! Prints    Test Number  6
     !           ‑12 spaces‑>‑>
  print using "12a, dd"; "Test Number " , A
     ! Prints same as above
  F$ = "12a, dd"
  print using F$; "Test Number ", A
     ! Prints same as above
  K6: image 3(ddd.d),/
  print using K6; Results(*)
     ! Prints all values from array Results, arranges the printout into three columns,
     ! each column is 5 characters wide.
