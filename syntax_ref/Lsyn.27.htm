log board end (BT-Basic)
Title: END LOG RECORD FOR A PC BOARD
The log board end function ends an @BTEST log record for the PC board under test started by a log board start function earlier in the testplan. The log record contains information needed by Pushbutton Q-STATS or (optional)  Q‑STATS II to produce SQC reports.
Syntax
  log board end <status>
  log board end <status>,<qualifier>
     <status> is a <numeric expression>
     <qualifier> can be:   <numeric expression>
                           <string expression>
Parameters
<status>
A number identifying the test status. If this parameter is not included, it defaults to the current value of the boardfailed function (0 = pass; 1 = failed).
<qualifier>
A number or string to be output as a message. Typically, the message is used to explain the conditions which determined the status at the end of the test.
Examples
  log board end 10, errn
General Information
When using multiple board states (board number is function) to test a multi‑board panel, an @BTEST log record ended by the log board end function is sent to the log buffer for the current board.
