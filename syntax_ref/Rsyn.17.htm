remove adjustments (DEBUG)
Title: CANCEL ALL CHANGES MADE TO TEST Parameters
The remove adjustments cancels all current adjustments made to the test parameters during debugging. The adjustments are also cancelled by the debug and debug end statements.
To view the current adjustments before cancelling, use the display adjustments statement.
Syntax
  remove adjustments
Parameters
(none)
Example
  remove adjustments
