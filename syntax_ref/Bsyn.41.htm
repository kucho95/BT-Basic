buffer$ (BT-Basic)
Title: RETURN CONTENTS OF INPUT BUFFER
The buffer$ function returns a string containing the last record entered by an enter, enter using, input, or input using function. The string can contain up to 2048 characters.
Syntax
  buffer$
Parameters
(none)
Examples
  input A$              ! User types 'board test'
  String$ = buffers$
  print String$         ! Prints 'board test'
  ! This example assumes the test system's RS-232 port is connected to an external device
  ! and the external device sends a string to the test system.
      assign @Input to '/dev/rs232_port'
 
  ! Now assume that "board test" with no <cr> is transmitted to the test system's
  ! '/dev/rs232_port'.
      enter @Input,,Error;String$
 
  ! This generates a timeout error and sets the variable 'Error' appropriately.
  ! Note that because an error occurred, "enter" does not retrieve the contents of
  ! the input buffer.
      if Error = Timeout then String$ = buffer$
  ! even though the data is incomplete -- that is, the string was not terminated by
  ! an EOR character.
 
      print String$      ! prints "board test"
General Information
This function returns a string even if an error occurred while reading the input data; for example, if the record is not terminated by a valid EOR character.
