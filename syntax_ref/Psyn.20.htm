piped (VCL)
Title: ALLOW FOR THE PIPE IN UNCOUNTED HOMING LOOPS
piped is an optional keyword used in homing loops. The keyword is used in vector execution statements to indicate which vectors are to be placed in the pipe after the exit if pass vector. If used, the piped statements must be located immediately after the exit if pass vector execution function, but need not be the last statements in the loop. The piped vectors will be executed while the software is determining whether or not to exit the loop.
If piped statements are used, they (and not the exit if pass vector) will determine the state of the device after the exit from the loop. The piped vectors are executed for every pass through the loop. Refer to The Pipe, referenced above, for more details of the use of the piped statements.
If piped vectors are not used in the loop, then twelve no‑op vectors will automatically be placed in the pipe after the exit if pass vector. These vectors will be executed for every pass through the loop.
piped can be used with any of the vector execution statements (refer to those statements for the syntax):
• execute
• preset counter
• count
Example
  ! in the Vector Execution section
        . . .
     homingloop
        execute Vec0
        execute Vec1 exit if pass
        execute Vec0 piped
        execute Vec_Home piped ! determines device's states after the exit
        execute Vec1
     end homingloop
        . . .
