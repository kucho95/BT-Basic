spoll (BT-Basic)
Title: SERIAL POLL (READ STATUS)
The spoll (serial poll) statement performs a serial poll of the GPIB bus and returns a value which indicates the status of the selected device.
The returned value is a (decimal) integer whose lower eight bits are the status byte of the device addressed. The actual interpretation of the bit‑states is device‑dependent.
Syntax
  spoll (<GPIB device>)
     <GPIB device> is a <file id> or an @<name>
        <file id> is a <string expression>
        <name> is a <label>
Parameters
<GPIB device>
The address of the selected GPIB device. The value returned is a (decimal) integer whose lower eight bits are the status byte from the device.
Example
Shortcut Method:
  A = spoll ( "/dev/dmm")
  assign @DVM to "/dev/dmm"
  Q = spoll ( @DVM )
  print Q                 ! If Q = 41, the byte was 00101001
 
Absolute Path Method:
  Bus$ = btgetenv$("I3070_ICT_ROOT")
  A = spoll ( Bus$&"/dev/dmm")
  assign @DVM to Bus$&"/dev/dmm"
  Q = spoll ( @DVM )
  print Q                 ! If Q = 41, the byte was 00101001
General Information
 
 
These examples assume the dev file hpib1 contains the SICL interface name hpib7.
