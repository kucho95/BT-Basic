execute (SOFTKEY)
Title: EXECUTE A FUNCTION ON THE COMMAND LINE
The execute softkey (f4) executes the function or line currently in the command line of the workstation screen. The cursor can be at any character in the command line when execute is pressed; this is especially useful when editing statements which have been executed previously and have been recalled from the command stack by the recall plus softkey. If the command line is blank, the last line in the recall stack is executed.
Examples
  execute "notepad my_file"      ! Start the Windows Notepad application and load
                                 ! the file "my_file" in it.
