clear connect keep (ANALOG)
Title: CLEAR AND CONNECT PORTS AND KEEP THE CONNECTION
Use the clear connect keep function in analog functional and mixed tests to connect any of the AccessPlus Card ports (Mux systems) or balanced ports (Utility Card) to nodes when the connection is to be maintained until it is explicitly disconnected with the disconnect function. The clear connect keep function opens all previously closed analog relays (except those that were previously connected with clear connect keep or connect keep statements), then closes the necessary relays to connect specified ports to specified nodes. A node can be specified by node name, brc location, device pin, or pin; however, we recommend using node names, device pin, or pin in place of brc locations, because error checking is more extensive.
The clear connect keep function has a settling delay to allow the relays to settle.
• Connect/Keep Access Ports (Mux systems)
• Connect/Keep Balanced Ports (Utility Card)
