cd (BT-Basic)
Title: SET THE WORKING DIRECTORY
The cd function lets a test developer change the working (default) directory.
 
 
The cd and msi functions are equivalent, but cd was added for user convenience.
If the slash (/) is the first character of an identifier for a directory or for a file, then that identifier is assumed to be referenced to the root directory. If the identifier starts with any other character, then the identifier is assumed to be referenced to the current working directory.
Note that cd is just an abbreviated form of the mass storage is function. The two statements are interchangeable, but you will probably find the short form more convenient to use because it requires less typing.
Identifiers referenced to the working directory do not contain the name of that directory; see the example below.
Syntax
  cd <directory id>
  cd btgetenv$ ("I3070_ICT_ROOT") & <filename>
  cd <directory id>,<error variable>
     <directory id> is a <string expression>
     <error variable> is a <numeric variable>
Parameters
<directory id>
The identifier of the directory which is to be the working directory. This directory must already exist.
<error variable>
The identifier of an error variable.
Example
  cd "/production/area_2/test"
  cd "/production/area_1/tests",Err
  ! Includes an error varriable
The cd btgetenv$ statement must be used in a BT-Basic window, instead of the cd statement, if you are using the environment variable.
  cd btgetenv$ ("I3070_ICT_ROOT") & "/production/area_2/test/12c0836a"
General Information
You can specify relative pathnames (pathnames that include . or . . entries) in an cd function.
