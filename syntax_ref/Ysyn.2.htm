yes (BT-Basic)
Title: OPERATOR CONTROL YES
The yes function returns the current value of the Yes variable, then resets it. The Yes and No variables are set by the operator key pad. If the yes control is pressed, a 1 is returned; otherwise a 0 is returned. There is no wait after execution of this function before the variable is read.
Syntax
  yes
Parameters
(none)
Example
  loop
     if Yes then print "YES was pressed."
     else goto End
  endloop
     .
     .
     .
  End:
     end
