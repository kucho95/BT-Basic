val$ (BT-Basic)
Title: DECIMAL VALUE TO STRING
The val$ function returns a string which contains the decimal number from the function's numeric argument.
The number in the string appears in free format, except that no space is allowed for the sign of a positive number.
Syntax
  val$ (<numeric expression> )
Parameters
<numeric expression>
Number to be converted to a string.
Example
  print val$( ‑1145.47 )         ! prints    ‑1145.47
  print val$(1)                  ! prints    1
  print val$(123)                ! prints    123      (no sign‑space)
  print 123                      ! prints    123      (leaves a sign‑space)
  print val$( val("27") )        ! prints    27
  input "Name?", Name$
  input "Serial Number?" , Serial_number
  A$ = "Name: " & Name$ & " Serial: " & val$(Serial_number)
  print A$
