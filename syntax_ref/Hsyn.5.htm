homingloop hexadecimal (VCL)
Title: START HEXADECIMAL HOMING LOOP IN A FLASH ISP TEST
The homingloop hexadecimal function is used in the Vector Execution section of a Flash ISP test to mark the start of a homing loop; the end homingloop function marks the end of the loop.
Syntax
  homingloop hexadecimal <hex number of> times
      <hex number of> is a <string constant>
Parameters
<hex number of>
Maximum number of times the statement in the loop are expected to be executed. The loop can be repeated up to 231 – 1 times; the value must be 1 or greater. Specify the number in hexadecimal, e.g. "FF23".
Examples
     homingloop hexadecimal "FF23" times
.
.
.
     end homingloop
