set receiver offset (DEBUG)
Title: TEMPORARILY CHANGE THE OFFSET ON A RECEIVER
The set receiver offset statement changes the offset on one or more receivers, or on the probe. Unless the optional <active event> parameter is used, the offset will apply to the specified pins whenever they are referenced in the test.
Syntax
  set receiver offset on <identifiers> to <time>
  set receiver offset <active event> on <identifiers> to <time>
     <identifiers> can be:   device <designator>
                             device <designator> pins <pin‑id list>
                             groups <group-id list>
                             nodes <node-id list>
                             pins <pin-id list>
                             probe
        <designator> is a <string expression>
        <pin-id list> can be:   <pin id>
                                <pin id>,<pin id>
                                <pin id>,<pin id>, . . . <pin id>
           <pin id> is a <string expression>
        <group-id list> can be:   <group id>
                                  <group id>,<group id>
                                  <group id>,<group id>, . . . <group id>
           <group id> can be:   <label>
                                <string expression>
        <node-id list> can be:   <node id>
                                 <node id>,<node id>
                                 <node id>,<node id>, . . . <node id>
           <node id> is a <string expression>
     <time> is a <numeric expression>
     <active event> can be:   a
                            b
Parameters
 
<identifiers>
The list of receivers whose offsets are to be changed. Except for the probe, only output pins and bidirectional pins can be specified.
<designator>
String representing a device. The device must be referenced in the test being debugged.
<id list>
The list of pins or nodes to be changed.
<time>
The offset, in seconds, from the event on which the activity is to occur. The value can range from ‑30 ns to 100 ns. A value cannot be used if it would place two transitions (state changes) on the same pin closer than 50 ns, or if the transition would then occur in the next vector.
<active event>
The offset is to be applied, in each vector pair, to the first (a) or second (b) active event on the specified pins (refer to Advanced Testing With VCL in Digital Testing for details).
Example
  set receiver offset on device "U24" to 15n
  set receiver offset on device "U68" pins "13", "11" to 15n
  set receiver offset on groups Data_in, "Data_out" to -10n
  set receiver offset b on pins "12" to 40n
