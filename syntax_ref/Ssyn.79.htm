supplies utility (CONFIGURATION)
Title: POWER SUPPLY CONFIGURATION ON UTILITY CARD
The supplies utility statement configures the power supply channels (channels 7 and 8) on the Utility Card. It must be used within a block defined by a module and end module statement. This statement is used in both the system configuration file and the board configuration file. The Utility Card must already be enabled.
There can only be one supplies utility statement for each channel on the Utility Card in each module (that is, maximum of 8 if all four modules are used). Each channel can be used either for muxed power supply or high current power supply. Channel 7 and 8 may be configured differently, but it is not possible to set different voltage levels for the sub-channels within a channel.
Note the following:
• The same power supply cannot be used more than once in a module. For example, the following is not valid and will result in an error during compilation:
   supplies utility hp6751.1 channel 7
   supplies utility hp6751.1 channel 8
• Different power supplies can be used in the same module. However, the old power supplies (66xx) cannot be used together with the newer power supplies (N67xx).
• The same power supply cannot be shared by different modules.
Syntax
System config:
supplies utility <ps type>.<ps output id> channels <channel id range>
Board config:
supplies utility <ps type>.<ps output id> <logical id> channels <channel id range> [mux]
  <ps type> can be:  ps5747
                     ps6751
                     ps6752
                     ps6746
                     ps6773
                     ! i3070 Series 5 systems only:
                       hp6621
                       hp6624
                       hp6634
                       hp6642
  <ps output id> is an integer from 1 to 4
  <logical id> can be: an integer from 1 to 24 for DUT power supplies
                       an integer from 25 to 32 for muxed power supplies
     <channel id range> can be:  7
                                 8
                                 7,8
                                 7 to 8
Parameters
<ps type>
The type of power supply.
<ps output id>
The output ID for the specified power supply (1 to 4).
<logical id>
The power supply number:
• 1 to 24 for DUT power supplies
• 25 to 32 for muxed power supplies
The power supply number must be unique in every supplies utility statement.
<channel id range>
The power supply channel (7 and/or 8).
mux (optional)
Specify mux to use the sub-channels to route individual power supply outputs to a panelized board. Without the mux option, the sub-channels are connected together to provide a high current output.
Examples
supplies utility ps5747.1 25 channels 7
supplies utility ps5747.1 26 channels 8 mux
supplies utility ps6752.1 25 channels 7
supplies utility ps6746.1 25 channels 7, 8
supplies utility ps6773.1 25 channels 8 mux
