failure (SHORTS)
Title: SPECIFY FAILURE MESSAGE
The failure function specifies a failure message that is sent to the report printer if a shorts or opens test fails.
A failure function is in effect until the next failure function. To turn off a failure message use the failure function with a null string.
Syntax
  failure <message>
     <message> is a <string constant>
Parameters
<message>
An appropriate failure message for the failed node(s).
Example
  failure "Look for open fuse in FB-1."
  threshold 12
  short "FB-1.1L" to "FB-1.1R"
  short "FB-1.2L" to "FB-1.2R"
  short "FB-1.3L" to "FB-1.3R"
  failure ""                    ! Turn off the failure message.
