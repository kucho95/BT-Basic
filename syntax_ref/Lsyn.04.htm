learn test time (DEBUG)
Title: LEARN THE EXECUTION TIME OF A VCL TEST
The learn test time function runs a VCL test a specified number of times, and reports the time required for the test to run. The report is sent to the printer is device. If the test is run more than once, the maximum, average, and minimum run times are reported. Because of overhead time associated with learning, the reported time is slightly longer than the actual time. Typically, the extra time is 8 microseconds.
You can use this function to estimate a value to specify in the test time (VCL) function in a test which has time‑undeterministic constructs, such as uncounted loops and waits, whose execution time cannot be predetermined (see Advanced Testing With VCL in Digital Testing for more information).
The test must be capable of running without any execution errors.
Syntax
  learn test time
  learn test time <count>
     <count> is a <numeric expression>
Parameters
<count>
Number of times the test is to be run.
Examples
  learn test time       ! executes the test once
  learn test time 5     ! executes the test 5 times
