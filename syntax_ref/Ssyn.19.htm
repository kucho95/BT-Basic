send (BT-Basic)
Title: SEND GPIB COMMAND & DATA
The send statement is used to send a series of GPIB commands or data to the bus.
A command (cmd) sets bus line ATN (attention) true (0), and data sets ATN false (1).
Syntax
  send <GPIB>;cmd <expression list>
  send <GPIB>;data <expression list>
  send <GPIB>;cmd <expression list> data <expression list>
     <GPIB> can be a <file id> or an @<name>
        <file id> is a <string expression>
        <name> is a <label>
     <expression list> can be:
        <expression>
        <expression>,<expression>
        <expression>,<expression>, . . . <expression>
           <expression> can be numeric or string
Parameters
<GPIB>
The address of the bus.
<expression>
The expression to be sent to the bus.
• If the expression is a variable, it cannot be a complete array; <array id>(*) cannot be sent.
• If the expression is numeric, it is rounded to an integer and only the lowest eight bits of the integer are sent.
• If the expression is a string, it is sent unchanged.
Example
Shortcut Method:
  send "/dev/hpib1" ; cmd "?U$", "F0R6T1M3E"
  assign @Auto to "/dev/hpib1"
  send @Auto ; data List$
  send @Auto ; cmd Instruction$ data List$
 
Absolute Path Method:
  Bus$ = btgetenv$("I3070_ICT_ROOT")
  send Bus$&"/dev/hpib1" ; cmd "?U$", "F0R6T1M3E"
  assign @Auto to Bus$&"/dev/hpib1"; read, write, shared
  send @Auto ; cmd Instruction$
  send @Auto ; data List$
  send @Auto ; cmd Instruction$ data List$
General Information
 
 
These examples assume the dev file hpib1 contains the SICL interface name hpib7.
