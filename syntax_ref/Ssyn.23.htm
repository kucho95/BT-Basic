set driver state on (DEBUG)
Title: MODIFY THE STATE OF A DRIVER
The set driver state on statement modifies the driver state on a specified node or pin for one or more machine vectors. The driver state can be set to 0, 1, or X for a single machine vector, for a group of machine vectors, or for the entire test. No-op vectors cannot be modified using this statement.
Normally this statement automatically modifies the vector that follows the vector, or vectors, specified in the statement. This is referred to as vector + 1 patching and prevents the subsequent vectors from possibly being affected by the changes. The off parameter turns vector + 1 patching off.
Syntax
  set driver state on <identifier> to <state> at <vectors>
  set driver state on <identifier> to <state> at <vectors>; off
     <identifier> can be:   node <node-id>
                            device <designator> pin <pin-id>
                            pin <pin-id>
        <node-id> is a <string expression>
        <designator> is a <string expression>
        <pin-id> is a <string expression>
     <state> can be:   <string expression>
                       <numeric expression>
     <vectors> can be:   <vector>
                         <start vector>, <end vector>
                         all
        <vector>, <start vector> and <end vector> are <numeric expressions>
Parameters
<identifier>
The name of the node or device pin whose receiver state is being modified.
<state>
The logical state can be set to 0, 1, or X; quotes are optional.
<vectors>
The machine vector, or vectors, to be modified. If this is a single vector, just that vector is modified. If a range of vectors, all vectors in the range, including the start and end vectors, are modified. If all is specified, all vectors in the test are modified.
Example
  set driver state on device "U25" pin "7" to "1" at 26 ! modifies vector number 26
  set driver state on device "U25" pin "7" to "1" at 41, 60  ! modifies 20 vectors
  set driver state on node "OSC_ENABLE" to "0" at all        ! modifies all vectors
  set driver state on pin "12" to "0" at 54; off        ! turns off vector + 1 patching
General Information
When this statement is used, sufficient memory must be available in the directory RAM, sequence RAM and pin RAM. Use the debug status statement to determine how much memory is available in each of the RAMs.
