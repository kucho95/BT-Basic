configuration (edit)
Title: INVOKE CONFIGURATION MODE
The configuration function clears everything currently in the workspace and sets the workstation into configuration mode. This mode must be selected to edit the configuration file, config, or to generate a new configuration file for use by the i3070 In-Circuit Test Software.
The statements entered are syntax checked to ensure that they are valid configuration statements. Editing and other mode selection statements can be executed as usual in the configuration mode.
Syntax
  configuration
Parameters
(none)
Example
  configuration           ! Sets mode to "configuration"
General Information
The configuration function is not programmable.
