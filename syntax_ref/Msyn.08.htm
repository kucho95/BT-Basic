message (VCL)
Title: OUTPUT MESSAGES WITH FAILING VECTORS
The message function is used in the Vector Execution section of the test to output user‑defined messages, keyed to the failing vectors, to the report printer. All failing vectors that are executed after a message output that message. Once executed, a message function stays in effect until replaced by a subsequently executed message, or until the end of the test. To turn a message off without replacing it, specifying a null string ("") in the message function.
If there are two or more contiguous message statements, their messages are concatenated to form one message. This enables you to output messages of any length.
Syntax
  message <message>
     <message> is a <string constant>
Parameters
<message>
The message to be output to the report printer.
Example
  message "This failure may be related to a faulty clock."
  execute V1
     ! a failing V1, or subsequent failing vector, outputs:
     ! This failure may be related to a faulty clock.
  message "This failure can be caused by test timing;"
  message "check U18 pin 6 first."
  execute V6
     ! a failing V6, or subsequent failing vector, outputs:
     ! This failure can be caused by test timing; check U18 pin 6 first.
  message ""   ! turn messages off
General Information
There are no restrictions to the placement of messages within program constructs, such as repeat loops. However, this practise is not recommended because of the large number of repetitive messages that can result.
