fabon (BT-Basic)
Title: TURN ON VACUUM SYSTEMS A & B
The fabon function controls the A and B vacuum systems. If neither vacuum system has been previously turned on, the fabon function turns on both vacuum systems. If either vacuum A, or vacuum B, has been turned on, the fabon function turns on the other vacuum (so that both vacuum systems are on at the same time). This function is useful for dual stage fixtures.
Any of the four vacuum off statements (faoff, fboff, fcoff, fdoff), turns off all vacuum which is currently turned on; they do not open GP relays that were previously connected.
Syntax
  fabon
Parameters
(none)
Examples
  faon      ! Turns on vacuum system A.
  fabon     ! Turns on vacuum B (vacuum A remains on).
  fboff     ! Turns off both vacuums A and B.
