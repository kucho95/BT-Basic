nfetr (ANALOG)
Title: DEPLETION MODE N‑CHANNEL FET Ron TEST
This function is used within an analog in-circuit test block to measure the channel resistance (Ron) of a depletion mode N‑channel FET.
Syntax
  nfetr <specs>
  nfetr <designator>,<specs>
     <designator> is a <string expression>
     <specs> can be:   <hi>,<lo>
                       <hi>,<lo>,<return>
                       <hi>,<lo>,<options>
                       <hi>,<lo>,<options>,<return>
        <hi> & <lo> can be <numeric expressions> or *
        <return> is a <numeric variable>
        <options> can be one or more of the options in Table N-1, separated by commas.
Parameters
 
<designator>
A string constant of up to 16 characters which identifies the a subtest. If the component fails, the system will include the <designator> in the failure message sent to the report is device.
<hi> and <lo>
Numeric expressions which specify the and upper and lower test boundaries, respectively, in ohms. Note that numeric expressions used in analog statements do not allow user-definable functions.
An asterisk (*) can be used in place of zero. If zero or * is specified for both tolerance values, the results of the test are not compared to any limits; the test will not fail.
<options>
The test uses the default option values given in Table N-1, unless otherwise specified.
<return>
A numeric variable which holds the measured value.

Example
     on failure report "PART NUM: 1145-0233; LOCATION: J5"
     clear connect s to "NODE_1"; i to "NODE_2"; g to "GND", "NODE_3"
     nfetr 10.24k, 4,906k, wb, ed, as
General Information
If the fr option is not specified, the system will use a DC source. If the fr option is included, the system will use an AC source of the frequency specified.
Note that the DC source amplitude range is -10.0 VDC to 10.0 VDC; and that the AC source amplitude range is 0.0 Vrms to 7.07 Vrms.
