fn (BT-Basic)
Title: USER‑DEFINABLE FUNCTION CALL
fn calls and starts a user definable function; it can also pass parameters (data) to it. When the fn function is executed, current system activity is suspended while the statements in the function are executed. When the function terminates, it returns a value (numeric or string) to the expression which invoked the function (i.e., it operates like any standard function in the system); system activity then resumes.
When the function is invoked, a list of parameters (data) can be optionally passed to it as the argument of the function. Each passed parameter is assigned, in turn, a name from the function's formal parameter list, in the order in which the parameters appear in the lists. Each parameter passed must match the formal parameter to which it is assigned (i.e., numeric or string, strings of the proper length, simple or array, etc.).
If no parameters are passed to the function, then it must operate on its local parameters, or on global parameters (see the global function).
Syntax
  fn<function id>
  fn<function id> (<parameter>)
  fn<function id> (<parameter>,<parameter>)
  fn<function id> (<parameter>,<parameter>, . . . <parameter>)
     <function id> can be:   <label>
                             <label>$
     <parameter> can be:   <numeric expression>
                           <string expression>
                           <array id>(*)
                           @<name>
        <name> is a <label>
Parameters
 
<function id>
The name of the function being invoked. If the id has a dollar sign ($), it is a string function; if not, it is a numeric function. The function must be in the workspace when it is invoked.
<parameter>
An actual parameter to be passed to the function. A parameter can be either a source of data on which the function is to operate, or a destination where the function is to send results. A parameter can be both at the same time. Each passed parameter must be of the same type as the formal parameter which is assigned to it. The number of parameters passed must be the same as the number of formal parameters. The function can have up to 31 formal parameters.
A parameter can be numeric or string; it can be a value, a variable id, or an @<name>. A variable can be a simple variable, an array element, an array, or a substring. An @<name> represents a file or device. A substring cannot be a destination.
 
The function can change the contents of any variable, file or device passed to it as a parameter; the change is then in effect after the return from the function. However, if the parameter is a substring, then that substring retains its original contents after the return, regardless of any changes made during execution of the function.
Examples
  ! Main program containing calls to functions:
     dim Sales(1:10) , Board_Name$(1:3), Components(1:3)
           . . .
     input X   |   print 3*fnSinesquared(X)/4
           . . .
     for I = 1 to 10  |  input Sales(I)  |  next I
     print fnSum(@Printer, Sales(*), 10)
           . . .
     for I=1 to 3  |  input Board_Name$(I), Components(I)  |  next I
        print "Board with largest number of components is:"
        print fnLargest$(Board_Name$(*), Components(*))
  end
  ! The function definitions follow:
     def fnSinesquared(V)  |  return sin(V)^2  |  fnend
     def fnSum( @Dev, Any_array(*), Size)
        for P=1 to Size
           output @Dev; Any_array(P)       ! Prints each value
           Total = Total + Any_array(P)
        next P
        return Total
     fnend
     def fnLargest$ (N$(*), A(*))
        if A(1) > A(2)  then
           Q=A(1) | W$=N$(1)       !
        else | Q=A(2) | W$=N$(2)   ! Function selects largest of three different values
        end if                     !
        if A(3) > Q   then
           return N$(3)
        else | return W$
        end if
     fnend
