report (SHORTS)
Title: SHORTS TEST REPORT DEFINITION
In shorts mode, the report statement controls the content of the shorts test report. More than one report statement can be included in a shorts file. Do not confuse this statement with the report (BT-Basic) statement. See syntax descriptions of both statements for details.
The phantoms keyword directs the system to include phantom shorts as part of the shorts test report. Phantoms reporting may affect shorts test speed.
The limit <# of nodes> option sets the maximum number of nodes reported in the shorts test report. The range for the <# of nodes> parameter is from 1 to 1408.
The netlist option directs the system to include connection information as part of the shorts test report. The shorts report will list all devices and pins connected to that node. Note that netlist reporting does not affect shorts test speed.
The common devices option directs the system to include device connection information as part of the shorts report. The test report lists all the devices that are common to the nodes involved in the short or open. If there are more than ten such devices, the list is terminated after the first ten devices. Common devices reporting does not affect the speed of shorts test.
Syntax
  report netlist
  report netlist, common devices
  report common devices
  report common devices, netlist
  report phantoms
  report limit <# of nodes>
     <# of nodes> is a <numeric constant>
Parameters
 
<netlist>
If netlist is selected, the shorts report lists all devices and pins connected to the nodes involved in the shorts or opens.
<common devices>
If common devices is selected, the shorts report lists only those devices common to two or more of nodes involved in the shorts or opens.
<phantoms>
If phantoms is specified, both shorts and phantom shorts are reported.
<# of nodes>
Used with the limit keyword, an integer between 1 and 1408 that sets the maximum number of nodes that are reported shorted or open to another node.
Example
  report phantoms     ! Perform a shorts test; report phantom shorts as they are found.
  report netlist      ! Perform a shorts test; include netlist information.
  report limit 5      ! Limits the report to a maximum of five nodes.
  report netlist, common devices
                      ! Perform a shorts test; include netlist info and common devices.
General Information
The shorts test report as defined by the report (SHORTS) statement is automatically output to the selected report device if a shorts pattern found during production testing does not match the known shorts.
