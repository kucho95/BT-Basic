set probe (DEBUG)
Title: PROGRAM THE PROBE TIMING
The set probe statement programs the probe to set the same values as those currently set on the specified receiver pin. If you subsequently change the values on that pin and need to change the same values on the probe, then execute a new set probe statement, because the probe values will not update automatically.
If you need to look at the actual signals on a driver, you must still program the probe to a receiver’s values. If there is no receiver with suitable values, use the set ref statement to program the probe.
If the specified pin is bidirectional, the probe will be programmed to that pin’s receiver values.
Syntax
  set probe to <identifier>
     <identifier> can be:   device <designator> pin <pin id>
                            node <node id>
                            pin <pin id>
        <designator>, <pin id> and <node id> are <string expressions>
Parameters
<identifier>
The node or pin whose values are to be programmed on the probe. Only outputs (receivers) and bidirectional pins can be specified.
<designator>
String constant representing a device. The device must be referenced in the test being debugged.
<pin id>
The selected pin.
<node id>
The selected node.
Example
  set probe to device "u18" pin "6"
  set probe to pin "u18-2"
  set probe to node "Carry"
