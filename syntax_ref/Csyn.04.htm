capacitor (ANALOG)
Title: CAPACITOR TEST
This function is used within an analog in-circuit test block to test fixed capacitors. It can be used to test variable capacitors if the ad option is included.
Starting with i3070 In-Circuit Test Software release 08.00p, test techniques have been added to:
• Test capacitances from 1000 uF to 30 mF, using a DC source.
• Test capacitances from 10 pF to 47 pF using a high frequency source provided by the Digitized Measurement Circuit (DMC) on the ASRU Revision N Card. The additional test frequencies are 100 kHz and 200 kHz (specify the fr100k or fr200k option).
Syntax for small and mid-range capacitors (AC test method)
  capacitor <specs>, <comp/nocomp>
  capacitor <designator>,<specs>, <comp/nocomp>
     <designator> is a <string constant>
     <specs> can be:   <value>,<+tol>,<‑tol>
                       <value>,<+tol>,<‑tol>,<return>
                       <value>,<+tol>,<‑tol>,<options>
                       <value>,<+tol>,<‑tol>,<options>,<return>
     <value> is a <numeric expression>
     <+tol> & <‑tol> can be <numeric expressions> or *
        <return> is a <numeric variable>
           <options> can be one or more of the measurement options in Table C-1.
     <comp/nocomp> can be:   comp
                             comp0
                             comp1
                             nocomp
                             nocomp0
                             nocomp1
 
 
 
You must set the <comp/nocomp> parameter for each capacitor.
On UnMux systems, the i3070 In-Circuit Test Software will write the analog source file with either comp or nocomp. comp0, comp1, nocomp0, and nocomp1 will not be used in the source file.
Syntax for large capacitors (DC test method)
  capacitor <specs>
  capacitor <designator>,<specs>
     <designator> is a <string constant>
     <specs> can be:   <value>,<+tol>,<‑tol>
                       <value>,<+tol>,<‑tol>,<return>
                       <value>,<+tol>,<‑tol>,<options>
                       <value>,<+tol>,<‑tol>,<options>,<return>
     <value> is a <numeric expression>
     <+tol> & <‑tol> can be <numeric expressions> or *
        <return> is a <numeric variable>
           <options> can be one or more of the measurement options in Table C-1.
Parameters
<designator>
A string constant of up to 16 characters which identifies the subtest. If the component fails, the system includes the <designator> in the failure message sent to the report is device.
<value>
A numeric expression which represents the expected value in farads. Note that numeric expressions used in analog statements do not allow user-definable functions.
<+tol> & <-tol>
Numeric expressions which specify the plus and minus tolerances, respectively, as percentages. Note that numeric expressions used in analog statements do not allow user-definable functions.
An asterisk (*) can be used in place of zero. If zero or * is specified for both tolerance values, the results of the test are not compared to any limits; the test does not fail.
<options>
The system uses the options and values given in Table C-1, unless otherwise specified.
<return>
A numeric variable which holds the measured value.
<comp/nocomp>
Specifies whether or not capacitance compensation is performed on the test (AC test method only):
• To specify that capacitance compensation is NOT to be performed, <comp/nocomp> can be:
  comp0   nocomp   nocomp1
• To specify that capacitance compensation IS to be performed, <comp/nocomp> can be:
  comp    comp1   nocomp0
Notes
• To specify AC or DC test method – The idc option must be included to indicate a test for a large capacitor using the DC method.
When the idc option is not included, testing will be done using the AC method.
• Capacitor tests using the AC test method must not include options for the DC test method and vice versa.
• For the DC test method, note the following:
• The comp/nocomp option is not used. All DC tests are nocomp.
• An interval option specifies the time between samples.
• The pm or sm option is required. If the capacitor is in isolation, choose sm. If it has parallel resistance then choose pm.

Examples
Small and mid-range capacitors (AC test method):
   clear connect s to "C1-1"; i to "C1-2"
   capacitor 2u, 11.8, 12.4, re2, fr128, nocomp, as
Large capacitors (DC test method):
   capacitor 10m, 5.0, 5.0, idc 40m, interval 25u, sm
General Information
To eliminate the capacitance of the system and of the test fixture, capacitance compensation is used. Capacitor tests that require compensation are executed before the fixture is activated. This happens only the first time the testplan is run after being loaded. Because the board under test is not in contact with the fixture, only the capacitance of the system and fixture is measured. This learned value is stored. When the capacitor is tested, the learned compensation value is subtracted from the measured capacitor value. This is done before the result of the test is compared to the test limits to determine pass or fail. The test (BT-Basic) statements that execute the capacitor tests that require compensation are in the testplan between the learn capacitance on and learn capacitance off (BT-Basic) statements.
The capacitor function allows the pc option. This option is a debug tool and can only be used in the debug mode. It adds a 100 pF capacitor in parallel with the capacitor under test. When the pc option is included, the result of the measurement should increase by 100 pF.
Variable capacitors can be tested by including the ad, adjust, option with the capacitor function.
