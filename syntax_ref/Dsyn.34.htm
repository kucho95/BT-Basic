Disconnect Balanced Ports (Utility Card)
Syntax
  disconnect all
  disconnect <port> from <relay list>
  disconnect <port> from <relay list>; <port> from <relay list>
  disconnect <port> from <relay list>; <port> from <relay list>; ... <port> from <relay list>
    <port> can be:  <bp instrument name> high
                    <bp instrument name> low
          <bp instrument name> is a <string constant>
    <relay list> can be:  <explicit relay list>
                          <implicit relay list>
          <explicit relay list> can be: pins <pin list>
                                        relays <brc list>
                                        nodes <node list>
                                        device <device name> pins <pin list>
               <pin list> can be: <pin>
                                  <pin>, <pin>
                                  <pin>, <pin>, . . . <pin>
               <brc list> can be: <brc>
                                  <brc>, <brc>
                                  <brc>, <brc>, . . . <brc>
               <nodes list> can be: <node>
                                    <node>, <node>
                                    <node>, <node>, . . . <node>
               <pin> can be:  <pin number>
                              <pin name>
                  <brc> is an <integer constant>
                  <node> is a <string constant>
                  <device name> is a <string constant>
                  <pin number> is an <integer>
                  <pin name> is a <string constant>
          <implicit relay list> can be: <relay>
                                        <relay>, <relay>
                                        <relay>, <relay>, . . . <relay>
               <relay> can be: <node>
                               <brc>
Parameters
<bp instrument name>
A string constant that describes the instrument connected to the balanced port (maximum length 32 characters). This name is declared in the board configuration file.
• high - Specifies the high side connection.
• low - Specifies the low side connection. This option opens the red Reed Relay, if it is closed.
<pin number>
An integer constant that describes the pin.
<pin name>
A string constant that describes the pin.
<brc>
A numeric constant describing the physical location (coordinate) of the module pin that connects to the specified node. A coordinate consists of five numeric characters that are expressed in a brc (Bank Row Column) format:
<node name>
A string constant identifying the node to which the specified bus is to be connected. The node name must be the same one entered for that node in the board description forms.
Examples
disconnect all
disconnect "dvm" high from "node_1"
disconnect "dvm" low from "node_2"
General Information
You can use only an explicit relay list or an implicit relay list within one disconnect-powered function. You cannot use a combination of explicit and implicit connections within one function.
