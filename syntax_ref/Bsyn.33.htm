boards wired in parallel (CONFIGURATION)
Title: SPECIFY PARALLEL-WIRED BOARDS FOR DUAL-WELL SHARED WIRING
Use the boards wired in parallel function in the board configuration file to specify which boards are to be wired in parallel for Dual-Well Shared Wiring. If Dual-Well Shared Wiring is enabled, there must be at least one boards wired in parallel function.
There must be a consecutive numbering of boards across the panel. A board number can be included in only one boards wired in parallel function. All boards on the fixture must be included. The boards function cannot appear in the testhead configuration file.
Syntax
  boards <board #> wired in parallel
  boards <board #> to <board #> wired in parallel
  boards <board #>, <board #> wired in parallel
  boards <board #>, <board #>, <board #> wired in parallel
     <board #> can be an integer from 1 to 256
Parameters
<board #>
An integer that identifies the board in the panel.
Example
  ! Boards 1, 2, 3 are wired in parallel
  ! Boards 4, 5, 7 are wired in parallel
  ! Board 6 is not wired in parallel
     boards 1 to 3 wired in parallel
     boards 4, 5, 7 wired in parallel
     boards 6 wired in parallel
