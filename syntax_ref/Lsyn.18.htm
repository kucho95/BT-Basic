lli$ (BT-Basic)
Title: DETERMINE THE CURRENT LOG LEVEL SETTING
The lli$ function returns a string that is equal to the information logging level set by the most recently executed log level is function.
Note that this function does not change the log level setting, it simply indicates what that level is. The returned string does not include the log level is <without> parameter.
Syntax
  lli$
Parameters
(none)
Examples
  if lli$ = "none" then
        log level is failures
     else log level is all
  end if
General Information
For information about log levels, refer to the description of the log level is (BT-Basic) function.
