/ (BT-Basic)
Title: DIVISION
This arithmetic operator divides the expression on its left by the expression on its right. The priority is 6.
Syntax
  numeric expression> / <numeric expression>
Parameters
<numeric expression>
The quantities to be operated on.
Example
  print 12/4              ! prints    3
  print (2+8)*(-6)/5      ! prints    -12
  print 4+6/3             ! prints    6 ( / has higher priority than + )
  A = 21 \ print A/3;A    ! prints    7    21
