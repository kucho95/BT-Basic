lwc$ (BT-Basic)
Title: LOWERCASE A STRING
The lwc$ function returns a string which is a copy of the argument string but with all upper case letters converted to lower case. The argument string remains unaltered.
Syntax
  lwc$ (<string expression> )
Parameters
<string expression>
The string to be copied, with upper case characters converted to lower case.
Examples
  print lwc$("THIS IS NEAT")     ! prints   this is neat
  print lwc$("3.14159")          ! prints   3.14159
  A$="This is CARBON14"
  print lwc$(A$[9])              ! prints   carbon14
  print A$                       ! prints   This is CARBON14
