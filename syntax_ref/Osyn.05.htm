off failure (ANALOG)
Title: TURN OFF AN ON FAILURE LOOP IN A TEST BLOCK
The off failure function is used within an analog test block to turn off an on failure (ANALOG) function. Refer to the on failure (ANALOG) function description for details.
Syntax
  off failure
Parameters
(none)
Example
  on failure
     report "PART #: 0180-1533****LOCATION: A5"
  end on failure
  clear connect s to "Filter"; i to "GND"
  capacitor 1u, 10.6, 11.5
  off failure
  clear connect s to "J1"; i to "Out"; g to "GND"
  capacitor 6.8u, 18.8, 19.2
General Information
(none)
