generate debug (VCL)
Title: GENERATE THE DEBUG DATA FILE
The generate debug function instructs the compiler to generate a debug data file when the executable version of the VCL test is compiled. The data is stored in an object file name <test name>.d and placed in the same directory as the VCL test.
The debug data is used by the debug software to correlate the numbers of the vectors as they are defined in the test with the numbers of the vectors in the order they are executed.
If the generate debug function is used in the test, the .d file is generated even if you do not specify the debug option in the compile function, and regardless of the default setting in the .hp3070 file (see General Information).
Syntax
  generate debug
Parameters
(none)
Examples
  generate debug
General Information
Two parameters in the .hp3070 file (Dcomp.Debug: and Mcomp.Debug:) set the default for the .d file. In the standard file, these parameters are set to no (the .d file is not generated). This enables the test developer to decide which tests require the debug data. If the parameters are changed to yes then the .d file is always generated.
