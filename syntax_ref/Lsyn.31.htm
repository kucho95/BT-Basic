log devices (BT-Basic)
Title: GENERATE LOG RECORDS FOR SELECTED DEVICES
The log devices function specifies that log records are to be generated for the selected devices. For the selected devices, this function overrides the current log level, except that the records are not generated if the level is none.
The log devices statements are cumulative. A maximum of sixteen devices can have selected status at any one time. If more are selected, a runtime error occurs. Any currently selected devices remain selected through all subsequent program runs until the devices are cancelled, or until the user logs off the system. All current device selections are cancelled when a log devices off function is executed.
Syntax
  log devices <device list>
  log devices <device list> <without>
     <device list> can be:   <designator>
                             <designator>,<designator>
                             <designator>,<designator>, . . . <designator>
        <designator> is a <string expression>
     <without> can be:   without nhls
                         without pins
                         without nhls,pins
                         without pins,nhls
Parameters
<designator>
The name of the device for which a log record is to be generated. The name can have a maximum of eight characters.
<without>
Turns off generation of the following records:
• nhls: nominal‑high‑low (@LIM3)
• high‑low (@LIM2)
• pins: interface pin list (@PIN)
(See General Information).
If the same device is specified in more than one log devices function, any <without> parameters for that device in the last function override any <without> parameters for that device in the earlier statements.
Examples
  log devices "R1", "U21" without pins, nhls
  R1$ = "A24R301" | R2$ = "A24R501"
  log devices R1$, R2$, "D73"
  log devices "CR1" without nhls     ! Turns off "nhls"
  log devices "CR1"                  ! Turns "nhls" back on
General Information
The without parameters, nhls and pins, turn off generation of specific types of records. nhls turns off logging of a component's nominal value (if any), and the high and low value limits. pins turns off the logging of failed interface pins.
