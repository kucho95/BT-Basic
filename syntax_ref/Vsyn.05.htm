values (ANALOG)
Title: MARK THE BEGINNING OF A LIST OF VALUES IN AN ANALOG DATA BLOCK
The values function marks the beginning of a list of values in an analog data block. values statements must be located inside a block delimited by data and end data statements. See the syntax description of the data and end data statements.
The values defined by the values statements in an analog data block are to be used by the Arbitrary Waveform Generator source, the measure (ANALOG) function, and the report analog (ANALOG) function. See the syntax description of these statements.
The values defined by the values function can be from 10 to -10.
Syntax
  values <value>
  values <value>, <value>
  values <value>, <value> . . . <value>
     <value> is a <numeric constant>
Parameters
<value>
A numeric constant from 10 to -10.
Example
  data "waveform"
     values 0.0, 0.5, 1.0, 1.5, 2.0, 2.5, 0.0, 0.5, 1.0
     values 1.5, 2.0, 2.5, 0.0, -0.5, -1.0, -1.5, -2.0, -2.5
     values -2.0, -1.5, -1.0, -0.5, 0.0
  end data
