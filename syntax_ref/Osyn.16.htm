output (BT-Basic)
Title: OUTPUT DATA
The output function is used to output data sequentially to files and devices, using free‑field format.
The file or device to which the output data is to be sent is specified in the function's <destination> parameter. A device is assumed to be part of the file system. A file or device can be addressed either by its <file id> or by an @<name> associated with that <file id>. If <file id> is used, the file or device opens for the access and then closes when that access is complete. If an @<name> is used, the file or device is opened when the @<name> is first assigned, and the file or device then remains open so that each new access can start where the previous access stopped.
The data to be output is contained in the function's <print list>. Using free‑field formatting, the listed items which have a comma as a delimiter are output in standard fields, with twenty characters per field. Where a semicolon is used as a delimiter, that item's field is packed; i.e., it is lengthened or shortened to suit the length of the data item. If the print list contains a tab function, the next field starts at the column indicated by that function's argument.
With free‑field format, an EOL (End Of Line) sequence is generated after every line, with each line containing a maximum of 80 characters. An EOL is also generated after all items in the list have been output, provided that an EOL has not already been generated for the last line—i.e., there will not be two EOL's at the end of the output. If the function has no print list, then just the final EOL (a blank line) is generated. Each time an EOL occurs, the system sends the appropriate sequence to the destination file or device. (The system automatically sends the proper sequence to all of the recognized standard and optional devices.)
For example, if the data is being printed, the printer receives and executes a CR/LF (Carriage Return/Line Feed). If the data is being sent to a file, an EOR (End Of Record) is received. The end of the current record is then marked and, if there is more data, a new record is started.
The output function writes data to the destination file or device sequentially, record by record. The length of each record is determined by the EOL, as explained above. The maximum length a record can have is 2044 characters, although with free‑field format no more than 80 characters can be output before an EOL is generated. During the output operation the system tracks its position in the file or device by means of a pointer. Provided that the file or device is not closed, the pointer remains in position when the output operation is completed. The next output then starts a new record immediately after the last record, where the previous output stopped.
Syntax
  output <destination>
  output <destination>;<print list>
  output <destination>,,<error variable>
  output <destination>,,<error variable>;<print list>
     <destination> can be:
        @<name>
        <file id>
           <name> is a <label>
           <file id> is a <string expression>
     <error variable> is a <numeric variable>
        [Note the double comma preceding <error variable>]
     <print list> can be:
        <item>
        <item><delimiter><item>
        <item><delimiter><item><delimiter> . . . <item>
           <item> can be:
              <numeric expression>
              <string expression>
              <tab function>
                 [If <expression> is an array, use <array id>(*)]
           <delimiter> can be:
             ,  (comma)
             ;  (semicolon)
Parameters
 
<destination>
The file or device where the output data is to be sent. If a <file id> is specified, the file or device is first opened and then closed when the output operation is completed, regardless of whether or not the output was successful. If an @<name> is specified, the file or device remains open for further access. If used, the @<name> must have previously been assigned.
<error variable>
The identifier of an error variable.
<print list>
The list of data items to be output in free‑field format. A data item is output in a standard field if its delimiter is a comma, and it is output in a packed field if its delimiter is a semicolon.
To output a complete array of data, use <array id>(*).
If the item is a tab function, the print position moves to the column indicated and the next field then starts in that column. If the column indicated is to the left of the current print position, an EOL is output and the field starts at the indicated column on the next line.
There is no difference between a comma and a semicolon used as the delimiter for the tab function. Neither affects the format in this case.
Example
  A = 128
  output "/dev/ptr" ; "Total =", A, "Units"
     ! Prints    Total =       128        Units
     !       ‑‑‑‑‑20 spaces‑‑‑‑‑>‑‑‑‑‑20 spaces‑‑‑‑‑>‑‑‑‑‑‑20‑‑
  output "/dev/ptr" ; "Total ="; A, "Units"
     ! Prints    Total = 128     Units
     !      ‑‑‑7‑‑>‑‑13 spaces‑>‑‑‑‑‑20 spaces‑‑‑‑‑>
  T$ = "Resistor values measured during test:"
  output @Typewriter,,Check; T$, tab(1), Results(*)
     ! Prints out T$ and then prints the values from the array, four values per line,
     ! starting on the next line; note the error variable, Check.
  output "/dev/ptr"; A(*); B(*); ""
     ! Since the last item in the print list cannot be a delimiter, inclusion of the
     ! dummy output item (the null string) allows the second array to be packed.
  R$ = "File_4"
  output R$; A, B, C; D; E
  output R$    ! Outputs an EOL (a blank line)
