unlink (BT-Basic)
Title: REMOVE A NODE FROM A DIRECTORY
The unlink function removes a node name from a directory and breaks that directory's link to it. If the node is a directory, that directory is purged from the file system, provided that directory is empty.
If the node is a file, it may or may not be purged. Breaking one link to a file has no effect on any other link to the same file. When all links to a specific file are broken, that file no longer exists in the system—that is, it has been purged, and the disk space which it occupied is freed for use by the system.
The unlink function can also be used to purge a file by specifying that file’s file id in the function.
Syntax
  unlink <id>
  unlink <id>,<error variable>
     <id> is a <string expression> that can be:
        <file id>
        <directory id>
     <error variable> is a <numeric variable>
Parameters
<id>
The identifier (link) to be deleted, which can be a file or a directory.
<error variable>
The identifier of an error variable.
Example
  unlink "/test/analog/amp"
 
  msi "/test/analog"                ! The second two statements together are equivalent
  unlink "amp"                      ! to the first function.
 
  F$ = "myfile" \ unlink F$, Err    ! Includes error variable
