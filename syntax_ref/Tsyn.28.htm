testhead name (CONFIGURATION)
Title: TESTHEAD NAME
The testhead name statement in the testhead configuration file declares the name of the testhead. This name is mapped to the IP address in the /etc/hosts file.
The testhead name statement in the system config file identifies the block in the bootptab file that contains hardware and IP addresses for the System Card and Module Control Cards. This statement includes only the modules that are present.
The System Card is represented by testhead1. The Module Control Card in each module is represented by module<n>.
Modules are mapped in the hosts file. Using this information, specific hardware addresses can be determined in the bootptab file.
Syntax
  testhead name <name> <modules>
     <name> is a <string constant>
     <modules> is an optional string specifying one or more modules
Parameters
<name>
A name that identifies the testhead to the system controller.
<modules>
Specifies one or more modules. The order in which the modules are listed is not important. The system recognizes the names as assigned to their respective modules.
Example
  testhead name "testhead1" "Module4" "Module3"
General Information
The name must conform to the conventions used in the /etc/host file.
