rnd (BT-Basic)
Title: RANDOM NUMBER GENERATOR
The rnd statement generates a (pseudo) random number less than 1 and greater than 0. The statement generates each new value from a seed. The first seed is established when the system workspace is cleared; each subsequent seed is based on the previous random value generated.
The statement is pseudo random because the sequence of numbers generated is repeatable each time a program is run. However, the programmer can change the sequence, by executing a randomize statement to change the current seed.
Syntax
  rnd
Parameters
(none)
Example
  print rnd       ! prints   .904836095164
  print 2*rnd     ! prints   .535865461135
                  ! depending on the seed, different values may be obtained
