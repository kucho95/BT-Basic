tan (BT-Basic)
Title: TANGENT
The tan statement returns the tangent of the statement's argument. The argument is in radians.
Syntax
  tan (<numeric expression>)
Parameters
<numeric expression>
The argument of the statement.
–1.49^8 <= argument <= 1.49^8
Example
  print tan(pi/4)          ! prints   1
  print tan(‑2)           ! prints   2.18503986326
  print 10+4*tan(pi/6)     ! prints   12.3094010768
