rexit (ANALOG) (BT-Basic)
Title: TERMINATE ALL SERVICES
The rexit statement terminates a measurement server. Because exiting BT-Basic terminates the connection between BT-Basic and the measurement server, you usually will not need to use this statement. When the rexit statement is executed, it terminates Keysight VEE immediately and does not wait for the current user statement, if any, to finish.
Syntax
   rexit
   rexit <server name>
   rexit <server name>; abort
   rexit; abort
      <server name> is a <string expression>
Parameters
<server name>
A string expression containing the unique name of a measurement server. If no value is specified, <server name> defaults to the last server that was referenced; i.e., whichever measurement server is currently in use.
abort
This parameter adds no functionality to the statement. Its purpose is to document the program to remind the programmer that Keysight VEE terminates unconditionally.
Example
rexit         ! Terminate whichever measurement server is in use.
rexit "vee"   ! Terminate a specific measurement server named "vee".
rexit; abort  ! Same as "rexit".
General Information
If you do use the rexit statement, it probably will appear in the following sequence with the other programming statements used with measurement servers:
   "rinit" a measurement server.
         . . . . .
   "rcall" statements to execute subprograms on the measurement server.
         . . . . .
   "rexit" the service specified in the "rinit" statement.
Thus, you usually will not need to provide the <server name> being terminated by an rexit statement.
A <string expression>, such as <server name>, is passed by value. The subprogram being called cannot alter data in the BT-Basic environment when data is passed by value.
