sequential (VCL)
Title: SEQUENTIAL DEVICE
The sequential statement appears in the Declaration section of the test to indicate that the device to be tested is sequential. That is, the device has memory, so its outputs at any time are a statement of its present and previous inputs. If the device type (sequential or combinatorial) is not specified, the test assumes that the device is sequential (see also the combinatorial statement).
If used, sequential must precede the assign to statements in the test (see Vector Control Language (VCL) in Digital Testing).
The sequential statement contains information for the program generators. For a combinatorial device, they discard the individual vector‑execution statements which have topology conflicts with the device description input to the i3070 In-Circuit Test Software. For a sequential device, they discard the complete conflicting digital unit from the Vector Execution section of the test (see Resolving Topology Conflicts in Digital Testing).
The sequential statement is ignored if it is used in an executable test.
