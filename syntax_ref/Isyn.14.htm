<space spec>
   x
   xx
   xx....x
The <space spec> represents one or more character spaces.
INPUT using <space spec>
When a <space spec> is used to input data, each x causes one character to be skipped, i.e., read and discarded.
Example of data input with <space spec>
Read: image 4a, 2x, 4a
enter "dev/tape" using Read; Alpha1$, Alpha2$
  ! assuming tape contains "abcdefghijklm"
print Alpha1$; Alpha2$
  ! prints    abcdghij
OUTPUT using <space spec>
When a <space spec> is used to output data, each x causes one space to be output.
Example of data output with <space spec>
      A = 10.5 \ B = 12
      F9: image  13A, xx, dddd.d,x,a,x,4d,2x,3a,x,8d
      print using F9; "The result of", A, "*", B, "is:", A*B
      !
      ! prints    The result of    10.5 *   12  is:      126
      !           ‑‑‑‑‑13‑‑‑‑‑>‑>‑‑6‑‑>>>>‑4‑>‑>‑‑>>‑‑‑8‑‑‑>
      ! position of spaces    xx      x x    xx   x
