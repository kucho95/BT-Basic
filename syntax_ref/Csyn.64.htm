create ascii (BT-Basic)
Title: CREATE A FILE
The create ascii function allows a test developer to create empty, record‑oriented files. These are the standard ASCII files used to store text and programs. Other statements, such as save and copy, also create files, but those files are not empty.
Syntax
  create ascii <file id>
  create ascii <file id>,,<error variable>
     <file id> is a <string expression>
     <error variable> is a <numeric variable>
        [Note the double comma preceding <error variable>]
Parameters
<file id>
The <id> of the file to be created. This file must not already exist.
<error variable>
The identifier of an error variable.
Examples
  create ascii "test_report"      ! Creates file "test_report" in the
                                  ! current directory
  File$ = "/production/voltmeters/board_test"
  create ascii File$ ,, Failed
