end (BT-Basic)
Title: MARK THE PHYSICAL END OF A PROGRAM
The end function marks the physical location in memory where the program ends, and separates the main program from the subprograms, if any, that follow. If end is used, it must be the last function in the main program.
If the end is executed, it behaves exactly like the stop function. The stop function must be used if the program is to stop execution at any other point in the program.
Syntax
  end
Parameters
(none)
Examples
  if Error=1 then \ print "TEST FAILED" \ stop \ end if
  print "TEST WAS SUCCESSFUL"
  end
