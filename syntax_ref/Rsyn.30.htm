report out (BT-Basic)
Title: SEND DATA IN THE REPORT BUFFER TO A DEVICE OR FILE
The report out statement sends the current contents of the report buffer to a device or to a file.
The report buffer's contents are sent to the default report device (established by a report is statement) unless report out specifies another device or file.
This statement is applicable only when buffered reporting is enabled.
Syntax
  report out
  report out,<error variable>
  report out <file id>
  report out <file id>,<error variable>
  report out <file id>,<error variable>;<access>
  report out <file id>;<access>
     <error variable> is a <numeric variable>
     <file id> is a <string expression>
     <access> can be:
        <a/n/o>
        <e/s>
        <a/n/o>,<e/s>
        <e/s>,<a/n/o>
           <a/n/o> can be:
              append
              new
              over
           <e/s> can be:
              exclusive
              shared
Parameters
<file id>
The identifier of the file or device where the reported data is to be sent. The file will be opened, written to, and then closed. If no file is specified, the reported data is sent to the current default report device.
<a/n/o>
Determines how the data will be written:
• append – adds data to the existing file;
• over – replaces data in the existing file;
• new – creates a new file; an error occurs if it already exists.
If omitted, this parameter defaults to over.
<e/s>
Determines whether the file is opened for exclusive use or for shared use. If omitted, defaults to exclusive. The file should be opened shared only so that one user can write to it, and the other(s) read from it. If more than one user writes to the file, the results can be unpredictable.
<error variable>
The identifier of an error variable.
Example
  report is "report_file"; append   ! Open default report device (in this case, a file)
     . . .
  report out     ! Output is added to any existing data at default report device.
                 ! If a "board number is" statement appeared earlier in the board test
                 ! to specify a multi-board panel, then the output is the contents of
                 ! the report buffer for the current board.
  report out "/dev/report" & th$, Err1     ! Includes an error variable
General Information
Use this statement with the buffered reporting on/off statement to output data.
