gpconnect (ANALOG)
Title: GENERAL-PURPOSE RELAY CONNECT
The gpconnect (ANALOG) function is used in analog test blocks to close general purpose (GP) relays. See the corresponding gpdisconnect (ANALOG) function for opening GP relays in analog test blocks.
The ANALOG gpconnect and gpdisconnect statements coincide with the BT-Basic gpconnect and gpdisconnect statements. See the syntax descriptions of these statements for more information.
Unlike the other bus connections in analog test blocks, the GP relay connections are not bound to the test or subtest level. Instead, GP relay connections are maintained through tests and subtests until they are opened with the gpdisconnect function.
GP relay connections on the Module Control Card can be made or changed at any time. GP relay connections on the AccessPlus Card (Mux systems only) or Utility Card can be made or changed at any time except during an active controllerloop.
The gpconnect (ANALOG) and gpdisconnect (ANALOG) statements can be used within an on failure block.
The ANALOG gpconnect and gpdisconnect statements, and the BT-Basic gpconnect and gpdisconnect statements are interactive. That is, GP relay connections made with ANALOG statements can be opened with BT-Basic statements and vice versa.
Executing the unpowered statement will open all GP relays.
Syntax
  gpconnect <relay> to <relay>
     <relay> can be:   <node name>
                       <brc>
        <node name> is a <string constant>
        <brc> is a <numeric constant>
Parameters
<node name>
A string constant that describes the name of the node to which the GP relay connects. The name must be the one entered for that node in the i3070 In-Circuit Test Software.
<brc>
A numeric constant that describes the physical location (coordinate) of the module interface pin that connects to the specified node and GP relay. A coordinate consists of five numeric characters that are expressed in a brc (bank row column) format:
• the first numeric character (b) designates the testhead bank, either 1 or 2. Bank 1 covers modules 0 and 1, Bank 2 covers modules 2 and 3.
• the next two characters designate the horizontal row from the bottom of the testhead.
• the last two characters designate the vertical column from the right side of the testhead.
Example
  test powered analog
     gpconnect 11816 to 11817          ! Close the GP relay.
     gpconnect "Node_1" to "Node_2"
     clear connect s to "IN"
     connect i to "OUT"; l to "GND"
     source dcv, amplitude5.0, icompliance1
     detector dcv, expect 0
     measure .2, ‑.2
     gpdisconnect 11816 from 11817     ! Open the GP relay.
     gpdisconnect "Node_1" from "Node_2"
  end test
General Information
The gpconnect function closes only one relay. To close multiple relays requires multiple statements.
