generate backpatch (DEBUG)
Title: OUTPUT CURRENT DEBUG ADJUSTMENTS TO BACKPATCH FILE
The generate backpatch function creates a file named <test path>.bp where <test path> is the pathname of the test being debugged. For mixed tests the <test path> is the pathname to the digital source file of the mixed test. This file contains a listing of the current debug adjustments and contains the same information given by the display adjustments debug function. The debug adjustments of a session can be retained by generating a backpatch file and reading it into the next debug session. The backpatch file also serves as a checklist when making changes to a digital source file.
The current adjustments are cancelled by the following debug statements:
• debug
• debug end
• remove adjustments
Syntax
  generate backpatch
Parameters
(none)
Examples
  generate backpatch      ! For an in-circuit test with file name "<test name>",
                          ! the backpatch file generated is "<test name>.bp".
  generate backpatch      ! For a functional cluster test with file name
                          ! "functional/<test name>/test", the backpatch file
                          ! generated is "functional/<test name>/test.bp".
  generate backpatch      ! For a mixed test with file name
                          ! "mixed/<test name>/test.o", the backpatch file
                          ! generated is "mixed/<test name>/digital.bp".
