stop (BT-Basic)
Title: LOGICALLY STOP A PROGRAM
The stop statement stops and aborts a program. Once stopped, a program cannot be continued; it must be rerun.
If the stop statement is executed in a subprogram all levels of subprogram are exited and the main program is stopped.
If the program is controlling a testhead when the stop occurs, the following events take place:
1 The DUT power supplies are disconnected.
2 Vacuum to the fixture is turned off.
3 All of the testhead modules are initialized.
4 All general-purpose and auxiliary relays are opened.
5 All functional (powered) and in‑circuit (unpowered) testing is inhibited.
Syntax
  stop
Parameters
(none)
Example
  if Err=1 then \ print "TEST FAILED" \ stop \ end if
  print "TEST PASSED"
General Information
If a program is paused, it can be continued. See the pause and cont statements for details.
