baseline (BT-Basic)
Title: BASELINE COMMANDS
A set of baseline commands on the i3070 In-Circuit Test System allows users to monitor and validate whether the board directory contents have been modified. Use these commands to track and report when and where files change as boards are tested.
The initial baseline create on all command creates a baseline database named .dbRevTracker in the board directory being monitored and requires the user to enter passwords that allow access to that baseline database.
Syntax
baseline create on all        ! Create baseline on all files in board directory.
baseline create <filename>    ! Create baseline on specified file.
 
baseline update on all        ! Update baseline on all files previously baselined.
baseline update <filename>
 
baseline verify on all        ! Validate & report changes to files previously baselined.
baseline verify <filename>
 
baseline save                 ! Save the new baseline record.
 
baseline enable <filename>    ! Enable or disable baselining on specific files.
baseline disable <filename>
 
baseline revision on all; <option>
                              ! List revisions made to all files in board directory.
baseline revision <filename>; <option>
 
baseline delete on all        ! Delete all baselines.
 
baseline login <username>     ! Log in/log out commands for baseline database.
baseline logout
 
baseline password <username>  ! Change the login password.
 
   <filename> is a <string expressions>
   <username> can be: admin
                      proxy
   <option> can be: current
Parameters
filename
Name of the file being tracked in the board directory.
username
Predefined user names for accessing the baseline database. The admin user name provided unrestricted access to the baseline commands.
option
If current is specified for baseline revision, only the last revision is listed.

General Information
The general workflow for baselining is as follows:
1 Load the board test.
2 Execute baseline create on all to create the initial baseline.
3 Execute baseline verify on all to report any changes made in the board directory.
4 Execute baseline update on all to update the baseline, followed by baseline save to save the new baseline.
For further information, refer to Quality Control Tools > Version Tracking with Enhanced Log Records.
