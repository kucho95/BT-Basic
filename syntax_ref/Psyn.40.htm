probe (CONFIGURATION)
Title: PROBE CONFIGURATION
The probe function declares the existence of a guided probe in a module. The probe function can be used only in the testhead configuration file. The probe function must be used within a block defined by a module and end module function. The probe can be declared only in modules one or three.
There must be only one guided probe declared per testhead. If multiple probes are declared within a configuration file, a warning will be issued and the last probe declared will be the guided probe for that configuration.
Syntax
  probe
Parameters
(none)
Example
  module 3
     probe
     cards 1 asru n revision
     cards 2 to 5 hybrid high accuracy double density
     cards 6 control xtpb
     cards 7, 9 to 11 hybrid high accuracy double density
     supplies 1 to 4
     ports ext1, ext2
  end module
