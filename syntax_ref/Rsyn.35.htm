return (BT-Basic)
Title: RETURN VALUE FROM A FUNCTION
The return statement is used to exit a user‑defined statement and to return its final value to the calling environment. There can be any number of return statements in the statement, but there must be at least one.
Syntax
  return <expression>
Parameters
<expression>
Value to be returned from the statement. Must be of the same type, numeric or string, as the statement.
Example
  ! Main program
           . . .
        A = fnTrig( ‑3.14159*2 )
        print A
           . . .
     end
  def fnTrig (X)
     print "Results of Trig Function:"
        if X < 0 then
           return sin(X)
        else
           return cos(X)
        end if
  fnend
