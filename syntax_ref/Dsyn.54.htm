display probe (DEBUG)
Title: DISPLAY PROBE DATA
The display probe function runs the test and displays the states gathered by the probe. This display shows only actual data (see the display device function).
When this function is executed, you are prompted to place the probe at the point specified by the <message> parameter and instructed to then press start.
Before using the display probe function, you must program the probe to the required values by the set probe or other set statements (the probe cannot be programmed as a driver).
If the optional s (setups) parameter is used, the setups for the probe are listed to the printer is device. The listing includes the receiver high and low voltages programmed on the probe, and any offsets.
Syntax
  display probe <message>
  display probe <message> <display line>
  display probe s
     <message> is a <string expression>
     <display line> is a <numeric expression>
Parameters
<message>
The message indicating where the probe is to be placed. Make this a valid message which an operator can readily interpret.
<display line>
The line number at which to display the received data.
Examples
  display probe "Left end of R1"
  display probe "U1-6" 12         ! start the display at line 12
  display probe s
