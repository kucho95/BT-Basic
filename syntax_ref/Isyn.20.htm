inductor (ANALOG)
Title: INDUCTOR TEST
This function is used within an analog in-circuit test block to test fixed inductors. It can be used to test variable inductors if the ad option is included.
Syntax
  inductor <specs>
  inductor <designator>,<specs>
     <designator> is a <string constant>
     <specs> can be:   <value>,<+tol>,<‑tol>
                       <value>,<+tol>,<‑tol>,<return>
                       <value>,<+tol>,<‑tol>,<options>
                       <value>,<+tol>,<‑tol>,<options>,<return>
        <value> is a <numeric expression>
        <+tol> and <‑tol> can be <numeric expressions> or *
        <return> is a <numeric variable>
        <options> can be one or more of the options in Table I-1, separated by commas
Parameters
 
<designator>
A string constant of up to 16 characters which identifies the a subtest. If the component fails, the system includes the <designator> in the failure message sent to the report is device.
<value>
A numeric expression which represents the expected value in henries. Note that numeric expressions used in analog statements do not allow user-definable functions.
<+tol> and <-tol>
Numeric expressions which specify the plus and minus tolerances, respectively, as percentages. Note that numeric expressions used in analog statements do not allow user-definable functions.
The upper and lower test boundaries are computed as shown:
• upper = <value> * (1 + (<+tol>/100))
• lower = <value> * (1 ‑ (<‑tol>/100))
An asterisk (*) can be used in place of zero. If zero, or *, is specified for both tolerance values, the results of the test are not compared to any limits; the test does not fail.
<options>
Unless otherwise specified, the test uses the default option values given in Table I-1.
<return>
A numeric variable which holds the measured value.

Example
  on failure report "PART NUM: 1145-0149; LOCATION: G3"
  clear connect s to "06"; a to "06"; i to "01"; b to "01"
  inductor 100u, 10.3, 10.1, re1, fr8192, sa, sb, en, as
General Information
Variable inductors can be measured by including the ad, adjust, option with the inductor function.
