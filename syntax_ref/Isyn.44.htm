ito$ (BT-Basic)
Title: INTEGER TO OCTAL STRING
The ito$ function returns a string of characters representing the octal equivalent of the function's decimal, integer argument. With 16‑bit operation, the returned string can have a maximum of 6 characters (11 characters with 32‑bit operation). Leading zeros are suppressed.
Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. Values in the following ranges can be processed:
• 16-bit operation:
  -2^15 <= value <= 2^15 - 1
  (2^15 = 32768)
• 32-bit operation:
  -2^31 <= value <= 2^31 - 1
  (2^31 = 2147483648)
The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Syntax
  ito$ ( <numeric expression> )
  ito$ ( <numeric expression> , <error variable> )
     <error variable> is a <numeric variable>
Parameters
<numeric expression>
Decimal integer value to be converted to the octal string. If a conversion error occurs and there is an error variable, the null string is returned.
<error variable>
Identifier of an error variable.
Examples
  Word$ = ito$(255)
     print Word$                 ! prints    377
  print ito$(‑1)                 ! prints    177777  (16‑bits)
  print ito$(968)                ! prints    1710
  print ito$(‑9874)              ! prints    154556  (16-bits)
  A = 2.5
     print ito$(A)               ! prints    3
  print ito$( oti("56667") )     ! prints    56667
  Word$ = ito$(4e10, Err         ! too large for 16 or 32 bits
     if Err > 0 then print "conversion error"
