subend (BT-Basic)
Title: MARK END OF SUBROUTINE
subend marks the end of the body of the subroutine in the workspace. Since the subexit statement can be used to exit the subroutine, the subend statement is not required, but it is convenient for program editing purposes. If it is used, then subend must be the last statement in the subroutine. If a subend is executed it acts like the subexit statement and causes the exit from the subroutine.
Syntax
  subend
Parameters
(none)
