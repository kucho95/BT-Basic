segment hexadecimal (VCL)
Title: SEGMENT BY HEXADECIMAL A TEST THAT USES VARIABLE VECTORS
The segment hexadecimal statement appears in the Vector Execution section of a Flash ISP test to segment tests that contain variable vectors that must be executed many times. This is equivalent to the segment statement for Flash70 tests.
Syntax
  segment hexadecimal <hex number of vectors>
Parameters
<hex number of vectors>
The number of times each variable vector will be saved during each download. <hex number of vectors> is a <string constant> such as "FF23".
With Flash ISP, this value no longer needs to be evenly devisible into the inner repeat loop.
Example
  segment hexadecimal "800"     !800h = 2048 decimal
