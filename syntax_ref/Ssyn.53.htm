softkeys on/off (BT-Basic)
Title: SELECT USER-DEFINED SOFTKEYS
If new softkey definitions have been selected, you can programmatically switch between the new definitions and the default definitions with the softkeys on and softkeys off statements.
The softkeys on statement switches from the default definitions to the current user definitions.
If no user softkeys have been defined, a runtime error occurs. If the user softkeys are already active, then no action occurs.
The softkeys off statement switches from the user definitions to the default definitions. If the system defaults are already active, no action is taken.
Syntax
  softkeys on
  softkeys on <error variable>
  softkeys off
     <error variable> is a <numeric variable>
Parameters
<error variable>
The identifier of an error variable.
Example
  softkeys on
  softkeys off
General Information
Note that you can use an escape + tab sequence from the keyboard to toggle between user and default definitions.
This sequence enables immediate switching to and from the user definitions and the defaults.
