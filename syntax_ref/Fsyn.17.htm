file (VCL)
Title: IDENTIFY IMAGE FILE TO BE READ FOR A FLASH ISP TEST
The file function identifies the image file to be read by the compiler.
Syntax
  file <file id> <record format>
Parameters
<file id>
The pathname of the file that contains the data that is to be read by the Flash ISP compiler.
<record format>
The format of the flash file to be read in. Valid formats are as follows.
• srecord – Motorola S-Record
• intelhex – Intel hex record
• binary – Binary image file
• image – i3070 image file
Example
  file "1Mbits.srec" srecord
