lgt (BT-Basic)
Title: COMMON LOGARITHM
The lgt function returns the common logarithm (to the base 10) of the function's argument.
Syntax
  lgt (<numeric expression>)
Parameters
<numeric expression>
The argument of the function; it must be positive and greater than zero.
Examples
  print lgt(305.2)                       ! prints     2.48458452928
  print lgt(.0049)                       ! prints    ‑2.30980391997
  print lgt(1)                           ! prints    0
  print lgt(‑2)                          ! error
  V1=1.87 \V2=.002 \print 20*lgt(V1/V2)  ! prints    59.4162322175
General Information
Use the exponentiation operator (^) to calculate the inverse common log (i.e., 10^<numeric expression>).
