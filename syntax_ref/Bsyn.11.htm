binand (BT-Basic)
Title: BINARY‑AND TWO INTEGERS
The binand function returns a decimal, integer value which corresponds to the binary AND of the function's two decimal, integer arguments. Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. Values in the following ranges can be processed:
  16-bit operation:  -2^15 <= value <= 2^15 - 1  (2^15 = 32768)
  32-bit operation:  -2^31 <= value <= 2^31 - 1  (2^31 = 2147483648)
The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Syntax
  binand (<numeric expression> , <numeric expression> )
Parameters
<numeric expression>
The decimal integer values to be AND‑ed.
Examples
  print binand(6+1,2)        ! prints    2
  print binand (‑3,10)       ! prints    8
  print binand (2343,0)      ! prints    0
  print binand (‑12 , ‑5)    ! prints    ‑16
