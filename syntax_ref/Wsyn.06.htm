wait for trigger (ANALOG)
Title: WAIT FOR TRIGGER
You can use the wait for trigger function to establish timing in your test. For example, you can specify that the test make a measurement when a defined event or condition occurs.
The wait for trigger function causes the test to wait the specified number of seconds for the previously defined condition to occur before executing the next function. The wait for trigger function requires previous trigger and arm trigger statements.
Syntax
  wait for trigger <time>
     <time> is a <numeric expression>
Parameters
<time>
The number of seconds to wait for a trigger.
Example
  ! Measure the voltage on node "out" when node "Trig" goes low:
  !   1. connect rcva to node "Trig".
  !   2. connect i and l to the signal you want to measure.
  !   3. set up the detector.
  !   4. instruct the test to trigger from rcva.
  !   5. arm the trigger.
  !   6. instruct the system to wait up to 5 s for rcva (node "Trig") to go low.
  !   7. when rcva does go low, execute the measurment.
  test powered analog
     connect reva to "Trig"
     connect i to "out"
     connect l to "GND"
     detector dcv, expect 5.05
     trigger analog from rcva
     arm trigger
     wait for trigger 5
     measure 5.05, 5
  end test
