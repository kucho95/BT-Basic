testhead cleanup (BT-Basic)
Title: OPEN DIGITAL AND ANALOG RELAYS
The testhead cleanup statement issues a reset to the testhead that opens all digital and analog relays. No action will be performed if this command is executed when there is no testhead connected or when the testhead is not in the powered mode.
Syntax
  testhead cleanup
  testhead cleanup, <error variables>
Parameters
<error variable>
The identifier of an error variable.
Example
  testhead cleanup
  testhead cleanup, Err     ! Error returned to the variable named Err
