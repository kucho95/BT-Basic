set ref (VCL) (ITL)
Title: SET DRIVER/RECEIVER VOLTAGES
The set ref statement is optional; you can use it in the Declaration section of a VCL library test to set-up the digital driver and receiver voltages on individual pins. The direction of the referenced resources (inputs, outputs or bidirectional), and the default references for all drivers and receivers must be established in a family statement before the set ref statement can be used.
All drive and receive levels are set up automatically in the testhead before the VCL test starts. Once established, the drive and receive voltages cannot be changed during the VCL test. However, you can alter the levels and recompile the test for debugging purposes.
Generally, this statement is not expected to be used in library tests, or on more than one or two pins on a board. It is intended for debugging executable tests—when some particular node needs a special driver or receiver level to make the circuit operate, for example. However, there is nothing to prevent you from using this statement in library tests, or on as many pins as you wish.
The following describes the driver and receiver voltage levels that can be set.
Voltage levels for UnMux systems
There are two voltage levels:
• driver high (dh), and
• receiver high (rh).
Each voltage can be programmed from 0.0 to 5.0 volts, inclusive.
The high voltage always represents logic 1 in the system, and the low voltage represents logic 0 (regardless of the logic used on the board).
• dh is the actual voltage that will be driven to the referenced pins.
• rh is the threshold level which specifies the expected logic level to be received.
• An actual voltage received at or above the rh level is interpreted as a 1.
• An actual voltage received below the rh level is interpreted as a 0.
• A failure occurs if the voltage received is not consistent with the expected level, unless an X was expected—in which case the received voltage can be at any level.
 
Voltage levels for Mux systems
There are four voltage levels:
• driver high (dh),
• driver low (dl),
• receiver high (rh), and
• receiver low (rl).
Each voltage can be programmed from -3.5 to 5.0 volts, inclusive: dh must be more positive than dl, and rh must be more positive than rl.
The high (more positive) voltage always represents logic 1 in the system, and the low (more negative) voltage represents logic 0 (regardless of the logic used on the board).
• dh and dl are the actual voltages that will be driven to the referenced pins.
• rh and rl are threshold levels which specify the expected levels to be received.
• An actual voltage received at or above the rh level is interpreted as a 1.
• An actual voltage received at or below the rl level is interpreted as a 0.
• A failure occurs if the voltage received is not consistent with the expected level, unless an X was expected—in which case the received voltage can be at any level.
 
As shown in the syntax below, the parameters can be specified in any order in the set ref statement. However, the parameters must match the specified pins. The driver voltage levels can be specified only for input pins or bidirectional pins; the receiver voltage levels can be specified only for output pins or bidirectional pins. Levels which are not specified are determined by the levels established by the family statements.
Syntax
   set ref on <identifiers> to <ref specs>
      <identifiers> can be: pins <pin-id list>
                            device <designator> pins <pin-id list>
                            nodes <node-id list>
                            relays <relay-id list>
                            groups <group-id list>
          <designator> is a <string constant>
          format of <id lists> is: <item>
                                   <item>,<item>
                                   <item>,<item>, . . . <item>
              <item> can be:
                     for <pin-id list> — <numeric constant>
                                            <string constant>
                     for <node-id list> — <string constant>
                     for <relay-id list> — <5-digit numeric constant>
                                              (represents brrcc)
                     for <group-id list> — <label>
      <ref specs> for UnMux systems can be:
          <level>
          <level>,<level>
             <level> can be:
                dh <volts>
                rh <volts>
                   <volts> is a <numeric constant>
      <ref specs> for Mux systems can be:
          <level>
          <level>,<level>
          <level>,<level>,<level>
          <level>,<level>,<level>,<level>
             <level> can be:
                dh <volts>
                dl <volts>
                rh <volts>
                rl <volts>
                   <volts> is a <numeric constant>
Parameters
 
<identifiers>
The list of pins (groups, nodes, etc.) to be set to the specified levels. All pins specified in a statement must be compatible with each other: that is, they must all be inputs or bidirectional pins, or, they must all be outputs or bidirectional pins. Use pins for pin‑library tests, and nodes for node‑library tests.
<designator>
String constant representing a device under test. This is the same as the device designator entered in Board Forms. It can contain up to 48 printable characters, but with no space.
<id list>
A list of pins represented by the following types of id:
<pin id>
<node id>
<relay id>
<group id>
These parameters are the same as the ids used to identify the pins in the assign to statements in the test. See the description of the parameters in the assign to (VCL) statement.
<ref specs>
The types of circuits (driver or receiver), and their voltage levels, to be assigned to the listed pins. These can be specified individually or in pairs; the circuit type must match the pin type as described above. Levels which are omitted are determined by the levels set by the family statements.
<volts>
The drive and receive reference voltage; the units are volts.
• For UnMux systems:
   0.0 <= volts <= +5.0
• For Mux systems:
   -3.5 <= volts <= +5.0
   dl < dh
   rl < rh
Example
  family TTL
  set ref on device "U68" pins 13, "11" to rh 4.2
  set ref on relays 10962, 10403 to dh +1.08
  set ref on groups Control to dh 4.3
General Information
The standard families have the following driver and receiver voltages:
 
For UnMux systems:
           dh      rh
TTL       3.5      2.0
CMOS      4.0      3.6
For Mux systems:
          dh     dl     rh     rl
TTL      3.5    0.2     2.0    0.8
CMOS     4.0    0.8     3.6    1.3
ECL     -0.5   -2.7    -1.2   -1.5
