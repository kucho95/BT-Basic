datetime$ (BT-Basic)
Title: DATE AND TIME
The datetime$ function returns a 12‑character string containing the current date and time. The string has the form yymmddhhmmss (year, year, month, month, day, day, hour, hour, minute, minute, second, second).
See also the time$ function.
Syntax
  datetime$
Parameters
(none)
Examples
  print datetime$          ! prints (for example) 020116142346
 
 
 
For dates after the year 1999, the year (yy) still appears as a two-digit value. The example above represents the year 2002, January 16, 2:23:46 p.m. (represented as military time). This format DOES NOT record the current time zone.
General Information
This function is used extensively by the datalogging routines.
