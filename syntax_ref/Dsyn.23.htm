digital (edit)
Title: INVOKE DIGITAL MODE
The digital function clears the workspace and sets the workstation to digital mode. This mode must be selected to edit or write digital device tests. These tests, which consist of statements from the Vector Control Language (VCL), can be stored either in the library of digital devices, or in the test program files, under the digital directory.
Any statements entered in digital mode are Syntax‑checked to ensure that they are valid VCL statements. However, editing and other mode selection statements can be executed as usual during the digital mode.
Syntax
  digital
  digital;<option>
     <option> can be:   window
                        nowindow
Parameters
<option>
The options are:
• window – Opens a new window in digital mode.
• nowindow – Suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Examples
  digital;window            ! Opens a new window and sets it to "digital" mode.
  msi "/pc_test/scopes/a9842c"    ! Selects board under test
  digital                         ! Sets "digital" mode
  get "digital/u32"               ! Brings VCL test into workspace
     !
     ! Edits VCL statements
     !
  compile                         ! Recompiles and re-saves in original file
  basic                           ! Establishes "basic" mode
General Information
The digital function is not programmable.
