view test results (BT-Basic)
Title: VIEW TEST RESULTS FOR COVER-EXTEND TESTS
Use the view test results statement to display CET test results in the Cover-Extend Viewer. The Cover-Extend Viewer can also be launched from Pushbutton Debug.
Syntax
  view test results
  view test results, <error variable>
  view test results; <option list>
  view test results, <error variable>; <option list>
     <error variable> is a numeric variable
     <option list> can be: <item>
                           <item>, <item>
                           <item>, <item>, . . ., <item>
        <item> can be:  stimulus <file id>
                        nostimulus <file id>
                        limits <file id>
                        title <string expression>
           <file id> is a <string expression>
Parameters
<file id>
The file containing the data to be displayed.
<error variable>
The identifier of the error variable.
Example
view cover extend                ! Launches Cover-Extend Viewer in "demo" mode
view cover extend, Error         ! Returns an error if viewer cannot be scheduled
view cover extend; title "Test"  ! Sets the title for the Cover-Extend viewer
view cover extend; stimulus "sfile", nostimulus "nsfile", limits "j1.pvl", title "j1 results"
