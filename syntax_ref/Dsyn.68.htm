dps (BT-Basic)
Title: DISCONNECT DUT POWER SUPPLIES
The dps function sets the specified DUT power supplies to 0 V and disconnects them from the testhead. It will also execute the .discharge test once. If no DUT power supplies are specified, all supplies are set to 0 V and disconnected from the testhead (including any muxed power supplies on the Utility Card).
See also:
cps function for connecting all the DUT power supplies to the testhead.
sps function for setting up the DUT power supplies once they are connected.
Syntax
  dps
  dps <ps_number>
  dps <ps_number>, <ps_number>
  dps <ps_number>, <ps_number>, . . . <ps_number>
      <ps_number> is an integer from 1 to 32
Parameters
<ps_ number>
An integer that identifies the power supply to be disconnected (1 to 32). This is the logical supply number as declared in the board configuration file.
Example
  dps      ! Disconnect all DUT power supplies together with muxed power supplies
  dps 1          ! Disconnect power supply 1.
  dps 1,2,4      ! Disconnect power supplies 1, 2, and 4.
  dps 25         ! Disconnect all sub-channel relays on power supply 25
