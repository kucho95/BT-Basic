family (VCL)
Title: DECLARE LOGIC FAMILY
The family function appears in the Declaration section of a test to identify the logic family (or families) to which the device or circuit under test belongs. The system hardware allows any number of family types to be tested in any one VCL test.
The family function provides information to the compiler, enabling it to generate the coding which sets up the drivers and receivers on the pin cards in the testhead when the test is run.
The first family function in the test automatically specifies the default family. The default family initially applies to all pins in the test. Once the default family is established, the parameters on individual pin groups and on individual pins can be changed by subsequent family statements or by the set statements (set load, set ref, and set slew rate1). All family statements after the default must use the on parameter to specify the groups to which they apply. The on parameter is optional in the default family function.
The standard system families are TTL, CMOS, and ECL1. (See General Information.)
Syntax
  family <family id>
  family <family id> on <group id>
  family <family id> on <group id>,<group id>
  family <family id> on <group id>,<group id>, . . . . <group id>
     <family id> and <group id> are <labels>
Parameters
 
<family id>
The identifier of the logic family type to be referenced. The standard system families are TTL, CMOS, and ECL1. The specifications for any other families needed during the test must be entered into the board file before the program is generated.
<group id>
The identifier of a group of pins which belong to the specified logic family. The group must have been defined in an assign to function. Family statements referencing the same <family id> are cumulative, so more than one family function can be used if there is a large number of pin groups. The following power nodes <group id>’s (see the power function) are assumed for the standard families (see example below):
• for TTL — VCC and GND
• for CMOS — VDD and VSS
• for ECL1 — VCC1, VCC2 and VEE
1. Mux systems only.
Examples
family TTL        ! Only one logic family in this test
family My_family  ! Be sure to enter the family specifications in the board file
 
! This example shows a device with TTL input pins and CMOS output pins. In this device
! VSS (for CMOS), and GND (for TTL) are all connected internally to pin 16).
! (Not all device pins are shown.)
  assign  In      to pins   5,7
  assign  Enable  to pins   6
  assign  Out     to pins   1,2,3,4
  assign  VCC     to pins   9      !
  assign  GND     to pins   16     ! These statements assign the power nodes
  assign  VDD     to pins   8      !
  assign  VSS    to pins   16      !
     . . .
  power VCC, GND, VSS, VDD
     . . .
  family TTL               ! Default family covers all groups unless overridden
  family CMOS  on  Out, Enable, VSS, VDD   ! Overrides TTL on these groups
General Information
The following logic families are available in the standard system. These families are always in the board defaults file, although you can change or delete them for any one board test.
• TTL
• dh=3.5
• dl=0.2
• rh=2.0
• rl=0.8
• slew rate=275
• load=pull up
• def=X
• CMOS
• dh=4.0
• dl=0.8
• rh=3.6
• rl=1.3
• edge speed=275
• load=no load
• def=X
• ECL (Mux systems only)
• dh=‑0.5
• dl=‑2.7
• rh=‑1.2
• rl=‑1.5
• slew rate=150
• load=pull down
• def=0

You can specify other families for a specific board test. Each family specification must contain all of the parameters shown above.
