bsdl (BT-Basic)
Title: INVOKE BSDL MODE
The bsdl function clears the workspace and set the workstation to bsdl (Boundary Scan Description Language) mode. You must select this mode if you want to edit or write a BSDL source file. These files should be stored in your board's digital directory.
Statements entered in bsdl mode are not syntax-checked, so you must ensure that the statements that you use are valid. For more information about BSDL syntax, refer to IEEE BSDL in Boundary-Scan Testing.
Syntax
  bsdl
Parameters
(none)
Examples
  msi "/user/scan_brd/digital"     ! selects board under test
  bsdl                             ! sets "bsdl" mode
     ...
     ...                           ! user creates bsdl source file
     ...
  save "file"
  compile "file"                   ! compiles bsdl source file
General Information
This function is not programmable.
