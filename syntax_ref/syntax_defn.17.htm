Line
A line consists of zero or more characters followed by a return. The line can be up to 2048 characters long; this includes all spaces. A line ends when the return (or enter) key is pressed.
A line can be executed on the command line, or it can be stored and executed in a program. A program can have any number of lines, limited only by the system's ability to store and process them.
A line can have one or more statements or nothing - a blank line. Two statements on the same line are separated by a vertical bar (|). When you type the line you can use either the bar or the reverse slash (\) to separate statements; the slash is easier to type because it does not require the Shift. When the line is stored, all the slashes are automatically converted to vertical bars.
As well as containing statements, lines can also have labels and comments. If a line has a label (see Line Label), there can be only one, and it must be the first element on that line; the rest of the line can be blank, or it can contain other statements (including a comment).
A line can also consist of just a comment, or of statements followed by a comment. If a line contains a comment, that comment must be the last element on the line.
Example 9 contains examples of random lines; from labels Start through Finish there are seven lines:
Example 9  
  Start:
  A$ = "string constant"
  ! a line can have just a comment or, like the next line, nothing
  A=6 | Bee = Bee+1 \ print A*Bee | goto Start
  stop
  Finish: print A,B | input "Name?", Name$ ! get next name
 
Line Label
A line can be identified by means of a line label; a goto statement can then reference that line by its label.
A line label consists of a label followed by a colon (:). The label must be the first element on the line. The line label can be the only element on the line or it can be followed by other elements such as statements or a comment, as in the examples above. Any statements which reference a line label specify the label but not the colon, because the colon is a delimiter, and is not an actual part of the label. One of the example labels above is
  Start:
but the goto statement that references that label is
  goto Start
Note that a line label and an image identifier (<image id>) are the same.
Line Number
Program lines are automatically assigned numbers by the system. These numbers are volatile in that, as program lines are inserted or deleted, the system changes the numbers automatically to accommodate the line changes. The number is not an actual part of the line, so is not counted in the line length.
Line numbers can be referenced only from the keyboard, for editing purposes. They are not programmable and cannot be referenced from the program, but they do appear in program listings generated by the list command. Use line labels, described above, to reference lines from program statements.
