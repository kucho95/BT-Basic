topology device pin data$ (BT-Basic)
Title: GET AN ITEM OF INFORMATION ABOUT A DEVICE PIN FROM THE BOARD FILE
The topology device pin data$ function returns an item of information about the specified device pin. The information is returned as a string expression.
You can find:
• the use of the pin
• if the pin is critical or not
• the name of the node that the pin is attached to, and
• the name of the family of the pin.
Syntax
  topology device pin data$ (<device name>, <pin name>, <item>)
     <device name> is a <string expression>
     <pin name> is a <string expression>
     <item> is a <numeric expression>
Parameters
<device name>
The reference designator of the device such as U100.
<pin name>
The number of the device pin.
<item>
A number (1 through 4) that represents the item of information to be returned. The items are:
• 1 – The pin use. It can be undefined, unconnected, input, output, bidirectional, power, nondigital
• 2 – If the pin is critical or not. It can be undefined, yes, no
• 3 – The name of the node which the pin is attached to.
• 4 – The family of the pin.
Example
  ! Tells you if pin 10 of U100 is critical, not critical, or undefined.
  Tested$ = topology device pin data$ ("U100", "10", 2)
General Information
To use any of the topology access functions you must first load the board file into memory.
To load a board object file, board.o, into memory execute the load board statement.
To remove a board file from memory use the scratch board statement.
The load board statement automatically scratches any file that is presently in memory.
