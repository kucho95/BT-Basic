capture (VCL)
Title: DESIGNATE VECTORS TO BE CAPTURED
The capture function is used in the Vector Execution section of a test to start a capture block: that is, a set of vectors that are to be captured. The block ends with the end capture function. The block must be located in a unit.
Capture blocks cannot be used in nondeterministic constructs such as homingloops. However, the blocks can be used in repeat loops because they are executed a known number of times.
The capture block can contain vector execution statements or PCF vectors.
The capture keyword is also used with the vector execution statements to capture data for individual vectors—see the count, execute and preset counter VCL statements.
Syntax
  capture
Parameters
(none)
Examples
   unit "Capture"
     execute V8
     capture
        execute V3
        pcf
           "1100011"
           "0101100"
        end pcf
     execute V5
   end capture
General Information
The captured pins must be set to X in all vectors that receive those pins when data is being captured. This prevents the pins from failing the test.
