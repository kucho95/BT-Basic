safeguard (edit)
Title: INVOKE SAFEGUARD MODE
The safeguard statement clears everything currently in the workspace and sets the workstation into safeguard mode. This mode must be selected to edit or create the SAFEGUARD files in the digital libraries. The information in these files is used by the safety routines to determine how to protect devices from possible damage which might otherwise result from overdriving during digital testing.
The statements entered are syntax checked to ensure that they are valid safeguard statements. However, editing and other mode selection statements can be executed as usual.
Syntax
  safeguard
  safeguard;<option>
     <option> can be:
        window
        nowindow
Parameters
<option>
Either window or nowindow.
• window opens a new window in safeguard mode
• nowindow suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Example
  safeguard                 ! Sets "safeguard" mode
  load "/library/ttl/safeguard/74xyz"
     . . .
  thermal resistance 55     ! Make a change to the contents of the file
     . . .
  re‑store                  ! Re-saves in original file
  basic                     ! Establishes "basic" mode
  safeguard;window          ! Opens a new window and sets it to "safeguard" mode.
General Information
The safeguard statement is not programmable.
