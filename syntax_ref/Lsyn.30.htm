log clear for retest (BT-Basic)
Title: CLEAR CORRUPT LOG DATA STORED IN BUFFER
The log clear for retest function selectively clears the buffer of log data known to be corrupt because of a true pinsfailed function. For example, suppose a test fails because of poor pin contact, which sets pinsfailed true. The test operator can recycle the vacuum until pinsfailed goes false, and a log clear for retest can discard the corrupt data acquired when pinsfailed was true.
Syntax
  log clear for retest
Parameters
(none)
Example
  :
  TestThisBoard:
  :
  log board start BoardID$, IsGoodBoard$
  :
  Cleanup:
  :
  if boardfailed then
     print "FAILED"
     test "pins"
     if dutfailed then
        log clear for retest
        call CycleVacuum
        log board end BadPinContact
        clear failures
        goto TestThisBoard     ! Again
    end if
  else
     print "PASSED"
     log board end Passed
  end if
  :
  log out LogFile$
  log clear
  :
General Information
Each log clear for retest generates an @RETEST log record to show that a log clear for retest occurred. (Also see the log clear function.)
When using multiple board states (board number is function) to test a multi‑board panel, an @RETEST log record produced by the log clear for retest function is sent to the log buffer for the current board.
