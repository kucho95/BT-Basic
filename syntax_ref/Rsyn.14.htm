recycle to vector (DEBUG)
Title: REPEAT TEST UNTIL SPECIFIED VECTOR
The recycle to vector statement repeatedly executes the test currently being debugged, until the Break key is pressed. The test is executed each time to the point where the specified vector has been executed. After each execution, the results are sent to the report is device.
When test execution stops, the current states of the drivers are maintained.
Syntax
  recycle to vector <vector>
     <vector> is a <numeric expression>
Parameters
<vector>
An integer value representing the number of the vector where the test stops.
Example
  recycle to vector 9
General Information
safeguard none must be specified before this statement can be used.
