local (BT-Basic)
Title: SET GPIB LOCAL MODE
The local function issues the GPIB interface message local to devices on the GPIB bus. The local message sets the devices to their local states so they can be manually operated.
If a device is addressed, the function sends GTL (go to local) to the selected device. If the bus is addressed, the function clears the GPIB interface line REN (Remote ENable) to 1.
Syntax
  local <GPIB>
  local <GPIB device>
     <GPIB> and <GPIB device> can be:   <file id>
                                        @<name>
        <file id> is a <string expression>
        <name> is a <label>
Parameters
<GPIB>
The address of the bus. Clears REN to 1, deactivating all remote operation.
<GPIB device>
The address of the selected GPIB device. Sends GTL (Go To Local) to that device.
Examples
Shortcut Method:
  local "/dev/hpib1"                ! Clear REN on bus 7 to 1
  local "/dev/counter"              ! Send GTL to the counter
  assign @Auto_DVM to "/dev/dmm"
  local @Auto_DVM                   ! Send GTL to the dmm
 
Absolute Path Method:
  Bus$ = btgetenv$("I3070_ICT_ROOT")
  local Bus$&"/dev/hpib1"           ! Clear REN on bus 7 to 1
  local Bus$&"/dev/counter"         ! Send GTL to the counter
  assign @Auto_DVM to Bus$&"/dev/dmm"
  local @Auto_DVM                   ! Send GTL to the dmm
General Information
 
 
These examples assume the dev file hpib1 contains the SICL interface name hpib7.
