module/end module (CONFIGURATION)
Title: TESTHEAD MODULE CONFIGURATION
The module and end module statements delimit a module configuration block in the testhead and board configuration files. In the testhead configuration file, these statements must appear inside bank and end bank statements. The testhead can have up to four modules (numbered 0 through 3), depending on your system. For every module function used, there must be a matching end module function.
Syntax
  module <module number>
     <module number> can be: 0
                             1
                             2
                             3
  end module
Parameters
<module number>
The module being configured.
Example
  module 1
     cards 1 asru n revision
     cards 2 to 5 high accuracy double density
     cards 6 control xtpb
     cards 7, 9 to 11 high accuracy double density
  end module
