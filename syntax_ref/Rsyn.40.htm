rli$ (BT-Basic)
Title: DETERMINE THE CURRENT REPORT LEVEL SETTING
(Mux systems only)
The rli$ function returns a string that is equal to the report level set by the most recent report level is statement.
Note that executing this function does not change the report level setting, but only returns a string that is equal to the current report level setting.
Syntax
  rli$
Parameters
(none)
Example
  rli$     ! Returns a string containing: "none"
           !                              "report"
           !                              "log"
           !                              "all"
General Information
(none)
