node (ITL)
Title: IDENTIFIES NODE TO BE TESTED OR DISABLED
The node statement is used within a nodes or disables block to identify the node to be tested or disabled. The node statement can be followed by a card list that tells the system which type of resource to use to perform the test or disable task.
Syntax
For nodes block
node <node name> test <device.pin>, <device.pin>,...<device.pin>
node <node name> <card list> test <device.pin>, <device.pin>,...<device.pin>
silicon node <node name> test <device.pin>, <device.pin>,...<device.pin>
  <node name> is a <string expression>
  <device.pin> is a <string expression>
    <card list> can be: hybrid
                        channel          ! On Mux systems only
                        hybrid; channel  ! ";" indicates first choice preferred
                        channel, hybrid  ! "," indicates no preference
 
For "disables" block
node <node name> <card list>
node <node name> <card list> default <state>
  <node name> is a <string expression>
  <state> can be: 0, 1, k, t
Parameters
<node name>
Provides the name of the node that will be tested.
<device.pin>
Identifies the device connections to the node to be tested.
<card list>
Identifies the type of resource to use during the test or disable task.
<state>
Identifies the state value for the default.
