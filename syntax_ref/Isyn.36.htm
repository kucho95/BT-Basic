int (BT-Basic)
Title: INTEGER FUNCTION
The int function returns the next lower (more negative), integer value from the function's argument. (This is sometimes referred to as the floor function.)
Syntax
  int (<numeric expression>)
Parameters
<numeric expression>
The argument of the function.
Examples
  print int(2.718)        ! prints     2
  print int(‑36.28)       ! prints    ‑37
