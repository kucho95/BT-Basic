print level (BT-Basic)
Title: PRINT LEVEL
The print level statement controls the amount of printing returned to the BT-Basic screen.
Syntax
  print level <Test Type> is <Action>
  <Test Type> can be:
     testjet      ! VTEP tests
     polarity
     pld isp
     discharge    ! UnMux systems only
  <Action> can be:
     all
     none
Example
  print level pld isp is all          ! enables printing from JBC player.
  print level pld isp is none         ! disables printing
General Information
For PLD ISP tests, use of this command can present debugging information to the screen from playing a programming file. This pertains to STAPL or Jam files only. However, SVF files are converted to a STAPL file before it is compiled to a JBC object file. Therefore, you can edit this STAPL file to add print level statements to help describe what the test is doing.
