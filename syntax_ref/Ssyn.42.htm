shift (BT-Basic)
Title: BINARY SHIFT AN INTEGER
The shift statement returns a decimal, integer value which corresponds to the shifted, binary representation of the statement's first argument. The amount and direction of the shift is specified by the statement's second argument. As bits are shifted, left or right, the empty bit positions are zero‑filled.
Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Values in the following ranges can be processed:
• 16-bit operation:
-2^15 <= value <= 2^15 - 1
(2^15 = 32768)
• 32-bit operation:
-2^31 <= value <= 2^31 - 1
(2^31 = 2147483648)
Syntax
  shift ( <value> , <shift> )
     <value> and <shift> are <numeric expressions>
Parameters
<value>
Decimal, integer value whose binary representation is to be shifted.
<shift>
Decimal, integer value represents the number of bit‑places to shift and the direction. A positive value indicates right‑shift, a negative value, left‑shift; zero indicates no shift.
Example
  print shift( 24, 2 )              ! prints   6
  print shift( bti("111"), ‑2 )     ! prints   28
  print shift(‑16589 , 0)           ! prints   ‑16589
  H=‑3 \ print shift (‑13,H)        ! prints   ‑104
  print shift(108, 36)              ! prints   0
