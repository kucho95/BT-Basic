bidirectional (ITL)
Title: BIDIRECTIONAL NODES
The bidirectional statements appear in the nodes block of a silicon nail test to indicate which nodes to the device under test are bidirectional. This entry is made after all of the node and silicon node and fixed node statements and prior to the unit statement.
bidirectionals is also supported.
See also the inputs and outputs statements.
Syntax
  bidirectional <node>
  bidirectional <node>, <node>
  bidirectional <node>, <node>, . . . <node>
     <node> is a <string constant>
Parameters
<node>
The identifier of a node name.
Examples
  nodes
  node "NI1" test "U6.2"
  silicon node "U3_2" test "u3.2", "U6.1"
  ...
  inputs ...
  outputs ...
  bidirectional "Data0", "U6_9"
  pcf order is ...
  unit
