checkerboard (ITL)
Title: TEST PATTERN CONTROL FOR BOUNDARY SCAN CONNECT TEST
The checkerboard statement is optionally used in connect tests. Without it, the default test patterns drive and receive all ones and all zeros. Using it alters the test patterns to a checkerboard pattern in which there is a mix of ones and zeros at one test vector and the inverse at the next test vector. The position of the node statement in the list of nodes determines the starting logic value for that node. The starting values alternate with each successive node statement in the file. Because the listing may randomly intermix inputs, outputs and bidirectional pins, better checkerboard results may be obtained by re-arranging the order. Reference the .x file to see the patterns.
Syntax
  checkerboard
Parameters
(none)
Examples
  ! at the top of the ITL file
        connect "U15"
        checkerboard
General Information
The general motivation to use the checkerboard command and pattern is to reduce ground bounce and associated failures and test instabilities. Some believe that it allows detection of some open pins on CMOS devices not otherwise detectable by the default pattern. For this detection, pins adjacent to the fault must be tested at the opposite state from the faulty pin. That is, to catch an open on pin 2, pins 1 and 3 should be tested at a high while pin 2 is being tested at a low. This command, coupled with manual re-arrangement of the sequence of nodes can achieve this behavior.
