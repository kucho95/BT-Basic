data/end data (ANALOG)
Title: MARK THE BEGINNING OF AN ANALOG DATA BLOCK
The data function marks the beginning of a list of values statements. This is called an analog data block. The data function also specifies the name of the data block.
Each data block must have a unique id. Every data function must have a corresponding end data function. See the Syntax description of the end data and values statements.
An analog data block defines a set of values to be used by the Arbitrary Waveform Generator source, the measure (ANALOG) function, and the report analog (ANALOG) function. The values defined in an analog data block can be from 10 to -10.
Analog data blocks must be placed inside the analog test immediately following the test powered function.
Syntax
  data <data block id>
     <data block id> is a <string constant>
Parameters
<data block id>
A string constant that identifies the data block.
Examples
  data "waveform"
     values 0.0, 0.5, 1.0, 1.5, 2.0, 2.5, 0.0, 0.5, 1.0
     values 1.5, 2.0, 2.5, 0.0, -0.5, -1.0, -1.5, -2.0, -2.5
     values -2.0, -1.5, -1.0, -0.5, 0.0
  end data
