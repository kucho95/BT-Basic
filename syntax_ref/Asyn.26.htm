auxconnect (BT-Basic)
Title: CLOSE THE SPECIFIED EXTERNAL RELAYS
The auxconnect command closes any combination of the external relays on the system card, provided they are not specified as vacuum ports in the testhead config file.
The auxdisconnect command opens the specified external relays. See the syntax description of the auxdisconnect command.
Note that if an auxiliary relay has been declared as a “special” relay, the auxconnect and auxdisconnect commands cannot be used to control it.
Syntax
  auxconnect <relays>
     <relays> can be:   <relay>
                        <relay>, <relay>
                        <relay>, <relay>, <relay>
                        <relay>, <relay>, <relay>, <relay>
                        <relay>, <relay>, <relay>, <relay>, <relay>
                            <relay> can be:  1
                                             2
                                             3
                                             4
                                             5
                                             6
                                             7
                                             8
                                             9
Parameters
<relay>
Specifies the external relay to be closed. Note that relays 6 to 9 are only available on the i-System Card.
Examples
  auxconnect 5     ! Closes external relay 5.
