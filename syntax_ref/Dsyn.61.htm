display swap (DEBUG)
Title: SWAP TWO LINES IN THE DISPLAY
The display swap function exchanges two lines in the display, but does not renumber the lines (see the display renumber function). Swapping lines is useful for grouping signals together for visual comparison, or for grouping lines into sets of four before you change to a hexadecimal display (see the display hex function). This function cannot be used in a hex display.
Syntax
  display swap <first line>,<second line>
     <first line> and <second line> are <numeric expressions>
Parameters
<first/second line>
The numbers of the lines whose positions are to be swapped.
Examples
  display swap 11, 23     ! moves line 11 to where line 23 is, and moves
                          ! line 23 to where line 11 was
