tolerance margin (BT-Basic)
Title: CHANGE TOLERANCE MARGINS
Use the tolerance margin statement to change test limits of analog in-circuit tests. This statement increases or decreases the test limits by the specified percentage of the test limit window. The limits are changed with respect to the arithmetic mean of the original test limit window.
Modified test limits remain in effect until a run statement is executed, the user logs off the system, or until another tolerance margin statement is executed. The new test limits for subsequent tolerance margin statements are calculated using the original test limits.
Syntax
  tolerance margin <value>
     <value> is a <numeric constant>
Parameters
<value>
A numeric constant which specifies how much to scale the tolerances. The valid range of tolerance margins is -100 to 300%. If no value is specified, the default value used is 0 and the test limits do not change.

Formulas:
To calculate new test limits, for a specified tolerance margin, use the following formulas.
     LOW      =     NOMINAL LOW_VALUE
     HIGH     =     NOMINAL HIGH_VALUE
     SCALE    =     (TOLERANCE_MARGIN / 100) + 1
     NEW_LOW  =     MEAN - abs (LOW - MEAN) * SCALE
                                NOTE: abs is absolute value
     NEW_HIGH =     MEAN + abs (HIGH - MEAN) * SCALE

Testplan Example
If you want to change the nominal tolerances for R34 from ±10% to ±15%, the tolerance margin is increased by 50% and the tolerance margin is set to 50 as shown in the following testplan fragment.
  Testplan:
     tolerance margin 50
     test "analog/R34"
  Test Block:
     clear connect s to "R34-1"; a to "R34-1"; i to "R34-2"; b to "R34-2"
     resistor 2k, 10, 10, sa, sb, en, ed
General Information
Note that executing a tolerance margin statement does not actually change the programmed tolerances, but does change the test limits for all subsequent in-circuit tests.
