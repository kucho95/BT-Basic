measure (ANALOG)
Title: ANALOG FUNCTIONAL TEST MEASUREMENT
The measure function initiates the detector, fetches the result, and evaluates the result against the hi and lo limits. Optionally, the measure function can store the result of the measurement in a variable.
For the digitizer detector, the measure function initiates the detector, fetches the multiple results, and compares the results against previously defined data blocks or numeric arrays. Optionally, the measure function can store the multiple results in an array.
For tests that require special triggering or evaluation of the result, the measure function can be replaced with the initiate, fetch, and report analog statements. See the syntax description of these statements for details.
Syntax
  measure <hi>,<lo>
  measure <hi>,<lo>, <result>
  measure <hi limits>, <lo limits>
  measure <hi limits>, <lo limits>, <numeric array id>
     <hi> and <lo> are <numeric expressions>
     <result> is a <numeric variable>
     <hi limits> and <lo limits> can be:   <string expressions>
                                           <numeric array ids>
        <numeric array id> is a <label>
Parameters
 
<hi> & <lo>
Numeric expressions which specify the acceptable upper and lower test limits. The unit is the same as that of the selected detector (voltage, frequency, time, etc.) If the hi and low limits are 0,0, the test will always pass and no datalogging or debug information will be generated.
<result>
A numeric variable which holds the measured result. The unit is the same as that of the selected detector.
<hi limits> & <lo limits>
Can be string expressions that identify previously defined data blocks, or labels that identify numeric arrays. These options can only be used with the digitizer detector.
<array id>
A label that identifies an array. This option can only be used with the digitizer detector.
Example
Example of a test that uses the measure function to for a single result.
     test powered analog
        clear connect s to "node_1"; i to "node_2"; l to "node_3"
        source sine, amplitude 6, frequency 100, icompliance 1, offset 2
        detector dcv, expect 5
        measure 5.0, 4.9
     end test
Example of a test that uses the measure function to for a multiple results.
     test powered analog
        data "waveform"
           values 0.0, 0.5, 1.0, 1.5, 2.0, 2.5
                          .
                          .
                          .
        end data
        data "HiLimits"
           values 0.5, 1.0, 1.5, 2.0, 2.5, 3.0
                          .
                          .
                          .
        end data
        data "LoLimits"
           values -0.5, 0.0, 0.5, 1.0, 1.5, 2.0
                          .
                          .
                          .
        end data
        dim Results(2048)
        connect s to "Node_1"
        connect i to "Node_2"; l to "Node_3"
        source arb, samples 1024, repetition 512, voltages "Waveform", on
        detector digitizer, expect 4.5, rising 0.2, interval 100u, samples 2048
        measure "HiLimits", "LoLimits", Results(*)
     end test
General Information
The measure function has no effect on the source.
The names used in data logging are obtained from the file names.
