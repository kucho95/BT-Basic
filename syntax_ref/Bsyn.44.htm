bvi$ (BT-Basic)
Title: RETURN VALUE OF BOARD VERSION IS STATEMENT
Use the bvi$ function to return the current value of the board version is string. If the board version is statement has not been issued, bvi$ returns a null string. If the base version has been set, bvi$ still returns the null string.
Syntax
   bvi$
Parameters
(none)
Example
   board version is "A"     ! Sets the board version to "A"
   print bvi$               ! Prints "A"
     . . .
   board version is "A"     ! Sets the board version to "A"
   print bvi$               ! Prints null string
