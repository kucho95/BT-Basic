add receiver on (DEBUG)
Title: ADD A RECEIVER
The add receiver on function adds a receiver to the node or device pin specified. An error occurs if the driver/receiver channel connected to the node has no receiver available, or if the node has no fixture wire connected. The expected state of the receiver is set to X, which means the receiver is not expecting a 1 or a 0. The expected state of the receiver can be modified by using the digital debug function set receiver state on. Parameters for the added receiver, such as timing offsets and reference levels, are derived from the debug object file. These parameters can be seen using the s parameter with the display function. To change any of these parameters use the appropriate debug statements.
Syntax
  add receiver on <identifier>
     <identifier> can be:   node <node-id>
                            device <designator> pin <pin-id>
                            pin <pin-id>
        <node-id> is a <string expression>
        <designator> is a <string expression>
        <pin-id> can be:   <string expression>
                           <numeric expression>
Parameters
<identifier>
The node or device pin to which the receiver should be added.
Examples
  add receiver on node "DATA_1"
  add receiver on device "U25" pin "7"
  add receiver on pin "12"    ! Adds receiver to pin 12 of device being debugged
