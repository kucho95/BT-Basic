subexit (BT-Basic)
Title: SUBROUTINE EXIT
The subexit statement causes an exit from a subroutine back to the subroutine calling point:
• to the statement following the statement which called the subroutine — for call and on - call
• to the beginning of the line which was being executed when the subroutine was called — for on break call and on error call
A subroutine can contain any number of subexit statements.
Syntax
  subexit
Parameters
(none)
Example
For examples of the use of the subexit statement refer to the sub and call statements.
General Information
The subexit statement is not used in VCL subroutines.
