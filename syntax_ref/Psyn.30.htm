ppoll (BT-Basic)
Title: PARALLEL POLL
(Mux systems only)
The ppoll function performs a parallel poll on the bus; the bus returns the status bit message, which is a decimal integer value. This function can be used only on the optional, auxiliary bus. The ppoll function sets ATN and EOI, waits 300 microseconds, reads the data and then clears ATN and EOI.
When a parallel poll is made, each of those bus devices which has the capability (simultaneously) outputs its predefined status bit onto one of the eight data lines. The value returned by the ppoll function is the decimal equivalent of the 8‑bit byte formed by the individual status bits on the data lines. After the byte has been read, the status bits are automatically cleared.
Syntax
  ppoll (<GPIB>)
        <GPIB> can be a <file id> or an @<name>
        <file id> is a <string expression>
        <name> is a <label>
Parameters
<GPIB>
The address of the bus, which must be the auxiliary bus.
Example
Shortcut Method:
  A=ppoll ("/dev/hpib1")           ! Returns result of parallel poll
  assign @Auto to "/dev/hpib1"
  Q=ppoll (@Auto) | print Q        ! If Q = 41, then byte was 00101001
 
Absolute Path Method:
  Bus$ = btgetenv$("I3070_ICT_ROOT")
  A=ppoll (Bus$&"/dev/hpib1")      ! Returns result of parallel poll
  assign @Auto to Bus$&"/dev/hpib1"
  Q=ppoll (@Auto) | print Q        ! If Q = 41, then byte was 00101001
General Information
All non-IPC controllers support parallel poll. IPCs with a GPIB card also support this. IPCs with an 82357A USB/GPIB adpter do not support parallel poll.
