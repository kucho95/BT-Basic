Printable Characters
The term printable characters appears in several places, such as in the definition of a string, and when describing characters that can be used in the names entered in the i3070 In-Circuit Test Software. Intuitively, a character can be described as printable if it appears on your workstation screen when the appropriate key is pressed. So T, Q, q, 9, %, ^ and [ are all printable; whereas Tab and Enter are not printable characters since they result in some activity. However, a space does count as a printable character.
More precisely, printable characters includes characters that are represented by eight bits. The system uses the standard ASCII (American Standard Code for Information Interchange) set unless it has been localized to use some other set.
