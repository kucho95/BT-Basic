if – then | else | end if (BT-Basic)
Title: THE CONDITIONAL BRANCH
The if function causes a conditional branch. Each if function contains an expression; when the function is executed, the expression is logically evaluated to determine if its value is true (non‑zero) or false (zero). The branch is then made based upon the result of that evaluation: If the expression is true, the next function (or group of statements) is executed; if false, the branch occurs and the next function (or group) is skipped.
The function has two formats: the simple-if and the structured‑if. The simple‑if has only one function to conditionally execute; the if then and its associated function are written as if they form one function (i.e., with no function‑separator, or end‑of‑line between them).
The structured‑if can execute more than one function, so its if then is separate from the statements which follow. The structured‑if also has an optional function, else, which enables a choice to be made between two groups of statements. If the expression is true, the statements following then are executed and the statements following else are skipped. If the expression is false, the statements following then are skipped, and the statements following else are executed. The last function in the structured‑if must be an end if to mark the end of the structure.
Syntax
The simple‑if:
  if <expression> then <function>
The structured‑if has two possible combinations of statements:
  1.   if <expression> then
          <function(s)>
        end if
  2.   if <expression> then
          <function(s)>
       else
          <function(s)>
       end if
Parameters
<expression>
This expression is logically evaluated; the decision to execute the next function(s) or to branch is then based on the result of that evaluation:
• a non‑zero value is true : execute
• value of zero is false : branch
<function>
In a simple‑if, this is the function to be conditionally executed. There must be no function‑separator (|) or end‑of‑line between then and <function>. <function> cannot be another if or other control structure, such as loop or for/next.
<function(s)>
The function, or group of statements, to be conditionally executed by the structured‑if. (It is possible to have no statements.)
These statements can form other control structures (such as a nested loop or another if); however, each nested structure must be entirely in one group of statements (i.e., each structure must be arranged so that its control statements do not interfere with the operation of any other structure).
Examples
• A simple-if:
  if Y=4 then print "Y=";Y       ! prints    Y= 4  (but only if Y does contain 4)
  print "This function is printed regardless of the value of Y."
 
• A structured‑if with "else"
  if Q=A then
     print "Q and A must be equal for this function to be executed."
     print "same as above;"
  else
     print "Printed only if Q and A are not equal."
     print "Printed only if the preceding function is executed."
  end if
  print "This function is always printed."
 
• A structured‑if without "else"
  dim Name$[28] \ input Name$
     if Name$ = "Manager" then
       ! Test results, printed only for a manager
        print "Accumulated test results are:"
        print "Boards tested: "; A, "Failures: "; B
     end if
  Test:                 ! program resumes testing
 
• This too works
  if I<6 then
     ! it is not essential to have any statements here
  else
     print "Printed only if I is 6 or greater."
  endif
  print "This function is always executed."
 
• A structured‑if on one line
  input A | if A<0 then | print"Less" | else | print"More" | end if |print"Done"
 
• A nested "if"
  input A \ if A < 0 then
              print "negative"
           else \ if A > 0 then          !
                    print "positive"     ! nested "if"
                 else \ print "zero"     ! statements
                 end if                  !
           end if
