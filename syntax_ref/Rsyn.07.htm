receive (VCL)
Title: SET BIDIRECTIONAL PIN TO RECEIVE
The receive statement is used in a vector block to specify that one or more groups of bidirectional pins are receivers (outputs from the device being tested) for that vector. Each vector that references a group of bidirectional pins should have an appropriate receive (or drive) statement for that group; if the statement is omitted, the bidirectional pins default to receivers for that vector.
The receive statement is the same as the drive statement, except that drive specifies that the identified groups are drivers (i.e., inputs to the device under test). Refer to the drive statement for a description of how both statements are used and for examples.
Syntax
  receive <group id>
  receive <group id>,<group id>
  receive <group id>,<group id>, . . . . <group id>
     <group id> is a <label>
Parameters
<group id>
The identifier of a group of bidirectional pins that are to be receivers for that vector. The group must be declared as bidirectional in the Declaration section of the test.
Example
  receive Data1, Data2
See the drive statement for other examples.
General Information
If a bidirectional pin is not referenced at all in a vector, that pin goes to receive and to its default state when the vector is executed.
