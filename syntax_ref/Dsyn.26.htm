diode (ANALOG)
Title: DIODE TEST
The diode function is used within an analog in-circuit test block to measure the forward bias voltage of a diode.
Syntax
  diode <specs>
  diode <designator>,<specs>
     <designator> is a <string constant>
     <specs> can be:   <hi>,<lo>
                       <hi>,<lo>,<return>
                       <hi>,<lo>,<options>
                       <hi>,<lo>,<options>,<return>
        <hi> & <lo> can be <numeric expressions> or *
        <return> is a <numeric variable>
           <options> can be one or more options separated by commas (Table D-3)
Parameters
<designator>
A string constant of up to 16 characters which identifies the a subtest. If the component fails, the system includes the <designator> in the failure message sent to the report is device.
<hi> & <lo>
Numeric expressions which specify the upper and lower test boundaries, respectively, in volts. Note that numeric expressions used in analog statements do not allow user-definable functions.
An asterisk (*) can be used in place of zero. If zero, or *, is specified for both tolerance values, the results of the test are not compared to any limits; the test does not fail.
<options>
The diode test uses the option values given in Table D-3, unless otherwise specified.
The voltage compliance option has a range of 0 to 10 volts.
<return>
A numeric variable which holds the measured value.

Examples
  clear connect s to "D23A"; i to "D23C"
  diode 800m, 400m, idc25m, co1.5
General Information
The diode and zener tests, contrary to all other analog in-circuit tests, do not require the en option when using the sa option.
The diode and zener statements are the only two statements that do not allow the dwa option.
