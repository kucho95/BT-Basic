topology get internal devices (BT-Basic)
Title: GET THE NAMES OF THE INTERNAL DEVICES FROM THE BOARD FILE
The topology get internal devices statement fills a string array with the names of internal devices in the board file.
Syntax
  topology get internal devices <device id>, <array id>
  topology get internal devices <device id>, <array id>, <error variable>
     <device id> is a <string expression>
     <array id> is a <string array>
Parameters
<device id>
The reference designator of the device such as U100.
<array id>
The name of the array.
Example
  dim Devices$(1:100)[48]      ! Dimension an array.
  topology get internal devices "U100", Devices$(*)
                   ! Place the names of all internal devices for U100 into the array.
General Information
To use any of the topology access functions you must first load the board file into memory.
To load a board object file, board.o, into memory execute the load board statement.
To remove a board file from memory use the scratch board statement.
The load board statement automatically scratches any file that is presently in memory.
