report (BT-Basic)
Title: REPORT DATA
The report statement outputs data, in free‑field format, to the report printer, which is established by the report is statement.
The report statement allows the test developer to designate a device or file as the report printer and send selected test failure data to that printer. All other program output data and messages, not directly related to test failure data, can then be sent to the normal default printer.
Operation of the report statement is similar to operation of the print statement, except that:
• report writes to the report printer and print writes to the default printer.
• report is closes the report printer so that subsequent report statements are ignored, while printer is closes the current default printer but specifies that the user’s workstation is the new default; i.e., subsequent print statements are not ignored.
What data appears at the report printer is also determined by the report level is statement.
Syntax
  report
  report <print list>
     <print list> can be:
        <item>
        <item><delimiter><item>
        <item><delimiter><item><delimiter> . . . <item>
           <item> can be:
              <numeric expression>
              <string expression>
              <tab statement>
                 [If <expression> is an array, use <array id>(*)]
           <delimiter> can be:
              ,   (comma)
              ;   (semicolon)
Parameters
 
<print list>
The list of data items to be output in free‑field format. A data item is output in a standard field if its delimiter is a comma, and it is output in a packed field if its delimiter is a semicolon. If the list contains no items, just the EOL—i.e., a blank line—is output.
To output a complete array of data, use <array id>(*).
If the <item> is a tab statement, the print position moves to the column indicated, and the next field then starts in that column. If the column indicated is to the left of the current print position, an EOL is output and the next field starts at the indicated column on the next line.
There is no difference between a comma and a semicolon used as the delimiter after a tab statement. Neither affects the format in this case.
Example
  report is "/dev/rpr02"          ! Selects report printer on workstation #2
  report "Failed‑‑Resistor R62 Measured"; Res(A); "ohms"
General Information
For imaged formatting of the data, refer to the report using statement.
When using multiple board states (board number is statement) and buffered reporting (buffered reporting on/off statement) to test a multi‑board panel, the report statement sends data to the report buffer for the current board.
