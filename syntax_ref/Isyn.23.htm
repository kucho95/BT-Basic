in module <x> (DIGITAL)
Title: ASSIGN ALL RESOURCES TO A SINGLE MODULE
The in module <X> function is used in the wirelist file to ensure that all resources that need to be in the same module are assigned to the same module. This is necessary for programming PLDs.
Syntax
  test digital <testname>
     wire <node> to * <resource>   in module <X>
     wire <node> to * <resource>   in module <X>
  end test
Parameters
 
<node>
A string constant.
<resource>
Can be any of the following:
s                     i
g                     l
l on xl               a
b                     gl
aux                   detector high
detector low          source
drive                 drive on receive bus
dynamic               none
receive               receive on drive bus
receive <class>       receive <class> on drive bus
serial1               serial2
serial3               serial4
serial5               serial6
serial7               serial8
serial9               serial10
serial11              serial12
clock                 clock receive
clock receive frequency      fast clock
trigger                      ext <ext#>
acc <acc#> <connection>      general
ground                       ccguard
ccground                     ccrefnode
ccrefret
<X>
Any letter from ‘A’ to ‘Z’, indicating which connections to group together – those connections with the same letter <X> will be gr ouped into the same module.
Examples
test digital "jbc1"
  timing module 3
  clock internal
  wire "CLK" to 21522 drive in module A
  wire "CLK_DISABLE" to 21521 drive
  wire "IN"  to 21503 drive in module A
  wire "MOD" to 21502 drive in module A
  wire "OUT" to 21501 receive in module A
end test
General Information
Even though there is a maximum of four modules the Test System can use, the letters A through Z can be used to group 26 sets of resources so that all wires in each set are kept in the same module. This allows you to specify several sets of wires to keep together, and allows the Test System software to perform the most appropriate resource allocation possible within those limitations.
