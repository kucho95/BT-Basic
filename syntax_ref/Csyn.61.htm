cover extend supplies mapped to (BT-Basic)
Title: MAP THE SPECIFIED SUPPLIES FOR (COVER-EXTEND TESTS)
For Cover-Extend tests, this command is required to allow the fxoff and unpowered statements to disconnect the specified power supplies. Without this command, the CET supplies that use auxiliary connect are still physically connected to system ground; when the CET test is done and an unpowered or faoff is issued, an error will occur (system short to GND).
Syntax
cover extend supplies mapped to <supply>
cover extend supplies mapped to *
   <supply> can be: <item>
                    <item>, <item>
                    <item>, <item>, . . ., <item>
   <item> can be: auxiliary <relay>
      <relay> can be: 1
                      2
                      3
                      4
                      5
Parameters
<supply>
The power supply used (can be auxiliary relay).
Examples
  cover extend supplies mapped to auxiliary 5
  cover extend supplies mapped to *
