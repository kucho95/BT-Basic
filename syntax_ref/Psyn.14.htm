pcf (VCL)
Title: START PCF BLOCK
The pcf (Pattern Capture Format) function is used in the Vector Execution section of the VCL test to start a PCF block; the end of the block is marked by the end pcf function. The block contains a series of PCF strings, representing a series of vectors and their execution statements.
There can be any number of PCF blocks in a VCL test; each PCF block must be in a digital unit (see the unit function). PCF blocks cannot be nested: that is, one block cannot be located within another. In addition to the PCF strings, only the following VCL statements are allowed inside a PCF block:
• include
• use pcf order
• timing set (Mux systems only)
• warning
• ! (comment)
These statements can be located anywhere in the block, except that only the comment can be inserted between two strings which define the same vector.
If CRCs are to be generated from PCF vectors, then the vectors to be compressed must be located inside a compression block (see the VCL compress function). The complete PCF block containing those vectors must be enclosed in the compression block.
PCF cannot be used on formatted pins. On Mux systems, if timing sets are used in the test, use timing set statements appear in the blocks to associate the vectors which follow with specific timing sets.
If the pcf block does not have a use pcf order function, then the default order is assumed.
PCF can be used in both library and executable tests.
Syntax
  pcf
Parameters
(none)
Example
  ! in the Declaration section
        . . .
           ! pins 4 through 11 are assigned to "Address"
     assign Address to nodes "U2-4","U2-5","U2-6","U2-7","U2-8"
     assign Address to nodes "U2-9","U2-10","U2-11"
     !
     assign CS to nodes "U2-22", "U2-24"
     assign RDY to nodes "U2-3"
           ! pins 15 through 21 are assigned to "Data"
     assign Data to nodes "U2-15","U2-16","U2-17","U2-18","U2-19"
     assign Data to nodes "U2-20","U2-21"
     !
        . . .
     inputs RDY, Address
     outputs CS
     bidirectional Data
        . . .
        !  define the default pcf order
     pcf order is RDY, Address, Data     ! the pcf pins are now in ascending order
     pcf order is CS
        . . .
  ! in the Vector Execution section
        . . .
     pcf
           "1111011110011001LL"          ! Data is driven
           "101Z00110HHLLHHLHH"          ! Data is received
     end pcf
        . . .
General Information
PCF vectors are normally downloaded to the test system from a CAD system or a simulator and stored in text files. The vectors must then be incorporated into the VCL test and syntax checked in digital mode. If you need to do so, you can edit the vectors, either in the text or the digital files. You can also generate PCF vectors by hand.
The include function is useful for incorporating large PCF blocks into the VCL test.
