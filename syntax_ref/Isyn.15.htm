<string spec>
   <string constant>
The <string spec> consists of text enclosed in quotation marks. To use a <repeat factor> with this spec, the spec must be enclosed in parentheses; i.e., a replication spec with just one item in its <spec list> must be used.
INPUT using <string spec>
When a <string spec> is used to input data, the <input spec> skips, i.e., reads and discards, one input character for each character in the string (spec). Note that this is similar to the <space spec> (x).
Example of data input with <string spec>
      ! assume tape contains abcdefghi
      BS1 : image 3a, "QQQ", 3a
      enter "/dev/tape" using BS1; T$, K$
      print T$, K$
      !
      ! prints    abc   ghi
OUTPUT using <string spec>
When a <string spec> is used to output data, the text is output when the <spec> is executed.
Example of data output with <string spec>
      F6: image 14x, 25("*")
      F5: image 14x, "*", 23x, "*"
      F10: image 14x, "*", 6x, 11a, 6x, "*"
      print using F6
      print using F5
      print using F10; "TEST REPORT"
      print using F5
      print using F6
      !
      !             ‑‑‑14 spaces‑>‑‑‑‑‑‑‑‑‑‑25‑‑‑‑‑‑‑‑‑‑‑‑>
      ! prints:
      !                           *************************
      !                           *                       *
      !                           *      TEST REPORT      *
      !                           *                       *
      !                           *************************
      !
      ! Note that "TEST REPORT" could be used in place of
      ! "11a" in F10, instead of in the "print" function.
