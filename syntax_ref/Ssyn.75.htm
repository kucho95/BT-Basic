subtest/end subtest (ANALOG)
Title: MARK THE BEGINNING OF AN ANALOG SUBTEST
The subtest statement marks the beginning of an analog subtest and specifies the name of the subtest.
Subtests are used in tests that require multiple measurements that, when taken together, determine a final test value. Subtests are also used when a connection must be maintained across two or more measurements.
Each subtest must have a unique subtest id. Every subtest statement must have a corresponding end subtest statement. See the syntax description of the end subtest statement.
Syntax
  subtest <subtest id>
     <subtest> is a <string constant>
Parameters
(none)
Example
  test powered analog
     clear connect s to "node_1"
     source sine, amplitude 6, frequency 100, icompliance 1, offset 2
     initiate source
     test "part1"
     test "part2"
  end test
     subtest "part1"
        global First_Result
        connect i to "node_2"; l to "node_3"
        detector dcv, expect 2
        initiate detector
        fetch First_Result
        report analog 2.1, 1.9, First_Result
     end subtest
     subtest "part2"
        global First_Result
        connect i to "node_4"; l to "GND"
        detector dcv, expect 8
        initiate detector
        fetch Second_Result
        report analog 5.1, 4.9, (First_Result + Second_Result) / 2
     end subtest
General Information
Subtests can use local and global variables.
Test level connections cannot be redefined in any of the subtests. Any connections made in a subtest are automatically disconnected at the end of the subtest.
