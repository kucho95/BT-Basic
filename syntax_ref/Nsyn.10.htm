nodes (SHORTS)
Title: SHORTS TEST NODES
The nodes function specifies the nodes to be checked during shorts testing. The i3070 In-Circuit Test Software generates the shorts file that contains nodes statements. Nodes are checked in the order in which they are listed in the shorts file.
The nodes can be specified by node name or brc format. If node names are given, the wirelist must be available during compilation so that each name can be mapped onto its corresponding brc location. If a node uses more than one brc location, only one location will be checked.
Syntax
  nodes <node>
  nodes <node>,<node>
  nodes <node>,<node>, . . . . <node>
     <node> can be:   <node id>
                      <relay id>
        <node id> is a <string constant>
        <relay id> is a <numeric constant>
Parameters
<node id>
A string constant which identifies the name of the node to be checked. The name is the one entered for that node in the i3070 In-Circuit Test Software.
<relay id>
A numeric constant describing the bank/row/column address of the interface pin of the specified node. It has the form brc to identify the pin by its physical position in the testhead. It consist of five numeric characters:
• the first designates the bank. There are two banks: bank 1 covers modules 0 and 1, bank 2 covers modules 2 and 3.
• the second and third designate the horizontal row from the top (back) of the module. The valid range of rows is 01 through 11 (leading zero required).
• the fourth and fifth designate the vertical column from the left side of the bank. The valid range is 01 through 78 (leading zero required).
