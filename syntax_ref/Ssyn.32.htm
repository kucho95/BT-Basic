set slew rate (DEBUG)
Title: TEMPORARILY CHANGE THE SLEW RATE OF A DRIVER
The set slew rate statement changes the slew rate on one or more drivers. The change is temporary.
Syntax
  set slew rate on <identifiers> to <speed>
  set slew rate on <identifiers> to fastedge
  set slew rate on <identifiers> to slowedge
     <speed> is a <numeric expression>
     <identifiers> can be:   device <designator>
                             device <designator> pins <pin‑id list>
                             groups <group-id list>
                             nodes <node-id list>
                             pins <pin-id list>
        <designator> is a <string expression>
        <pin-id list> can be:   <pin id>
                                <pin id>,<pin id>
                                <pin id>,<pin id>, . . . <pin id>
           <pin id> is a <string expression>
        <group-id list> can be:   <group id>
                                  <group id>,<group id>
                                  <group id>,<group id>, . . . <group id>
           <group id> can be:   <label>
                                <string expression>
        <node-id list> can be:   <node id>
                                 <node id>,<node id>
                                 <node id>,<node id>, . . . <node id>
           <node id> is a <string expression>
Parameters
 
<speed>
The slew rate for the selected pins. The units are volts/microsecond, with increments of 25.
25 <= speed <= 250
fastedge = 100
slowedge = 50
<identifiers>
The list of drivers whose slew rates are to be changed. Only input pins and bidirectional pins can be specified.
<designator>
String constant representing a device. The device must be referenced in the test being debugged.
<id list>
The list of pins or nodes to be changed.
Example
  set slew rate on device "U68" pins "13", "11" to 125
  set slew rate on groups Read_1, "Read_3" to 80          ! rounds to 75 v/us
  set slew rate on nodes "in_1", "in_2", "in_3", "in_4" to 75
  set slew rate on pins "2" to fastedge
