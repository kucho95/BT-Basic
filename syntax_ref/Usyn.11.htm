use parameters (SAFEGUARD)
Title: ASSIGN A PARAMETER BLOCK TO A DEVICE
The use parameters function appears in a SAFEGUARD file to specify which parameter block the safety analysis routines are to use for a specific device. Every library directory which contains digital in‑circuit tests must have a SAFEGUARD file; that file must have a use parameters function for each in‑circuit test and mixed test in that directory. The SAFEGUARD file does not normally reference functional tests; however, it should reference the in‑circuit library tests for the devices included in those functional tests.
The SAFEGUARD file for a board test is generated by the compiler. It reads the library SAFEGUARD files and copies from them the appropriate parameter blocks and use parameters statements for the digital devices on the board.
The use parameters statements can be located anywhere in the file; except that they cannot be located in a parameter block, and each one must be located after the parameter block which it references. The use parameters statements can be arranged in any order.
Syntax
  use parameters <block name> for <part name>
     <block name> and <part name> are <string constants>
Parameters
<block name>
The name of the parameter block specified in that block’s parameters function. Any leading or trailing spaces in the name string will be ignored.
<part name>
In a library SAFEGUARD file: the name of the file containing the referenced in-circuit library test, or the name of a directory containing a mixed test.
In a board test SAFEGUARD file: the name of the device entered into the board.o file.
Example
  parameters "TTL_custom_devices"
        . . .
  end parameters
  use parameters "TTL_custom_devices" for "my_74wb99"
     ! "my_74wb99" could be either the file name of an in‑circuit library test, or
     ! the directory name of a mixed, library test.
