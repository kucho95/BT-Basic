board object is (TEXT)
Title: FAULT DICTIONARY CONFIGURATION FILE
(Mux systems only)
The board object is function is used in the fault configuration file, fault.config. This function specifies the path for the board object file, board.o.
If a board object file is available, the fault dictionary translator cross-checks the reference designators, pins, and output node names in the translated fault object with those in the board object file. This check is important because the test system cannot test devices that are not listed in the board object file.
We recommend that you always supply a board object. If you do not supply a board object, naming problems are not caught until after translation (i.e., test compilation or execution).
The board object file is usually named board.o and located at the board directory. The default value for this function is ../../../board.o. Paths that do not start with a / are relative to the directory containing the configuration file.
Syntax
   board object is <file id>
      <file id> is a <string expression>
Parameters
<file id>
The identifier of the file containing the board object file.
Examples
   ! board object is     - defaults to "../../../board.o"
   board object is "/all_board_objects/cpu_board.o"
