board graphics highlight device (BT-Basic)
Title: CAUSES THE BOARD GRAPHICS VIEWER TO HIGHLIGHT A SPECIFIED DEVICE
The board graphics highlight device function causes the board graphics viewer to change the color of a specified device to show its status: active, fail, or pass.
This function lets you selectively highlight either:
• The device outline and all pins on the device.
• The device outline and specific pins on the device.
Syntax
  board graphics highlight device <device id>
  board graphics highlight device <device id>, <error variable>
  board graphics highlight device <device id> pins <pin list>
  board graphics highlight device <device id>, pins <pin list>, <error variable>
  board graphics highlight <status> device <device id>
  board graphics highlight <status> device <device id>, <error variable>
  board graphics highlight <status> device <device id> pins <pin list>
  board graphics highlight <status> device <device id>, pins <pin list>, <error variable>
     <status> can be:   active
                        fail
                        pass
     <device id> and <pin id> are <string expressions>
     <error variable> is a <numeric variable>
     <pin list> can be:   <pin id>
                          <pin id>, <pin id>
                          <pin id>, <pin id>, . . . <pin id>
Parameters
<status>
The optional status of the highlighted device, which can be:
• active: Highlight the device in yellow to draw attention to it.
• fail: Highlight the device in red to denote that it has failed.
• pass: Highlight the device in green to denote that it has passed.
If no value is specified for <status>, it defaults to active (yellow).
<device id>
The identifier or designator of the device to be highlighted.
<pin list>
An optional list of one or more pins to be highlighted along with the outline of the specified device. If you do not specify a value for <pin list>, the device outline and all pins are highlighted.
<error variable>
The identifier of an optional error variable.
Examples
  board graphics highlight device "Q3"
         ! Highlight in yellow (default) the outline and all pins of device Q3.
  board graphics highlight pass device "U1"
         ! Highlight in green the outline and all pins of passing device U1.
  board graphics highlight active device "R3", Error
         ! Draw attention to device R3 by highlighting its outline and
         ! all pins in yellow. Includes an error variable.
  board graphics highlight fail device "U2" pins 1, 8
         ! Highlight in red the outline of failing device U2 and its pins 1 & 8.
General Information
Use the active (yellow) highlight to draw attention to a device. For example, suppose your testplan requires that a potentiometer be adjusted. You can use the board graphics viewer to display the potentiometer and highlight it in yellow, which helps production operators find the correct potentiometer when making the adjustment.
