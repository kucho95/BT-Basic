fixture lock (BT-Basic)
Title: LOCK FIXTURE TO TESTHEAD
The fixture lock command locks the fixture to the testhead, turns off the DUT power supplies, takes the testhead out of powered or unpowered mode, turns off all vacuum, and opens the external relays.
If the fixture is installed on the testhead incorrectly, the misplacement of the fixture is detected.
The fixture unlock function unlocks the fixture from the testhead. See the syntax description of the fixture unlock function for more details.
