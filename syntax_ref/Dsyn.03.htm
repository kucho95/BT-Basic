data/end data (VCL)
Title: DATA BLOCKS FOR VARIABLE VECTORS
The data function is used in the Vector Definition section of a test to start a data block. The block contains values and file statements that define a set of values that are to be applied as vector states to a group of pins. The block ends with the end data function.
Each data block must have a unique id. Every data function must have a corresponding end data function.
The values in the data block are treated similarly to the values saved in VCL arrays (see the variable to groups function). Values are the decimal equivalents of 32-bit, two's complement values (or ASCII characters). The values are binary and are not subject to format statements. The bits are used by the vector execution statements to assign states to the pins in the specified pin group. The bits are assigned to the pins from right (lsb) to left (msb) in the same order the pins appear in the assign to function.
During vector execution, the data in the block is read sequentially, with the next value being read each time the block is accessed. The data can be read by the count, execute or preset counter statements. A rewind function sets the access point back to the beginning of the data block.
Syntax
  data <data block id> to groups <group id>
     <data block id> and <group id> are <labels>
Parameters
<data block id>
The name of the data block.
<group id>
The name of the group of pins that are driven or received by the states in the data block by vectors that reference the data block.
<label>
This is the same as a BT-Basic <label>. It can contain up to 32 characters, but with no spaces. The first character must be an uppercase letter and the remaining characters can be letters, numbers, or underscores (_).
Examples
  ! in the Declaration section of the test
         . . .
  assign Write_enable to pins 10,12
  assign Data_bus to pins 1, 2, 3
        . . .
  ! in the Vector Definition section of the test
        . . .
  data FlashRAM_Data to groups Data_bus
     values 2, 3, 7, 6
     values A(3), A(9), A(21)
     values B(2:51)
     file "Data_File" 120
  end data
        . . .
  ! in the Vector Execution section
        . . .
  execute V1 drive data FlashRAM_Data    ! drives the states defined for V1 and
                                         ! the variable states from the data block
                                         ! to group "Data_Bus"
        . . .
