test analog (ANALOG)
Title: MARK THE BEGINNING OF AN ANALOG IN-CIRCUIT TEST BLOCK
The test analog statement and a corresponding end test statement mark the beginning and end of an explicit analog in-circuit test block. A test block contains the analog statements necessary to perform an analog in‑circuit test with one or more measurements. The i3070 In-Circuit Test Software automatically creates in-circuit test blocks and places them in a directory named analog under the board directory.
Analog in-circuit test blocks are executed from the testplan with the test (BT-Basic) statement. The test statement specifies the test block by path name.
To pass parameters to and from the test block, the variable id must be included with the test analog statement.
The test analog and test end statements are similar to BT-Basic sub and subend statements.
Syntax
  test analog
  test analog; <parameter>
  test analog; <parameter>, <parameter>
  test analog; <parameter>, <parameter>, . . . . <parameter>
     <parameter> can be:   <numeric variable id>
                           <string variable id>
                           <numeric array id>
        <numeric variable id> is a <label>
        <string variable id> is a <label>$
        <numeric array id> is a <label>(*)
Parameters
<parameter>
This formal parameter can be a numeric variable, a string variable, or a numeric array.
Example
  test analog; R
     clear connect s to "C1-1"; i to "C1-2"
     capacitor 50p, 20, 20, re6, fr1024, wb, R
  end test
General Information
To pass parameters into, or out of, test blocks, the test blocks must be explicit. That is, the test block must be delimited with the test analog and end test (ANALOG) statements.
