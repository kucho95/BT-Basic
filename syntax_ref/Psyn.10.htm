pause (BT-Basic)
Title: TEMPORARILY STOP A PROGRAM
The pause function stops program execution. It retains all program parameters so that (provided that the test developer changes nothing) when the program is continued, execution resumes as if the program had never stopped.
Syntax
  pause
Parameters
(none)
Example
  B=6\pause\print B        ! Halts program: does not print B until "cont" is executed
General Information
pause can be executed only from within a program.
Variables and files can be accessed during the pause. However, any changes made to them can alter the way the program executes when it is continued.
Also see pause (VCL).
