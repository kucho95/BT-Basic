display adjustments (DEBUG)
Title: LIST CURRENT CHANGES MADE TO TEST PARAMETERS
The display adjustments function lists, to the printer is device, all current adjustments; that is, all adjustments to test parameters made during debugging and not yet overridden or cancelled.
The current adjustments are cancelled by the following debug statements:
• debug
• debug end
• remove adjustments
