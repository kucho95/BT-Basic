find pins (BT-Basic)
Title: FIND FIXTURE WIRING CONNECTIONS
Use the find pins function and the guided probe to find fixture wiring connections to the fixture probes or to the board under test.
To use the find pins feature, type the find pins function, touch a fixture probe, or a point on the board under test, with the guided probe while pressing the start softkey (f1) or stepping on the foot switch. The system lists on the screen all the connection to that point. The information listed includes: device.pins, brc's, node names, and the resistance of the measurement.
You can use softkey (f6) to instruct the find pins feature how to list connections to digital ground BRC's. Show all dig gnds causes find pins to list every connection to a digital ground BRC. Show one dig gnd causes find pins to list only one connection to ground. Pressing softkey f6 causes it to toggle between these two definitions.
After finding connections to one point, the system asks you to probe another point. This continues until you press the stop softkey (f8).
Note that the find pins function automatically executes an unpowered function to prepare the system to execute the find pins feature.

General Information
The find pins feature requires board.o and wirelist.o files. Therefore, you must in the board directory and execute the load board function before executing a find pins function.
