display states (DEBUG)
Title: CHANGE DISPLAY FORMAT TO STATES FORMAT
The display states function changes the display format from its current format to the states format. There are three display formats: graphics, states and hexadecimal—also see the display graphics and display hex statements).
The states display shows the logic states represented as 1's, 0's and X's. These characters can be changed by the display format function.
Different colors are used in the display to denote the different types of data:
• Green represents actual states; that is, states that have been received by a system receiver or by the probe.
• White represents expected driver and receiver states read from the test.
• Red represents failed states. When a state fails, the expected level for that state is displayed.
