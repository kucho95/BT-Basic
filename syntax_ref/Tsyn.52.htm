topology get node connections (BT-Basic)
Title: GET THE DEVICES AND PINS CONNECTED TO A NODE FROM THE BOARD FILE
The topology get node connections statement fills a string array with the names of all devices which are connected to the specified node. It also fills another array with the pin names of the devices which are connected to the specified node.
You must first dimension two arrays: one array for the device names, and one array for the pin names. The device array must be at least 48 characters long and the pin array must be at least 8 characters long.
The information in the two arrays is parallel. Element one of the device array is paired with element one of the pin array. A device is listed in the device array once for every pin that is connected to the specified node.
Syntax
  topology get node connections <node id>, <device array>, <pin array>
  topology get node connections <node id>, <device array>, <pin array>, <err var>
     <node id> is a <string expression>
     <device array> is a <string array>
     <pin array> is a <string array>
Parameters
<node id>
The name of the node.
<device array>
The name of the array in which to place the device names.
<pin array>
The name of the array in which to place the pin names.
Example
! Place the names of the devices which are connected to node "U100-1" in an array called
! Devices$ and place the names of the device pins in another array called Pins$.
 
  dim Devices$(1:100)[48]     ! Dimension an array for the device names.
  dim Pins$(1:100)[8]         ! Dimension an array for the pin names.
  topology get node connections "U100-1", Devices$(*), Pins$(*)
General Information
To use any of the topology access functions you must first load the board file into memory.
To load a board object file, board.o, into memory execute the load board statement.
To remove a board file from memory use the scratch board statement.
The load board statement automatically scratches any file that is presently in memory.
