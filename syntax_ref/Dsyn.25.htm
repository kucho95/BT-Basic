dim (BT-Basic)
Title: DIMENSION VARIABLES
The dim function dimensions variables: that is, it initializes and reserves memory for them, and it declares their identifiers (names), dimensions and boundaries. Variables which must be dimensioned are:
• numeric arrays
• string arrays
• simple string variables whose lengths are not defaulted
(the default length for a string variable is 80 characters). No other reference can be made to any of these variables until they have appeared in a dim function.
The dim function also initializes the variables: numeric variables to zero, string variables to the null string ("").
Not all variables must be dimensioned by a dim function. Simple numeric variables and simple string variables are automatically initialized by the first function that references them. Simple numeric variables cannot be dimensioned by dim. Simple string variables do not have to be dimensioned by dim, but they can be; those string variables not included in dim automatically default to a dimensioned (maximum) length of 80 characters. If they are to be some other length (up to 2048 characters) then they must be dimensioned by dim.
The dimension function consists of the dim keyword followed by one or more specifications separated from each other by commas. Each specification defines an array, or a simple string variable.
Syntax
  dim <dim spec>
  dim <dim spec>,<dim spec>
  dim <dim spec>,<dim spec>, . . . . <dim spec>
     <dim spec> can be:   <numeric variable id>(<bounds>)
                          <string variable id>(<bounds>)
                          <string variable id>(<bounds>)[<length>]
                          <string variable id>[<length>]
        <numeric variable id> is a <label>
        <string variable id> is <label>$
        <length> is a <numeric constant>
        <bounds> can be:   <bound pair>
                           <bound pair>,<bound pair>
                           <bound pair>,<bound pair>, . . . . <bound pair>
           <bound pair> can be:   <upper bound>
                                  <lower bound>:<upper bound>
              <lower/upper bound> is a <numeric constant>
Parameters
 
<dim spec>
The specification for an array, or for a simple string variable.
<numeric variable id>
The identifier of a numeric array (see the definition of <label>). The id must be unique; that is, no other variable, simple or array, numeric or string, can exist at the same time with the same label in its id. A variable cannot be dimensioned again if it already exists. The workspace currently occupied by one variable cannot be re‑assigned to another variable until the workspace is cleared or a new program‑run starts.
<string variable id>
Identifier of a string array or simple string variable (see the definition of <label>). The information given above for numeric variables also applies to string variables.
<length>
Integer value specifies the maximum number of characters a simple string, or each element in a string array. It can be:
1 <= length <= 2048 (default = 80)
<bounds>
Specifies the dimensions of the array. An array can have up to 6 dimensions.
<bound pair>
Defines one dimension of the array. Any one dimension can have up to (and including) 32767 elements, numbered consecutively. An array can have a maximum of 2^17 elements (131072, or approximately 4*32767).
<lower/upper bound>
Integer values determine the range of each dimension by specifying the number of its lowest‑numbered element (lower bound), and of its highest‑numbered element (upper bound). If the lower bound is omitted, it defaults to zero. These three conditions must be met:
• –32767 <= bound <= 32767
• lower bound <= upper bound
• (upper bound – lower bound + 1) <= 32767
(Note that the elements are numbered consecutively in each dimension.)
Examples
  dim Nodes(1:100)        ! 1-dimensional numeric array with 100 elements (1-100)
  Nodes(8) = 368.9              ! assigns value to 8th element
  dim Tests(100)                ! 1x101 numeric array; elements are 0 through 100
  Tests(8) = 12                 ! assigns value to 9th element
  dim Test_scores(1:5,1:20)     ! 5x20 numeric array — can store five test scores
                                ! for 20 students
  dim Space(10,10,10)     ! 3‑dimensional numeric array — each dimension has 11 elements
  dim A(‑3:3,1:10)        ! 7x10 numeric array — rows are ‑3, ‑2, ‑1, 0, 1, 2, 3.
  dim Title$[20]          ! one string variable of no more than 20 characters in length
  dim Types_of_tests$(15)   ! 16 strings with a maximum length of 80 characters each
                            ! (the default)
  dim Q$(1:12,1:115)[22]    ! 12 sets of 115 strings, each string with maximum length
                            ! of 22 characters each
  Q$(6,38) = "Resistor‑‑passed"    ! assigns a string to an element in the array
  dim Gh$(‑6:1,4,6,6)[8]           ! string arrays can also have any number
                                   ! of dimensions (with a maximum of six)
  dim N(8), M(10), SA$(8)[12], Cd(10,‑10:‑5)
                                   ! several declarations in one function
