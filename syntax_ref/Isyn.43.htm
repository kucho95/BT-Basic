itl (BT-Basic)
Title: INVOKE ITL MODE
The itl function clears the workspace and set the workstation to itl (InterconnectPlus Test Language) mode. You must select this mode if you want to edit or write an ITL source file. These files should be stored in your board's digital directory.
Statements entered in itl mode are not syntax-checked, so you must ensure that the ITL statements that you use are valid. For more information about ITL syntax, refer to Testing Boundary-Scan Device Chains in Boundary-Scan Testing.
Syntax
  itl
  itl; <option>
     <option> can be:   window
                        nowindow
Parameters
<option>
Either window or nowindow.
• window opens a new window in itl mode.
• nowindow suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Examples
  msi "/user/scan_brd/digital"     ! selects board under test
  itl                              ! sets itl mode
     ...
     ...                           ! user creates itl source file
     ...
  save "file"
  compile "file"                   ! compiles itl source file
     itl;window                    ! opens a new window in itl mode
General Information
This function is not programmable.
