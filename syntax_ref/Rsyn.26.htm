report clear (BT-Basic)
Title: DISCARD THE CONTENTS OF THE REPORT BUFFER
If buffered reporting is enabled, a report clear statement discards the contents of the report buffer for the current board. Once the report buffer has been cleared, the next failing test will send a new report header to the buffer.
If buffered reporting is not enabled, the next failing test following a report clear statement sends a new report header to the report device (a printer or a file).
Syntax
  report clear
Parameters
(none)
Example
If buffered reporting is enabled:
  report clear   ! Clears the report buffer. Next failing test sends a new report header
                 ! to the report buffer.
If buffered reporting is not enabled:
  report clear   ! Nothing happens now, but the next failing test sends a new report
                 ! header to the report device.
