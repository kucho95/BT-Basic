backdrive current (SAFEGUARD)
Title: BACKDRIVE CURRENT PER PIN
The backdrive current function appears in a SAFEGUARD file to specify the current that flows through a power (or ground) pin when one of a device's output pins is overdriven. When compiling the executable digital tests, the compiler uses this information for SAFEGUARD analysis. The total current through the power or ground pin is the sum of the currents through the device output pins which sink or source current through that (power or ground) pin.
Backdrive‑current data is required for all power pins, and for both logic levels (1 and 0); if there is more than one value of current for a given level, then the highest (worst case) value should be used.
Syntax
  backdrive current of <amps> for <level>
  backdrive current of <amps> for <level>, <amps> for <level>
     <amps> is a <numeric constant>
     <level> can be:   "1"
                       "0"
Parameters
<amps>
A positive number representing the current, in amps, which can be backdriven through one output pin on the device.
Defaults: high (1) = 720 mA, low (0) = 720mA (defaults are the levels for Schottky TTL devices).
Range: 0 to 10.000A
<level>
The level to which the pin is to be driven. Following the convention for the test system, the 1 represents the higher (more positive) level, and the 0 the lower (more negative) level.
Examples
  backdrive current of 100m for "0"
  backdrive current of 125m for "1", 270m for "0"
