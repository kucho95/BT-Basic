generate nested repeat warning (VCL)
Title: GENERATE WARNINGS FOR NESTED REPEAT LOOPS
The generate nested repeat warning function is used in the Declaration section of the test to instruct the compiler to generate a warning if it cannot optimize a nested repeat loop. The function should be used only with nested loops in memory tests, where optimizing the use of space in the directory RAM may be critical to completing the test.
Syntax
  generate nested repeat warning
Parameters
(none)
