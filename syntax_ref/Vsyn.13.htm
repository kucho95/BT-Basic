verify grounds (BT-Basic)
Title: VERIFY GROUNDS
(UnMux systems only)
The verify grounds function executes a small shorts test on the BRCs that are defined as extra ground pins in the wirelist file under the ground block. This is to verify that the extra ground BRCs are wired to the board ground node in the fixture.
This command is included as a subroutine in the testplan under sub Verify_Grounds. Defining the ground block in the wirelist is optional if the test developer feels that additional grounds (other than the 12 fixed ground points per pin card) are needed for signal integrity. The test developer may choose to define extra BRCs to cater for more grounding. If the ground block is not used, then this subroutine can be commented to save some time in the testplan.
Syntax
  verify grounds
Parameters
(none)
Example
sub Verify_Grounds (Status_Code, Message$)
global Status
   if Message$ <> "" then print tab(5);Message$
   Status = Status_Code
   verify grounds
subend
General Information
(none)
