recycle to fail (DEBUG)
Title: REPETITIVELY EXECUTE UNTIL A FAILURE OCCURS
The recycle to fail statement repeatedly executes the test currently being debugged, until the Break key is pressed. The statement restarts the test immediately if a failure occurs. However, if the halt parameter is used, test execution halts when the first failure is found.
If there are no failures the test executes to the end each time. After each execution, the results are sent to the printer is device.
Syntax
  recycle to fail
  recycle to fail; halt
Parameters
(none)
Example
 recycle to fail
  recycle to fail; halt
