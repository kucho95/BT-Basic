test cont (BT-Basic)
Title: CONTINUE A TEST
The test cont statement can be used in the testplan to continue an analog or digital test after the test has been stopped by a halt or a pause statement. The test continues from the point at which it stopped.
In the case of a digital test which was halted, if safeguard protection is in effect (see the safeguard <type> statement), normal cool‑down delays will be enforced before the test is continued.
A test cannot be continued if it was stopped by an error or by test time out. Tests which stopped because they had finished, and tests which have not yet been started, cannot be continued.
Syntax
  test cont
Parameters
(none)
