testorder (BT-Basic)
Title: INVOKE TESTORDER MODE
The testorder statement clears everything currently in the workspace and sets the workstation to testorder mode. In this mode all statements entered into the work area of the screen are syntax-checked to ensure that they are valid testorder statements.
Loading an existing testorder file into the work space from any other mode automatically sets the mode to testorder.
Syntax
  testorder
  testorder; <option>
     <option> can be:   window
                        nowindow
Parameters
<option>
Either window or nowindow.
• window opens a new window in testorder mode
• nowindow suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Example
  text                 ! Sets the "text" mode; all syntax checking is turned off.
  testorder            ! Sets "testorder" mode.
  testorder;window     ! Opens a new window and sets "testorder" mode in it.
General Information
The testorder statement is not programmable.
