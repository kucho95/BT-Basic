test pins (VTEP)
Title: SPECIFY PINS TESTED BY VTEP
For a device tested using VTEP, each pin to be tested must be specified using the test pins statement. These entries are normally provided by the i3070 In-Circuit Test Software, but can be modified as needed.
Syntax
  test pins <pin list>
  test pins <pin list>;  <test options list>
     <pin list> can be: <pin id>
                        <pin id>, <pin id>
                        <pin id>, <pin id>, ... <pin id>
          <pin id> can be: <numeric constant>
                           <string constant>
     <test options list> can be: <option>
                                 <option>, <option>
                                 <option>, <option>, ... <option>
          <option> can be: threshold low <threshold> high <threshold>
                           throughput adjustment <adjustment>
                 <threshold> is a numeric constant
                 <adjustment> can be: 0
                                      1
                                      2
                                      4
Parameters
 
<adjustment>
The values are:
• For VTEP tests
0 – Normal (high accuracy mode)
1 – Throughput mode (faster)
• 2 – For iVTEP. (Do not change the thresholds written by ADB when using this option.)
• 4 – An enhanced mode that reduces guard path impedance.
Example
device "u101"
test pins 1 ; threshold low 300 high 600
pins 2,3 ! subsequent listings can omit "test"
test pins 4,5,6
! test pins 7 ! Ground pins commented by IPG.
test pins 8
test pins 11
test pins 12
test pins 13
! test pins 14 ! Fixed pins commented by IPG.
inaccessible pins 9,10
end device
General Information
In the example above, the omission of test before pins in the second test line is actually a unique statement. The use of the pins statement must always follow a test pins statement for each device. The syntax for pins is identical to that of test pins.
