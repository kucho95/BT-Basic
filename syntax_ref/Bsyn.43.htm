buswire (ITL)
Title: IDENTIFIES BOUNDARY SCAN CHAIN TEST TYPE AS BUSWIRE
The buswire statement is used at the beginning of the file to identify that a buswire test type is desired. Buswire tests are ones in which bussed boundary scan drivers are targeted for testing to identify that each pin operates and is not open. Like the interconnect test, other boundary scan pins are used as drivers and receivers.
Syntax
  buswire <chain name>
     <chain name> is a <string constant>
Parameters
<chain name>
Provides the name of the device in the chain that will be tested. This will be used in the failure repair message and log reports.
Examples
  buswire "U1_U4"
Refer to the ITL sample files in the Boundary Scan section for an example in context.
