topology get nodes (BT-Basic)
Title: GET THE NAMES OF ALL THE NODES FROM THE BOARD FILE
The topology get nodes statement fills an array with the names of all the nodes.
Syntax
  topology get nodes <array>
  topology get nodes <array>, <err var>
     <array> is a <string array>
Parameters
<array>
The array in which to place the node names.
Example
  dim Nodes$(1:100)[48]           ! Dimension an array.
  topology get nodes Nodes$(*)    ! Place the names of all nodes in array Nodes$.
General Information
To use any of the topology access functions you must first load the board file into memory.
To load a board object file, board.o, into memory execute the load board statement.
To remove a board file from memory use the scratch board statement.
The load board statement automatically scratches any file that is presently in memory.
