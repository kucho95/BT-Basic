remove sync (DEBUG)
Title: CLEAR THE DEBUG SYNC VECTOR
The remove sync statement cancels the debug sync currently associated with a vector. Any syncs programmed into the test using the VCL sync keyword are not affected.
Syntax
  remove sync
Parameters
(none)
Example
  add sync at 125     ! associates sync with vector 125
  add sync at 69      ! moves sync from vector 125 to vector 69
  remove sync         ! cancels sync from vector 69
General Information
(none)
