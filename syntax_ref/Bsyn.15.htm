bit (BT-Basic)
Title: READ BIT FROM AN INTEGER
The bit function returns a binary bit (specified by the second argument) read from a decimal, integer value (the first argument). Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. Values in the following ranges can be processed:
  16-bit operation: -2^15 <= value <= 2^15 - 1  (2^15 = 32768)
  32-bit operation: -2^31 <= value <= 2^31 - 1  (2^31 = 2147483648)
The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Syntax
  bit ( <value> , <bit number> )
     <value> and <bit number> are <numeric expressions>
Parameters
<value>
The decimal, integer value from which the specified bit is to be read.
<bit number>
The number of the bit to be read from the first argument. Bits are numbered zero to 15 (31); zero represents the least significant (most right bit).
Examples
  print bit(14,0)                             ! prints 0
  print bit(bti( "0001000110001001" ), 12)    ! prints 1
  if bit(N, 0) then print "N is odd."         ! odd if bit‑0 is 1
  if bit(N,15) then print "N is negative."    ! negative if bit‑15 is 1
                                              ! (assuming 16-bit operation)
