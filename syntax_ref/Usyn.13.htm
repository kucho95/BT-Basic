use timing set (VCL)
Title: ASSIGN A TIMING SET TO A VECTOR
(Mux systems only)
The use timing set function designates the timing set to be used with a vector. The function is used in a vector definition block to associate that vector with a specific timing set. The function is also used in the Vector Execution section in the PCF blocks. In a PCF block, all the vectors following the function are associated with the same timing set, until the next use timing set function or until the end of the PCF block. There can be more than one use timing set function in a PCF block.
When a vector execution function is encountered, if timing sets are being used, the function executes the timing set referenced by the vector. The timing set contains the instructions which execute the actual vector.
A vector can use only one timing set; so if it references more than one, then only the last one is valid. If a vector does not reference a timing set (or if vectors in a PCF block are not preceded by a use timing set function) then the default timing set is automatically assumed (see the timing set function).
If a vector definition starts with an initialize to (VCL) function, then that vector will automatically reference the same timing set as the initializing vector; if required, you can override that by inserting a use timing set function after the initialize to function.
Syntax
   use timing set <set id>
      <set id> is a <label>
Parameters
<set id>
The identifier of the required timing set.
Example
   ! in the Vector Definition section
            . . .
      vector V1
         use timing set T1           ! specifies T1
            set Enable to "11"
            set Inputs to "00101"
      end vector
      vector V2
         initialize to V1            ! specifies T1
            set Address to "011101"
      end vector
      vector V3
         initialize to V1            ! specifies T1
         use timing set T2           ! overrides T1 and specifies T2
            set Enable to "01"
            set PortA to "00101101"
      end vector
         . . .
   ! in the Vector Execution section
         . . .
      execute V1                      ! uses timing set T1
      execute V3                      ! uses timing set T2
         . . .
      pcf
         ! default timing set applies
            "11110HHHL"               ! uses default timing set
            "11000LHHL"
         use timing set T2
            "10100LLLH"               ! uses timing set T2
         . . .  
            "11111HHHH"
         use timing set T1
            "01010LHLH"               ! uses timing set T1
      end pcf
         . . .
      execute V2                      ! uses timing set T1
         . . .
