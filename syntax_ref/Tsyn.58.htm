topology node data$ (BT-Basic)
Title: GET AN ITEM OF INFORMATION ABOUT A NODE FROM THE BOARD FILE
The topology node data$ function returns an item of information about the specified node. The information is returned as a string expression.
You ask for the information by item number. The item numbers are:
1 Was the node entry crosschecked? The returned values can be: undefined, no, or yes.
2 What is the failure message from the board file? If there is no failure message the return string will be null.
3 not used.
4 What is the supply type? The returned values be:
• undefined
• derived
• ground
• fixed
• variable
5 What is the supply number?
6 What is the voltage setting of the power supply?
7 What is the current setting of the power supply?
8 What is the family name and logic level of the node? The returned values can be the family name followed by: 0 or 1 or X.
Syntax
  topology node data$ (<node name>, <item>)
     <node name> is a <string expression>
     <item> is a <numeric expression>
Parameters
<node name>
The name of the node.
<item>
A number (1 through 8) that represents the item of information to be returned. The items are described above.
Example
  FamilyAndLevel$ = topology node data$ ("U100-1", 8)
     ! Get the nodes family name and logic level
General Information
To use any of the topology access functions you must first load the board file into memory.
To load a board object file, board.o, into memory execute the load board statement.
To remove a board file from memory use the scratch board statement.
The load board statement automatically scratches any file that is presently in memory.
