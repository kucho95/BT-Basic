dround (BT-Basic)
Title: ROUND TO SIGNIFICANT DIGITS
The dround function rounds its first argument to the number of significant places determined by its second (integer) argument.
In the rounded value, the last significant digit is rounded up if the following digit was 5 or greater.
Syntax
  dround (<numeric expression>,<numeric expression>)
Parameters
<numeric expression>
The argument of the function. The first expression is the value to be rounded. The second expression indicates the number of significant digits the rounded value is to have. This number is an integer.
If it is less than 1, the function returns 0; if it is greater than 17, no rounding occurs.
Examples
  print dround(34576215 , 4)       ! prints    34580000
  print dround(34572215 , 4)       ! prints    34570000
  print dround(32.6758612 , 5)     ! prints    32.676
  print dround(‑156.64999 , 4)     ! prints    ‑156.6
  print dround(132 , 0.7)          ! prints    100 — remember, .7 is rounded to 1
  print dround(132 , 0.49)         ! prints    0
