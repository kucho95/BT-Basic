buffered reporting on/off (BT-Basic)
Title: ENABLE/DISABLE BUFFERED REPORTING
The buffered reporting on/off function enables and disables the internal buffering of report data. When buffered reporting in on, report data is held in a buffer until testing is complete; when buffered reporting is off, report data is immediately sent to the report device (a printer or a file).
The report out function sends the current contents of the report buffer to a device or to a file. Refer to the report out function for additional information.
If buffered reporting is on, executing a buffered reporting off function immediately clears the report buffer and turns off buffered reporting.
When testing a panel of boards (as opposed to testing a single board), report data is sent to the buffer for the current board, defined by a board number is function.
For more information about report data, see the syntax description of the report function.
Syntax
  buffered reporting on
  buffered reporting off
Parameters
(none)
Examples
  buffered reporting on      ! Temporarily hold report data in a buffer.
  buffered reporting off     ! Send report data directly to the report device.
                             ! Also clear the report buffer of any existing data.
General Information
A report clear function clears the contents of the report buffer; for details, refer to the functions’s description.
