test digital (VCL)
Title: SPECIFY THE NAMES OF THE FORMAL VARIABLES
The test digital statement is used in a VCL test to specify the test’s names for the formal variables passed to the test when it is executed. The variables are passed to the test by the BT-Basic test statement that executes the test (see General Information below).
If there is more than one test digital statement, they are cumulative. The test digital statements must be located near the beginning of the test, before any of the assign to statements.
Syntax
  test digital; <variable>
  test digital; <variable>,<variable>
  test digital; <variable>,<variable>, . . . <variable>
     <variable> is numeric and can be:   <label>
                                         <label>(*)
Parameters
<variable>
The identifier of a numeric variable. A maximum of 30 variables can be passed to one test.
The identifier must represent either a simple variable or a one‑dimensional array. Individual array elements and multi‑dimensional arrays cannot be specified.
Use an asterisk to specify an array, as in A(*). The same label cannot be used for a simple variable and for an array in the same test. All arrays in VCL are zero-based.
Example
  test digital; Serial_Number, A(*)
  test digital; B(*)
General Information
Array variables must be dimensioned in the testplan before the digital test is executed. When you dimension the variables, remember that the number of the first element defaults to 0 (zero) if it is omitted (see the BT-Basic dim statement).
The program generator will not include any of these variables in the testplan. Therefore, you must edit the testplan to dimension the variables and to add them to the BT-Basic test statement that executes the digital test.
