test node (VTEP)
TEST NODE AND DRIVEN DEVICES USING VTEP
This test node function evaluates devices tested using DriveThru in the vtep file (UnMux systems) or testjet file (Mux systems).
Syntax
  test node <node id>
  test node <node id>; <test options list>
     <node id> is a <string constant>
     <test options list> can be: <option>
                                 <option>, <option>
                                 <option>, <option>, ... <option>
         <option> can be: threshold low <threshold> high <threshold>
                          throughput adjustment <adjustment>
              <threshold> is a numeric constant
              <adjustment> can be: 0
                                   1
                                   2
                                   4
Parameters
<node id>
<node id> is used for VTEP mode with DriveThru Test.
<adjustment>
The values are:
• For VTEP tests
0 – Normal (high accuracy mode)
1 – Throughput mode (faster)
• 2 – For iVTEP. (Do not change the thresholds written by ADB when using this option.)
• 4 – An enhanced mode that reduces guard path impedance.
Example
  device "u101"
     test node "1"; threshold low 300 high 600
  end device
