display graphics (DEBUG)
Title: CHANGE DISPLAY TO GRAPHICS FORMAT
The display graphics function changes the display format from its current format to the graphics format. There are three display formats: graphics, states and hexadecimal (also see the display states and display hex statements).
The graphics display represents logical states as waveforms, to represent the 1, 0 and X levels. This is the default format when debugging is started. Each vertical line in a graphics display normally represents one vector. Refer to the display vector statement
Different colors in the waveforms denote the different types of data:
• Green: actual states; that is, states that have been received by a system receiver or the probe.
• White: expected driver and receiver states read from the test.
• Red: failed states. When a state fails, the expected level for that state is displayed.
