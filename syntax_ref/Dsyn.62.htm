display update (DEBUG)
Title: RE-COLLECT DEBUG DATA & UPDATE THE DISPLAY
The display update function must be used if you are debugging a test and you recompile that test because you change its source code. If you recompile a test, the debug data is no longer valid for that test. The update runs the new test, collects new data and redraws the display with that new data.
When the function is executed, it clears any modifications made to vectors. However, any other debug adjustments made earlier, such as changing the vector cycle time in debug, remain in effect after the update (if required, use the remove adjustments function to clear the current adjustments).
Syntax
  display update
Parameters
(none)
Examples
  debug "digital/u43"
     . . .
  ! edit the VCL test and re-save it
  compile "digital/u43"; debug
  display update
