trimr$ (BT-Basic)
Title: STRIP TRAILING SPACES FROM A STRING
The trimr$ (trim right) function returns a string which is a copy of the argument string but with any trailing spaces removed.
Syntax
  trimr$ (<string expression>)
Parameters
<string expression>
The string to be copied, but with trailing spaces removed.
Example
  A$ = "    Test1     "
  len (A$)                          ! returns    13
  len (trimr$(A$))                  ! returns    9
  print "#" & trimr$ (A$) & "#"     ! prints     #         Test1#
  print A$; len (A$)                ! prints     Test1     13
