clear connect-powered (ANALOG)
Title: CLEAR AND CONNECT RESOURCES TO NODES
The clear connect-powered function is used within an analog functional or a mixed test. It opens all previously closed analog relays (except those that were previously closed with clear connect keep or connect keep statements), then closes the necessary relays to connect specified resources (buses or balanced ports) to specified nodes. A node can be specified by the node name or the brc location; however, we recommend using node names in place of brc locations, because error checking is more extensive.
The clear connect-powered function has a settling delay to allow the relays to settle.
• Clear/Connect Buses
• Clear/Connect Balanced Ports (Utility Card)
