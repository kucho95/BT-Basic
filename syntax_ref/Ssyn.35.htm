set terminators (VCL) (ITL)
Title: CONNECT RC NETWORKS TO RECEIVERS
The set terminators statement connects the RC networks in the receiver circuits on hybrid pin cards. This can be used to enhance high‑speed signal quality. The statement can connect terminators (on in the syntax) or disconnect them (off).
When it generates the executable version of a test, the program generator turns the terminators on in that test if all pin cards in the board config file are listed as hybrid cards. If required, you can delete or change that statement, or override it for individual pins. The set terminators statements are order‑dependent: if two statements conflict, the later one always overrides the earlier one.
Syntax
  set terminators to on
  set terminators to off
  set terminators on <identifiers> to on
  set terminators on <identifiers> to off
     <identifiers> can be:   device <designator> pins <pin‑id list>
                             groups <group-id list>
                             nodes <node-id list>
                             pins <pin-id list>
                             relays <relay-id list>
        <designator> is a <string constant>
        The format of the <id lists> is:
           <item>
           <item>,<item>
           <item>,<item>, . . . <item>
              <item> can be:
                 for <pin-id list> — <numeric constant>
                                     <string constant>
                 for <group-id list> — <label>
                 for <node-id list> — <string constant>
                 for <relay-id list> — <5-digit numeric constant>
                    (represents brrcc)
Parameters
 
<identifiers>
The list of pins (groups, nodes, etc.) for which the terminators are to be turned on or off. Only output pins and bidirectional pins can be specified.
<designator>
String constant representing the designator of the device under test. It can contain up to 48 printable characters, but with no space.
<id list>
A list of pins represented by the following types of id:
• <group id>
• <node id>
• <pin id>
• <relay id>
These parameters are the same as the ids used to identify the pins in the assign to statements in the test. See the parameters described under the assign to (VCL) statement for details.
Example
  set terminators to on     ! set by the program generator in the executable test
     . . .
  set terminators on device "U68" pins 13, "11" to off
  set terminators on groups Control, Clock to off
  set terminators on relays 10962 to off
