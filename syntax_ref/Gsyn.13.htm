generate vtep (BT-Basic)
Title: RUN THE VTEP GENERATE PROGRAM
The generate vtep function runs the VTEP Generate program to generate files of board keepout areas or drill information for nanoVTEP (and VTEP) probes. The program uses device outline coordinates from the specified input file.
Syntax
  generate vtep probe <type> from <input file> to <output file>
  generate vtep probe <type> from <input file> over <output file>
     <type> can be:   keepout
                      drill
     <input file> is a <string expression>
     <output file> is a <string expression>
Parameters
<type>
The type of information to be generated:
• keepout – Instructs the program to generate an output file of board keepout areas.
• drill – Instructs the program to generate an output file of drill information.
<input file>
The name of the input file.
<output file>
The name of the output file.
Examples
  generate vtep probe keepout from "outlines" to "outlines_keepout"
     ! Generate a file of keepout area information called "outlines_keepout" from
     ! the information in an input file called "outlines".
 
  generate vtep probe keepout from "outlines" over "outlines_keepout"
     ! Generate a file of keepout area information over an existing file called
     ! "outlines_keepout".
 
  generate vtep probe drill from "outlines" to "outlines_drill"
     ! Generate a file of drill information called "outlines_drill" from the
     ! information in an input file called "outlines".
 
  generate vtep probe drill from "outlines" over "outlines_drill"
     ! Generate a file of drill information over an existing file called
     ! "outlines_drill".
