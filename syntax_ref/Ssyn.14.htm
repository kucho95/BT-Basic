scratch board (BT-Basic)
Title: REMOVE BOARD OBJECT DATA FROM MEMORY
The scratch board statement removes board object data from memory; data that was placed there by the load board statement. In particular, it scratches the board.o, wirelist.o, and the shorts.o file information from memory (but not from the associated disk files). Statements that require information from these files cannot execute until another load board statement is executed.
Syntax
  scratch board
Parameters
(none)
Example
  scratch board
