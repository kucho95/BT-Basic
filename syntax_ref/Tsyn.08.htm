test (ANALOG)
Title: EXECUTE A SUBTEST BLOCK
The test statement executes a subtest block defined by the subtest and end subtest statements. The test statement specifies the name of the subtest.
Syntax
  test <test id>
     <test id> is a <string constant>
Parameters
(none)
Example
  test powered analog
     clear connect s to "node_1"
     source sine, amplitude 6, frequency 100, icompliance 1, offset 2
     initiate source
     test "part1"
     test "part2"
  end test
     subtest "part1"
        global First_Result
        connect i to "node_2"; l to "node_3"
        detector dcv, expect 2
        initiate detector
        fetch First_Result
        report analog 2.1, 1.9, First_Result
     end subtest
     subtest "part2"
        global "First_Result"
        connect i to "node_4"; l to "GND"
        detector dcv, expect 8
        initiate detector
        fetch Second_Result
        report analog 5.1, 4.9, (First_Result + Second_Result) / 2
     end subtest
General Information
All variables used in a test are global to that test and its subtests.
