command/edit (SOFTKEY)
Title: SELECT AN AREA OF THE WORKSTATION'S SCREEN
The command/edit softkey moves the cursor between the command line and the work area of the workstation screen. The key acts like a toggle: if the cursor is in the command line, it moves to the workspace; if the cursor is in the workspace, it moves to the command line.
The softkey label toggles to show where the cursor moves if you press the softkey. When the cursor is on the command line, the label reads edit to show that pressing f1 moves the cursor into the workspace; when the cursor is in the work area, the label reads command to show that pressing f1 moves the cursor to the command line.
The cursor must be in the work area for writing and editing text and programs. The cursor must be in the command line when statements are executed, or a program is run. When you press f1, the cursor remembers its current position; when you press f1 the next time, the cursor returns to that same position.
