print (BT-Basic)
Title: PRINT DATA
The print function outputs in free‑field format data to the default output device, which is established by a printer is function.
The data to be printed is contained in the function's <print list>. Using free‑field format, the listed items which have a comma as a delimiter are output in standard fields containing twenty characters per field. Where a semicolon is used as a delimiter, the corresponding field is packed; i.e., it is lengthened or shortened to suit the length of the data item.
If the print list contains a tab function, the next field starts at the column indicated by that function.
Each time a line has been output, an appropriate EOL (End Of Line) sequence is sent to the output device; for example a CR/LF (Carriage Return/Line Feed) is sent to a printer. If there are no items in the list, just the EOL is sent; i.e., the function outputs a blank line.
Generally, a test developer will use the print function to display messages on the workstation's screen, or to generate a hardcopy of data on a printer. However, the data can also be output to other devices and to files. The printer is function selects the file or device which is to be the new default. printer is also opens the file or device for the exclusive use of the test developer who executed that function.
Data is output to a file or device sequentially, record by record. A record ends each time an EOL sequence is generated. Records can have a maximum of 2044 characters, although with free‑field format no more than 80 characters (one line) are output before an EOL sequence is generated. During the output, the system keeps track of its position in the file or device by means of a pointer. The pointer remains at the current position when the output is completed, so that the next output operation starts where the previous one stopped. The pointer can be returned to the beginning of the file or device by closing and then reopening it.
Syntax
  print
  print <print list>
     <print list> can be:
        <item>
        <item><delimiter><item>
        <item><delimiter><item><delimiter> . . . <item>
           <item> can be:
              <numeric expression>
              <string expression>
              <tab function>
                 [If <expression> is an array, use <array id>(*)]
           <delimiter> can be:
              ,  (comma)
              ;  (semicolon)
Parameters
<print list>
The list of data items to be output in free‑field format. A data item is output in a standard field if its delimiter is a comma, and it is output in a packed field if its delimiter is a semicolon. If the list contains no items, just the EOL—i.e., a blank line—is output.
To output a complete array of data, use <array id>(*).
If the <item> is a tab function, the print position moves to the column indicated, and the next field then starts in that column. If the column indicated is to the left of the current print position, an EOL is output and the next field starts at the indicated column on the next line.
There is no difference between a comma and a semicolon used as the delimiter after a tab function. Neither affects the format in this case.
Example
  print 14.5, ‑(2*6) , "Example 1"
     ! Prints    14.5               ‑12                 Example 1
     !          ‑‑‑‑‑‑20 spaces‑‑‑‑>‑‑‑‑‑‑20 spaces‑‑‑‑>‑‑‑‑‑‑20 spaces---->
  print 14.5; ‑(2*6); "Example 1 is"; " (packed)", "on one line."
     !
     ! Prints    14.5 ‑12 Example 1 is (packed)         on one line.
     !          ‑‑6‑‑>‑4‑>‑12 spaces‑>‑‑‑18 spaces‑‑‑‑‑>‑‑‑‑‑‑20 spaces---->
  print 147; tab(10), "This starts in column 10", "Packed"
  print 122, tab(10), "This starts on a new line", "Standard"
     ! Prints    
     !     147     This starts in column 10       Packed
     !     122
     !             This starts on a new line      Standard
     !    ‑‑‑‑9‑‑‑>‑‑‑‑‑‑‑‑‑31 spaces‑‑‑‑‑‑‑‑‑‑‑‑>‑‑‑‑‑‑‑‑20 spaces‑‑>
  print Scores(*)
     ! Outputs the entire array named "Scores"
  print Scores(*); ""
     ! Including the dummy output (a null string) enables the data from the array
     ! to be packed.
