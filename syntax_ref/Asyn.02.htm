abort (BT-Basic)
Title: ABORT (CLEAR) GPIB INTERFACE
The abort function resets the GPIB interface to its initialized state. The function activates the IFC line on the bus for 100 microseconds. This also has the effect of aborting any current bus activity.
Syntax
  abort <GPIB>
     <GPIB> can be a <file id> or an @<name>
        <file id> is a <string expression>
        <name> is a <label>
Parameters
<GPIB>
The address of the bus. The function pulls IFC (0), clears ATN (1) and sets REN (0).
Examples
Shortcut Method:
    abort "/dev/hpib1"          ! Activates IFC on the GPIB interface addressed
    assign @LINE to "/dev/hpib1"
    abort @LINE
 
Absolute Path Method:
    Bus$ = btgetenv$("I3070_ICT_ROOT")
    abort Bus$&"/dev/hpib        ! Activates IFC on the GPIB interface addressed
    assign @LINE to Bus$&"/dev/hpib1"
    abort @LINE
General Information
 
 
These examples assume the dev file hpib1 contains the SICL interface name hpib7.
