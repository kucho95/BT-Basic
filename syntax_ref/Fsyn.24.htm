findn (edit)
Title: FIND THE NEXT OCCURRENCE OF A STRING
The findn function (find next) locates the next occurrence of a string of characters in the workspace. The search begins at the current position of the cursor. findn operates exactly like the find function except that findn locates the next occurrence of the string instead of the first occurrence; see the description of the find function for details.
Syntax
  findn <string expression>
  findn <string expression>,<error variable>
     <error variable> is a <numeric variable>
Parameters
<string expression>
The string of characters to be found.
<error variable>
The identifier of an error variable.
Examples
  findn "Next test"
  FN$ = "test u" \ findn FN$
  findn "New test", Err       ! Includes error variable
