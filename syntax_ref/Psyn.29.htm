powered shorts (ITL)
Title: IDENTIFIES BOUNDARY SCAN CHAIN TEST TYPE AS POWERED SHORTS
The powered shorts statement is used at the beginning of the file to identify that a powered shorts test type is desired. Powered shorts tests test for shorts between nailed nodes and adjacent un-nailed boundary-scan interconnect nodes. Adjacency is determined by proximity of XY locations of the nodes in the board_xy file. The distance is controlled by a shorting radius entry in the board file or made via the i3070 In-Circuit Test Software.
The size of the test is variable depending on topology, proximity and which nodes are nailed.
Since these shorts may only be detected with power applied to the board, damage to the components is possible. The default testplan exits quickly and powers down the board if any failures are detected.
Syntax
  powered shorts <chain name>
     <chain name> is a <string constant>
Parameters
<chain name>
Name of the device in the chain that will be tested. This will be used in the failure repair message and log reports.
Examples
  powered shorts "U1_U4"
Refer to the ITL sample files in Boundary-Scan Testing for an example in context.
