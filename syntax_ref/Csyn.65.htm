create dir (BT-Basic)
Title: CREATE A DIRECTORY
This function creates a directory in the file system.
Syntax
  create dir <directory id>
  create dir <directory id>,<error variable>
     <directory id> is a <string expression>
     <error variable> is a <numeric variable>
Parameters
<directory id>
The identifier of the new directory.
<error variable>
The identifier of an error variable.
Examples
  create dir "/production/scopes/amp_40352"
                  ! Creates a directory for a new PC board test.
                  ! Directories "production" and "scopes" must already exist.
  create dir "reports"    ! Creates a directory that is named in the current directory.
  Name$ = "Test_Reports" \ create dir Name$, Err_var
General Information
When the directory is created, the two dot entries are automatically inserted. That is, the single dot (.), which represents the name of the new directory itself, and the double dot (..), which represents the name of its parent directory.
Use the unlink function to remove the directory.
Also see create ascii.
