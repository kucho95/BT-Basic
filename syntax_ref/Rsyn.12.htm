recycle to end (DEBUG)
Title: REPETITIVELY EXECUTE TO END OF TEST
The recycle to end statement repeatedly executes the test currently being debugged until the Break key is pressed. After each execution, results are sent to the report is device.
Syntax
  recycle to end
Parameters
(none)
Example
  recycle to end
