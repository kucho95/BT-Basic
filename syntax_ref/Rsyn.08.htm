receive delay (DEBUG)
Title: CHANGE THE RECEIVE‑DELAY TIME
The receive delay statement temporarily changes the receive delay in the test; that is, the delay time between strobing the drivers in a vector and strobing the receivers. The receive delay statement cannot be used with tests which have timing sets (on Mux systems only).
Except that it is temporary, receive delay in debug is the same as receive delay in VCL.
Syntax
  receive delay <time>
     <time> is a <numeric constant>
Parameters
<time>
The receive delay time, in seconds. See your system’s specifications for the range of the receive delay.
Example
  receive delay 560n       ! 600 nanosecs
  receive delay 0.0013     ! 1.3 msec
  receive delay 2.5u       ! 2.5 microsecs
General Information
safeguard none must be specified before the receive delay statement can be used.
