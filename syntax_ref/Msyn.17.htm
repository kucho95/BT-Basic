msi (BT-Basic)
Title: SET THE WORKING DIRECTORY
The msi function lets a test developer change the working (default) directory.
If the slash (/) is the first character of an identifier for a directory or for a file, then that identifier is assumed to be referenced to the root directory. If the identifier starts with any other character, then the identifier is assumed to be referenced to the current working directory.
Also see cd.
Note that msi is just an abbreviated form of the mass storage is function. The two statements are interchangeable, but you will probably find the short form more convenient to use because it requires less typing. In the interests of thoroughness, both forms are shown in the syntax description and example below.
Identifiers referenced to the working directory do not contain the name of that directory; see the example below.
Syntax
  msi <directory id>
  msi btgetenv$ ("I3070_ICT_ROOT") & <pathname>
  msi <directory id>,<error variable>
  mass storage is <directory id>
  mass storage is <directory id>,<error variable>
     <directory id> is a <string expression>
     <error variable> is a <numeric variable>
Parameters
<directory id>
The identifier of the directory which is to be the working directory. This directory must already exist.
<error variable>
The identifier of an error variable.
Example
  msi "/production/area_2/test"
     ! The following two statements now mean the same:
  rename "12c0836a" to "12c0836b"
  rename "/production/area_2/test/12c0836a" to "12c0836b"
     ! ... And these two statements mean the same:
  cat "../../area_4/test"
  cat "/production/area_4/test"
  msi "/production/area_1/tests",Err
     ! Includes an error variable
  mass storage is "/"     ! Specifies the root directory as the current default
  msi ".    ! Specifies the parent directory of the current default directory.
The msi btgetenv$ statement must be used in a BT-Basic window, instead of the msi statement, if you are using the environment variable.
  msi btgetenv$ ("I3070_ICT_ROOT") & "/production/area_2/test/12c0836a"
General Information
You can specify relative pathnames (pathnames that include . or . . entries) in an msi function.
