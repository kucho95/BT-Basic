compile Syntax for Multiple Board Versions
When no version is specified, the compile statement compiles the test for the base board.
To compile a device test for a particular version, use the following syntax:
  compile "<designator>"; version "<version label>"
 
Table C-6 Examples
Description
Example
When no version is specified, this statement compiles the test for the board version that is set in the BT-Basic window. For example, in Figure C-1 the version that will be compiled is the base version.
compile "pins"
If a version other than the base board version has been set in the BT-Basic window (for example, through a board version is new_version statement), then a base board test will only be compiled if the version label is set to the base board.
compile "r1"; version ""
 
This is equivalent to
compile "base_board/analog/r1"
This compiles the version specified.
compile "r1"; version "ver2"
This compiles the version specified in the path.
Do not specify both the version option and the path.
compile "ver2/analog/r1"
