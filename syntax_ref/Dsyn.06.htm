dbconnect (DEBUG)
Title: CONNECT A DEBUG PORT TO A RESOURCE
The dbconnect function is used to connect one of the three debug ports—sync, clock or data, to one of several resources, as shown in the list below. Each port can have only one resource connected at a time. Not all resources can be connected to all ports: refer to Table D-1 for details.
When a resource is connected to a port it remains connected until another resource is connected to that port. The ports are active only while debugging is active.
Do not use dbconnect data to <identifier> in Boundary Scan tests and VCL tests that use serial data capture. Owing to conflicting use of internal resources, that version of the function causes those tests to fail.
Syntax
  dbconnect <port> to <resource>
     <port> can be:   clock
                      data
                      sync
     <resource> can be:   debug sync
                          event clock
                          <identifier>
                          program sync
                          timing clock
                          vector clock
        <identifier> can be:   device <designator> pin <pin id>
                               pin <pin id>
                               node <node id>
           <designator>, <node id> and <pin id> are <string expressions>
Parameters
 
<port>
The debug port to which the specified resource is to be connected.
<resource>
The system resource to connect to the debug port. The resource must be compatible with the selected port. Compatible port/resource pairs are shown in Table D-1.

Examples
  add sync at 56                     ! associates debug sync with vector 56
  dbconnect sync to debug sync       ! connects vector sync pulse to port "sync"
  dbconnect data to device "U18" pin "9"
  dbconnect clock to timing clock
General Information
The default connections to the ports are:
• sync: program sync
• clock: vector clock
• data: (none)
