fixed (ITL)
Title: DECLARES FIXED NODES WITHIN A BLOCK
The fixed statement is used within a nodes block to declare fixed nodes. The fixed statement includes the state of the node (high or low); if the state cannot be determined, the statement is commented and the state is specified as unknown. You need to edit the file to change the state to either high or low and uncomment the statement.
Syntax
  fixed <state> <node name> test <device.pin>, <device.pin>,...<device.pin>
     <state> can be: high
                     low
     <node name> is a <string expression>
     <device.pin> is a <string expression>
Parameters
<state>
Identifies the fixed level of the node.
<node name>
Provides the name of the node that will be tested.
<device.pin>
Identifies the device connections to the node to be tested.
Examples
Refer to the ITL sample files following this section.
General Information
For fixed nodes with an unknown state ("X"), comment the (silicon) node statement.
