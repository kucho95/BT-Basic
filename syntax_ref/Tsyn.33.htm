text (edit)
Title: INVOKE TEXT MODE
The text statement clears everything currently in the workspace and sets the workstation to text mode. In this mode no syntax checking occurs, so anything can be typed into the work area of the screen and subsequently saved in a file. Editing and other mode selection statements can be executed as usual from the command line.
Syntax
  text
  text;<option>
     <option> can be:
        window
        nowindow
Parameters
<option>
Either window or nowindow.
• window opens a new window in text mode
• nowindow suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Example
  text                       ! Sets "text" mode; all syntax checking is off
     ...
        Anything #$@m7& can now be typed in the workspace
     ...
  save "/my‑stuff/letter‑to‑mom"
  basic                      ! Establishes "basic" mode
  text;window                ! Opens a new window and sets "text" mode in it.
General Information
The text statement is not programmable.
