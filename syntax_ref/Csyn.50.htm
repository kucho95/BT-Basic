cont (BT-Basic)
Title: CONTINUE A PAUSED PROGRAM
The cont function is used to resume running a program which was paused (halted) by a pause function, by the Break key, or by a runtime error.
cont can be used only to continue a run on a program which was running; it cannot be used to start a run. Operations which do not change the program statements, such as assigning values to variables, and goto statements, can be executed while the program is paused. If the program itself is edited while it is paused, the run cannot be continued; an edited program must be run from the beginning.
At what point in the program the run resumes depends on whether or not the cont function has a line parameter:
• LINE PARAMETER INCLUDED: The program run resumes at the beginning of the specified line. If the program paused in the main program, it must be continued in the main program. If it paused in a subprogram, it can be continued in the subprogram or in the main program.
• LINE PARAMETER NOT INCLUDED: The point at which the program resumes depends on what caused the program to halt, and on what operations were executed by the test developer while the program was halted. If the programmer changed the current position by executing, say, a goto function during the pause, then the run resumes at the line specified by that operation. If there were no such operations during the pause, then:
• If the pause resulted from pause or Break, execution resumes with the function following the last function to be executed before the pause occurred (does not necessarily resume at the beginning of a line).
• If the pause resulted from a runtime error, execution resumes at the beginning of the line containing the function which caused the error (see General Information below).
Syntax
  cont
  cont <line id>
  cont <line number>
     <line id> is a <label>
     <line number> is a <numeric expression>
Parameters
 
<line id>
The label at the beginning of the program line at which the program run is to continue.
<line number>
The number of the program line at which the program run is to continue. This is assumed to be a positive, integer value.
Examples
  cont Test3               ! Resumes the program run at the line labeled "TEST3"
  cont 46                  ! Resumes the program run at line 46
  A = 45 \ print "A=" \ pause \ print A
                           ! when "cont" is executed at the keyboard, the
                           ! program prints A= 45 and continues
General Information
If a program is paused by a runtime error and that error requires a function on the line to be edited, the run cannot be continued at that line. Executing cont at that line causes the error to occur again, and editing the line prevents the program from being continued.
If the error can be corrected without editing the line then the run can be continued at that line.
Provided you have not edited any statements while the program is paused, it is always possible to goto another line, in which case the program immediately continues running at that line.
The cont function is not programmable.
A program halted by a stop function cannot be continued.
