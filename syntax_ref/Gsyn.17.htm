goto (BT-Basic)
Title: MAKE AN UNCONDITIONAL BRANCH
The goto function causes a branch to the program line identified by the label specified in the function. A line with that label must exist at the time the goto function is executed.
If the function is executed during a program run, the program branches to the labelled line and continues program execution at that line. If the function is executed from the command line, the branch is made to the labelled line in the workspace and program execution starts at that line.
Any statements following the goto function and on the same line, are not executed.
The line to which the branch is to be made must be in the same program environment as the goto; that is, branches cannot be made between the main program and a subprogram, or between subprograms. You can use goto to cancel loops by branching out of them. Branching into a loop may cause unpredictable results.
Syntax
  goto <line id>
     <line id> is a <label>
Parameters
<line id>
The label at the beginning of the line to which the branch is to be made.
Examples
  NEXT_TEST: question "Place PC Board on the Fixture: press YES"
     . . .                                   ! (program tests board)
  question "Test Completed‑‑Remove Board: press YES"
  goto NEXT_TEST                             ! branch to start of program
  ! "goto" combined with simple‑if conditionally executes the branch
        A=10
     Print_Sqrt: print sqr(A)                !
        A=A+10                               ! program prints 10 values
     if A<110 then goto Print_sqrt           !
     print "end"
The next example illustrates the use of goto statements to selectively branch to various places in a program, depending on established conditions, or on inputs from the operator. This program is a simplified outline of a board‑test.
 
  NEW_TEST: question "Mount next PC board; then press YES"
     ! operator follows instructions and presses "YES" key
  T = 0               ! clears "failure" variable, T.
     ! *****
     ! These lines represent a program segment containing instructions to test the
     ! board. If a failure occurs, it sets T=1. When finished with the test, the program
     ! continues, below, to determine if a failure occurred.
     ! *****
  if T=1 then goto FAILURE                 ! branches only if board failed
  question "PASSED; remove board and press YES"
     ! operator follows instructions
  RERUN_TEST: question "Continue testing? YES or NO", More
     if More= 1  then goto New_Test        ! if YES, runs test on next board
     goto END                              ! if NO, branches to end of program
  FAILURE : question "FAILED; remove board and press YES"
     goto Rerun_test
  END:  print "TESTING FINISHED" \ end
General Information
The goto function by itself is an unconditional branch. As shown in the examples, goto can be combined with other program constructs, such as if, to form conditional branches.
