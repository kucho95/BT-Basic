vtep print level is (BT-Basic)
Title: SEND THE RESULTS OF VTEP MEASUREMENTS TO THE SPECIFIED DEVICE
The vtep print level is statement instructs the system to send a report of the results of VTEP measurements to the current printer is device. The report includes:
• device designator
• pin number
• measured value
• pass/fail status
• low and high limits
Example of output format:
    D: u3 P: 4 18.7 p 7.0 39.0
    D: u3 P: 7 tied
If a pin is tested using a drive-through node:
 D: u3 N: NodeName 192.7 p 147.0 264.0
If no vtep print level is statement is executed, no VTEP measurement information is generated.
Syntax
  vtep print level is <status>
     <status> can be:   all
                        none
Parameters
<status>
Specifies what information to send to the printer is device.
• all – The results of all VTEP measurements.
• none – No information.
Example
  vtep print level is all             ! Turn the reporting on.
  vtep print level is none            ! Turn the reporting off.
  sub VTEP                            ! Use the VTEP subroutine to generate report in
     printer is "measurements"        ! a file called "measurements".
     vtep print level is all
     test "vtep"
     vtep print level is none
     printer is *
  subend
