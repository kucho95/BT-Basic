<bit spec>
A <bit spec> is used to input or output data in groups of 8 to 64 bits at a time. Incoming ASCII characters are stored as numeric data, and numeric data being output with a <bit spec> is converted into the corresponding ASCII characters. A <bit spec> is used primarily to transfer binary data via GPIB.
Note that this spec cannot use a <repeat factor>.
<bit spec> can be:
• b - 8 bits (byte)
• w - 16 bits (word)
• i - 32 bits (integer)
• f - 64 bits (floating point)
<bit spec> is specified in multiples of 8, with 8 bits being the length of one ASCII character. Thus, a <bit spec> of b is 8 bits, or 1 character; a <bit spec> of w is 16 bits, or 2 characters, etc.
Example of data input with <bit spec>
  ! Input 8 bits (1 char) and convert to number
    Format1: image b
    input using Format1; A
    print A
  ! Running this program and inputting "U" prints 85
  ! 85 is the ASCII value equivalent to "U"
Example of data output with <bit spec>
  ! Output 8 bits (1 char) and convert number to character
    Format1; image b
    A = 85
    print using Format1; A
  ! Prints U
  ! "U" is the character equivalent of ASCII 85
