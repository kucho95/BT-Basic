set receiver offset (VCL)
Title: SET OFFSETS ON RECEIVERS
(Mux systems only)
The set receiver offset statement sets offsets on individual pins and on groups of pins. The statement can apply both to output pins and to bidirectional pins when they are declared as outputs.
Unless the optional <active event> parameter is used, the offset will apply to the specified pins whenever they are referenced in the test.
Syntax
   set receiver offset on <identifiers> to <time>
   set receiver offset <active event> on <identifiers> to <time>
      <identifiers> can be:   device <designator> pins <pin‑id list>
                              groups <group-id list>
                              nodes <node-id list>
                              pins <pin-id list>
         <designator> is a <string constant>
         <pin-id list> can be:   <pin id>
                                 <pin id>,<pin id>
                                 <pin id>,<pin id>, . . . <pin id>
            <pin id> can be:   <numeric constant>
                               <string constant>
         <group-id list> can be:   <group id>
                                   <group id>,<group id>
                                   <group id>,<group id>, . . . <group id>
            <group id> is a <label>
         <node-id list> can be:   <node id>
                                  <node id>,<node id>
                                  <node id>,<node id>, . . . <node id>
            <node id> is a <string constant>
      <time> is a <numeric constant>
      <active event> can be:   a
                               b
Parameters
 
<identifiers>
The list of receivers whose offsets are to be changed. Only output pins and bidirectional pins can be specified.
<designator>
String constant representing a device.
<id list>
The list of pins or nodes to be changed.
<time>
The offset, in seconds, from the event on which the activity is to occur. The value can range from ‑30 ns to 100 ns. A value cannot be used if it would place two transitions (state changes) on the same pin closer than 50 ns, or if the transition would then occur in the next vector.
<active event>
The offset is to be applied, in each vector pair, to the first (a) or second (b) active event on the specified pins.
Example
   set receiver offset on device "U68" pins 13, 11 to 15n
   set receiver offset on groups Data_in, Data_out to -10n
   set receiver offset b on pins 12 to 40n
