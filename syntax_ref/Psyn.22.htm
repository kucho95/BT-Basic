polarity print level is (BT-Basic)
Title: SEND RESULTS OF POLARITY CHECK MEASUREMENTS TO SPECIFIED DEVICE
The polarity print level is function instructs the system to send a report of the results of Polarity Check measurements to the current printer is device. The report includes:
• device designator
• measured value
• pass/fail status
• test threshold
If no polarity print level is function is executed, no Polarity Check measurement information is generated.
Syntax
  polarity print level is <status>
     <status> can be:   all
                        none
Parameters
<status>
Specifies which information to send to the printer is device.
• all – The results of all Polarity Check measurements.
• none – No information.
Example
  polarity print level is all        ! Turn the reporting on.
  polarity print level is none       ! Turn the reporting off.
  sub Polarity                       ! Use the Polarity subroutine to generate the
     printer is "measurements"       ! report in a file called "measurements".
     polarity print level is all
     test "polarity"
     polarity print level is none
     printer is *
  subend
