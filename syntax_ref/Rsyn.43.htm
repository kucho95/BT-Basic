rpmc (BT-Basic)
Title: RETURN VALUE OF FAILURE FLAG FOR POWER MONITORING CIRCUIT
The rpmc statement reads the failure flag on a Power Monitoring Circuit (PMC) channel and returns the value in the indicated variable. This statement is best used in between test statements to check for failure, as shown in the example below.
Syntax
rpmc <channel>, <flag>
   <channel> is an <integer>
   <flag> is a <variable name>
Parameters
<channel>
The channel number from 1 to 12. (See Table S-4 in the spmc description.)
<flag>
The variable in which to store the value of the failure flag:
1 – indicates a power failure
0 – no failure
Example
test "digital/u1"
rpmc 2, V_Flag    ! Read failure flag for PMC channel 2 and store in the variable V_Flag
test "digital/u2"
