list object (BT-Basic)
Title: CREATE A SOURCE LISTING OF AN OBJECT FILE
The list object function creates a source listing of an object file. You can specify the name of the list file. For Multiple Board Versions, the version label parameter allows you to specify the version of the board.
Syntax
  list object <object file id>
  list object <object file id> <option list 1>
  list object <object file id>; <option list 2>
  list object <object file id> <option list 1>; <option list 2>
     <object file id> is a <string expression>
     <option list 1> can be:
            <error variable>
            <over/to> <source file id>
            <over/to> <source file id>, <error variable>
            <over/to> <source file id>; version <version label>
            <over/to> <source file id>; version <version label>, <error variable>
        <over/to> can be:   over
                            to
        <source file id> is a <string expression>
        <error variable> is a <numeric variable>
        <version label> is a <string expression>
     <option list 2> can be:   <item>
                               <item>, <item>
                               <item>, <item>, <item>
        <item> can be:   <window>
                         <experience level>
                         <backup level>
           <window> can be:   window
                              nowindow
           <experience level> can be:   standard
                                        advanced
                                        expert
           <backup level> can be:   numbered
                                    unnumbered
                                    nobackup
Parameters
 
<option list 1>
Can be a source file name, an error variable, or a version label that specifies the version of the board for Multiple Board Versions.
<option list 2>
Optional parameters that determine how the function works. The options are described below.
<window>
Specifies whether or not a new window is automatically opened when the function is executed. Permissible values are:
• window – A new window is opened.
• nowindow – Suppresses the opening of a new window.
<experience level>
Sets the length (thoroughness) of the error messages the user receives and can also be used to restrict the user to a subset of the full system features. Permissible values are: standard, advanced, and expert.
<backup level>
Determines if the compiler stores an unchanged copy (a backup) of files before modifying them, and how the backup is stored. Permissible values are:
• nobackup – No file backup is made.
• numbered – Makes up to nine backups, numbered sequentially with .#~ (for example, (file.1~). Number one is the most recent backup. When more than nine backups occur, the oldest file is discarded, and the others are renumbered.
• unnumbered – A single backup is made, indicated with a tilde (~) in the file name.
Examples
• Create a source listing of the "wirelist.o" file and save it in a file called "wirelist".
     list object "wirelist.o" to "wirelist"
• Create a source listing of the "fixture.o" file and save it in a file called "fixture".
     list object "fixture/fixture.o" to "fixture/fixture"
• Multiple Board Versions: List the sections of the "board.o" file that apply to version 1, and save them in a file called "board.ver_1".
     list object "board.o" over "board.ver_1"; version "version_1"
