data (VCL)
Title: DATA BUS ASSIGNMENT FOR FLASH ISP TESTS
The data command assigns the data bus id to a group of dynamic vectors representing the data bus for Flash ISP tests.
Syntax
  data <data bus id> to groups <dynamic group id>
Parameters
<data bus id>
The name of the data bus id. The data bus to which data from the file image will be assigned.
<dynamic group id>
The name of the group of pins that are driven or received by the states in the data block . This group id is the same as defined by the assign statement in the assignment section of the test.
Examples
  data Data to groups DataBus
