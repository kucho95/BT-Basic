board number is (BT-Basic)
Title: TEST A SINGLE BOARD OR A MULTI-BOARD PANEL
The board number is function sets up BT-Basic to test either a single board or a panel of boards.
When testing a single board, the BT-Basic environment maintains test status information for that board, such as the boardfailed status, the dutfailed status, probe failures information, the contents of the log buffer, and (if buffered reporting is enabled) the contents of the report buffer.
When testing a panel of boards, the board number is function instructs BT-Basic to maintain separate status information for each board on the panel. After the panel has been tested, board number is * can be used to simultaneously clear the status information for all boards on the panel.
Syntax
  board number is <number>
  board number is *
     <number> is a numeric expression
Parameters
<number>
An integer from 0 to 256. If <number> is zero, the status information pertains to the overall panel. A <number> in the range 1 to 256 identifies an individual board on a multi-board panel. When testing begins, status information for each board is stored apart from the status information for other boards on the panel.
*
Clears the status information for all boards on a panel and returns to single board (non-panel) testing.
Examples
  board number is 3     ! The board being tested is number 3 on a panel.
                        ! Status information for this board is separated from the
                        ! status information for the other boards on the panel.
  board number is *     ! Clear status information for all boards on the panel.
                        ! Return to testing single boards.
  board number is 0     ! The status information is for the panel, not a board.
