threshold (SHORTS)
Title: SHORTS & OPENS RESISTANCE THRESHOLD
The threshold statement specifies the value above which a resistance is considered an open, and below or equal to which it is considered a short.
Syntax
  threshold <resistance>
     <resistance> is a <numeric constant>
Parameters
<resistance>
A numeric constant which expresses the threshold resistance in ohms. The range of resistance is 2 to 1000 ohms, if no threshold is specified, a value of 8 ohms is used.
Example
  threshold 20
  failure "Switch_A should be open."
  nodes "Switch_A.1"
  nodes "Switch_A.2"
