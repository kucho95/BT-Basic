<repeat factor>
A positive, integer constant in the range 0 to 256 which can (in most cases) precede a <spec> to indicate the number of times that <spec> is to be executed. A repeat factor applies only to the <spec> immediately following it, as in <repeat factor><spec>.
The following are some examples of <repeat factor>:
  5x, 4xx, and 3xxx = xxxxx
  2(aa, 2x, aaa) = aa, xx, aaa, aa, xx, aaa
(Also see <replication spec>.)
