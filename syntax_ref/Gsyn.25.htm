group (CONFIGURATION)
Title: DEFINE EXTERNAL DEVICE GROUP
The group function defines an external device group in the board config file. More than one external device may be connected and used via the optional Utility Card; however, to use the external devices simultaneously, they must be grouped and controlled by the same DLL. The DLL must have the ability to control multiple devices simultaneously.
Individual controls on an external device that is part of a device group are not allowed.
Syntax
group "<device_group_name>" is "<device_name>", "<device_name>", ... "<device_name>"
   <device_group_name> is a string
   <device_name> is a string
Parameters
<device_group_name>
Name of the device group (maximum 32 characters).
<device_name>
Name of the external device. Up to 12 external devices can be defined in a device group.
Examples
group "ICgroup" is "IC2", "IC4"
