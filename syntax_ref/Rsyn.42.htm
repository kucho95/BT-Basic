rotate (BT-Basic)
Title: BINARY ROTATE AN INTEGER
The rotate statement returns a decimal, integer value which corresponds to the circularly shifted, binary representation of the statement's first argument. The amount and direction of the rotation is determined by the statement's second argument.
Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Values in the following ranges can be processed:
16-bit operation: -2^15 <= value <= 2^15 - 1 (2^15 = 32768)
32-bit operation: -2^31 <= value <= 2^31 - 1 (2^31 = 2147483648)
Syntax
  rotate ( <value> , <rotate> )
     <value> and <rotate> are <numeric expressions>
Parameters
<value>
The decimal, integer value whose binary representation is to be rotated.
<rotate>
Specifies the direction of rotation and the number of bit‑places to rotate.
• Direction:
positive value = rotate right
negative value = rotate left
• Amount:
a.) Absolute value is rounded to the nearest integer;
b.) Integer is divided by 16 (or 32); the remainder is the amount by which to rotate:
(16-bit) rotate = |integer| mod 16
(32-bit) rotate = |integer| mod 32
Example
  print rotate(‑1,10)                ! prints   ‑1
  print rotate(‑1,1)                 ! prints   ‑1
  print rotate(‑1,‑3)                ! prints   ‑1
  print rotate (3400,0)              ! prints   3400
  print rotate ( bti("111"),‑2)      ! prints   28
  print rotate ( bti("111"),‑18)     ! prints   28
