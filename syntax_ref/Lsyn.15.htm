list versions (BT-Basic)
Title: LIST VERSION LABELS IN BOARD FILE
When using Multiple Board Versions, use the list versions statement to list the version labels in the board file:
Syntax
  list versions
  list versions; device <device>
  list versions to/over <file name>
  list versions to/over <file name>, <backup level>
  list versions to/over <file name>; device <device>, <backup level>
     <device> is a <string expression>
     <to/over> can be: to
                       over
     <file name> is a <string expression>
     <backup level> can be: numbered
                            unnumbered
                            nobackup
Parameters
<backup level>
The type of backup when listing to a file that already exists.
• nobackup – No file backup is made.
• numbered – Makes up to nine backups, numbered sequentially with .#~ (for example, file.1~). Number one is the most recent backup. When more than nine backups occur, the oldest file is discarded, and the others are renumbered.
• unnumbered – A single backup is made, indicated with a tilde (~) in the file name.
Examples
• List the version labels to the screen:
      list versions
• Lists the version labels to a file called "versions":
      list versions to "versions"
• List the version labels for the device U5, and saves them in a file called "versions_u5":
      list versions to "versions_u5"; device "U5"
