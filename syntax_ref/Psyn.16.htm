pcf order is nodes (ITL)
Title: MAP NODES TO PCF VECTORS
The pcf order is function is used in the disables section of an ITL test or in the nodes block, prior to the first unit, of a silicon nail test to define one set of PCF nodes and their sequence. A set of PCF nodes determines the order in which the nodes on the board under test will be mapped to the bits in PCF test patterns (vectors) listed.
The order in which the bits in the vectors are assigned to nodes is determined by the order that the nodes appear in the pcf order is statements. Multiple statements can be used on succeeding lines to define all the nodes; the results are cumulative. Unlike the VCL version of this statement, named orders are not supported.
Syntax
  pcf order is nodes <node>
  pcf order is nodes <node>, <node>
  pcf order is nodes <node>, <node>, ... <node>
     <node> is <string constant>
Parameters
<node>
The node name.
Example
  pcf order is nodes "U3_2", "NI1"
