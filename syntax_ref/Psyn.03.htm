package (SAFEGUARD)
Title: DEVICE PACKAGE MATERIAL
The package function appears in a SAFEGUARD file to specify the package material for a device; this determines to which damage class the device belongs: plastic or ceramic.
When compiling the executable digital tests, the compiler uses this information to choose which bond‑wire, maximum test‑duration formula to use in the SAFEGUARD analysis for the device. If both types of material are to be encountered during production testing, the more restrictive, ceramic, must be specified. (The Keysight‑supplied libraries specify ceramic.)
Syntax
  package <material>
     <material> can be:   ceramic
                          plastic
Parameters
<material>
The package material of the device. Default is ceramic.
Example
  package ceramic
  package plastic
