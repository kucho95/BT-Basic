bti (BT-Basic)
Title: BINARY‑STRING TO INTEGER
The bti function returns a decimal, integer value which is equivalent to the binary number contained in the function's string argument. With 16‑bit operation, the number in the string can have up to 16 contiguous one and zero characters; if it has less than 16 characters, leading zeros are assumed (32 characters with 32‑bit operation). Leading and trailing spaces are ignored. If the number in the string contains an embedded space, the number terminates at the space and any remaining characters are ignored.
Twos‑complement representation of the values is assumed, with either 16‑ or 32‑bit operation. Values in the following ranges can be processed:
   16-bit operation:
   -2^15 <= value <= 2^15 - 1
   (2^15 = 32768)
   32-bit operation:
   -2^31 <= value <= 2^31 - 1
   (2^31 = 2147483648)
The default operation is 16-bit, use the option bit statement to change to the 32-bit operation.
Syntax
  bti ( <string expression> )
  bti ( <string expression> , <error variable> )
     <error variable> is a <numeric variable>
Parameters
<string expression>
Binary string to be converted to its equivalent decimal value. If a conversion error occurs and there is an error variable, the function returns a zero.
<error variable>
Identifier of an error variable.
Examples
  print bti("11001")                      ! prints    25
  Val = bti("  0000000000010011")         ! Val = 19
  Negnum = bti("  1111111111011010   "    ! Negnum = ‑38 (16-bit)
  print bti("1001 0001 1000")             ! prints    9 [same as bti("1001")]
     loop                                 ! converts binary numbers to decimal
     input "Type binary string:" , Pattern$
     Val = bti (Pattern$, Err)
     if Err <> 0 then print "Improper pattern, please try again."
  exit if not Err\ end loop \ print Val
