frame/end frame (VCL)
Title: IDENTIFY THE BEGINNING OF A FRAME BLOCK
The frame function identifies the beginning of a block of pcf vectors used in testing boundary-scan devices. The binary values of each vector are shifted into the boundary-scan device via the Test Data In (TDI) port. When the frame bits have been captured by chain receivers, they are shifted out the Test Data Out (TDO) port, and stored in deep-capture RAM until all frames have been executed. The bits are then reassembled into signatures and compared to determine if a node passes or fails a test.
The frame function can have two parameters. The offset parameter tells the test system how many vectors to skip before starting to capture data. The skip parameter tells the test system how many vectors to skip between captured vectors. A frame that uses no parameters tells the test system to capture every vector.
The offset parameter is typically used to skip vectors that were used to set up the frame.
The skip parameter is typically used to tell the test system to capture every other vector. Because two vectors are required for each shift of data into or out of the boundary-scan chain (a rising and falling edge on TCK), pertinent data in the vector would be duplicated if every vector were captured.
Frames can be used inside a compress block to have the test system check for a failure. If the sum of the compress value is zero (0), the test system knows that it does not have to examine the data in the deep-capture RAM. If the sum is greater that zero, the test system invokes the Results Analysis Routine, which examines the data in the deep-capture RAM to diagnose the failure(s).
Syntax
  frame <offset> <skip>
     <offest> and <skip> are <integers>
  . . .
  . . .
  . . .
  end frame
Parameters
 
<offset>
Tells the test system how many vectors to skip at the beginning of the frame before capturing data and storing it in deep-capture RAM.
<skip>
Tell the test system how many vectors to skip between captured vectors.
Examples
  compress             ! compression used
  frame
  pcf
  use pcf order Scan
  "00ZX"               ! captured for diagnostics
  "10ZX"               ! captured for diagnostics
  "00ZX"               ! captured for diagnostics
  . . .
  . . .
  "01ZX"               ! captured for diagnostics
  "11ZX"               ! captured for diagnostics
  end pcf
  end frame
  end compress
     compress
  frame 1 1
  pcf
  use pcf order Scan
  "00ZX"               ! skipped because of offset specified
  "10ZX"               ! captured for diagnostics
  "01ZX"               ! skipped
  "11ZX"               ! captured for diagnostics
  "00ZX"               ! skipped
  "10ZX"               ! captured for diagnostics
  . . .
  . . .
  "01ZX"               ! skipped
  "11ZX"               ! captured for diagnostics
  end pcf
  end frame
  end compress
General Information
If multiple frames are used in one VCL file, they must have identical structure.
