softkeys clear (BT-Basic)
Title: RECALL ALL DEFAULT SOFTKEY DEFINITIONS
If you have redefined the softkeys, you can globally reselect the system default definitions for all softkeys with the softkeys clear statement. However, the change is local and you must save the change with the softkeys to or softkeys over statement to make it permanent.
Syntax
  softkeys clear
  softkeys clear,<error variable>
     <error variable> is a <numeric variable>
Parameters
<error variable>
The identifier of an error variable.
Example
  softkeys clear          ! Resets all softkeys to their default definitions
  softkeys clear, Err     ! Includes an error variable
General Information
To redefine an individual softkey to its default definition, execute the softkey clear statement.
