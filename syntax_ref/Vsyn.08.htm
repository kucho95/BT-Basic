vector (VCL)
Title: START VECTOR BLOCK
The vector function marks the start of a vector block in the Vector Definition section of a digital test; it also assigns a name (identifier) to the vector defined by the statements in that block. The statements in the Vector Execution section of the test then reference that vector by its name. The end vector function marks the end of the block.
Syntax
  vector <vector id>
     <vector id> is a <label>
Parameters
<vector id>
The identifier of the vector. The identifier for each vector must be unique within the device test. The program generators may create a vector called Disablevector to disable the outputs of busable devices; so the identifier Disablevector cannot appear in a library test.
Example
  ! in the Declaration section
        . . . .
  assign A_Clk to pins 7, 2, 6, 9, 13
        . . . .
  ! in the Vector Definition section
        . . . .
  vector  Clock_A_hi          ! define a vector named "Clock_A_hi"
     set A_Clk to "11101"     ! set states on the pins
  end vector
        . . . .
