dll_ (BT-Basic)
Title: BT-Basic DLL INTEGRATION
A set of commands allows users to call external DLL functions from within BT-Basic. The external DLL must accept the call from BT-Basic, interpret the parameters and forward them to the actual functions, then return the function results to BT-Basic. Multiple DLLs may be loaded at the same time.
The commands are dllload, dllcall, and dllunload.
 
Table D-4 DLL commands
Command
Description
dllload
Loads the DLL into memory.
dllcall
Calls the DLL to execute a custom function; parameters can be specified.
The dllload command must be issued before this command can be used.
dllunload
Unloads the DLL.
 
 
The External Application DLL feature license is required to use this set of commands.
Example
dllload "flash.dll", Handle_1, Error
dllcall Handle_1, "blank_check", Var_1, ErrMsg$; "0, 0xffff"
dllcall Handle_1, "blank_check", Var_1, ErrMsg$, Error; "0, 0xffff"
dllcall Handle_1, "blank_check", , , Error; "0, 0xffff"
dllunload Handle_1
dllunload Handle_1, Error
dllunload             ! Unload all DLLs from memory
dllunload , Error     ! Unload all DLLs from memory, includes an error variable
dllload
dllload "<dll-name>", <dll-handle>, [<error variable>]
 
<dll-name>
The DLL filename. The absolute path can be included. If no path is specified, BT-Basic will look for the DLL in I3070_ICT_ROOT\ext_dev or in the custom_ext_dev folder under the current board directory.
<dll-handle>
The DLL handle to be used with subsequent DLL functions.
<error variable>
The identifier of an error variable.
dllcall
dllcall <dll-handle>, "<custom function name>", [<return number>], ["<return string>"], [<error variable>]; ["<custom parameters>"]
 
<dll-handle>
The DLL handle returned from dllload.
<custom function name>
The function name (maximum 80 characters).
<return number>
Numeric value returned from the called DLL function (optional).
<return string>
String value returned from the called DLL function (optional, maximum 2048 characters).
<custom parameters>
The parameters to be passed to the custom function (maximum 2048 characters).
<error variable>
The identifier of an error variable.
dllunload
dllunload [<dll-handle>], [<error variable>]
 
<dll-handle>
The DLL handle returned from dllload. When no dll-handle is specified, this command unloads all the DLLs from memory.
<error variable>
The identifier of an error variable.
