control (BT-Basic)
Title: CONTROL AN RS-232 PORT
The control function defines the parameters for an RS-232 port that was previously defined with an assign to function.
Syntax
  control @<name>, <register>; <data>
     <name> is a label
     <register> and <data> are <numeric expressions>
Parameters
@<name>
The at-name of an RS-232 port, where <name> is a <label>.
<register>
A number from 1 to 17 that identifies which control register the <data> is written to, where each register controls some aspect of serial data transfer. The register numbers and their functions are given in Table C-9.
<data>
A decimal number that defines parameters for an RS‑232 port.
 
Table C-9 Control register functions
Register Number
Function
1
Specifies basic terminal input control; corresponds to c_iflag in termio.
2
Specifies system treatment of output; corresponds to c_oflag in termio.
3
Specifies the hardware control of the terminal; corresponds to c_cflag in termio.
4
Specifies how the line discipline should control terminal functions; corresponds to c_lflag in termio.
5
Specifies the line discipline; corresponds to c_line in termio.
6
Defines which special character generates an interrupt signal; defaults to DEL (ASCII 16).
7
Defines which special character generates a quit signal; defaults to FS (ASCII 28).
8
Defines which special character erases the preceding character; defaults to # (ASCII 35).
9
Defines which special character deletes an entire line (as delimited by a NL, EOF, or EOL character); defaults to @ (ASCII 64).
10
Defines which special character denotes an end of file (EOF); defaults to EOT (^D or ASCII 4).
11
Defines which special character denotes an end of line (EOL); defaults to NUL (ASCII 0).
12
(reserved)
13
Defines the SWTCH character; defaults to NUL (ASCII 0).
14
A 0 sent to this register waits for the output to drain and then sends a break, and a 1 waits for the output to drain; corresponds to the ioctl TCSBRK command in termio. Note that the status function cannot be used to return the value of this register.
15
Controls start/stop. A 0 sent to this register suspends output, and a 1 restarts output; corresponds to the ioctl TCXONC command in termio. Note that the status function cannot be used to return the value of this register.
16
Flushes the input/output queues. A 0 sent to this register flushes the input queue, a 1 flushes the output queue, and 2 flushes both; corresponds to the ioctl TCFLSH command in termio. Note that the status function cannot be used to return the value of this register.
17
This register cannot be written to. A status function that specifies this register returns the number of characters immediately readable from the terminal device; corresponds to the ioctl FIONREAD command in termio.
Examples
  assign @Terminal to "/dev/tty"        ! Associates @Terminal with device "/dev/tty"
  control @Terminal, 3; oti ("1000")    ! Sets 1200 baud
  output @Terminal; Com$                ! Sends string Com$ sequentially to @Terminal
  assign @Terminal to *                 ! Ends the I/O operation
General Information
Use the status function to examine the values written to registers by the control function.
