combinatorial (VCL)
Title: COMBINATORIAL DEVICE TEST
The combinatorial function appears in the Declaration section of the test to indicate that the device to be tested is combinatorial. That is, the device has no memory, so its outputs at any time are a function only of its inputs at that same time. If the device type (combinatorial, sequential, or functional) is not specified, the test assumes that the device is sequential (i.e., has memory—see the sequential function).
If used, combinatorial must precede the assign to statements in the test. The combinatorial function is ignored if it is used in an executable test.
Syntax
  combinatorial
Parameters
(none)
Examples
  combinatorial
General Information
The combinatorial function contains information for the i3070 In-Circuit Test Software. For a combinatorial device, the generators discard the individual vector‑execution statements which have topology conflicts with the device description entered in the i3070 In-Circuit Test Software. For a sequential device, they discard the complete conflicting digital unit from the Vector Execution section of the test (see Resolving Topology Conflicts in Digital Testing).
