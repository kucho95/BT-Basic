powered (BT-Basic)
Title: PREPARE SYSTEM FOR POWERED TESTING
The powered function initializes the system to recognize and execute powered test statements (setup power supplies, digital testing, and analog functional testing statements). The powered function must appear before the call to the power supplies section of the testplan.
Syntax
  powered
Parameters
(none)
Example
  ! PREPARE THE SYSTEM FOR POWERED TESTING:
     powered
