log is (BT-Basic)
Title: OPEN DEFAULT LOG DEVICE
The log is function opens and closes the default log file, which is the file or device to which log records are sent by a log out function that does not specify any other log file. If there is no default log file, then log out must specify the name of the file to which the log records are to be sent.
When log is is executed, it first closes the current log file, if any, and then opens the new file. The type of access, shared, exclusive, etc., depends on the parameters used in the function. If the file does not exist, it is created; however, an error occurs if new is specified and the file already exists.
Once the default log file is established, it remains established, regardless of the number of times programs are run, until closed by another log is function, or by the user logging out.
Syntax
  log is <file id>
  log is <file id>,<error variable>
  log is <file id>,<error variable>;<access>
  log is <file id>;<access>
  log is *
  log is *,<error variable>
     <file id> is a <string expression>
     <error variable> is a <numeric variable>
     <access> can be:   <a/n/o>
                        <e/s>
                        <a/n/o>,<e/s>
                        <e/s>,<a/n/o>
        <a/n/o> can be:   append
                          new
                          over
        <e/s> can be:   exclusive
                        shared
Parameters
 
<file id>
The identifier of the file or device to be the new default log file. The old <file id> is closed and the new <file id> is then opened. If the new <file id> cannot be opened (it is already opened exclusively), the old <file id> remains as the default.
<a/n/o>
Determines how the data is written (the file is created if it does not exist). If not specified, defaults to over:
• append – Adds data below any existing data in the file (if none, writes from the beginning of the file).
• new – Creates a new file (an error occurs if it already exists) and writes from the beginning.
• over – Writes from the beginning of the file and destroys any existing data in the file.
<e/s>
Determines whether the file is opened for exclusive use or for shared use. If omitted, this parameter defaults to shared.
When a file is opened on a shared basis, only one user should write to it; the others should restrict themselves to reading from it. If more than one user writes to the file, the results can be unpredictable.
*
Asterisk closes the default log file without opening another file.
<error variable>
The identifier of an error variable.
Examples
  log is "logger"
  . . .
  log out              ! Output is sent to file "logger"
  T$ = "logger"
  log is T$            ! Same as above
  log is "/dev/printer", Err1; shared
  log is *             ! Closes the log file
