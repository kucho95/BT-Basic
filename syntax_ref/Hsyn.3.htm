heat source (SAFEGUARD)
Title: IC HEAT SOURCE DESCRIPTION
The heat source function appears in a SAFEGUARD file to describe the size of that part of an IC (e.g., a transistor emitter/base junction) which is heated by overdriving. When compiling the executable digital tests, the compiler uses this information for SAFEGUARD analysis.
Syntax
  heat source <length> by <width>
  heat source <length> by <width>, <number> per output
     <length>, <width> and <number> are <numeric constants>
Parameters
<length> & <width>
The length and width of the heat source in micrometers.
Defaults: <length> = 50, <width> = 10
Range: 0.001 to 50000
<number>
A positive integer designating the number of heat sources per output pin.
Default: 1
Range: 1 to 10000
Examples
  heat source 40 by 20
  heat source 40 by 20, 3 per output
