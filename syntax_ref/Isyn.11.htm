<line spec>
   /
   //
   // . . . . /
The <line spec> represents one or more EOL (End Of Line) sequences.
INPUT using <line spec>
When a <line spec> is used to input data, each / causes the input function to skip, i.e., read and discard, all characters up to the next EOL.
Example of data input with <line spec>
      ! File "tfile" contains the following records:
      ! "Test Data is contained in this record"(EOR)
      ! "Digital"(EOR)
      ! "Analog"(EOR)
      Read2: image 9a, /, 7a
      enter "tfile" using Read2;  T$, D$
      print D$; tab(9), T$     ! prints Digital Test Data
      !
      Read3: image 9a,//,6a
      enter "tfile" using Read3;  T$, D$
      print D$; tab(8), T$     ! prints Analog Test Data
OUTPUT using <line spec>
When a <line spec> is used to output data, for each / the image function outputs one EOL. The system automatically sends the proper sequence to all of the recognized standard and optional devices. For example, a CR/LF (Carriage-Return/Line‑Feed) is sent to a printer, and an EOR (End Of Record) to a file.
Example of data output with <line spec>
      A = 1
      TP: image 16x, 20a, 2/, 6a, 3d
      print using TP; "MONTHLY TEST REPORTS" , "TEST #", A
      !
      !          ‑‑16 spaces‑‑‑‑>‑‑‑‑20 spaces‑‑‑‑‑‑>
      ! prints:                  MONTHLY TEST REPORTS
      !
      !          TEST #   1
      !          ‑‑6‑‑>‑‑>
