jumper (ANALOG)
Title: JUMPER TEST
The jumper function is used within an analog in-circuit test block to test for the presence or the absence of a jumper. The test is essentially a resistor test that specifies a threshold value instead of tolerances. If the resistance measured is less than or equal to the threshold value, the test passes. If the measured resistance is greater than the specified threshold, the test fails.
Syntax
  jumper <specs>
  jumper <designator>,<specs>
     <designator> is a <string constant>
     <specs> can be:   <threshold>
                       <threshold>,<return>
                       <threshold>,<options>
                       <threshold>,<options>,<return>
        <threshold> can be a <numeric expression> or *
        <return> is a <numeric variable>
        <options> can be one or options, separated by commas (Table J-1).
Parameters
 
<designator>
A string constant of up to 16 characters which identifies the a subtest. If the component fails, the system includes the <designator> in the failure message sent to the report is device.
<threshold>
A numeric expression specifying a value in ohms. If the test measures a value less than or equal to the specified threshold, the jumper is considered present. Note that numeric expressions used in analog statements do not allow user-definable functions.
An asterisk (*) can be specified instead of a value in ohms. If an asterisk is specified, the results of the test are not compared to the limit; the test does not fail (if the op options is specified and an asterisk is used the <threshold> is effectively 0).
<options>
The test uses the default option values given in Table J-1, unless otherwise specified.
<return>
A numeric variable which holds the measured value.

Examples
  clear connect s to "J1-1"; i to "J1-2"
  jumper 10, pf, as
  clear connect s to "J2-1"; i to "J2-2"
  jumper 10, pf, as
  clear connect s to "J3-1"; i to "J3-2"
  jumper 100k, op, pf, as
General Information
You can use the pf option to specify that the test return only a pass or fail indication instead of an actual resistance value. This makes the failure report much clearer. With the pf option the test returns a 0 for a failing test and 1 for a passing test.
You can use the op, opposite, option to reverse the jumper test. The jumper test passes when the measured resistance is less than or equal to the threshold. So when a jumper is present, the test passes, and when the jumper is not present, the test fails. To test a jumper location where there is not supposed to be a jumper, you can use the op option with the jumper function. This specifies that the test passes when the measured resistance is greater than the threshold. So you can verify the absence of a jumper. This is useful for verifying the position of jumpers such as for line voltage selection.
