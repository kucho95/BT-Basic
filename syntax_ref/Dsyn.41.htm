display dump (DEBUG)
Title: SEND THE DISPLAY TO A FILE
The display dump function formats the current debug data and sends it in ASCII format to a specified file. The data in the file can then be printed, if required (use the save display over/to function if you need to recall the data to the display).
The dump retains the current display format—graphics, states or hex—and formats the data into pages, 80 characters wide by 66 lines long.
The over and to keywords act the same as they do for the copy over/to (BT-Basic) function: over creates a new file, or writes over an existing one; to creates the file, or generates an error if the file already exists.
If the optional vector numbers are specified, only the data from <start vector> to <stop vector> is dumped. If the vectors are not specified, all current debug data is dumped. If the start vector is not included in the current data, all current data up to the stop vector is dumped. If the stop vector is not included, all current data from the start vector is dumped.
The display marker and cursor are not dumped.
Syntax
  display dump over <file id>
  display dump over <file id> <start vector>,<stop vector>
  display dump to <file id>
  display dump to <file id> <start vector>,<stop vector>
  <file id> is a <string expression>
     <start vector> & <stop vector> are <numeric expressions>
Parameters
<file id>
The identifier of the file to which the data is sent.
<start/stop vector>
The number of the vector where the dump is to start/stop.
Examples
  display dump to "test_results"            ! sends data to file "test_results"
  display dump over "test_results"          ! overwrites data in "test_results"
  display dump over "test_results" 1,20     ! dumps vectors 1 through 20, inclusive
