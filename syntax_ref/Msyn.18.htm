msi$ (BT-Basic)
Title: LOCATE THE WORKING DIRECTORY
The msi$ function identifies the working (current) directory in the file system. It returns the pathname from the root to the current directory. Note that execution of this function does not change the working directory.
The maximum length of the string produced by this function is 256 characters.
Also see pwd
If the pathname is longer, msi$ will return as many characters as possible, starting from the end, to include the last complete node name before the 256 character limit. In this case, several node names may be truncated from the beginning, and the pathname will not begin with the root (/).
Syntax
  msi$
Parameters
(none)
Example
     !
     !
  mass storage is btgetenv$("I3070_ICT_ROOT") & "/Testfile"
                  ! Establish a working directory.
  print msi$      ! Identify the working directory (prints "$I3070_ICT_ROOT/Testfile")
  A$ = msi$       ! A$ contains "$I3070_ICT_ROOT/Testfile"
     !
     !
