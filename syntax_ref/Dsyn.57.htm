display scale (DEBUG)
Title: SCALE THE DISPLAY TO VIEW SUBCYCLES
(Mux systems only)
The display scale function scales the debug subvector display (display subvector function) so that you can view subcycles of the reference clock period, or in tests with timing sets, subcycles of the events in the timing sets. If no parameter is specified, the display scale is set to vector (i.e., one column per vector).
The scale value must be a sub‑multiple of the clock period, or of the event spacing for the test.
However, if you specify an incorrect value, the system automatically scales the display to the nearest acceptable value.
When displaying subcycles, the system uses a sampling technique to gather the received data; this slows the response of the display. The smaller the subcycles, the more samples must be taken, and the greater the number of samples, the slower the response.
Syntax
   display scale
   display scale <time>
      <time> is a <numeric expression>
Parameters
<time>
The display scale value in nano-seconds. The value is an integer which can range from 4 up to the event spacing, with a maximum value of 100.
Examples
   display scale 10   ! the scale is 10 ns
   display scale      ! the scale reverts to "vectors"
