rps (BT-Basic)
Title: READ DUT POWER SUPPLY OUTPUT VOLTAGE AND CURRENT
The rps statement returns the present values of current and voltage for a selected DUT power supply. Before executing rps, the powered and cps statements must have been executed.
Syntax
  rps <ps_number>, <voltage>, <current>
  rps <ps_number>, <voltage>, <current>, <error variable>
     <ps_number> is an integer from 1 to 32
     <voltage> is a <numeric variable>
     <current> is a <numeric variable>
     <error variable> is a <numeric variable>
Parameters
<ps_number>
An integer that identifies the power supply (1 to 32) to be read.
<voltage>
The value of the DUT supply output voltage (V).
<current>
The value of the DUT supply output current (A).
<error variable>
The error variable.
Example
  faon
  powered
  cps
  sps 1,5,500m
  sps 2,12,800m
  rps 1,V_1,C_1     ! V_1 = 5     C_1 = 350m
  rps 2,V_2,C_2     ! V_2 = 12    C_2 = 550m
