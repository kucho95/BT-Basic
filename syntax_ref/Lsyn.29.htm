log clear (BT-Basic)
Title: CLEAR LOG DATA STORED IN BUFFER
The log clear function clears the buffer of all test data.
Syntax
  log clear
Parameters
(none)
Examples
  All = 4 ! Number of boards on a panel
  :
  for Board_tested = 1 to All
     input "Read bar code on next board." , Board_id$
     Board_data$ = trim$(Board_id$)
     faon
        ! Test program module
        ! (Testplan modified for four identical tests.)
     faoff
     log out Board_data$         ! Store test failure data
     log clear                   ! Clear data in buffer
     clear failures              ! Clear failure flags
     print "Board"; Board_data$; ", number "; Board_tested; " done."
  next Board_tested
  :
General Information
Most test programs include a prompt line telling the operator to press the START key. In the program, this prompt is followed by the wait for start function. log clear can be used in a similar manner by using an input function that prompts the user to press the Return key. Unlike the wait for start function, log clear does not clear failures, or check the autofile code on the test fixture.
log clear can be used to store test failure data as individual records when testing multiple, identical boards on a single panel. The test failure data is stored using a log out function prior to log clear. Because log out does not automatically clear the failure flags, a clear failures function should follow log clear in your program. This precaution assures that none of the tests within the sequence are adversely affected by a previous test failure.
When using multiple board states (board number is function) to test a multi‑board panel, the log clear function clears the log buffer for the current board.
