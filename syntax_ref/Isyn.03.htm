ignore all failures (BT-Basic)
Title: HALT FAILURE PROCESSING
The ignore all failures function turns off failure processing which was established by default or by the acknowledge all failures function.
With this function, you can obtain the estimated execution time of a program before a fixture is built, without interruptions by failures. (However, fixture enable and safety disable jumpers must be present.)
Note that the boardfailed variable is not affected by ignore all failures. And, because no failures are processed after execution of this function, the dutfailed function always returns a 0 (false) after the next test function is executed.
Note that even though failure processing of digital tests is turned off, the digital test is halted at the first failure. See the description of the ignore digital failures function.
The acknowledge all failures function resumes error processing. See the syntax description of the acknowledge all failures function for details.
