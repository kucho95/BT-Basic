first pass yield (BT-Basic)
Title: First Pass Yield (FPY)
The first pass yield function specifies the counters that will be used to update the first pass yield information in the operator interface. The FPY data is also recorded in the file FirstPassYield\first_pass_yield.txt, located in the board directory of the board under test.
Syntax
   first pass yield <status>, <tested>
      <status> can be 0 or 1
      <tested> can be 0 or 1
Parameters
<status>
Number of boards passed or failed.
0 – failed
1 – passed
<tested>
Number of boards tested.
0 – not tested
1 – tested
Examples
  first pass yield 0, 1 ! FPY Failed, Tested
  first pass yield 1, 1 ! FPY Passed, Tested
  first pass yield 0, 0 ! Clear the FPY data
