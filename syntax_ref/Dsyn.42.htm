display failure (DEBUG)
Title: START THE DISPLAY AT THE FIRST FAILING VECTOR
The display failure function runs the test to the first failing vector and homes the window directly to that vector. The function collects new data for all lines currently in the display and adds a new line for each pin that fails and that is not already in the display. The display must be set to vectors when the display failure function is executed (see display vector).
The recycle parameter executes the test repeatedly until a failure occurs, or until the BREAK key is pressed.
Syntax
  display failure
  display failure; recycle
   display failure, <error variable>
   display failure, <error variable>; recycle
     <error variable> is a <numeric variable>
Parameters
(none)
Examples
  display failure
  display failure, Error; recycle
