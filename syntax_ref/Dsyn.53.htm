display previous (DEBUG)
Title: DISPLAY PREVIOUS OCCURRENCE OF A SPECIFIED STATE
The display previous function displays the previous occurrence of the specified state on the logic analyzer line at which the cursor is currently positioned. This function operates only with the states display.
It shows either the expected or actual state according to the current selection for the display. This function cannot be used with the hand-held probe.
Syntax
  display previous <resource type> state <state>
     <resource type> can be:   driver
                               receiver
     <state> can be:   "0"
                       "1"
                       "Z"
                       "X"
Parameters
<resource type>
The direction of the node represented by the current line.
<state>
The type of state that is to be displayed.
Examples
  display previous driver state "1"
