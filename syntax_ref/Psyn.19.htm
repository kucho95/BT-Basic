pins (BT-Basic)
Title: INVOKE PINS MODE
The pins function clears everything currently in the workspace and sets the workstation to pins mode. In this mode all statements entered into the work area of the screen are syntax-checked to ensure that they are valid pins statements.
Loading an existing pins file into the work space from any other mode automatically sets the mode to pins.
Syntax
  pins
  pins; <option>
     <option> can be:   window
                        nowindow
Parameters
<option>
Either window or nowindow.
• window opens a new window in pins mode
• nowindow suppresses the opening of a new window (if your test system is configured to automatically open a new window whenever a mode change is specified).
Example
  text            ! Sets the "text" mode; all syntax checking is turned off.
  pins            ! Sets "pins" mode.
  pins;window     ! Opens a new window and sets "pins" mode in it.
General Information
The pins function is not programmable.
