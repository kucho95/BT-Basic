save (BT-Basic)
Title: SAVE THE WORKSPACE IN A NEW FILE
The save statement creates an ASCII file and stores the lines currently in the workspace into it. The workspace remains unchanged. The file must not exist prior to executing this statement.
If the mode is not specified, the current mode of the workspace is recorded in the file. If the mode is specified, it must be the same as the current mode of the workspace, or be text. If text is specified, text mode is recorded in the file, regardless of the current mode of the workspace.
Syntax
  save <file id>
  save <file id>,<parameters>
  save <mode> <file id>
  save <mode> <file id>,<parameters>
     <file id> is a <string expression>
     <mode> can be:
        analog
        basic
        configuration
        digital
        pins
        safeguard
        shorts
        states
        testorder
        text
        wirelist
     <parameters> can be:
        <first line>
        <first line>,<last line>
        <first line>,<last line>,<error variable>
        <first line>,,<error variable>
        ,<last line>
        ,<last line>,<error variable>
        ,,<error variable>
           <first line> is a <numeric constant>
           <last line> is a <numeric constant>
           <error variable> is a <numeric variable>
 
 
 
If an intermediate parameter is omitted, the syntax requires a comma if a later parameter is included.
Parameters
 
<file id>
The identifier of the new file to be created. It must not already exist, and it cannot represent a device.
<mode>
The mode to be recorded in the file.
<first line>
A positive integer that specifies the number of the first line to be saved in the file. The line must exist in the workspace. If this parameter is omitted, it defaults to the first line in the workspace.
<last line>
A positive integer that specifies the number of the last line to be saved in the file; any subsequent lines in the workspace are ignored. If this parameter is omitted, it defaults to the last line in the workspace.
If <last line> is specified and it is beyond the last line in the workspace, the existing last line is assumed.
<last line> must be equal to, or greater than, the number of the first line to be saved.
<error variable>
The identifier of an error variable.
Example
  save "/market/ts/my‑file"          ! Saves all lines in the workspace
  msi "/production/test/a3564b"
  save "report1", 25                 ! Saves lines 25 to end of workspace
  save "report2", 62,136             ! Saves lines 62 through 136
  save "report3",,, Alpha            ! Saves all lines: error variable specified
                                     ! ‑ note the "place‑saving" commas
  save text "board‑47/shorts1",2,4,Err
General Information
The save and store statements are identical.
