trigger (BT-Basic)
Title: GROUP EXECUTIVE TRIGGER
The trigger statement sends the Group Executive Trigger message (GET) to the GPIB interface. A trigger message causes a device, or group of devices, to initiate some device‑dependent activity; e.g., a counter starts counting.
If the bus as a whole is addressed (<GPIB>), then all devices currently set to listen respond. If the statement addresses a specific device (<GPIB device>) which is not a listener, that device is set to listen and then it responds. If a current listener is addressed, then all current listeners respond, just as if the bus was addressed.
Syntax
  trigger <GPIB>
  trigger <GPIB device>
     <GPIB> and <GPIB device> can be:
        <file id>
        @<name>
           <file id> is a <string expression>
           <name> is a <label>
Parameters
<GPIB>
The address of the bus.
<GPIB device>
The address of the selected GPIB device.
Example
Shortcut Method:
  trigger "/dev/hpib1"          ! Sends GET to the bus, all current listeners respond
  assign @Auto_DVM to "/dev/dmm"
  trigger @Auto_DVM
 
Absolute Path Method:
  Bus$ = btgetenv$("I3070_ICT_ROOT")
  trigger Bus$&"/dev/hpib1"     ! Sends GET to the bus, all current listeners respond
  assign @Auto_DVM to Bus$&"/dev/dmm"
  trigger @Auto_DVM
General Information
 
 
These examples assume the dev file hpib1 contains the SICL interface name hpib7.
