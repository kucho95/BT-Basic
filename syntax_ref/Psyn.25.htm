potentiometer (ANALOG)
Title: POTENTIOMETER TEST
This function is used within an analog in-circuit test block to test potentiometers. Potentiometers (pots) are defined as three-legged variable resistors where none of the three legs are connected to each other.
Variable resistors, which have two of their three legs connected together, are not considered to be potentiometers, and like fixed resistors are tested with the resistor (analog) function and ad, adjust, option.
Syntax
  potentiometer <specs>
  potentiometer <designator>,<specs>
     <designator> is a <string constant>
     <specs> can be:   <value>,<+tol>,<‑tol>
                       <value>,<+tol>,<‑tol>,<return>
                       <value>,<+tol>,<‑tol>,<options>
                       <value>,<+tol>,<‑tol>,<options>,<return>
        <value> is a <numeric expression>
        <+tol> and <‑tol> can be <numeric expressions> or *
        <return> is a <numeric variable>
        <options> can be one or more of the options in Table P-3, separated by commas.
Parameters
 
<designator>
A string constant of up to 16 characters which identifies the a subtest. If the component fails, the system will include the <designator> in the failure message sent to the report is device.
<value>
A numeric expression which represents the expected value in ohms. Note that numeric expressions used in analog statements do not allow user-definable functions.
<+tol> & <-tol>
Numeric expressions which specify the plus and minus tolerances, respectively, as percentages. Note that numeric expressions used in analog statements do not allow user-definable functions.
The upper and lower test boundaries are computed as shown:
• upper = <value> * (1 + (<+tol>/100))
• lower = <value> * (1 ‑ (<‑tol>/100))
An asterisk (*) can be used in place of zero. If zero or * is specified for both tolerance values, the results of the test are not compared to any limits; the test will not fail.
<options>
The test uses the default option values in Table P-3 when the DC source is used (fr is not specified) unless otherwise specified. When the AC source is used, the options are the same except that fr is specified and pm (parallel mode) is used.
<return>
A numeric variable which holds the measured value.

Example
  on failure report "PART NUM: 1145-0081; LOCATION: I7"
  clear connect s to "R1_W"; i to "R1-1"
  potentiometer "LEG1", 5k, 12, 12, wb, ad, R, as
  clear connect s to "R1_W"; i to "R1-3"
  potentiometer "LEG2", 5k, 32, 32, wb, ed, as
General Information
Potentiometers are measured twice. First, the potentiometer function is executed with the ad option to allow the operator to center the wiper of the potentiometer. This measurement checks the resistance between the wiper and one leg. Then, the function is executed again, without the adjust option, to measure the resistance between the other leg and the wiper. The result of each measurement is compared to half of the potentiometer's value. The second measurement has wider tolerances to accommodate any inacurracy in the adjustment.
