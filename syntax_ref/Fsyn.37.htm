format (VCL)
Title: ESTABLISH FORMAT FOR THE SET TO STATEMENTS
The format function determines the format of the pin states assigned to specified groups of pins by the set to (VCL) statements used to define vectors. Possible formats are binary (each state applies to one pin), octal (each state applies to three pins), or hexadecimal (each state applies to four pins).
Any given format function affects only the set to statements which are located after it in the test. Later format statements can override the earlier format statements. The format function can be used in the Declaration and Vector Definition sections of the test. However, if the test uses timing sets (allowed on Mux systems), the function can be located only in the Declaration section.
The format function does not affect the default pin states optionally included in the assign to (VCL) function. Neither does it affect the PCF vectors, which are always binary.
Each time a pin group has states assigned to it, the group has the format established by the latest format function that specifies that group. If a format function is located in a vector block, that format also applies to any later defined vectors which reference its pin groups. Groups which are not specified by any format function default to binary. Refer to the set to function for a description of the way in which the formats affect the vector definitions.
There can be any number of format statements in a test.
Syntax
  format <number base> <group id>
  format <number base> <group id>,<group id>
  format <number base> <group id>,<group id>, . . .<group id>
     <number base> can be:   binary
                             octal
                             hexadecimal
     <group id> is a <label>
Parameters
<number base>
The format of the characters in the state specification strings in the set to statements which reference the listed pin groups. The default is binary format (i.e., one pin per state).
<group id>
The identifier of a group of pins which is to have the specified format.
Examples
  (See also the "set to" function)
  format hexadecimal Bus_out
  format octal Inputs_1, Inputs_2
        . . .
     set Bus_Out to "9"      ! same as binary "1001"
     set Inputs_1 to "5"     ! same as binary "101"
