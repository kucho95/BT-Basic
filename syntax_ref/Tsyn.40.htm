timeout (BT-Basic)
Title: DEVICE TIMEOUT
The timeout statement sets a timeout for the specified device (which must be associated with an @<name> by an assign to statement). Note that this does not affect the timeout of digital tests.
The effect of this statement is to set the maximum time limit for a peripheral device to respond after receiving a command from a system controller. For example, consider the following situation:
• The system controller instructs the ASRU Card to take a measurement and return the results via a measure statement.
• Due to an optional wait parameter included in an associated detector statement, the measurement takes longer than the timeout value currently specified for the ASRU Card’s GPIB bus.
In the above situation an GPIB timeout error would occur. The problem can be corrected by increasing the timeout to a value large enough to allow the measurement to complete.
Once a timeout value is set for a device or bus, it remains in effect until another timeout statement is executed for that bus or device. Timeouts are independent of logging out.
Syntax
  timeout @<name>,<seconds>
     <name> is a <label>
     <seconds> is a <numeric expression>
Parameters
@<name>
A label that is associated with a device file identifier using the assign to statement. The @<name> can be associated with any device in the /dev directory.
When a timeout is set for either an GPIB bus or an GPIB device, that timeout is inclusive for the bus and all devices on that bus.
<seconds>
The timeout in seconds, which must be in the range 0.01 seconds to 2000 seconds.
Example
Shortcut Method:
  assign @Auto to "/dev/hpib1"
  timeout @Auto, 1                      ! Sets a 1 second timeout
  Time = 150m | timeout @Auto, Time
Absolute Path Method:
  Bus$ = btgetenv$("I3070_ICT_ROOT")
  assign @Auto to Bus$&"/dev/hpib1"
  timeout @Auto, 1                      ! Sets a 1 second timeout
  Time = 150m | timeout @Auto, Time
General Information
Default time-outs are automatically set when a device or bus is installed in the /dev directory. Table T-2 lists the default timeout values for all devices and buses in the /dev directory that are affected by the timeout statement.
 
Table T-2 Default timeout
Device Type
Default Timeout Value
testhead
4 seconds
all other types
5 seconds
 
 
These examples assume the dev file hpib1 contains the SICL interface name hpib7.
