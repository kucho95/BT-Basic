grade tests (BT-Basic)
Title: GRADE TESTS WITH THE BOARD TEST GRADER
The grade tests (BT-Basic) function instructs the Board Test Grader to grade the device tests. There are three steps to grading the device tests, they are:
1 Create a configuration file.
2 Create a testplan.
3 Generate the grading reports.
Syntax
  grade tests; <action>
     <action> can be:   configuration
                        testplan
                        report
Parameters
<action>
The options are:
• configuration – Creates a configuration file, config.bdg.
• testplan – Creates a testplan for grading tests, testplan.bdg
• report – Generates the grading reports.
Examples
  grade tests; configuration
  grade tests; testplan
  grade tests; report
