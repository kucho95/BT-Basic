Statement
The statement is the fundamental executable unit of the system's language. Most BT-Basic statements can be executed both from the command line in the display and from a program. Each statement has one or more keywords, which define what the statement does. Most statements also have one or more parameters (data) on which to operate.
A statement can have up to 2048 characters (up to one line length), including spaces. There can be more than one statement on a line, but a statement cannot be continued on a second line.
Example 10 Examples of statements
  stop
  print "Total = ", Sum(6)
  copy "Myfile" to "Yours"
  enter @Tape using Form$; A,B,C,Que$
  Sine=sin(pi/2) | A=6   ! two statements on a line, separated by "|"
