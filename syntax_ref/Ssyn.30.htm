set ref (DEBUG)
Title: TEMPORARILY CHANGE DRIVER/RECEIVER VOLTAGES
The set ref statement changes the driver and receiver, high and low reference voltages on the specified pins and nodes. This statement is similar to the set ref (VCL) statement, except that, in debug, set ref can also set reference voltages on the probe.
The probe can be designated as a receiver, but not as a driver. However, the probe can be used as a receiver on a driven node, to determine that the system is driving the correct signal to that node.
The voltage levels are:
• dh (driver high)
• rh (receiver high)
• dl (driver low) - Mux systems only
• rl (receiver low) - Mux systems only
Syntax
  set ref on <identifiers> to <ref specs>
     <identifiers> can be:   device <designator>
                             device <designator> pins <pin‑id list>
                             groups <group-id list>
                             nodes <node-id list>
                             pins <pin-id list>
                             probe
        <designator> is a <string expression>
        <pin-id list> can be:   <pin id>
                                <pin id>,<pin id>
                                <pin id>,<pin id>, . . . <pin id>
           <pin id> is a <string expression>
        <group-id list> can be:   <group id>
                                  <group id>,<group id>
                                  <group id>,<group id>, . . . <group id>
           <group id> can be:   <label>
                                <string expression>
        <node-id list> can be:   <node id>
                                 <node id>,<node id>
                                 <node id>,<node id>, . . . <node id>
           <node id> is a <string expression>
     <ref specs> can be:   <level>               ! On UnMux systems
                           <level>,<level>
        <level> can be:   dh <volts>
                          rh <volts>
     <ref specs> can be:   <level>               ! On Mux systems
                            <level>,<level>
                            <level>,<level>,<level>
                            <level>,<level>,<level>,<level>
         <level> can be:   dh <volts>
                           dl <volts>
                           rh <volts>
                           rl <volts>
           <volts> is a <numeric expression>
Parameters
<identifiers>
The list of drivers/receivers whose reference voltages are to be changed.
<designator>
String constant representing a device. The device must be referenced in the test being debugged.
<id list>
The list of pins or nodes to be changed.
<ref specs>
The types of circuits (driver or receiver), and their voltage levels, to be assigned to the listed pins. These can be specified individually or in pairs; the circuit type must match the pin type.
<volts>
The drive and receive reference voltage; the units are volts.
0.0 <= volts <= +5.0
Example
  set ref on device "U68" pins "13", "11" to rh 4.2
  set ref on pins "6","3" to dh +1.08
  set ref on groups Clock, "Reset" to dh 1.2
  set ref on probe to rh 4.2
  set ref on nodes "both_ways" to dh 3.5, rh 2.0
