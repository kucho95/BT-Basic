learn (BT-Basic)
Title: THE LEARN FLAG
The learn function is used to turn on or off a program flag. The flag is used with digital tests using CRCs and with Connect Check tests on Mux systems. Once set on, the flag remains on until it is turned off or until the user logs off the system. If the flag is not turned on, it defaults to off.
The learn flag is used in conjunction with the test function to learn and store data from a known good board.
In digital testing (see the test function), only those statements which request a CRC (Cyclic Redundancy Check) must be run with learn on, to learn CRCs. If a VCL test runs with the learn flag on, the test learns data from the board and saves it in the object file (the source file is not updated) for the test. When the test runs with learn off, the test compares data read from the board with the data saved in the object file. If the two are the same, the test passes; if they are different, the test fails.
The <number of> parameter in the learn function determines the number of times the test reads each set of data when the learn flag is on. Each time the data is reread, it is compared with what was previously read. If there is any inconsistency, then an error message is generated and the data is not stored. If all readings of the data are the same, then it is assumed to be good data and is stored for future testing purposes.
For Connect Check tests on Mux systems, the stimulus pins and measurement values are learned. Both the source file and the object file are updated.
Syntax
  learn on
  learn <number of> times
  learn off
     <number of> is a <numeric expression>
Parameters
<number of>
Number of times the data is to be read before it is stored:
1 ≥ value ≥ 32767
If the data is not exactly the same for each reading then it is not stored. If not specified, the value defaults to 1 (learn on) and the data is stored as read.
Examples
  learn 10 times        ! data is read 10 times
  learn A times
  learn on              ! same as — learn 1 times
  learn off             ! don't learn—used for testing
