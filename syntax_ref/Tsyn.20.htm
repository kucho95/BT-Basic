test on boards (BT-Basic)
EXECUTE TESTS FOR PANELTEST AND THROUGHPUT MULTIPLIER OR ADVANCED THROUGHPUT MULTIPLIER
The test on boards statement executes the specified test on all boards that have a status of non-zero in the specified board states array.
The board states array is a one-dimensional numeric array created by the testplan. There is one board states array for each board type on the panel.
Syntax
  test <test id> on boards <array id>
     <test id> is a <string expression>
     <array id> is a <label>
Parameters
<test id>
A string expression that identifies the test to be executed. This is the non-expanded name of the test.
<array id>
A label that identifies the array.
Example
  dim BoardSet_Boards_1_to_5 (1:5)
  dim BoardSet_Boards_6_to_9 (6:9)
  ! set boardset 1 to 5 bits. 1 to 5 to "1"
  ! set boardset 6 to 9 bits. 6 to 9 to "1"
  test "u10" on boards BoardSet_Boards_1_to_5(*)
                                            ! Test U10 on boards 1 through 5.
  test "u10" on boards BoardSet_Boards_6_to_9(*)
                                            ! Test U10 on boards 6 through 9.
