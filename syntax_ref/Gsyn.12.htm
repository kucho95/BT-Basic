generate static test (VCL)
Title: PRECOMPILE DYNAMIC DATA FROM DATA FILES
The generate static test function instructs the compiler to read data from data files into the test when the executable version of the test is compiled—the function is ignored by the library compiler. The function must appear near the beginning of the test, before any of the assignment statements. Without this function, the data is read during the first run of the test.
The data files are identified by files (VCL) statements in data blocks in the test. If the files are not available when the test is compiled, an error is generated. In this case, either comment out the generate static test function or provide the required data files before recompiling.
