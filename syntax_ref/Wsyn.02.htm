wait (ANALOG)
Title: WAIT
The wait function causes the test to wait the specified number of seconds before executing the next function.
Syntax
  wait <time>
     <time> is a <numeric expression>
Parameters
<time>
The number of seconds to wait before executing the next function.
Example
  !  Wait five seconds before executing the next function.
     wait 5
