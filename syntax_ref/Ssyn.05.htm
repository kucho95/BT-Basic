save display (DEBUG)
Title: SAVE CURRENT DEBUG SETTINGS
The save display statement saves the current debug settings and display coding in a file. The saved data can then be recalled later so that debugging can continue with the same data (see the recall display statement). The saved data does not include the test‑specific data; that is regenerated when the data is recalled.
The over and to keywords act the same as they do for the copy over/to (BT-Basic) statement: over creates a new file, or writes over an existing one; to creates the file, or generates an error if the file already exists.
Use the display dump (DEBUG) statement if the screen is to be printed.
Syntax
  save display over <file id>
  save display to <file id>
     <file id> is a <string expression>
Parameters
<file id>
The identifier of the file to which the data is sent.
Example
  debug "digital/u34"
     . . .
  save display to "sample"
  debug end
  ! at a later time . . .
     . . .
  debug "digital/u34"
  recall display from "sample"
