listn (edit)
Title: LIST THE WORKSPACE FROM THE CURRENT LINE
The listn function prints the contents of the workspace from the current line to the end of the workspace. The printout goes to the default print device, unless the default has been changed by a printer is function.
Line numbers are printed to the left of each line, as shown in the example below.
Lines longer than 72 characters are split into two lines when printed.
Syntax
  listn
Parameters
(none)
Examples
     ! Line one
     ! Line two
   ‑ ! Line three     <‑‑‑‑  cursor positioned at this line
     ! Line four
     ! Last line
  listn
     ! prints   3: Line three
                4: Line four
                (# of last line): Last line
General Information
The listn function is not programmable. Also see the list and listm statements.
