board placement (BT-Basic)
Title: RUN BOARD PLACEMENT
The board placement function executes the Board Placement program of the Fixture Generation Software. Board Placement automatically determines the board’s locality on the test fixture and specifies the placement in the fixture.o file. You can manually control the placement of the board by supplying placement information in the board_xy file or with the board placement function.
The board placement is specified as:
• X and Y direction offsets of the board origin from the bank 2 fixture origin.
For bank 1 fixtures, add 142500 tenth-mils to the X offset.
• Number of degrees to rotate the board; a positive rotation is counter-clockwise and a negative rotation is clockwise. If you do not want to rotate the board, specify a rotation of 0.
Note the board is rotated first, then the X and Y offsets are applied.
On i3070 Series 5 (i307x, i317x, i327x) Systems
• Board Placement automatically positions the board so that it is compatible with the Express Cassette fixture even if you are using the SimPlate Express fixture. Board Placement has no action for the SimPlate Fixture.
• You can also use the center keyword to instruct Board Placement to position the board on the fixture so that the board is centered over the testhead resources (configuration). If you specify only the X offset or the Y offset, and include the center keyword, the board is centered over the testhead resources for the direction that was not specified.
• If you instruct Board Placement to center the board for the SimPlate Express fixture, Board Placement may move the board in both the X and Y directions.
• The placement is not compatible with the Express Cassette fixture. It may also cause the need for a larger support plate on the test fixture. If you instruct Board Placement to center the board for the Express Cassette fixture, Board Placement moves the board in thes X direction only.
On i3070 Series 5i Inline Systems
• The default placement of the board is at the center of the modules with the edge of the board 28.1 mm from the front edge of the fixture.
Setting a default for the center keyword
You can set a default for the center keyword with the Bpl.center parameter in the .hp3070 file. The software uses the default value.
• To instruct Board Placement to always use center, add the following line to the .hp3070 file:
  Bpl.center: Yes
• To instruct Board Placement not to use center add the following line:
  Bpl.center: No
• If the Bpl.center parameter is not specified, the default is No.
Providing a complete board placement (X offset, Y offset, and rotation) overrides the center keyword and default.
Syntax
  board placement
  board placement <option list 1>
  board placement; <option list 2>
  board placement <option list 1>; <option list 2>
     <option list 1> can be:
                        <directory name>
                        <directory name>, <error variable>, <error variable>
     <directory name> is a <string expression>
        <error variable> is a <numeric variable>
     <option list 2> can be:   <item>
                               <item>, <item>
                               <item>, <item>, . . . <item>
        <item> can be:   center
                         rotation <r>
                         xoffset <x>
                         yoffset <y>
                         <experience level>
                         <backup level>
           <r> is a <numeric constant>
           <x> is a <numeric constant>
           <y> is a <numeric constant>
           <experience level> can be:   standard
                                        advanced
                                        expert
           <backup level> can be:   numbered
                                    unnumbered
                                    nobackup
Parameters
 
<option list 1>
Can be either the directory pathname, or an error variable, or both.
<option list 2>
A list of optional parameters that determine how the function works. The options are listed below.
center
Instructs Board Placement to center the board over the testhead configuration. If either the X offset or Y offset is specified, the center keyword instructs Board Placement to center the board in the direction that is not specified.
rotation <r>
Specifies the rotation of the board in degrees; positive values specify a counter-clockwise rotation, negative values specify a clockwise rotation.
xoffset <x>
Specifies the offset in the X direction, from the bank 2 fixture origin, in tenth mils.
yoffset <y>
Specifies the offset in the Y direction in tenth mils.
<experience level>
Sets the length (thoroughness) of the error messages the user receives and can also be used to restrict the user to a subset of the full system features. Permissible values are: standard, advanced, and expert.
<backup level>
Determines if the program stores an unchanged copy (a backup) of files before modifying them, and how the backup is stored. Permissible values are:
• nobackup – No file backup is made.
• numbered – Makes up to nine backups, each numbered sequentially with .#~, such as file.1~. Number one is the most recent backup. When more than nine backups occur, the oldest file is discarded, and the others are renumbered.
• unnumbered – A single backup is made. The backup file name is appended with a tilde (~); for example, file~.
Examples
  board placement "/boards/cpu_board",E
           ! Let Board Placement determine the position of the board for the            ! /boards/cpu_board directory. E is the error variable.
     board placement; xoffset 1000, yoffset 5000, rotation 0.0
           ! Run Board Placement on the current directory and move the board
           ! 0.1 inch in the X direction, and .5 inches in the Y direction.
     board placement; yoffset 5000, rotation 0, center
           ! Run Board Placement on the current directory, move the board
           ! 0.5 inches in the Y direction, and center the board in the X direction.
General Information
The i3070 In-Circuit Test Software automatically runs Board Placement during test development.
