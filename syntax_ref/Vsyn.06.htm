values (VCL)
Title: ASSIGN VALUES TO A DATA BLOCK
The values function appears in a data block in the Vector Definition section of a test to assign values to the block. The values can be numeric constants, or can be numeric variables passed to the test when it is executed. The values are saved in 32-bit, two’s complement format and can represent values or ASCII characters. The values are binary and are not subject to format statements.
The values will be read from the block in the same order they are assigned to the block. Also see the file function.
Syntax
  values <value list>
     <value list> can be:   <value>
                            <value>,<value>
                                 <value>, <value>, . . . <value>
        <value> can be:   <integer constant>
                          <variable>
        <variable> can be:   <variable id>
                             <array id>(<element>)
                             <array id>(<start element>:<end element>)
           <id> is a <label>
           <element> is an <integer constant>
Parameters
 
<value>
A single value, or a set of values to be assigned to the block. A <value> can be a constant, a variable, an array element, or a set of contiguous array elements. Arrays passed to the test must be one dimensional. All arrays in VCL are zero-based.
<start/end element>
Specifies the first and last elements to be read from the array. Starting with the start element, all elements up to, and including, the end element will be read from the array into the block.
<label>
This is the same as a BT-Basic <label>. It can contain up to 32 characters, but with no spaces. The first character must be an uppercase letter and the remaining characters can be letters, numbers, or underscores (_).
Example
  ! in the Declaration section of the test
        . . .
  assign Write_enable to pins 10,12
  assign Data_bus to pins 1, 2, 3
        . . .
  ! in the Vector Definition section of the test
        . . .
  data FlashRAM_Data to groups Data_bus
     values 2, 3, 7, 6
     values A(3), A(9), A(21)
     values B(2:51)
     file "Data_File" 120
  end data
  ! in the Vector Execution section
        . . .
  execute V1 drive data FlashRAM_Data
        . . .
