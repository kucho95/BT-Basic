softkey clear (BT-Basic)
Title: RECALL A DEFAULT SOFTKEY DEFINITION
If you have redefined the softkeys, you can reselect the system default definition for any softkey with the softkey clear statement.
This statement will redefine a specified softkey to its default definition without affecting the other softkeys. However, the change is local and you must save the change with the softkeys to or softkeys over statement to make it permanent.
Syntax
  softkey clear <key>
  softkey clear <key>,<error variable>
     <key> is a <numeric expression>
     <error variable> is a <numeric variable>
Parameters
<key>
Identifies the softkey for which you want to select the system default definition. The numeric expression must resolve to a number from 1 to 8, inclusive after rounding.
<error variable>
The identifier of an error variable.
Example
  softkey clear 3     ! Resets f3 to its default definition.
General Information
To globally redefine all softkeys to their default definitions, execute the softkeys clear statement.
