topology get devices (BT-Basic)
Title: GET THE NAMES OF THE DEVICES FROM THE BOARD FILE
The topology get devices function fills a string array with the names of devices in the board file. You can get the names of all devices or the names of a specified type of devices.
Syntax
  topology get devices <type>, <array id>
  topology get devices <type>, <array id>, <error variable>
     <type> is a <numeric expression>
     <array id> is a <string array>
Parameters
<type>
A numeric expression that represents the type of devices. The values for <type> are:
• 0 – All devices
• 1 – Undefined devices
• 2 – Capacitors
• 3 – Connectors
• 4 – Diodes
• 5 – FETs
• 6 – Functional devices
• 7 – Fuses
• 8 – Inductors
• 9 – Jumpers
• 10 – Library devices
• 11 – Potentiometers
• 12 – Resistors
• 13 – Switches
• 14 – Transistors
• 15 – Zeners
<array id>
The name of the array.
Example
  dim Devices$(1:100)[48]                 ! Dimension an array.
  topology get devices 0, Devices$(*)     ! Places the names of all devices in
                                          ! the Devices array.
  dim Devices$(1:100)[48]                 ! Dimension an array.
  topology get devices 2, Devices$(*)     ! Places the names of all capacitors
                                          ! in the Devices array.
General Information
To use any of the topology access functions you must first load the board file into memory.
To load a board object file, board.o, into memory execute the load board statement.
To remove a board file from memory use the scratch board statement.
The load board statement automatically scratches any file that is presently in memory.
