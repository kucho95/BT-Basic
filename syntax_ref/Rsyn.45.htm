rti delay (ITL)
Title: Set Run-Test/Idle delay
The rti delay statement appears between the Test Type statement and the chain description block of the boundary-scan (interconnect, powered short, buswire) ITL file.
A capacitor placed between non-compliant IEEE 1149.1/1149.6 differential pins might interfere during boundary-scan testing. For example, a 0.1 uF capacitor has an approximate time constant of 5 microseconds, which is twice the typical Update-IR and Capture-DR default of 2.5 TCK or 2.5 microseconds. The state of these two boundary-scan cells connected to the capacitor at Update-IR is uncertain.
The rti delay statement adds the specified delay between Update-IR and Capture-DR by inserting a repeat cycle into Run-Test/Idle during execution of the VCL test.
 
 
rti delay is available on i3070 In-Circuit Test Software release 07.10p and above. The rti delay statement only applies to a non-compliant differential signal during a 1149.1 boundary-scan test.
Syntax
  rti delay  <time>
     <time> is a <numeric constant> (0 to 10000)
Parameters
<time>
The rti delay time can be 0 to 10000 microseconds. If an rti delay is not specified, the delay time defaults to rti delay 10 (10 microseconds). rti delay 0 is the same as no delay.
Example
interconnect "chain"
rti delay 25             ! RTI delay 25 microseconds
chain "Chain1"
tdi "Buffer-1"
tdo "Buffer-2"
General Information
The compliant aio (IEEE 1149.6) boundary-scan Run-Test/Idle delay is provided in the BSDL statement:
Attribute AIO_EXTEST_Pulse_Execution of ACDEV:entity is
"Wait_Duration 1.0e-3";
