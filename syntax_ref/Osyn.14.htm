or (BT-Basic)
Title: DISJUNCTION
The or operator is used to evaluate Boolean expressions. It returns a value of 1 if either the expression on the left or the expression on the right (or both) is true (non‑zero). If both expressions are false (zero), the operator returns a value of zero. This operator has a priority of 1.
Syntax
  <numeric expression> or <numeric expression>
Parameters
<numeric expression>
The quantities to be evaluated.
Example
  print 12 or ‑123.4                         ! prints    1
  print 0 or 345                             ! prints    1
  print 0*20 or 0                            ! prints    0
  A = 2*pi/8 or sqr(5^2+11^2) \ print A      ! prints    1
