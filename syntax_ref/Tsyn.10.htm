test (ITL)
Title: IDENTIFIES NODE CONNECTIONS TO BE TESTED
The test statement is used within a nodes block in conjunction with the node statement. The test statement identifies the node connections that will be tested.
Syntax
  node <node name> test <device.pin>, <device.pin>,...<device.pin>
  node <node name> <card list> test <device.pin>, <device.pin>,...<device.pin>
  silicon node <node name> test <device.pin>, <device.pin>,...<device.pin>
     <node name> is a <string expression>
     <device.pin> is a <string expression>
     <card list> can be:  hybrid
                          channel          ! On Mux systems only
                          hybrid; channel  ! ";" indicates first choice preferred
                          channel, hybrid  ! "," indicates no preference
Parameters
(none)
Examples
  silicon node "U1_3" test "u1.3", "u2.22"
