board... uses (CONFIGURATION)
Title: ASSIGN EXTERNAL DEVICE TO BOARD
When using external devices with a panelized board, each external device must be assigned to a board number. The board... uses command is used to do so in the board config file.
Note the following:
• A device slot ID (xd<n>) cannot be shared among boards, unless the boards are wired in parallel. However, an external device with more than one xd ID assigned may be shared among boards.
• Boards which are wired in parallel need to use the same set of external devices.
• The board... uses statement must be added after the boards... in statement.
• The external device assigned to a board must match the module assigned to the board.
Syntax
board <board_number> uses <xd_range>
  <board_number> is an <integer>
  <xd_range> can be: <xd_id>
                     <xd_id>, <xd_id>
                     <xd_id> to <xd_id>
    <xd_id> is an integer from 1 to 12
Parameters
<board_number>
Integer that identifies the board in the panel.
<xd_range>
The external device(s) to be assigned. The assignment is based on the device slot IDs.
Examples
board 1 uses xd1, xd2
board 2 uses xd3
