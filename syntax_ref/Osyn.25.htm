override xt analog (CONFIGURATION)
Title: OVERRIDE ADAPTIVE TEST
The override xt analog function is used to globally override adaptive testing for resistors and capacitors.
 
 
If this function is added to the configuration, any previously existing adaptive analog tests MUST be recompiled to remove this test technique.
Capacitor testing and resistor testing (see Analog Testing) by default use adaptive measurements. If you do not wish to use this feature, use the OVERRIDE ADAPTIVE MEASUREMENTS (oxt) option to force non-adaptive measurements within individual tests.
Syntax
  override xt analog
Parameters
(none)
Example
