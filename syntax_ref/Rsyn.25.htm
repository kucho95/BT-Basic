report analog (ANALOG)
Title: REPORT ANALOG TEST RESULTS
The report analog statement compares the result of a measurement or calculation against the specified limits, produces the proper data logging information, and produces any failure report information.
The measure statement initiates the detector, gathers and evaluates the result. For tests that require special triggering, or manipulation of the measurement result, the measure statement can be replaced by the initiate, fetch, and report analog statements.
The report multiple statement compares multiple results of a measurement or calculation against the specified limits. The specified limits can be data blocks referenced by string expressions, or they can be one-dimensional numeric arrays reference by labels. The report multiple statement also produces the proper data logging information and any failure report information.
Syntax
  report analog <hi>, <lo>, <value>
  report multiple <hi limits>, <lo limits>, <numeric array id>
     <hi> and <lo> are <numeric expressions>
     <value> is a <numeric expression>
     <hi limits> and <lo limits> can be:   <string expression>'s
                                           <numeric array id>'s
     <numeric array id> is a <label>
Parameters
<hi> & <lo>
Numeric expressions which specify the acceptable upper and lower test limits.
<value>
A numeric expression or value to be compared against the specified limits.
<hi limits> & <lo limits>
Can be string expressions that identify previously defined data blocks or labels that identify numeric arrays.
<numeric array id>
A label that identifies an array.
Example
Example of a subtest that uses the report analog statement.
  subtest "part1"
     global First_Result
     connect i to "node_2"; l to "node_3"
     detector dcv, expect 2
     initiate detector
     fetch First_Result
     report analog 2.1, 1.9, First_Result
  end subtest
Example of a test that uses the report multiple statement.
  test powered analog
     data "waveform"
        values 0.0, 0.5, 1.0, 1.5, 2.0, 2.5
                   .
                   .
                   .
     end data
     data "HiLimits"
        values 0.5, 1.0, 1.5, 2.0, 2.5, 3.0
                   .
                   .
                   .
     end data
     data "LoLimits"
        values -0.5, 0.0, 0.5, 1.0, 1.5, 2.0
                   .
                   .
                   .
     end data
     dim Results(2048)
     connect s to "Node_1"
     connect i to "Node_2"; l to "Node_3"
     source arb, samples 1024, repetition 512, voltages "Waveform", on
     detector digitizer, expect 4.5, rising 0.2, interval 100u, samples 2048
     initiate detector
     fetch Results(*)
     report multiple "HiLimits", "LoLimits", Results(*)
  end test
General Information
The names used in data logging are obtained from the test and subtest names.
