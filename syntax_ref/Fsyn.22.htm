find vtep probes (BT-Basic)
Title: IDENTIFY nanoVTEP PROBES
Use the find vtep probes function and the guided probe to identify nanoVTEP (and VTEP) probes. This is useful when verifying or debugging the test fixture.
Use the guided probe to touch the sensor of the nanoVTEP probe that you want to identify and execute the find vtep probes function. The system might take a few seconds to identify the nanoVTEP probe. After the system beeps to let you know it found the probe, press the start softkey or step on the foot switch to instruct the system to display the address and probe number on the screen; if autostart is on (set by softkey (f7), you do not need to press the start softkey or step on the foot switch.
See also the syntax description of the verify vtep (BT-Basic) function.
