board graphics (BT-Basic)
Title: INVOKES THE BOARD GRAPHICS VIEWER
The board graphics function invokes the board graphics viewer used to graphically display features on boards.
Syntax
  board graphics
  board graphics, <error variable>
     <error variable> is a <numeric variable>
Parameters
<error variable>
The identifier of an optional error variable.
Examples
  board graphics            ! Invokes the board graphics viewer.
  board graphics, Error     ! Includes an error variable.
General Information
This function requires that a valid board.o and board_xy.o file be present in the current directory. If a load board function is executed before executing the board graphics function, the board graphics viewer reads the files in the directory from which the load board function was executed.
