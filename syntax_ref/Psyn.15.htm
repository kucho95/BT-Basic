pcf order is (VCL)
Title: MAP NODES TO PCF VECTORS
The pcf order is function is used in the Declaration section of a VCL test to define sets of PCF pins and to assign groups of pins to those sets. A set of PCF pins determines the order in which the nodes on the board under test, or the device pins, will be mapped to the bits in PCF test patterns (vectors) loaded from CAD systems.
Because the different sets of PCF pins do not all have to be the same length, test vectors of different lengths can be downloaded. However, the vectors to be used with any one set of PCF pins must all have the same length—which is the same as the length of that set of PCF pins.
The order in which the bits in the vectors are assigned to pins (or nodes) is determined, first, by the order that the groups appear in the pcf order is statements, and second, by the order of the nodes within those groups (as assigned by the assign to statements).
If the VCL test uses PCF vectors, then at least one set of PCF pins must be defined. The sets can be given names for identification purposes. A use pcf order function is then used in the vector blocks to associate the vectors with a specific set of PCF pins.
One, and only one, of the sets of PCF pins must be the default set; this set is automatically used by any set of PCF vectors which does not have a use pcf order function. The default set can be defined either by using the optional default keyword, or by not naming that set, as shown in the syntax and examples.
If more than one pcf order is function specifies the same name, then those statements are cumulative; that is, they assign groups of pins to the same set of PCF pins, in the order the statements appear in the test. If any one of the cumulative statements includes the default keyword, then the specified set becomes the default set and all of its pins are included in the default set. (For readability, we recommend that you use the default keyword in all statements which define the default set.)
The same pin cannot be included in more than one pin group in the same set of PCF pins.
Sets of PCF pins cannot contain formatted pins, the DUT clock, power pins or nondigital pins.
PCF can be incorporated both in library tests and in executable tests. Not all pins in the test necessarily have to be included in the sets of PCF pins. Ordinary vectors can also reference the PCF pins.
Syntax
pcf order is <group list>
pcf order <name> is <group list>
pcf order default is <group list>
pcf order default <name> is <group list>
  <group list> can be:   <group id>
                         <group id>,<group id>
                         <group id>,<group id>, . . . <group id>
        <group id> is a <label>
     <name> is a <label>
Parameters
<group list>
The identifiers of the groups of pins to be included in the set of PCF pins.
<name>
The identifier of the set of PCF pins.
Example
  ! in the Declaration section
     . . .
              ! pins 4 through 11 are assigned to "Address"
  assign Address to nodes "U2-4","U2-5","U2-6",U2-7","U2-8"
  assign Address to nodes "U2-9","U2-10","U2-11"
  assign CS to nodes "U2-22", "U2-24"
  assign RDY to nodes "U2-3"
              ! pins 15 through 21 are assigned to "Data"
  assign Data to nodes "U2-15","U2-16","U2-17","U2-18","U2-19"
  assign Data to nodes "U2-20","U2-21"
     . . .
  inputs RDY, Address
  outputs CS
  bidirectional Data
     . . .
              ! define the default set of PCF pins
  pcf order is RDY, Address, Data          ! the pcf pins are now in ascending order
  pcf order is CS
     . . .
  !!!  random example statements
              ! this set is named "G1"
     pcf order G1 is A, B, C
              ! order of groups in set "G2" is D E F J K G H I
     pcf order G2 is D, E
     pcf order G2 is F, J, K
     pcf order G2 is G, H, I
              ! set "G3" is a default group
     pcf order G3 is AA, BB, CC
     pcf order default G3 is DD
     pcf order G3 is EE, FF
              ! set definitions can be mixed
              ! "One" is XX YY ZZ
              ! "Two" is HH II JJ KK
     pcf order One is XX, YY
     pcf order Two is HH
     pcf order One is ZZ
     pcf order Two is II, JJ, KK
General Information
When a PCF vector is executed, as occurs when an ordinary vector is executed, pins not specifically driven or received by that vector go to their default states.
