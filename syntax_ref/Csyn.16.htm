check boardxy (BT-Basic)
Title: CHECK THE SYNTAX OF A board_xy FILE
The check boardxy function checks the syntax of a board_xy file. This is important if you have edited your board_xy file manually.
You can instruct the check boardxy function to place a listing of the checked file under another name; otherwise, it overwrites the original file. In any case, the check boardxy function produces a backup of the original file; the file is backed up regardless of the instructions in the .hp3070 file or in the function itself.
You can also use the list option to instruct the check boardxy function to produce an error listing of the board_xy file called board_xy.e.
Syntax
  check boardxy <file name>
  check boardxy <file name> <option list 1>
  check boardxy <file name>; <option list 2>
  check boardxy <file name> <option list 1>; <option list 2>
     <file name> is a <string expression>
     <option list 1> can be:   over/to <list file name>
                               over/to <list file name>, <error variable>
                               <error variable>
        <list file name> is a <string expression>
        <error variable> is a <numeric variable>
     <option list 2> can be:   <item>
                               <item>, <item>
                               <item>, <item>, . . . , <item>
        <item> can be:   list
                        <experience level>
                        <backup level>
           <experience level> can be:   standard
                                        advanced
                                        expert
           <backup level> can be:   numbered
                                    unnumbered
                                    nobackup
Parameters
 
<option list 1>
Can be either a list file name, or an error variable, or both.
<option list 2>
A list of optional parameters that determine how the function works. The options are described below.
list
Produces a list of errors found in the board_xy file. The list is placed in a file called board_xy.e.
<experience level>
Sets the length (thoroughness) of the error messages the user receives and can also be used to restrict the user to a subset of the full system features. Permissible values are: standard, advanced, and expert.
<backup level>
Determines if the system stores an unchanged copy (a backup) of files before modifying them, and how the backup is stored. Permissible values are:
• nobackup – No file backup is made.
• numbered – Makes up to nine backups, each numbered sequentially with .#~, such as file.1~. Number one is the most recent backup. When more than nine backups occur, the oldest file is discarded, and the others are renumbered.
• unnumbered – A single backup is made. The backup file name is appended with a tilde (~); for example, file~.
Examples
  check boardxy "/board_a/board_xy",E
         ! Checks the syntax of the board_xy file in the board_a directory.
  check boardxy "/board_a/board_xy"; unnumbered
         ! Checks the syntax of the"board_xy" file and makes a single backup of any files
         ! that get modified.
  check boardxy "board_xy" to "check_xy"; list
         ! Places a listing of the checked file in a new file called "check_xy" and
         ! places a list of errors from the board_xy file in a new file called
         ! "board_xy.e".
