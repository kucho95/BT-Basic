tms (ITL)
Title: IDENTIFES TEST MODE SELECT NODE
The tms statement identifies the test mode select node of the boundary-scan chain. A name is assigned to this node using the tms statement.
Syntax
  tms <node name>
  tms <node name> <card list>
     <node name> is a <string expression>
     <card list> can be:  hybrid
                          channel          ! On Mux systems only
                          hybrid; channel  ! ";" indicates first choice preferred
                          channel, hybrid  ! "," indicates no preference
Parameters
<node name>
The name of the node assigned to tms.
Examples
  tms "Buffer-3"
     tms "Data_3" hybrid
