npn (ANALOG)
Title: NPN TRANSISTOR MEASUREMENT
The npn function tests the gain of npn transistors by measuring the base voltage at two different levels of emitter current.
Syntax
  npn <specs>
  npn <designator>,<specs>
     <designator> is a <string expression>
     <specs> can be:   <hi>,<lo>
                       <hi>,<lo>,<return>
                       <hi>,<lo>,<options>
                       <hi>,<lo>,<options>,<return>
        <hi> & <lo> can be <numeric expressions> or *
        <return> is a <numeric variable>
<options> can be two or more of the options in Table N-2, separated by commas.
Parameters
<designator>
A string constant of up to 16 characters which identifies the a subtest. If the component fails, the system will include the <designator> in the failure message sent to the report is device.
<hi> & <lo>
Numeric expressions which specify the upper and lower test boundaries, respectively, as DC beta values. An asterisk (*) can be used in place of zero. If zero or * is specified for both tolerance values, the results of the test are not compared to any limits; the test will not fail.
<options>
The range of co is 0 volts to 15 volts. The idc option is required. The test uses the option values given in Table N-2, unless otherwise specified.
<return>
A numeric variable which holds the measured value.

Example
  on failure report "PART NUM: 114500217; LOCATION: H2"
  clear connect s to "Q1_E"; i to "Q1_B"; g to "Q1_C"
  npn 200, 50, co2.7, idc171.7u, idelta15
General Information
The idc and idelta options must be specified in the test function. The system chooses the correct source resistor and reference resistor. The range of idc is 100uA to 150 mA. The range of idelta is 5 to 50%.
