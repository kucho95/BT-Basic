downcounter (VCL)
Title: DEFINE A DOWNCOUNTER
The downcounter function is used in a vector block to assign a binary downcounter to a group of pins. If used, the function must be the last function in the block before the end vector function. The downcounter function must be preceded by at least one set to function, to preset the counter pins to their initial states.
Counter operation (for downcounters, graycounters and upcounters) is described in the section referenced above.
Syntax
  downcounter <group id>
     <group id> is a <label>
Parameters
<group id>
The identifier of the group of pins to form the counter. The number of pins in the group determines the maximum value the counter can have. The group can contain a maximum of 31 pins. Pins in the group can be referenced in other vectors, and can be assigned counters in other vectors (only one counter per vector).
Examples
  downcounter Input
Refer to Vector Control Language (VCL) in Digital Testing to see how to execute vectors which contain counters.
