dim (ANALOG)
Title: DIMENSION VARIABLES
The dim (ANALOG) function dimensions one-dimensional numeric arrays inside analog tests: that is, it initializes and reserves memory for them, and it declares their identifiers (names).
No reference can be made to any of these arrays until they have appeared in a dim function.
The dim function also initializes the array elements to zero.
The elements of the array are numbered consecutively.
The dimension function consists of the dim keyword followed by one or more specifications separated from each other by commas. Each specification defines one numeric array.
dim statements must be placed inside the analog test immediately following the test powered function.
Syntax
  dim <dim spec>
  dim <dim spec>,<dim spec>
  dim <dim spec>,<dim spec>, . . . . <dim spec>
     <dim spec> is a:   <numeric array id>(<bounds>)
        <numeric array id> is a <label>
        <bounds> can be:   <upper bound>
                           <lower bound>:<upper bound>
           <lower/upper bound> is a <numeric constant>
Parameters
 
<dim spec>
The specification for a one-dimensional numeric array.
<numeric array id>
The identifier of a numeric array (see the definition of <label>). The id must be unique; that is, no other variable or array, numeric or string, can exist at the same time with the same label in its id. A variable cannot be dimensioned again if it already exists. The workspace currently occupied by one variable cannot be reassigned to another variable until the workspace is cleared or a new program‑run starts.
<bounds>
Defines the size of the array. The size of a one-dimensional numeric array can be up to (and including) 32767 elements.
<lower/upper bound>
Integer values determine the bounds (size) of the array by specifying the number of its lowest‑numbered element (lower bound), and of its highest‑numbered element (upper bound). If the lower bound is omitted, it defaults to zero. These three conditions must be met:
• –32767 <= bound <= 32767
• lower bound <= upper bound
• (upper bound – lower bound + 1) <= 32767
Examples
  dim Nodes(1:100)      ! A 1x100 numeric array, elements numbered 1 through 100.
  Nodes(8) = 368.9      ! Assigns value to 8th element.
  dim Tests(100)        ! A 1x101 numeric array, elements numbered 0 through 100.
  Tests(8) = 12         ! Assigns value to 9th element.
