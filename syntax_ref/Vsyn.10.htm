vector cycle (VCL) (ITL)
Title: SET VECTOR CYCLE TIME
The vector cycle function appears in the Declaration section of the test to establish the vector cycle time; that is, the time between starting each vector. Once established, the cycle time remains the same for all vectors throughout the VCL test. The vector cycle function cannot be used with tests which have timing sets (on Mux systems only).
If the pll parameters are included, the test timing is synchronized to an external clock. If those parameters are not included, the test timing is synchronized to an internal clock in the test system.
Syntax
  vector cycle <time>
  vector cycle <time> pll <clock time> period edge <polarity>
     <time> and <clock time> are <numeric constants>
     <polarity> can be:   rising
                          falling
Parameters
<time>
The vector cycle time, in seconds. The range of the time is from 80 nsec (50 nsec in a 20 MHz system) to 1.59375 msec. If the <clock time> parameter is specified, then:
<clock time> <= <time> <= (255 * <clock time>)
If not specified the vector cycle time defaults to 500 nsec.
<clock time>
The period, in seconds, of the external clock. The range of the external clock depends on which test system is being used.
<time> / 255) <= <clock time> <= <time>
<polarity>
Specifies the external clock edge to which the reference clock will be synchronized.
Example
  vector cycle 450n          ! 450 nsec
  vector cycle 0.0015        ! 1.5 msec
  vector cycle 3u            ! 3 msec
  vector cycle 500n pll 100n period edge falling
