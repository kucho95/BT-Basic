ipg from (BT-Basic)
Title: RUN IPG ON THE TESTS LISTED IN A TEST LIST FILE
The ipg from function runs the Integrated Program Generator (IPG) on the tests listed in a file. To run the program generator on several, but not all, of the tests in your board directory, list the tests in a file and invoke the program generator with the ipg from function.
To run the program generator on a limited number of tests (one to four), use the ipg on function.
Refer to the ipg function description for details of the integrated program generator.
Unless you specify a directory path name, the program generator assumes the current directory.
While IPG is running, all keys are ignored except the Break key.
Syntax
  ipg from <test list file>
  ipg from <test list file>, <error variable>
  ipg from <test list file>; <option list>
  ipg from <test list file>, <error variable>; <option list>
  ipg <directory id> from <test list file>
  ipg <directory id> from <test list file>, <error variable>
  ipg <directory id> from <test list file>; <option list>
  ipg <directory id> from <test list file>, <error variable>; <option list>
     <test list file> is a <string expression>
     <directory id> is a <string expression>
     <error variable> is a <numeric variable>
     <option list> can be:   <item>
                             <item>, <item>
                             <item>, <item>, . . . , <item>
        <item> can be:   shorts
                         pins
                         discharge
                         <window>
                         <wait>
                         <experience level>
                         <backup level>
           <window> can be:   window
                              nowindow
           <wait> can be:   wait
                            nowait
                            failwait
           <experience level> can be:   standard
                                        advanced
                                        expert
           <backup level> can be:   numbered
                                    unnumbered
                                    nobackup
Parameters
 
<test list file>
The file id of the file containing the list of tests to be developed by the program generator.
<directory id>
The pathname of the board directory.
<option list>
A list of optional parameters that determine how the function works. The options are:
• shorts - Re-generate the shorts file in addition to the devices in the specified file.
• pins - Re-generate the pins file in addition to the devices in the specified file.
• discharge - Re-generate the discharge test in addition to the devices in the specified file.
<window>
Specifies whether or not a new window is automatically opened when the function is executed. Permissible values are:
• window - A new window is opened.
• nowindow - Suppresses the opening of a new window.
<wait>
Specifies how the command executes. Permissible values are:
• failwait - The function executes and, if a failure occurs, the results remain on the screen so you can examine them.
• nowait - The function executes and does not pause for you to examine the results.
• wait - The function executes and the results remain on the screen so you can examine them.
<experience level>
Sets the length (thoroughness) of the error messages the user receives and can also be used to restrict the user to a subset of the full system features. Permissible values are: standard, advanced, and expert.
<backup level>
Determines if the system stores an unchanged copy (a backup) of files before modifying them, and how the backup is stored. Permissible values are:
• nobackup - No file backup is made.
• numbered - Makes up to nine backups, each numbered sequentially with .#~, such as file.1~. Number one is the most recent backup. When more than nine backups occur, the oldest file is discarded, and the others are renumbered.
• unnumbered - A single backup is made. The backup file name is appended with a tilde (~); for example, file~.
Examples
  ipg "/boards/cpu_board" from "test_file" 
       ! Run IPG on the tests listed in "test_file" under "/boards/cpu_board".
  ipg from "test_file"; unnumbered
       ! Run IPG on the tests listed in "test_file" and make a single backup
       ! of any files that are modified.
General Information
The Break key is used to stop program generation before it is completed.
