xd__ commands (BT-Basic)
Title: BT-Basic Commands for External Devices
When external devices are used, it is up to the developer to add the appropriate commands in the testplan to control them. A typical command sequence is shown in Table X-1.
 
Table X-1 Typical command sequence
 
Command
Description
1
xdload
Loads the DLL into memory.
2
xdconnect
Connects the external device.
3
xdcall
Calls the DLL to execute a custom function on the external device; parameters can be specified.
4
xddisconnect
Disonnects the external device(s).
5
xdunload
Unloads the DLL from memory.
If xdcall is used without first issuing the xdload and xdconnect commands, those two commands will automatically be triggered.
Example
xdload "flash"
xdconnect "flash", 0.5
xdcall "flash", "custom", Var_1, Err$; "12, 15"
xddisconnect "flash"
xdunload "flash"
xdload
xdload "<device_name>"
   <device_name> is a string
 
 
 
Only one DLL can be loaded at a time.
xdconnect
xdconnect "<device_name>"
xdconnect "<device_name>",<timeout>
   <device_name> is a string
   <timeout> must be at least 0.1 seconds
The device name must be unique across the board.
xdcall
xdcall "<device_name>", "<custom function name>", [<return number>], [<return string>]; ["<custom parameters>"]
   <device_name> is a string
   <custom function name> is a string (max 80 characters)
   <return number> is a numeric variable (optional)
   <return string> is a string variable (optional, max 80 characters)
   <custom parameters> is a string (max 80 characters)
xddisconnect
xddisc0onnect "<device_name>"
xddisconnect "<device_name>",<timeout>
xddisconnect
xddisconnect <timeout>
   <device_name> is a string
   <timeout> must be at least 0.1 seconds
When no device name is specified, this command disconnects all external devices.
xdunload
xdunload "<device_name>"
   <device_name> is a string
