display measurement (DEBUG)
Title: DISPLAY MEASUREMENT
The display measurement function displays the results of the specified test or subtest.
The function executes the test a specified number of times, applies Q‑STATS statistical analysis, and displays the data on the printer is device.
Syntax
  display measurement
  display measurement <number>
  display measurement <subtest id>
  display measurement <number> <subtest id>
     <number> is <numeric expression>
     <subtest id> is a <string expression>
Parameters
<number>
The number of times to execute the test. For statistical data integrity, the number should be at least 30. The default value is 50.
<subtest id>
The name of the subtest to execute for the measurement. The default is to execute all the subtests in a test.
Examples
  ! Execute subtest "R1_1" 40 times, analyze the results and display the data on
  ! the printer is device.
     display measurement 40 "R1_1"
