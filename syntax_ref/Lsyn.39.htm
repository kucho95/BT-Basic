loop | exit if | end loop (BT-Basic)
Title: UNCOUNTED LOOPS
The loop function marks the beginning of an uncounted loop, and the end loop marks the end of the loop. The program statements between the start and end of the loop are executed repetitively until the exit is made from the loop. Program execution then resumes with the function after the end loop.
Whether or not to exit the loop is determined by the numerical expression in the exit if function. When the function is encountered, its expression is logically evaluated to determine if it is true or false (same as for the if‑then function). If the expression is true, the exit is made; if it is false, execution of the statements in the loop continues.
The loop function need not be the first function on a line. There can be any number of exit if statements, located anywhere in the loop; however, the exit if cannot be included in another structured function, such as in an if‑then function.
Loops can be nested to any depth.
Syntax
The structure of the loop is:
     loop
        <program statements, including one or more "exit if" statements>
     end loop
The syntax of the exit function is:
     exit if <numeric expression>
Parameters
<numeric expression>
The expression to be evaluated to determine whether or not to exit the loop:
• a non‑zero value is true – exit the loop
• a value of zero is false – do not exit
Examples
  ! load 1's into a ten element array
        dim Total(1:10) \ I = 0
     loop
        I=I+1  \  Total(I)=1
     exit if I = 10
     end loop
  ! this causes an error
     loop
        if A > 6 then exit if B < 10     ! error — "exit if" in another
        print A                          ! structured function
     end loop
(See Branching, Looping, and Subprograms in BT-Basic Programming for more examples.)
General Information
You can also use a goto to cancel the loop. If loops are nested, exit if can exit only one level at a time, but goto can exit any number of levels at once.
