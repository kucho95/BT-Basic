dynamic (VCL)
Title: ASSIGN DYNAMIC RESOURCES TO A SPECIFIED GROUP OF NODES
The dynamic function appears in the Declaration section of the VCL test to instruct the Module Pin Assignment software (MPA) to assign dynamic pins to the specified node groups. This is used with pins that are to drive or receive dynamic data (i.e., pins that are assigned vector values from variables and data blocks). MPA assigns pins that are as close together as possible in the testhead, thus minimizing the number of cards that must be accessed when the dynamic data is downloaded.
If you add a dynamic function to a test with an existing wirelist, MPA does not assign dynamic resources to nodes that already have (ordinary) resources assigned. However, MPA assigns dynamic resources to any new nodes that have been specified as dynamic.
The compiler issues a warning if the test uses dynamic data but contains no dynamic statements. In this case, add the missing dynamic statements and recompile the test.
Syntax
  dynamic <group list>
     group list> can be:   <group id>
                           <group id>,<group id>
                           <group id>,<group id>, . . . . <group id>
        <group id> is a <label>
Parameters
<group id>
A group of nodes that are to drive or receive dynamic data.
Examples
  assign Address_bus to pins 3, 29, 28, 4, 25, 23, 26, 27
  assign Data_bus to pins 21,20,19,18, 17, 15, 14, 13
        . . .
  inputs Address_bus
  bidirectional Data_bus
        . . .
  dynamic Address_bus, Data_bus
