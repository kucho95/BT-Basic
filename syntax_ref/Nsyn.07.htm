node (STATES)
Title: START A NODE BLOCK IN THE STATES FILE
(Mux systems only)
The node function is used in a node states file to indicate the start of a node block. The block lists all changes of state which occur on a node during a functional test. The block also lists the numbers of the vectors in which the changes occur.
The node block consists of a node function (on a line by itself), followed by a set of transition statements (see the syntax and the examples).
If you need to edit the states file and there is no source file use the list object (BT-Basic) function to generate the source file from the object file.
The states file is used by the debug software.
Syntax
   [1. for the "node" function]
      node <node id>
         <node id> is a <string constant>
   [2. for the transition statements]
      <vector #>=<state>
      <vector #>=<state> <vector #>=<state>
      <vector #>=<state> <vector #>=<state> . . . . <vector #>=<state>
         <vector #> is an integer <constant>
         <state> can be:   "0"
                           "1"
                           "X"
Parameters
 
<node id>
The identifier of a node whose states are to be listed. The node name must exactly match the identifier of the node as entered in the Board Forms (except that uppercase and lowercase characters are equivalent).
<vector #>
The number of the vector where the change of state occurs. The vectors for any one node must be listed in ascending order.
1 <= vector number <= 134217737 (2^27 - 1)
<state>
A string indicating the change of state which occurs during the associated vector. If a vector number is not listed, the node state does not change. If vector number 1 is not listed, the node state is assumed to be X.
Example
The following shows three node blocks:
node "Input1"
   1="0" 3="1" 11="X"    ! states are 0011111111X (remains "X" until the end of the test)
node "C-2"
   4="1"  6="0"          ! states are XXX11000......
node "c-3"
    1="0"   3="1"   6="X"   7="0"   12="1"   13="0"   17="1"
   21="X"   25="0"   32="1"   37="0"
General Information
The states file can contain include statements, to segment a large file, but the include cannot be used inside a node block.
