on failure / end on failure (ANALOG)
Title: ANALOG IN-CIRCUIT CONDITIONAL LOOP
When an analog failure occurs, the standard failure report is generated. By using the on failure function, you can add more messages to be printed or reported, or both. You can also stop the test and pass control back to the testplan by including the exit test function with the on failure loop.
Use the print (ANALOG) and report (ANALOG) statements to print or report messages from the on failure loop. The message is sent to the device specified by the printer is (BT-Basic) or the report is (BT-Basic) statements.
If your on failure function contains only one line you do not need to use the end on failure. If your on failure function requires more than one line, as in the example below, you must terminate the on failure loop with the end on failure function.
When an analog in-circuit failure occurs, the on failure loop is executed. If the on failure loop does not contain an exit test command, test block execution continues at the next line in the analog test block. If the on failure loop does contain an exit test command, the test block is exited and testplan execution continues. Testplan execution continues at the next line following the test (BT-Basic), function that called the failing test block.
An analog in-circuit test block can have more than one on failure function. Each successive on failure function cancels the previous one.
See also the off failure (ANALOG), and the exit test (ANALOG) function descriptions.
Syntax
The simple form:
     on failure <function>
        <function> can be:   print <message>
                             report <message>
                             exit test
           <message> is a <string expression>
The structured form:
     on failure
        <function>
           .
           .
           .
        <function>
     end on failure
        <function> can be:   print <message>
                             report <message>
                             exit test
           <message> is a <string expression>
Parameters
<function>
For detailed descriptions of the three <function> parameters, refer to the function descriptions of the corresponding BT-Basic print and report statements, and the exit test (ANALOG) command.
Example
  Simple form:
     on failure report "PART NUM: 1145-0054; LOCATION: D6"
     clear connect s to "R1-1"; i to "R1-2"
     resistor 2k, 1.4, 1.3, wb, ed
  Structured form:
     on failure
        report "PART NUM: 1145-0116: LOCATION: B9"
        exit test
     end on failure
     clear connect s to "Pin_1"; i to "Wiper"
     potentiometer "Leg_1", 5k, 13.2, 12.5, wb, ad, R
     clear connect s to "Wiper"; i to "Pin_3"
     potentiometer "Leg_2", 10k-R, 26.3, 24.4, wb, ed
General Information
The exit test function is useful for test blocks that contain more than one measurement. This is the case with a potentiometer test. The result of the first measurement is used to determine the limits of the second measurement. If the first measurement fails, the second one is invalid. The exit test function allows you to inhibit the second measurement from being executed. This saves time and avoids an invalid error report.
