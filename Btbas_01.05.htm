Expressions
An expression is any valid sequence of characters which, when executed, results in a value. An expression can be numeric, which results in a numerical value, or it can be a string expression, which results in a string.
An expression can consist of any of the following elements, singly or in combination:
• a constant,
• a variable,
• an operator, and/or
• a function.
An expression can itself contain one or more expressions.
Many statements have parameters that are expressions. This lets these statements use calculated values, instead of operating only on constant values.
