Counted Loop (for/next loop)
The Counted Loop (for/next loop) enables the programmer to execute a sequence of statements a specified number of times. The for statement contains a counter to determine how many times to execute the statements in the loop. The sequence of statements is preceded by the for statement, and followed by the next statement. Here is an example of a for/next loop (in this case, the sequence of statements is just one statement, print I):
   for I = 1 to 5
      print I
   next I
This loop will print the numbers 1 through 5 and then exit. The counter range is 1 through 5: the first time through the loop, I is assigned a value of 1; the second time, its value is 2; and so on, until five passes have been made through the loop, and all five values have been printed. The next statement increments the value of I after each pass, and the for statement monitors that value to decide whether or not to exit the loop. After the exit from this loop, I equals 6.
Loops can appear anywhere in the main program, and in subprograms. They can contain nested loops and other program structures. Any nested loops and structures must be properly arranged so that they do not interfere with each other's operation, as shown later.
The statements shown in Table 4-6 control the loop.
 
Table 4-6 for loop control statements
Statement
Description
for
Marks the start of the loop, and initializes the loop counter; also monitors the value of the counter to determine when to exit the loop.
to
Secondary keyword; it sets the start and stop values for the counter (that is, it specifies the range of the counter).
step
Optional secondary keyword; it establishes the value by which the loop counter is incremented after each pass through the loop (if omitted, the increment value defaults to 1).
next
Marks the end of the loop; it also increments the loop counter and returns execution to the beginning of the loop.
The following routine prints values 2, 5, 8, 11, 14 and 17; the for/next loop prints the first five values and the last value is printed after the exit.
   for I = 2 to 15 step 3
      print I
   next I
   print I
In the preceding example loop, the for statement first initializes the counter variable (I) by assigning a start value (2) to it. The counter controls the number of times that the statements in the loop will be executed. for also monitors the counter's value, to determine whether to execute the statements in the loop, or to exit the loop because the required number of passes have been made. The next statement increments the counter by the step value (3), and returns execution to the for statement.
Counter operation is defined by the values established by the secondary keywords, to and step. The to values, start (2) and stop (15), define the counter's range, and the step value (3) defines the amount by which the next statement increments the counter after each pass of the loop. Each time for is executed, it examines the counter variable to determine if the present value of the variable is outside the start/stop range. If it is outside the range, the exit is made from the loop; if the value is within the range (including being equal to either the start or stop values), another pass of the loop is made.
During operation of the loop, the value of the counter variable cannot be changed by any statement except the next statement. After the exit from the loop, the counter variable retains its last value (that is, some value outside the start/stop range). However, if a goto statement is used to exit the loop, then looping is canceled and the counter variable retains whatever value it had at that time.
For/next loops can be nested to any depth; that is, one loop can contain a second loop, which can contain a third, and so on. Each of the nested loops must have its own counter variable. Nested loops cannot overlap, so the exit must be made from the last loop entered before the execution of the previous loop can be continued; this is shown in Table 4-7.

The following rules also apply:
• A loop can be on one line, or on any number of lines; the for does not necessarily have to be the first statement on a line.
• A goto statement which branches execution out of the loop, cancels the loop. In nested loops, the standard exit (counter is out of range) can exit only one level at a time; a single goto can be used to exit and cancel many levels at once.
Example 4-11 contains an example of nested for/next loops.
Example 4-11 Example of nested for/next loops
   ! reset all strings in a 4-by-10 array to the null string
   for I = 1 to 4
      for J = 1 to 10             ! J‑loop executes
         Scores$(I,J) = ""        ! 10 times for each
      next J                      ! pass through I‑loop.
   next I
 
The start, stop, and step values do not have to be constants: they can also be expressions or variables. Because of this, it is possible for the start value to be out of range when the counter is first initialized. When the for statement is first executed, if it determines that the count value is already out of range, then it will exit the loop immediately, and none of the statements in the loop will be executed.
For example, in this loop, nothing will be printed because I is out of range when the loop starts:
   for I = 6 to 2
      print I
   next I
But in this loop the values will be printed; I is initially in range because the step value is negative:
   for I = 6 to 2 step -1
      print I
   next I
