Miscellaneous Numeric Functions
There are special-purpose functions which return a value as described in Table 3-8.
 
Table 3-8 Miscellaneous numeric functions 
Function
Returns
boardfailed
1 if any “test” statement failed; 0 if not (see the command description in Syntax Reference).
dutfailed
1 if the last “test” statement failed; 0 if last test passed (see the command description in Syntax Reference).
errl
Line number where an error occurred (see Branching, Looping, and Subprograms).
errn
Error number of the most recent runtime error (see Branching, Looping, and Subprograms).
learning
Status of the learn flag (see Digital Theory and Testing in Digital Testing).
msec
Number of milliseconds since a base date/time.
no
Returns a 1 if the “no” button on the operator toolbar or the “no” softkey was pressed.
nrun
Number of program runs.
pslimit
Value indicating which, if any, power supplies are in current limit.
yes
Returns a 1 if the “yes” button on the operator toolbar or the “yes” softkey was pressed.
