String Variable
A string variable can contain strings of different lengths. A string constant, or another variable, is assigned to (stored in) a variable by the assignment operator (=). When a string is assigned to a variable, the variable then has the same length as that string. If a string with a different length is subsequently assigned to the same variable, then the length of the variable changes to the new length. However, an error occurs if an attempt is made to assign a string that is longer than the maximum length that the variable can have.
A string variable has a current length and a dimensioned, maximum length. These are not necessarily the same:
• The current length of a variable is the same as the length of the last string assigned to it, as described in the preceding paragraph.
• The dimensioned length is the space reserved in the workspace for that variable when it is first initialized. The default dimensioned length for a string variable is 80 characters.
A variable is initialized when it is first referenced. If a string is not assigned to it at that time, then it has zero current length, that is, it contains a null‑string (""). If the variable is initialized by a dimension (dim) statement, then its dimensioned length can be set to any length, up to and including, 2048 characters. Once the dimensioned length of a given variable has been established, it cannot be changed until the system workspace is subsequently cleared (scratch) or a program is run (run). However, the current length of a string variable can be changed at any time, by assigning to that variable a string which has a different length.
The identifier for a string variable consists of a label with a dollar sign ($) appended to it. Example 2-7 contains some examples of string variables.
Example 2-7 Examples of string variables
  A$                        ! simple string variable named A$
  Test_results$             ! simple variable named Test_results$
  First_name$ = "Charlie"
  Second_name$ = "Goodman"  ! string constants
  Identity$ = First_name$ & " " & Second_name$
                            ! & is the concatenation operator, it joins strings
  print Identity$           ! prints  Charlie Goodman
  dim L$[180]               ! Variable with a dimensioned length of 180
                            ! characters and a current length of zero.
  L$ = "abcdefg"            ! Current length is now 7, but it can still have
                            ! strings of up to 180 characters assigned to it.
