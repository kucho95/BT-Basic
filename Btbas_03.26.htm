User‑definable Functions
A user‑definable function is a subprogram which is defined and written by the user, but which operates just like the standard mathematical and string functions in the system (see Operators and Functions). For example, if a function called Cube_root has been defined, the following statement would print two times the cube root of 64:
   print 2 * fnCube_root(64)   ! prints 8
Notice the similarity between this statement and a statement which uses one of the system functions:
   print 2 * sqr(64)           ! prints 16
In the first statement, the fn indicates that a user-definable function is being called.
Any number of user‑definable functions can be contained in the workspace. A function can invoke another function or a subroutine as part of its operation, but a function cannot be physically located in another function, or in a subroutine. All user‑definable functions required by a program must be in the workspace when the program is executed, and must be located after the main program's end statement. If the function is not defined in the program, a runtime error will result if the an attempt to call the function is made.
The following program statements are associated with the user‑definable functions.
 
Table 4-10 Statements associated with user-definable functions
Statement
Description
def
Establishes the beginning of the function, its name, and the number and type of the parameters required by its argument.
fn
Invokes (starts execution of) the function and passes parameters (data) to it.
global
Lists the main program parameters which can be accessed by the function without their being passed to the function. Global parameters can include variables and @<name>'s. If used, this statement must immediately follow the def statement.
return
Causes the function to return its final value to the calling point.
fnend
Marks the end of the function in memory.
The function is bounded in the workspace by the def and fnend statements. def also names (identifies) the function and establishes its formal parameters; data is passed to these parameters by means of the fn statement which invokes the function.
The function can also have local and global parameters. Parameter passing, and the use of formal, global and local parameters, is the same for the user‑definable functions as it is for subroutines (see Parameters of the Subroutine). Example 4-16 shows one possible definition of the Cube_root function described above.
Example 4-16 Possible definition of the Cube_root function
def fnCube_root (X)
   A = exp( log(X) / 3 )     ! calculates cube root of value
                             ! passed in X;
   return A          !   the value of the function is returned;
fnend                !   (X is a formal parameter; A is local).
The same function can be written on one line:
def fnCube_root (X) | return exp(log(X)/3) | fnend
 
Like any of the standard functions in the system, the user‑definable function is invoked from an expression, as shown in the example print statement used earlier:
   print 2 * fnCube_root(64)
When the function is encountered, evaluation of the expression is suspended while the function is executed. When the function's final value is returned (4 in this example), evaluation of the expression continues and the result (8) is printed.
A function can be either numeric or string: if numeric, it returns a number; if string, it returns a string. A string function always has a dollar sign ($) appended to its name (for example, fnTitle$).
Except for the global variables and any variables passed to the function when it is invoked, variables named in the function are local. Once the return has been made from the function, its local variables can no longer be accessed. Except for the actual name of the function, which must be unique, any labels used in the function are local; therefore, any given line label can appear in any number of functions (and in the main program). These line labels cannot interfere with each other since a branch (goto) in one function cannot go to a label in another function, or to a label in the main program.
Example 4-17 shows a user‑definable function and a program which invokes it twice, each time with a different set of data. In this example, the function's argument has more than one parameter.
Example 4-18 shows a user-definable function that returns a string based on an integer value passed to the function.
Example 4-17 Example of a user-definable function with more than one parameter
   ! MAIN PROGRAM
   print fnPythag (3,4)      ! prints  5
     . . .
   S1 = 12 | S2 = 9
   print "Hypothenuse of triangle =  "; fnPythag(S1,S2); "inches"
            ! prints     Hypothenuse of triangle =   15 inches
   end
 
   ! FUNCTION
   def fnPythag(A,B) | return sqr(A^2 + B^2) | fnend
 
Example 4-18 Example of a user definable string function
   ! MSIN PROGRAM
   for T = 1 to 3
      print "TITLE:  "; fnTitle$(T)   ! the appropriate title is
        . . .                         ! printed for each pass:
   next T
   end
 
   !  Function
   def fnTitle$(N)
      dim Name$(3)
      Name$(1) = "Shorts Test"
      Name$(2) = "Analog Tests"
      Name$(3) = "Digital Tests"
      return Name$(N)          ! returns appropriate title to
                               ! main program
   fnend
 
   Output on the display when program is run:
      TITLE:  Shorts Test
        . . .
      TITLE:  Analog Tests
        . . .
      TITLE:  Digital Tests
