What is a Subroutine?
A subroutine is a subprogram consisting of a group of statements which can be called and executed from any point in a program. When the subroutine is called (call statement), execution of the program is suspended while the subroutine is executed. When the subroutine ends, execution of the program resumes at the next statement after the statement which called the subroutine.
From the calling program's point of view, the subroutine looks like a single statement. The subroutine can also have one or more values passed to it so that, if required, it can operate on different data each time it is called. Example 4-12 shows a program making calls to a subroutine named Printer.
Example 4-12 Example of calling subroutine Printer
   ! Main program
     . . .
   input N | call Printer(N)
     . . .
   ! more statements
     . . .
   input X | call Printer(X)
     . . .
   end     ! end of main program
   ! Subroutine
   sub Printer(Passed_value)
      print "This is the latest value input", Passed_value
   subend
 
The program calls the subroutine twice to print the two values, N and X, together with the message. As explained later, the subroutine thinks that it is printing its variable (Passed_value), but actually it accesses the variable passed to it when it is called—in this case, the first time N, and the second time X. The next example show that, if the subroutine changes the value of a variable passed to it, then that variable retains its new value after the exit from the subroutine.
   A = 6 | print A            ! prints  6
   call Sub_X(A) | print A    ! prints  100
   end
 
   sub Sub_X(New_Value)
      New_Value = 100
   subend
A subroutine can also be called from another subroutine or from a user‑definable function: this is referred to as nesting subroutines and is explained later. Subroutines (and user‑definable functions), if any, must be located in the workspace below the main program (that is, after the end statement, as shown in the above example).
Most of the statements which can appear in a main program can also appear in a subroutine. The statements in Table 4-8 control the operation of the subroutines; they can be located only in a subroutine.
 
Table 4-8 Statements found only in a subroutine
Statement
Description
sub
The first statement in the subroutine; it establishes the name of the subroutine (its <id>) and the names (<id>s) of its formal parameters.
global
Lists the main program parameters which can be accessed by the subroutine without their being passed to the subroutine. Global parameters can include variables and @<name>'s. If used, this statement must immediately follow the sub statement.
subexit
(Optional) Causes the exit from the subroutine; can be located anywhere in the subroutine.
subend
The last statement in the subroutine; it marks the physical end of the subroutine in the workspace (if executed, it acts like subexit).
