Parameters of the Subroutine
In this context, the term parameters refers to the data on which the subroutine operates. The data can consist of variables, @<name>'s, expressions and constants. Subroutines can operate on three types of parameters: local, global, and passed. (The subroutine itself can contain a fourth type of parameter, referred to as formal parameters; these relate to and are described with passed parameters.) Depending on how a subroutine is structured, the subroutine can use any or all of the three types of parameters.
Local parameters exist only within a subroutine; they cease to exist after the exit from that subroutine. Global parameters are parameters which exist in the main program, but which are declared as global in the subroutine so that the subroutine can operate on them directly. Passed parameters are also parameters which exist outside the subroutine. When the subroutine is called, the names of these parameters are listed in the call statement that calls the subroutine (only subroutines which list formal parameters can have parameters passed to them).
Global and passed parameters are very different: since the global parameters are named in the subroutine, the same parameters are used each time the subroutine is called. The passed parameters, on the other hand, are named by the statement which calls the subroutine; so a different set of parameters could be named each time the subroutine is called.
