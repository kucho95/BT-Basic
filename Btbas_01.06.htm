Numeric Expressions
A numeric expression is any valid sequence of characters that has, or can have, a numerical value.
Example 2-3 Example of numeric expressions
36                 ! Integer numeric constant
‑14.34             ! Floating numeric constant
3.68e‑9            ! Floating numeric constant with exponent
52 + 13            ! Two integer constants with an operator
A                  ! A variable. A = zero if no other value assigned
R(30)+Q            ! Numeric variable array with an operator and another variable
sin(2*pi)          ! A function (sin) with two numeric constants and an operator.
                   ! Note that "pi" is a built-in constant in BT-Basic
(1‑cos(Lat))/2     ! Constants, function (cos), operators, and variable (Lat)
(F(8,9)‑32)*5/9    ! Two-dimension array variable (F), operators, and constants
shift( bti("001110"), ‑3)    ! Two functions (shift, bti), string and
                             ! numeric constamts
Test(6,7) > 85               ! Two-dimension array variable (Test), three numeric
                             ! constants and a relational operator (>).
                             ! Expression is 1 if true, 0 if false.
len(A$)        ! Function returns the number of characters in string variable A$.
