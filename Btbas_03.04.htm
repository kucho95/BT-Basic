Program Environments
Branches can be made to any point in a main program or within a subprogram (see Subroutines). However, it is not possible to branch between different environments; that is, between the main program and a subprogram, or between subprograms. Communication between environments is usually by calls to subroutines and by running user‑definable functions. However, the recover keyword in the on break and on error statements does allow some limited branching between environments (see Break and Error Trapping).
Within the workspace, the main program is first; any subprograms (that is, subroutines and user‑definable functions) must be located after the main program's end statement. When the program is started, the main program runs first and is therefore in the highest environment. Each subprogram has its own environment, which is always lower than the main environment. If each subprogram terminates before the next is called, then they are all executed at the same environment level. If subprograms are nested (one subprogram calls another subprogram), then each successively called subprogram is in a lower environment than the one that called it.
