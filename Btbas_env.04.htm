The Command Area
The next line is the command line, which is used to execute statements, run programs, and so on. For example, here is how you can use the print statement to print some text to the screen.
1 If the yellow cursor is not on the command line, either press the command/edit softkey, F1 or use the mouse to click on the command line.
2 On the command line, type:
  print "This is a number ‑‑ ";601
3 Press Return or the execute softkey, F4.
The text message (the part in quotes) and the number are printed in the work area of the BT-Basic window. The text output should look like this:
   This is a number -- 601
The maximum length of the command line is 2048 characters. If the command line is too long to fit in a single row on the screen, only 80 characters of it are visible at a time.
