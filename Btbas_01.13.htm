Arrays
An array consists of some number of elements arranged in a matrix. Each element in the matrix is like, and behaves like, a simple variable. In numeric arrays, each element can contain a number; in string arrays, each element can contain a string. Numbers and strings cannot be mixed in an array.
The elements in an array are arranged in a matrix. The matrix can have up to six dimensions:
• A single‑dimensioned matrix is referred to as a scalar array; that is, the elements are arranged in a single row (or column): so a scalar array with 75 elements can be either a 1 by 75 array or a 75 by 1 array.
• An array with more than one dimension is described as a multi-dimensioned array. If it has two dimensions, the elements can be thought of as being arranged in a rectangle, with rows and columns: thus a 30 by 50 array has 30 rows, each of 50 elements, or, 50 columns, each of 30 elements; it contains 1500 elements. A three-dimensional array is analogous to a box, with length, breadth and height; thus a 5 by 10 by 20 array has 1000 elements.
