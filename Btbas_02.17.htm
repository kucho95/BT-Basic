Miscellaneous String Functions
All of these functions return strings. With the exception of errm$ and errmlong$, these functions have no arguments; for example:
time$  ! returns: Fri Jun 18, 2004   2:45 pm
 
Table 3-13 Miscellaneous string functions 
Function
Description
buffer$
Returns a string containing the last record entered by an enter, input, enter using, or input using statement (see Input/Output).
crt$
Returns a one‑character string containing the number of the user's workstation.
datetime$
Returns a string containing the system date and time in yymmddhhmmss format.
errm$
Returns a string containing the error message associated with an error number (see Branching, Looping, and Subprograms).
errmlong$
Returns a string containing the long error message associated with an error number (see Branching, Looping, and Subprograms).
lli$
Returns a string containing the current datalogging level.
msi$
Pathname from the root of the current working directory.
revision$
Returns a string containing the revision number of the system software.
th$
Returns a string containing 1 if the testhead is available, and 0 if it is not.
time$
Returns a twenty‑six‑character string containing the system date and time.
