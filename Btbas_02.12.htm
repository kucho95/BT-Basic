Bit Manipulation Functions
The functions in this group perform bit‑operations on the binary representation of decimal numbers. In all cases the arguments and the results of the functions are decimal integers. Values assume twos‑complement representation using either 16 bits or 32 bits—selectable by the option bit statement.
The bit‑manipulation functions can operate on decimal integers in the following range:
16-bit operation: ‑2^15 <= integer <= 2^15‑1
                  (2^15 = 32768)
32-bit operation: -2^31 <= integer <= 2^31-1
                  (2^31 = 2147483648)
The functions in this group are shown in Table 3-9.
 
Table 3-9 Bit manipulation functions

Following are some examples illustrating the concept of bit‑manipulation using the binand and bineor functions. The examples show 16-bit operation but the same principles apply to 32-bit operation. (For complete details on the functions, refer to Syntax Reference.)
Example 1
This example uses the binand function; in this case both values in the argument are positive. The function converts both numbers to binary, AND's the bits, and converts the binary result back to decimal. The function then returns that decimal number as the result of the operation.
   binand (22, 15)   ! returns 6
The function calculates the result as follows:
   22(dec) = 0000000000010110(binary)
   15(dec) = 0000000000001111(binary)
   ----------------------------------
    6(dec) = 0000000000000110(binary)
Example 2
The bineor function performs an exclusive‑OR operation on each pair of bits; however, in this example one of the values is negative, so more steps are necessary than in the first example. In twos‑complement representation a positive decimal value is represented by its binary equivalent; a negative decimal value is represented by the twos‑complement of the binary equivalent of the (absolute) value. With 16‑bit operation, if a binary number has sixteen bits and a 1 as its most significant bit, then it must represent a negative, decimal value. If the binary number has less than sixteen bits (i.e., leading zeros are assumed), or if the most significant bit is a zero, then that number must represent a positive, decimal value.
   bineor (‑11, 19)  ! returns ‑26
1 Calculate the 2’s complement of the absolute value of ‑11:
    11(dec) = 0000000000001011 (binary)
              1111111111110100 1's complement
                            +1
             -----------------
   ‑11(dec) = 1111111111110101 2's complement
2 Exclusive‑OR the bits:
       -11(dec) = 1111111111110101
         9(dec) = 0000000000010011
                 -----------------
    exclusive‑OR  1111111111100110 — result
3 Because the 16th (most significant) bit is a 1, the result must represent a negative decimal value, so this step converts the (2's) result to binary:
     1111111111100110
                   ‑1
    -----------------
     1111111111100101
 
    Do a 1's complement:
    0000000000011010 (binary) = 26 (dec)
4 Because a conversion had to be made in Step 3, a negative, decimal number is returned as the value of the function:
    returns ‑26
