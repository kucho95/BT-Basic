Uncounted Loop (loop)
Uncounted loops enable the programmer to execute a set of statements a variable number of times. They also enable conventional looping constructions, similar to do‑while and repeat‑until, to be formed. Loops can appear anywhere in the main program, and in subprograms.
The statements in Table 4-4 are used to control the loop.
 
Table 4-4 Loop control statements
Statement
Description
loop
marks the start of the loop
exit if
determines when to exit the loop
end loop
marks the end of the loop and returns execution back to the beginning of the loop
When the loop statement is encountered, the statements between loop and end loop are executed repeatedly until the exit if statement causes the exit; execution of the program then continues with the statement following the end loop.
Here is an example of a loop:
   X = 0
   loop
      input N  |  X = X + N
      exit if X >= 1000
      print N, X
   end loop
This loop repetitively sums the input values into X and prints them until X is either greater than or equal to 1000, at which time the loop exits without printing.
As can be seen from the example loop, the exit if statement conditionally causes the exit from the loop; it can be placed anywhere in the loop. Also, there can be any number of exit if statements in the loop.
The exit if is followed by an expression which operates like the expression in the simple if statement (see Evaluating the Expression). When exit if is encountered, its expression is logically evaluated to determine if that expression is true (nonzero) or false (zero). If true, the program exits the loop; if false, the program continues with the next statement in the loop. Each time the end loop statement is encountered, the program returns to the first statement in the loop (that is, the statement immediately following the loop statement) and restarts execution of the loop. When the exit is made, execution resumes with the statement following end loop.
Loops can be nested (contained within each other) to any depth. In nested loops, the exit if and end loop statements apply to the most recent level of nesting. Each time a new loop is encountered, a new, deeper nesting level is established. Each time an exit occurs (the exit if expression is true), the current level is canceled and the program returns to the next higher level.
Before a new program run actually starts, the loop and end loop statements for each loop are examined to ensure that they are matched; if they are not, an error occurs. So when you write loops, ensure that they do not cross over each other, as shown in Table 4-5.
 
Table 4-5 Looping examples
Correct
Correct
Incorrect

   ..
end loop ! end of A
loop     ! loop B
   ..
end loop ! end of loop B  
loop        ! loop A
   ..

      ..

   ..

loop
   ..
   goto Out
end loop
 
Out: end loop  
Example (c) is wrong if the intention is to branch to Out and use that end loop to return to the beginning of the loop. If the intention is to use the goto to cancel the first loop, the example (c) is still wrong because there is no loop statement to match the second end loop.
The following rules also apply:
• A loop can be on one line, or on more than one line; the loop statement need not be the first statement on a line.
• A goto statement which branches execution out of the loop, cancels the loop (that is, as if the exit if had caused the exit). In nested loops, an exit if can exit only one level at a time; a single goto can be used to exit (and cancel) many levels at once.
Example 4-10 contains more examples of loops.
Example 4-10 More loop examples
   ! load 1's into a ten element array
   dim Total(1:10)
   I = 0
   loop
      I = I + 1
      Total(I) = 1
      exit if I >= 10      ! equivalent to a "repeat‑until"
   end loop
   ! find the first non‑space character in a string
   P = 1
   loop | exit if Line$[P;1] <> " "
                           ! equivalent to a "do‑while"
      P = P + 1
   end loop | print P
   ! an "exit‑when"
   dim Name$[20]
   loop
      input Name$, Age
      exit if Age < 0                  ! "exit‑when"
      print Name$, Age
   end loop
   ! nested loops; load 1's into a 5‑by‑10 array
   dim Tests(1:5, 1:10)
   I = 0
   loop
      I = I + 1 | J = 0
      loop
         J = J + 1 | Tests(I,J) = 1    ! the J‑loop repeats 10
         exit if J = 10                !   times for every pass
      end loop                         !   through the I‑loop
      exit if I = 5
   end loop
