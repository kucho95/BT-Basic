String Manipulation Functions
Functions in this group are described in Table 3-12.
 
Table 3-12 String manipulation functions 
Function
Description
len
returns current length of string
pos
returns position in parent string of substring
lwc$
converts any upper-case characters to lower-case
upc$
converts any lower‑case characters to upper‑case
trim$
strips a string of its leading and trailing spaces
triml$
(trim left) strips a string of its leading spaces
trimr$
(trim right) strips a string of its trailing spaces
The arguments of the functions described in Table 3-12 are strings. All of them return strings except len and pos, which return numeric values:
  len("Test Station")        ! returns 11
  pos("Test Station","Stat") ! returns  6
The remaining functions are used to modify strings as shown in Example 3-1.
Example 3-1 Examples of functions that modify strings
  lwc$ ("  Test Station ")       ! returns "  test station "
  upc$ ("  Test Station ")       ! returns "  TEST STATION "
  trim$ ("  Test station ")      ! returns "Test station"
  triml$ ("  Test station ")     ! returns "Test station "
  trimr$ ("  Test station ")     ! returns "  Test station"
 
The functions in Example 3-1 used string constants for clarity, but string variables could be used as well. You can also combine string functions to make program statements more compact. In Example 3-2, string functions are combined and use a string variable.
Example 3-2 Examples of string functions that use a string variable
  A_string$ = "  My program    "
  len (A_string$)                       ! returns 16
  len (trimr$ (A_string$))              ! returns 12
  pos (trim$ (upc$ (A_string$)), "P")   ! returns 4
 
Notice that none of these statements affect the original string:
  print A_string$ ; len (A_string$)
  ! prints     My program      16
