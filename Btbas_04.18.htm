Inputting Data in Imaged Format
When using imaged format for input, the input data appears as a string of characters and the image specifications are used to make sense of them. In the example in Example 5-12 the image specifications format input from a file. The input consists of text to be stored in a string variable, and three numbers to be stored in numeric variables. The image specifications are arranged to split the input characters into logical groups: the text, and three numbers. If a data item does not match its image specification—e.g., text is input for a numeric specification—then an error occurs. (Obviously, the test developer has to know beforehand what the input data looks like!)
Example 5-12 Example of the image specifications format being input
     ! The file contains (with no leading blanks):
     ! Test 1:+1.5231.5251524E‑03
     !
   assign @File to "my_data_file"
   T1: image 7a, sd.ddd, d.3d, d.dde
     ! Note: d.dde is the same as dddde for the purpose of
     ! inputting
   enter @File using T1; A$, P,R,T
     !
   print A$, P; R; T
     !
     ! prints:  Test 1:              1.523  1.525  1.524
     !          <‑‑‑‑‑20 spaces‑‑‑‑><‑‑7‑‑><‑‑7‑‑><‑6‑‑>
     !    (Note that last print field is not packed, so it ends
     !     at column #40)
 
During the input, the image specifications interpret the data, so any commas (delimiters) are ignored for numeric data. If the input is to a string, the commas are entered into the string as characters. When the input is completed—that is, when all of the listed variables have been filled—a final (EOI) End Of Input (EOR, EOF, etc.) is required. If data continues to be sent before the final EOI, then that data will be ignored. If an EOI is received before all of the variables have been filled, an error occurs.
Data can be input from only one record at a time, unless the image statement specifies otherwise. The <line spec> (/) is used to cross over a record boundary, as shown in Example 5-13.
Example 5-13 Example of crossing of a record boundary
     ! File "Headings" contains the following records:
     !   "Test Data is in this record"(EOR)
     !   "Digital"(EOR)
     !
   Read: image 9a,/,7a
   assign @Title to "Headings"
   enter @Title using Read; T$, D$
     !
   print D$; tab(9), T$
     !
     ! prints   Digital Test Data
