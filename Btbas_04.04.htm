Simple I/O Operations
Simple I/O operations are used for general purpose input (input) and output (print) at the workstation, and for printing test data (report). For example:
   print "3 plus 4 =", 3+4
prints the following on the screen:
   3 plus 4 = 7
And:
   input "Type your name and age",A$,Age
displays the message Type your name and age on the screen, then waits for you to type the responses. In this example the input responses from the user at the keyboard are stored in string variable A$ and in numeric variable Age, which are the two variables specified in the input statement's variable list.
   report "The measured value is"; R6; "ohms"
prints (with an assumed value in variable R6):
   The measured value is 962 ohms
on the report printer.
Notice that the print and report statements do the same thing except that they print on different devices. print writes to the default printer, and report writes to the report printer. It is convenient to be able to write to two different devices without having to designate a new default each time you want to switch devices. For example, during a board test you could print instructions on the screen for the operator, and report on the strip printer the test failure information for the repair department.
