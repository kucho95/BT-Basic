String Expressions
A string expression is any sequence of characters which represents a valid string. This includes string constants (strings in quotation marks), string variables, substrings (described at the end of this chapter), any string functions which return a string, and concatenated strings.
Example 2-4 shows examples of string expressions.
Example 2-4 Examples of string expressions
  "This is a string expression."
  A$                       ! A$ contains the null string ("") unless a string
                           ! was assigned
  B$ = "Test"
  print B$ & " Records"    ! The "&" operator concatenates the two strings.
                           !    The statement prints: Test Records
  ith$(16383)              ! "integer-to-hexadecimal string" function returns a
                           !  4‑character string (3FFF) representing the
                           !  hexadecimal value of the argument.
